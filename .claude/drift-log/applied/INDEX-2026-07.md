- **2026-07-13 — [mcp-write-tool-body-typing](2026-07-13-mcp-write-tool-body-typing.md)**
  (`applied`, MEDIUM). When three parallel agents added ~136 MCP write tools, they split on how
  a write tool declares its request body: wiki/forms typed it as the resource's pydantic model,
  the tracker agent used raw `body: dict` (~25 tools), degrading each tool's input schema to a
  bare `object`. Nothing codified which to use. Added a **"Typed request body — never `dict`"**
  subsection to `docs/conventions/resources.md` §4 so new endpoints use the typed model (the same
  one the CLI builds); `Base64Bytes` is the only exception. The fail-closed enforcement check and
  the backfill of the ~25 existing `body: dict` tools are deferred together (would fail on the
  current violations) — tracked in `STATE.md` and the improvement roadmap. *Codified in:*
  `docs/conventions/resources.md` §4.
