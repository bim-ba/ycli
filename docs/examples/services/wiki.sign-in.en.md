| You need | Set |
|---|---|
| a token | `YANDEX_ID_OAUTH_TOKEN`: a Yandex ID OAuth token; `ycli auth login` gets one. A ready IAM token in `YANDEX_CLOUD_IAM_TOKEN` works in its place |
| an organization | `YANDEX_ID_ORGANIZATION_ID` (Yandex 360, sent as `X-Org-Id`) or `YANDEX_CLOUD_ORGANIZATION_ID` (Yandex Cloud, sent as `X-Cloud-Org-Id`) |

How to get each of them: [Authenticate](../how-to/authenticate.md).
