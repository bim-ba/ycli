| You need | Set |
|---|---|
| a token | `YANDEX_CLOUD_IAM_TOKEN`: an IAM token, or a service account's key in `YANDEX_CLOUD_SERVICE_ACCOUNT_KEY_FILE`. A Yandex ID OAuth token is not taken |
| an organization | `YANDEX_CLOUD_ORGANIZATION_ID` (Yandex Cloud, sent as `x-dl-org-id`) |

How to get each of them: [Authenticate](../how-to/authenticate.md).
