Есть несколько способов добавить изображение на вики-страницу:

-   Вставить из буфера обмена.
-   Вставить по ссылке: например, добавить адрес рисунка, который загружен на другую вики-страницу.
-   Загрузить файл с компьютера.

# Просмотреть изображения

Чтобы просмотреть все изображения на странице в режиме галереи, нажмите на одно из них.

-   Переключайтесь между изображениями с помощью стрелок на клавиатуре или нажимайте миниатюры внизу.

-   Чтобы приблизить изображение, нажмите на его. Перетаскивайте увеличенное изображение мышью, чтобы нужные детали оказались в области просмотра.
    Чтобы вернуть изображение к прежнему масштабу, снова нажмите на него.

-   Чтобы развернуть изображение на весь экран, нажмите значок **Открыть полноэкранный режим** справа вверху или сочетание клавиш **Shift** + **F**.

-   Если нужно поделиться изображением, справа вверху нажмите **Скопировать ссылку**.

-   Если нужно сохранить изображение, справа вверху нажмите **Скачать**. В зависимости от настроек вашего браузера, изображение будет загружено на компьютер или откроется в новой вкладке.

# Вставить изображение из буфера обмена

Изображение из буфера обмена можно добавить как в визуальном режиме редактора, так и в режиме разметки:

1.  Скопируйте изображение в буфер обмена:

    -   скопируйте рисунок из графического редактора или сделайте снимок экрана;
    -   скопируйте рисунок с веб-страницы;
    -   скопируйте файл с изображением из файлового менеджера на вашем компьютере.
2.  Вставьте в текст изображение из буфера обмена.

Изображение будет автоматически загружено на Вики и появится в списке ресурсов страницы: см. [Управлять загруженными файлами](https://yandex.ru/support/wiki/ru/wysiwyg/file#resources).

# Загрузить изображение на страницу

1.  В режиме визуального редактора или в режиме разметки на панели инструментов нажмите **Image**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Выберите вкладку **Загрузить с устройства** и выберите один или несколько файлов. Рисунок будет добавлен в текст.

3.  Чтобы изменить параметры изображения:

    -   В режиме визуального редактора наведите указатель на изображение и нажмите → **Редактировать**.

    -   В режиме разметки вы можете отредактировать атрибуты изображения, например:

        ```
        ![<Альтернативный_текст>](https://yandex.ru/support/wiki/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E%20%22%3C%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%3E%22%20=%3C%D0%A8%D0%B8%D1%80%D0%B8%D0%BD%D0%B0%3Ex%3C%D0%92%D1%8B%D1%81%D0%BE%D1%82%D0%B0%3E)
        ```

Изображение появится в списке ресурсов страницы: см. [Управлять загруженными файлами](https://yandex.ru/support/wiki/ru/wysiwyg/file#resources).

# Добавить изображение по ссылке

Визуальный редактор

Разметка Markdown

1.  На панели инструментов нажмите **Image**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Выберите вкладку **Добавить по ссылке**:

3.  В поле **Ссылка** вставьте адрес изображения или ссылку на один из прикрепленных файлов.

4.  Добавьте подпись к рисунку. Подпись будет отображаться при наведении указателя на изображение.

5.  Введите альтернативный текст. Текст будет отображаться, если не удастся загрузить изображение.

6.  Укажите размер изображения в пикселях. Изображение масштабируется пропорционально, поэтому значение высоты можно задать приблизительно.

7.  Нажмите **Сохранить**.

8.  Чтобы изменить параметры рисунка, в режиме редактирования наведите на него указатель и нажмите → **Редактировать**.

Чтобы разместить изображение в тексте, добавьте код в формате:

```
![<Альтернативный_текст>](https://yandex.ru/support/wiki/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E%20%22%3C%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%3E%22%20=%3C%D0%A8%D0%B8%D1%80%D0%B8%D0%BD%D0%B0%3Ex%3C%D0%92%D1%8B%D1%81%D0%BE%D1%82%D0%B0%3E)
```

Параметры разметки:

-   `<Альтернативный_текст>` будет отображаться, если не удастся загрузить изображение.
-   `<Адрес_изображения>`: URL-адрес рисунка в интернете или ссылку на один из прикрепленных файлов.
-   `<Подпись>` будет отображаться при наведении указателя на изображение.
-   `<Ширина>` и `<Высота>` в пикселях. Изображение масштабируется пропорционально, поэтому значение высоты можно задать приблизительно.

Если добавить изображение по ссылке с другой страницы, оно будет недоступно для пользователей, у которых нет доступа к странице – источнику изображения. [Как настроить доступ к странице](https://yandex.ru/support/wiki/ru/page-management/access-type)

# Вставить ссылку на скачивание изображения

Чтобы при нажатии на изображение его можно было скачать, используйте разметку:

```
[<Текст_ссылки>](https://yandex.ru/support/wiki/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E)
```

Пример

```
[Логотип Яндекса](https://img.yandex.net/i/logo95x37x8.png)
```

# Сделать изображение ссылкой

Вы можете сделать изображение ссылкой, чтобы при нажатии на изображение открывалась страница или файл. Для этого в элемент разметки ссылки вместо текста вставьте изображение:

```
[![<Альтернативный_текст>](https://yandex.ru/support/wiki/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E)](https://yandex.ru/support/wiki/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8%3E)
```

Пример

```
[![Логотип Яндекса](https://img.yandex.net/i/logo95x37x8.png)](https://ya.ru)
```

Результат:

[![Логотип Яндекса](https://yandex.ru/support/wiki/docs-assets/support-wiki/rev/r19559855/ru/_assets/logo95x37x8.png)](https://ya.ru/)
