На страницу Вики можно добавить цитату, примечание, кат, блок с заданным оформлением или секцию из нескольких ячеек.

В режиме визуального редактора блоки и другие элементы (например, абзацы и заголовки) можно перемещать и вкладывать друг в друга. Для этого наведите курсор на блок и потяните за значок слева.

Внутри элементов блочного форматирования можно использовать другие элементы разметки.

Чтобы добавить на страницу блок, выберите один или несколько абзацев и используйте кнопки на панели инструментов или сочетания клавиш:

| Блок | Кнопка на панели | Сочетание клавиш Windows | Сочетание клавиш macOS |
| --- | --- | --- | --- |
| Примечание |  | **Ctrl** + **Shift** + **8** | **⌘** + **⌥** + **8** |
| Блок кода |  | **Ctrl** + **Alt** + **E** | **⌘** + **⌥** + **E** |
| Кат |  | **Ctrl** + **Shift** + **7** | **⌘** + **⌥** + **7** |

# Примечание

Визуальный редактор

Разметка Markdown

1.  Чтобы добавить примечание, на панели инструментов нажмите кнопку  **Примечание**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  В меню под блоком выберите тип примечания:

    -    **Примечание**
    -    **Совет**
    -    **Важно**
    -    **Внимание**
3.  Введите заголовок и текст примечания. Используйте другие элементы форматирования текста.

4.  Чтобы удалить блок, в меню под блоком нажмите кнопку .

Чтобы разместить блок «Примечание», добавьте в текст код в формате:

```
{% note <тип_примечания> "Заголовок" %}

Добавьте содержание для примечания

{% endnote %}
```

-   Укажите тип примечания:

    -   `{% note info "" %}` — Примечание.

    -   `{% note warning "" %}` — Важно.

    -   `{% note alert "" %}`— Внимание.

    -   `{% note tip "" %}`— Совет.

-   Чтобы изменить текст заголовка по умолчанию, после указанного типа добавьте свой заголовок в кавычках `""`.

# Блок кода

Визуальный редактор

Разметка Markdown

-   Чтобы добавить блок кода, на панели инструментов нажмите кнопку  **Блок кода**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

-   Чтобы включить подсветку синтаксиса, нажмите на блок кода и в меню настройки блока выберите из выпадающего списка язык, на котором написан код.

-   Чтобы включить перенос длинных строк вместо горизонтальной прокрутки, нажмите на блок кода и в меню настройки блока нажмите .

    Перенос также можно включить в режиме просмотра. Для этого нажмите в правом верхнем углу блока кода.

-   Чтобы включить нумерацию строк в блоке кода, нажмите на блок кода и в меню настройки блока нажмите .

-   Чтобы скопировать блок кода, нажмите на блок кода и в меню настройки блока или в режиме просмотра нажмите .

    Скопировать блок кода также можно в режиме просмотра. Для этого нажмите в правом верхнем углу блока кода.

-   Чтобы удалить блок кода, нажмите на блок кода и в меню настройки блока нажмите .

**Пример:**

````
```sql
price= '2000'
size= '24'
color= 'primary'
variant= 'detailed'
```
````

**Результат:**

```sql
price= '2000'
size= '24'
color= 'primary'
variant= 'detailed'
```

-   Чтобы оформить фрагмент кода как отдельный блок, отделите его символами ` ``` ` . Для подсветки синтаксиса укажите в начальной строке блока язык, на котором написан код.

-   Чтобы включить нумерацию строк в блоке кода, укажите в начальной строке блока параметр `showLineNumbers`.

-   Внутри блока исходного кода все символы разметки автоматически экранируются. Чтобы отобразить символ `` ` `` в обычном тексте, используйте [экранирование](https://yandex.ru/support/wiki/ru/wysiwyg/block-format#shielding).

# Кат

Визуальный редактор

Разметка Markdown

1.  Чтобы добавить кат, на панели инструментов нажмите кнопку  **Кат**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Введите заголовок и текст ката. Используйте другие элементы форматирования текста.

3.  Чтобы свернуть или развернуть кат, нажмите значок .

Чтобы разместить блок «Кат»:

1.  Перед блоком оставьте пустую строку.

2.  Добавьте разметку в формате:

    ```
    {% cut "Заголовок ката" %}

    Контент, который отобразится по нажатию.

    {% endcut %}
    ```

# Вкладки

Визуальный редактор

Разметка Markdown

1.  Чтобы добавить на страницу блок с вкладками, на панели инструментов нажмите кнопку  **Табы**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Чтобы добавить новую вкладку, нажмите в списке вкладок.

3.  Чтобы удалить вкладку, нажмите справа от ее заголовка.

4.  Чтобы переключаться между вкладками, нажмите на ее заголовок.

5.  Наполните вкладки контентом, используя другие элементы форматирования текста.

Чтобы разместить блок «Табы», добавьте в текст код в формате:

```
{% list tabs %}

- Заголовок первой вкладки

    Текст первой вкладки

- Заголовок второй вкладки

    Текст второй вкладки

{% endlist %}
```

Перед текстом вкладки сделайте отступ 2–4 пробела или нажмите клавишу **Tab**.

# Цитата

Визуальный редактор

Разметка Markdown

1.  Чтобы добавить цитату, на панели инструментов нажмите кнопку  **Цитата**.

    Вы также можете добавлять элементы форматирования [с помощью клавиатуры](https://yandex.ru/support/wiki/ru/edit-page#keyboard) или использовать меню быстрого доступа: введите символ `/` и выберите элемент из списка.

2.  Внутри цитаты используйте другие элементы форматирования текста.

3.  Отделите цитату от остального текста пустой строкой.

```
> Для отображения цитаты используйте специальный символ.
>>Чтобы оформить вложенную цитату, в начале абзаца вставьте два таких символа.
```

-   Для отображения цитаты используйте символ `>`.

-   Чтобы оформить вложенную цитату, в начале абзаца вставьте символы `>>`.

# Блок оформления

Визуальный редактор

Разметка Markdown

1.  Чтобы добавить блок с оформлением, на панели инструментов нажмите кнопку  **Блок оформления**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Чтобы настроить правила блока оформления, в его правом верхнем углу нажмите :

    -   **Выравнивание** — Расположение блока относительно остального содержимого страницы:

    -   **None** — Без выравнивания. На одной горизонтали с блоком не смогут расположиться другие элементы, а сам блок будет находиться у левого края страницы.

    -   **Left** — Выравнивание по левому краю.

    -   **Center** — Выравнивание по центру.

    -   **Right** — Выравнивание по правому краю.

    -   **Ширина** — Ширина блока в пикселях (px).

    -   **Отступы** — Внутренний отступ между рамкой и содержимым блока.

    -   **Тип рамки** — Внешний вид рамки:

    -   **None** — Нет рамки.

    -   **Solid** — Сплошная линия.

    -   **Dashed** — Пунктирная линия.

    -   **Размер рамки** — Толщина рамки.

    -   **Цвет рамки** — Цвет рамки:

    -   **Info** — Синий.

    -   **Tip** — Зеленый.

    -   **Warning** — Оранжевый.

    -   **Alert** — Красный.

Чтобы разместить блок оформления, добавьте в текст код в формате:

```
{% block align=center width=1000 padding=xs border=solid borderSize=m borderColor=warning %}

Текст внутри блока

{% endblock %}
```

Параметры блока:

-   `align` — Расположение блока относительно остального содержимого страницы. Можно не указывать.

    Доступные значения:

    -   `left` — По левому краю.
    -   `center` — По центру.
    -   `right` — По правому краю.
-   `width` — Ширина блока в пикселях (px). Можно не указывать.

-   `padding` — Внутренний отступ между рамкой и содержимым блока. Можно не указывать.

    Доступные значения:

    -   `xs` — 4 px.
    -   `s` — 8 px.
    -   `m` — 12 px.
    -   `l` — 16 px.
    -   `xl` — 20 px.
-   `border` — Внешний вид рамки. Можно не указывать.

    Доступные значения:

    -   `solid` — Сплошная линия.
    -   `dashed` — Пунктирная линия.
-   `borderSize` — Толщина рамки.

    Доступные значения:

    -   `xs` — 1 px.
    -   `s` — 2 px.
    -   `m` — 4 px.
    -   `l` — 6 px.
-   `borderColor` — Цвет рамки. Если не указывать, рамка будет черной.

    Доступные значения:

    -   `info` — Синий.
    -   `tip` — Зеленый.
    -   `warning` — Оранжевый.
    -   `alert` — Красный.

# Секция

Визуальный редактор

Разметка Markdown

1.  Чтобы добавить секцию и разделить часть страницы на несколько ячеек, на панели инструментов нажмите кнопку  **Секция**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Чтобы добавить новую ячейку, нажмите на пространство со значком между существующими ячейками. Внутри ячейки можно использовать другие элементы разметки нового редактора.

3.  Чтобы изменить ширину ячейки, в ее правом верхнем углу нажмите и измените значение поля **Ширина**.

4.  Чтобы удалить ячейку, в ее правом верхнем углу нажмите →  **Удалить ячейку**.

5.  Чтобы изменить режим отображения для всех ячеек сразу, нажмите на любую из ячеек. Появится меню, в котором вы сможете:

    -   Установить количество и размер ячеек по одному из четырех шаблонов:

        -    **Две ячейки**
        -    **Большая справа**
        -    **Большая слева**
        -    **Три ячейки**
    -   Выровнять блок с ячейками относительно остального содержимого страницы:

    -    **Вся секция по левому краю**

    -    **Вся секция по центру**

    -    **Вся секция по правому краю**

    -   Удалить секцию нажатием на кнопку .

Чтобы разместить секцию, добавьте в текст код в формате:

```
{% layout gap=l cols=auto justify=start %}

{% block col=3 %}

Содержимое первой ячейки

{% endblock %}

{% block col=7 %}

Содержимое второй ячейки

{% endblock %}

{% block col=1 %}

Содержимое третьей ячейки

{% endblock %}

{% endlayout %}
```

Параметры блока:

-   По умолчанию установлено растягивание секции на всю ширину страницы. Чтобы изменить выравнивание блока, для `layout` впишите параметры `cols=auto` и `justify=` со значением:

    -   `start` — По левому краю.
    -   `center` — По центру.
    -   `end` — По правому краю.
-   Чтобы добавить ячейку, между главными тегами вставьте открывающий `{% block %}` и закрывающий `{% endblock %}` теги ячейки.

-   Для `block` задайте ширину ячейки `col=` со значением от 1 до 12.

-   Между тегами и содержимым ячейки должен быть отступ не менее одной строки.
