Чтобы упростить навигацию по страницам и разделам Вики, можно добавить на страницу содержание (оглавление) и структуру раздела — список подстраниц.

Блок **Содержание страницы** отображает список [заголовков](https://yandex.ru/support/wiki/ru/wysiwyg/text-format#headers) на странице.

Визуальный редактор

Разметка Markdown

Чтобы добавить содержание текущей или любой другой страницы Вики:

1.  На панели инструментов нажмите **Другие действия** и выберите **Содержание страницы**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  В окне настройки блока укажите параметры:

    -   Укажите [адрес страницы](https://yandex.ru/support/wiki/ru/structure#relative), для которой хотите сформировать содержание в формате `/<раздел>/<подраздел>/<имя_страницы>`. Например: `/users/username/my-page/`.

        Если адрес не указан, будет добавлено содержание текущей страницы.

    -   В полях **От** и **До** укажите максимальный и минимальный уровень заголовков, которые будут включены в содержание.

        Если оставить значение `—`, в содержание будут включены заголовки от 1 до 6 уровня.

3.  Нажмите **Сохранить**.

Чтобы изменить уже созданное содержание страницы, в режиме редактирования в правом верхнем углу блока нажмите .

Чтобы разместить на странице оглавление, используйте разметку:

```
{% toc page="/<раздел>/<подраздел>/<имя_страницы>" from="h1" to="h6" %}
```

Например: `{% toc page="/users/username/my-page" from="h1" to="h6" %}`.

Параметры разметки:

-   `page` — адрес страницы, для которой нужно сформировать содержание, [относительно главной страницы](https://yandex.ru/support/wiki/ru/structure#relative).

-   `from`, `to` — уровень заголовков, которые будут включены в содержание, от самого высокого до самого низкого. Допустимые значения: от `h1` до `h6`.

# Структура раздела

Блок **Структура раздела** отображает древовидный список страниц любого раздела.

Новый редактор

Разметка Markdown

Чтобы вставить список страниц текущего раздела:

1.  В режиме редактирования на панели инструментов нажмите **Другие действия** и выберите **Структура раздела**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  В окне настройки блока укажите параметры:

    -   **Адрес страницы**, для которой нужно построить структуру вложенных страниц, [относительно главной страницы](https://yandex.ru/support/wiki/ru/structure#relative).
        Если адрес не указан, структура будет построена для текущей страницы.
    -   **Глубина** — количество уровней вложенности раздела, которые будут отображаться в структуре, включая текущую страницу.
    -   **Сортировать по**: названию, дате создания, дате изменения.
    -   **Сортировка**: по возрастанию или по убыванию.
3.  Нажмите **Сохранить**.

Блок со структурой раздела отобразится на странице. Чтобы отредактировать или удалить структуру раздела, в режиме редактирования в правом верхнем углу блока нажмите .

Чтобы добавить на страницу структуру заданного раздела, используйте разметку:

```
{% tree page="/<раздел>/<подраздел>" depth="5" sort="asc" sort_by="title" %}
```

Например: `{% tree page="/users/username depth="5" sort="asc" sort_by="title" %}`.

Параметры:

-   `page` — адрес страницы, для которой нужно построить структуру вложенных страниц, [относительно главной страницы](https://yandex.ru/support/wiki/ru/structure#relative).
-   `depth` — количество уровней вложенности раздела, которые будут отображаться в структуре, включая текущую страницу.
-   `sort` — сортировка страниц:
    -   `asc` — по возрастанию;
    -   `desc` — по убыванию.
-   `sort_by` — параметр для сортировки:
    -   `title` — название;
    -   `created_at` — дата создания;
    -   `modified_at` — дата изменения.
