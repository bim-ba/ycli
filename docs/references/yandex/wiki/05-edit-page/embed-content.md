Чтобы встроить видео, музыкальный трек или любой другой интерактивный объект, размещенный на стороннем ресурсе, используйте блок «Фрейм».

В блоке «Фрейм» необходимо использовать ссылку, которая предназначена для размещения на сторонних ресурсах. Чаще всего такие ссылки называются «Код для вставки» или «HTML-код».

Пример

Чтобы добавить видео из YouTube, используйте ссылку вида:

```
https://www.youtube.com/embed/oCRQj_zyPjk
```

Для получения ссылки под видео выберите **Поделиться** → **Встроить** и скопируйте значение параметра `src`.

# Вставить объект

Визуальный редактор

Разметка Markdown

1.  На панели инструментов нажмите **Фрейм**.

2.  В поле **Ссылка** вставьте URL-адрес объекта из внешнего источника.

3.  Укажите размер блока в пикселях.

4.  Нажмите **Сохранить**.

5.  Чтобы отредактировать блок «Фрейм», в режиме редактирования страницы наведите на него указатель и нажмите → **Редактировать**.

    Параметры блока «Фрейм»:

    -   Ссылка для вставки объекта из внешнего источника.
    -   Размер блока в пикселях.
    -   Отображение полос прокрутки: `yes` — включить; `no` — выключить; `auto` — включать автоматически в зависимости от размера объекта внутри блока.
    -   Политика разрешений для встроенного объекта: например, доступ к геолокации или воспроизведение медиа. По умолчанию включены все разрешения.
    -   Рамка вокруг блока.

Чтобы разместить блок «Фрейм» с встроенным объектом, добавьте в текст код в формате:

```
/iframe/(src="https://example.com" width="300" height="100" frameborder="0" scrolling="yes" allow="geo")
```

Параметры блока «Фрейм»:

-   `src` — Ссылка для вставки объекта из внешнего источника.
-   `width` — Ширина блока в пикселях.
-   `height` — Высота блока в пикселях.
-   `frameborder` — Рамка вокруг блока: 0 — блок отображается без рамки, 1 — с рамкой.
-   `scrolling` — Отображение полос прокрутки: yes — включить; no — выключить; auto — включать автоматически в зависимости от размера объекта внутри блока.
-   `allow` — Политика разрешений для встроенного объекта: например, доступ к геолокации или воспроизведение медиа. По умолчанию включены все разрешения.

## Расширить список разрешенных доменов

Администратор организации может добавить 10 любых доменов к списку тех, что уже разрешены по умолчанию.

*Как добавить домен*

1.  На панели слева нажмите **Администрирование**.
2.  Перейдите в раздел **Разрешенные домены**.
3.  Если разрешенных доменов еще нет, в центре экрана нажмите **Добавить домен**.
    Чтобы добавить еще один домен, внизу списка нажмите **Добавить**.
4.  Введите домен сайта без протокола, например `example.com`.
    Если у сайта есть поддомены (`ru.example.com` или `en.example.com`), и все они должны попасть в список разрешенных, добавьте символ `*` в начале доменного имени, например `*.example.com`.
5.  Добавьте комментарий, как вы планируете использовать информацию с этого ресурса на вики-страницах. Комментарий увидят другие администраторы организации.
6.  Нажмите **Добавить**.

Теперь вы сможете использовать контент этих сайтов в блоке «iframe» на вики-страницах.

Чтобы удалить домен из списка, справа от него нажмите и подтвердите действие.

Если страница не отображается, значит домен запрещает встраивание.
