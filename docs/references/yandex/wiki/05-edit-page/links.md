Чтобы добавить ссылку:

1.  Выделите фрагмент текста или нажмите на ту область, куда нужно добавить ссылку.

2.  На панели инструментов нажмите .

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

3.  Укажите адрес прямой или [относительной](https://yandex.ru/support/wiki/ru/structure#relative) ссылки. Если вы не выбрали фрагмент текста, введите текст, который будет отображаться как ссылка.

    Чтобы вставить ссылку на раздел вики-страницы, добавьте [якорь](https://yandex.ru/support/wiki/ru/wysiwyg/links#anchor) к адресу страницы через символ `#`, например: `<адрес_страницы>/#moj-razdel`.

4.  Нажмите **Сохранить**.

Также вы можете:

-   Вставить в текст URL-адрес, например `https://example.com/`, и он автоматически преобразуется в гиперссылку.

    Как предотвратить преобразование URL в ссылку

    Перейдите в режим разметки и экранируйте символы в URL-адресе с помощью символа `\`, например:

    -   `https:\//example.com/`
    -   `https\://example.com/`

-   Скопировать адрес ссылки, выделить фрагмент текста и нажать сочетание клавиш **Вставить** (**Ctrl + V** для Windows, **⌘ + V** для macOS). Выделенный текст станет ссылкой.

Чтобы изменить или удалить ссылку:

1.  Нажмите на ссылку.

2.  Внесите изменения и нажмите **Сохранить**.

### Ссылки на веб-ресурсы

-   URL-адрес без разметки автоматически преобразуется в ссылку.

    Чтобы предотвратить такое преобразование, вы можете экранировать символы в URL-адресе с помощью символа `\`, например:

    -   `https:\//example.com/`
    -   `https\://example.com/`
-   Чтобы сделать ссылку на почтовый адрес, добавьте `mailto:` перед почтовым адресом.

### Ссылки на вики-страницы

-   Вместо полного адреса страницы можно указывать [относительный адрес](https://yandex.ru/support/wiki/ru/structure#relative).
-   Чтобы вставить ссылку на раздел вики-страницы, добавьте якорь к адресу страницы через символ `#`. Подробнее читайте в разделе [Якоря](https://yandex.ru/support/wiki/ru/wysiwyg/links#anchor).

| **Пример** | **Описание** |
| --- | --- |
| `[Страница Олега](https://yandex.ru/users/oleg/page)` | Относительная ссылка на страницу `wiki.yandex.ru/users/oleg/page` |
| `[Раздел новой страницы](https://yandex.ru/support/newpage/#moj-razdel)` | Ссылка на раздел страницы `newpage` с якорем `#moj-razdel` |
| `[Якорь на этой странице](#my-anchor)` | Ссылка на якорь на текущей странице |

# Ссылки на страницы в Трекере, Вики и Формах

Вы можете добавить в текст *магические ссылки* на страницы в Вики, на формы или на сущности из Трекера: задачи, очереди, компоненты, проекты, портфели, цели и дашборды.

Для этого в режиме визуального редактора или в режиме разметки вставьте в текст URL-адрес страницы в Вики, Формах или в Трекере. Магическая ссылка автоматически покажет вместо адреса информацию о ресурсе, на который вы ссылаетесь:

-   **Страница на Вики**

    Магическая ссылка на страницу содержит логотип Вики, название страницы и якорь заголовка (если он содержится в адресе). Чтобы добавить магическую ссылку, вставьте полный адрес страницы на Вики, например:

    ```
    https://wiki.yandex.ru/users/name/page#anchor
    ```

-   **Форма в Яндекс Формах**

    Магическая ссылка содержит логотип сервиса и название формы. Чтобы добавить магическую ссылку, вставьте полный адрес формы, например:

    ```
    https://forms.yandex.ru/cloud/u/1a2b345cd6s/
    ```

-   **Задача в Трекере**

    Магическая ссылка на задачу содержит логотип Трекера, ключ, название, статус задачи и имя исполнителя. Чтобы добавить магическую ссылку, вставьте ключ задачи (например, `TEST-123`) или ее полный адрес, например:

    ```
    https://tracker.yandex.ru/TEST-123
    ```

-   **Другая сущность в Трекере**

    Чтобы добавить магическую ссылку, вставьте полный адрес проекта, портфеля, цели, дашборда, очереди или компонента. Такая ссылка содержит логотип Трекера, значок типа сущности и название. Ссылка на некоторые сущности содержит и другие элементы, например, статус и дедлайн:

    ```
    https://tracker.yandex.ru/pages/projects/1234
    ```

Если вы хотите, чтобы ссылка не превращалась в *магическую*, вы можете оформить ее как фрагмент кода или использовать стандартную разметку ссылки. Например:

```
`TEST-123`
[Задача TEST-123](https://tracker.yandex.ru/TEST-123)
[Моя страница](https://wiki.yandex.ru/users/name/page)
```

# Якоря

Якорь — это метка в тексте страницы, с помощью которой можно сослаться на подраздел или любую другую часть страницы.

Для каждого подраздела на странице якорь автоматически формируется из заголовка. Например, для заголовка `Мой раздел` будет назначен якорь `moj-razdel`. С помощью разметки Markdown вы можете задать якорь для подраздела вручную.

На одной странице идентификаторы якорей не должны повторяться.

Чтобы добавить якорь в любом месте страницы:

1.  Установите курсор в нужное место на странице и на панели инструментов нажмите .

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Нажмите на появившийся на странице значок `#` и в открывшемся окне укажите:

    -   **Идентификатор якоря** — идентификатор, который будет использоваться в ссылках для перехода к якорю на странице. Идентификатор должен состоять из цифр, символов и латинских букв.
    -   **Подсказка** — текст подсказки, который должен появляться при наведении указателя на якорь.

Созданный элемент `#` виден только в режиме разметки.

-   Чтобы задать якорь для подраздела страницы, добавьте после заголовка разметку: `{#<идентификатор>}`

    Например:

    ```
    ## Мой подзаголовок {#subheading}
    ```

-   Чтобы добавить якорь в любом месте страницы, используйте разметку:

    ```
    #[<видимый текст>](https://yandex.ru/support/wiki/%3C%D0%B8%D0%B4%D0%B5%D0%BD%D1%82%D0%B8%D1%84%D0%B8%D0%BA%D0%B0%D1%82%D0%BE%D1%80%3E%20%22%3C%D1%82%D0%B5%D0%BA%D1%81%D1%82%20%D0%BF%D0%BE%D0%B4%D1%81%D0%BA%D0%B0%D0%B7%D0%BA%D0%B8%3E%22)
    ```

    -   Идентификатор — используется в ссылках для перехода к якорю на странице. Идентификатор должен состоять из цифр, символов и латинских букв.
    -   Видимый текст — если указан текст в квадратных скобках, он будет отображаться на странице на месте якоря.
    -   Тест подсказки — всплывающая подсказка, которая появляется при наведении указателя на видимый текст якоря.

Чтобы сделать ссылку на место, отмеченное якорем, добавьте к адресу страницы символ `#` и идентификатор якоря:

```
[<текст_ссылки>](https://wiki.yandex.ru/page/#moj-razdel)
```
