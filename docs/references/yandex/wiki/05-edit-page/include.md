# Вставка контента с другой страницы

Блок позволяет разместить на странице контент с другой страницы в Вики.

Если добавить в текст фрагмент другой страницы, он будет недоступен для пользователей, у которых нет доступа к странице – источнику. [Как настроить доступ](https://yandex.ru/support/wiki/ru/page-management/access-type)

Визуальный редактор

Разметка Markdown

1.  На панели инструментов нажмите **Инклюд**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Укажите адрес страницы, которую хотите вставить, в формате `/<раздел>/<подраздел>/<имя_страницы>`. Например: `/users/username/my-page`.

3.  Если необходимо, выключите опцию, которая позволит показывать ошибку о страницах, к которым у пользователя нет доступа.

4.  В поле **От** / **До** укажите имена [якорей](https://yandex.ru/support/wiki/ru/wysiwyg/links#anchor) на странице Вики, ограничивающих содержимое, которое будет подключено. По умолчанию подключается вся страница. Имя якоря указывается без символа `#`.

5.  Нажмите **Сохранить**.

Чтобы разместить на странице контент с другой страницы в Вики, добавьте код в формате:

```
{% include page="/<раздел>/<подраздел>/<имя_страницы>" warning="false" from="a1" to="a2"%}
```

Например: `{% include page="/users/username/my-page" warning="false" from="a1" to="a2"%}`.

Параметры разметки:

-   `page` — Относительная ссылка на страницу.
-   `warning` — Опция, которая позволит показывать ошибку о страницах, к которым у пользователя нет доступа.
-   `from` / `to` — Имена якорей на странице Вики, ограничивающих содержимое, которое будет подключено. По умолчанию подключается вся страница. Имя якоря указывается без символа `#`.
