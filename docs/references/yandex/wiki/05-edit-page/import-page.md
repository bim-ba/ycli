# Добавить на страницу текст из файла

Чтобы добавить содержимое текстового файла TXT или документа в формате DOCX на страницу:

1.  Откройте страницу или [создайте новую](https://yandex.ru/support/wiki/ru/create-page).

2.  На панели инструментов нажмите нажмите **Другие действия**, затем выберите **Импортировать**. Откроется окно импорта.

3.  Нажмите **Выбрать файл** и укажите файл формата TXT или DOCX.

    Размер файла должен быть не более 10 МБ. Если вы выберете файл неподходящего формата, появится сообщение об ошибке.

Содержимое выбранного файла будет загружено на страницу:

-   Если вы загрузили файл TXT, текст файла будет полностью скопирован на страницу. Если в тексте есть [элементы разметки](https://yandex.ru/support/wiki/ru/wysiwyg/text-format), они будут отображаться корректно.

-   Если вы загрузили документ DOCX, текст вместе с элементами оформления будет преобразован в [разметку YFM](https://yandex.ru/support/wiki/ru/wysiwyg/text-format).

# Создать статичную таблицу из файла

Вы можете добавить на страницу статичную таблицу, содержащую данные из файла CSV или TXT:

1.  Подготовьте файл в формате CSV или TXT, содержащий данные для таблицы. Значения ячеек в файле должны быть разделены запятой, точкой с запятой или символом табуляции.

    Например, вы можете сохранить файл Microsoft Excel в формате CSV.

2.  Откройте страницу или [создайте новую](https://yandex.ru/support/wiki/ru/create-page).

3.  В режиме визуального редактора или в режиме разметки на панели инструментов нажмите → **Импортировать таблицу из CSV**.

    В режиме визуального редактора вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

4.  В открывшемся окне нажмите кнопку **Выбрать файл** и укажите файл CSV или TXT.

5.  При необходимости укажите символы, которые используются в качестве разделителя ячеек. По умолчанию разделитель определяется автоматически.

6.  Включите опцию **Пропускать пустые строки**, чтобы не добавлять в таблицу пустые строки из файла.

7.  Проверьте предварительную версию таблицы и нажмите кнопку **Сохранить**.

На страницу будет добавлена многострочная таблица, содержащая данные из файла.

Подробнее о статичных таблицах читайте в разделе [Статичная таблица](https://yandex.ru/support/wiki/ru/wysiwyg/tables-format).

# Добавить данные в динамическую таблицу

Вы можете загружать в динамические таблицы данные из файлов в формате CSV или TXT:

1.  Сохраните вашу электронную таблицу (например, файл Microsoft Excel) в формате CSV. Либо подготовьте файл TXT, в котором значения ячеек разделены запятой, точкой с запятой или символом табуляции.

2.  Откройте динамическую таблицу или [создайте новую](https://yandex.ru/support/wiki/ru/wysiwyg/grid#add).

3.  В правом верхнем углу таблицы выберите → **Загрузить данные из файла**.

4.  В окне **Загрузка данных из файла** укажите файл CSV или TXT.

    В одной таблице может быть не более 1000 строк и 300 столбцов.

5.  Укажите символы, которые используются в качестве разделителя ячеек и для форматирования строк.

6.  Если в файле есть заголовки столбцов, включите опцию **Первая строка содержит заголовки**. Иначе автоматически будут добавлены заголовки с порядковыми номерами столбцов.

7.  Для каждого столбца из файла выберите, куда будут загружены данные:

    -   **Новый столбец** — столбец будет помещен справа от уже существующих столбцов таблицы.

    -   Один из существующих столбцов — данные будут добавлены в конец выбранного столбца.

    -   **Игнорировать столбец** — столбец будет исключен из загрузки.

8.  Выберите тип данных для новых столбцов.

9.  Нажмите кнопку **Загрузить данные**.

Содержимое выбранного файла будет загружено в динамическую таблицу. Подробнее о работе с динамическими таблицами читайте в разделе [Динамическая таблица](https://yandex.ru/support/wiki/ru/wysiwyg/grid).
