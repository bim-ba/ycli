**Поддерживаемые цвета:**

- `gray` — серый;
- `yellow` — желтый;
- `orange` — оранжевый;
- `red` — красный;
- `green` — зеленый;
- `blue` — синий;
- `violet` — фиолетовый.

При форматировании текста вы можете комбинировать элементы разметки в любом порядке:

```
**_Оформление текста 1_** и **_Оформление текста 2_**

{orange}(~~Зачеркнутая часть~~ оранжевого текста)
```

Результат

***Оформление текста 1*** и ***Оформление текста 2***

~Зачеркнутая часть~ оранжевого текста

У каждого заголовка автоматически формируется якорь, на который можно сделать [ссылку](https://yandex.ru/support/wiki/ru/wysiwyg/links) из других частей страницы или с других страниц. Также вы можете задать якорь вручную в режиме разметки.

Заголовок может иметь уровень от 1 до 6. Чем выше уровень заголовка, тем крупнее шрифт.

Визуальный редактор

Разметка Markdown

Чтобы оформить заголовок, используйте один из способов:

-   На панели инструментов вверху страницы нажмите кнопку и выберите уровень заголовка.

-   Нажмите сочетание клавиш:

    -   Windows: **Ctrl** + **Shift** + **1**—**6**
    -   macOS: **⌘** + **⌥** + **1**—**6**

    Вы также можете добавлять элементы форматирования [с помощью клавиатуры](https://yandex.ru/support/wiki/ru/edit-page#keyboard) или использовать меню быстрого доступа: введите символ `/` и выберите элемент из списка.

Чтобы скрыть часть информации на странице, вы можете сделать заголовок сворачиваемым:

1.  Выделите заголовок. Появится панель инструментов редактирования выделенного элемента.

2.  На панели нажмите значок .

Контент под заголовком можно будет свернуть или развернуть. В редакторе нижняя граница текста, который попадет в сворачиваемый блок, обозначена значком с пунктирной линией.

```
# Заголовок первого уровня
##+ Сворачиваемый заголовок второго уровня
#### Заголовок четвертого уровня с якорем {#level4}
```

-   Чтобы оформить заголовок, в начале строки добавьте от 1 до 6 символов `#`, в зависимости от уровня заголовка.

-   Чтобы сделать заголовок сворачиваемым, после символов `#` добавьте `+`.

-   Чтобы вручную задать якорь для заголовка, в конце строки добавьте разметку `{#<имя_якоря>}`.

## Списки

Визуальный редактор

Разметка Markdown

Чтобы добавить список, выберите один или несколько абзацев и используйте кнопки на панели инструментов или сочетания клавиш.

Вы также можете добавлять элементы форматирования [с помощью клавиатуры](https://yandex.ru/support/wiki/ru/edit-page#keyboard) или использовать меню быстрого доступа: введите символ `/` и выберите элемент из списка.

| Список | Кнопка на панели | Сочетание клавиш Windows | Сочетание клавиш macOS |
| --- | --- | --- | --- |
| Маркированный список |  | **Ctrl** + **Shift** + **L** | **⌘** + **Shift** + **L** |
| Нумерованный список |  | **Ctrl** + **Shift** + **M** | **⌘** + **Shift** + **M** |
| Уменьшить отступ |  | **Shift** + **⇥** | **Shift** + **⇥** |
| Увеличить отступ |  | **⇥** | **⇥** |
| Контрольный список (чекбокс) |  | — | — |

**Нумерованный список**

Пример:

```
1. Первый пункт
1. Второй пункт
   1. Первый подпункт
   1. Второй подпункт
```

Результат: Первый пункт, Второй пункт, Первый подпункт, Второй подпункт

**Маркированный список**

Пример:

```
* Пункт списка
  - Подпункт списка
  - Подпункт списка
+ Пункт списка.
```

Результат: Пункт списка, Подпункт списка, Подпункт списка, Пункт списка

**Комбинированный список**

Пример:

```
1. Нумерованный пункт
   * Маркированный подпункт
   * Маркированный подпункт
1. Нумерованный пункт
```

Результат: Нумерованный пункт, Маркированный подпункт, Маркированный подпункт, Нумерованный пункт

**Контрольный список**

Пример:

```
[ ] Дело 1

[x] Дело 2

[ ] Дело 3
```

Результат: Дело 1, Дело 2, Дело 3

Чтобы добавить список, используйте цифры и специальные символы:

-   Нумерованный список: используйте цифры с символом `.` или `)`. Нумерация выполняется динамически, поэтому порядок цифр не важен.
-   Маркированный список: используйте символы `*`, `-` или `+`.
-   Вложенный список: добавьте отступ от двух до пяти пробелов перед пунктами дочернего списка. В нумерованном списке можно использовать вложенный маркированный список и наоборот.
-   Контрольный список: в качестве маркера используйте символы `[ ]`. Между элементами списка должна быть пустая строка.
    Чтобы отметить пункт списка флажком, вместо пробела добавьте между скобок символ `x`.

Вы также можете добавлять элементы форматирования [с помощью клавиатуры](https://yandex.ru/support/wiki/ru/edit-page#keyboard) или использовать меню быстрого доступа: введите символ `/` и выберите элемент из списка.

## Формулы

Визуальный редактор

Разметка Markdown

На панели инструментов нажмите и выберите вариант оформления:

-   **Формула в тексте** — формула будет размещена на странице в тексте;

-   **Блок с формулой** — формула будет размещена в отдельном блоке.

Вы также можете добавлять элементы форматирования [с помощью клавиатуры](https://yandex.ru/support/wiki/ru/edit-page#keyboard) или использовать меню быстрого доступа: введите символ `/` и выберите элемент из списка.

**Строка с формулой**

Пример: `Формула в тексте $e^{ix}=\cos x+i\sin x$`

Результат: Формула в тексте $e^{ix}=\cos x+i\sin x$

**Блок с формулой**

Пример:

```
$$
(√a)^2 = a;
$$
```

Результат: $(√a)^2 = a;$

-   Чтобы добавить формулу в строку текста, используйте символ `$`.
-   Чтобы отобразить формулу в отдельном блоке, отделите ее символами `$$`.

Для создания формул используйте синтаксис Katex, который совместим с форматом TeX/LaTeX. [Сайт Katex](https://katex.org/)

## Разделитель

Визуальный редактор

Разметка Markdown

Чтобы добавить разделитель между абзацами, на панели инструментов нажмите **Другие действия**, затем выберите **Разделитель**.

Вы также можете добавлять элементы форматирования [с помощью клавиатуры](https://yandex.ru/support/wiki/ru/edit-page#keyboard) или использовать меню быстрого доступа: введите символ `/` и выберите элемент из списка.

Чтобы добавить разделитель, в начале строки введите три или более символов «дефис» `-`, «звездочка» `*` или «подчеркивание» `_`:

```
Раделитель 1

---

Разделитель 2

****

Разделитель 3

____

```

Например: `:smile:`.

## Экранирование

В режиме разметки Markdown используйте экранирование, чтобы отобразить символы, которые которые обозначают элементы разметки:

-   Чтобы символ разметки не был интерпретирован, его можно экранировать с помощью символа `\`:

    ```
    Верхний^индекс^
    Верхний\^индекс^
    ```

    Результат

    Верхний^(индекс)
    Верхний^индекс^

-   Если нужно отобразить обратный апостроф внутри фрагмента исходного кода, окружите фрагмент кода двойными обратными апострофами ` `` `:

    ``` ``SELECT `id` FROM `table` `` ```

    Результат

    `` SELECT `id` FROM `table` ``

## Скрытый текст

В режиме разметки Markdown вы можете скрыть часть текста от других пользователей. Скрытый фрагмент будет виден только тем пользователям, которые редактируют текст, и только в режиме разметки.

Чтобы скрыть текст, используйте разметку:

`[//]: # (Скрытый текст)`

Обратите внимание, что перед скрытым текстом должна быть пустая строка.

Это может быть полезно, чтобы оставить заметку для себя или для соавторов, а также чтобы временно убрать неактуальную часть текста.

Вы также можете оставлять комментарии, которые увидят все пользователи, имеющие доступ к странице. Подробнее о работе с комментариями читайте в разделе [Комментарии](https://yandex.ru/support/wiki/ru/wysiwyg/comment).
