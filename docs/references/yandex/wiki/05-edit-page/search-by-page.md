На Вики можно использовать поиск по тексту страницы:

-   В режиме просмотра страницы работает упрощенная версия поиска.
-   В режиме редактирования можно искать на странице текст с учетом регистра и точного совпадения с поисковым запросом, а также заменить найденную фразу новым текстом.

*Как работает поиск и замена текста*

# Как искать по странице в режиме просмотра

Чтобы найти на странице слово или фразу в режиме просмотра:

1.  В правом верхнем углу страницы нажмите **Действия** и выберите **Найти на странице**, либо используйте сочетание клавиш:

    -   Windows и Linux — **Ctrl** + **Shift** + **F**;
    -   macOS — **⌘** + **Shift** + **F**.

    Если в режиме просмотра страницы нажать **Ctrl** + **F** (или **⌘** + **F**), откроется строка поиска вашего браузера. Такой поиск может дать неполные результаты, если текст страницы загрузился не до конца или если на странице есть динамические таблицы.

2.  На панели поиска справа введите слово или фразу, которую хотите найти.

    Будут найдены все совпадения введенной фразы с текстом страницы, включая совпадения с частями слов, без учета регистра (заглавных и строчных букв). Найденные фрагменты будут выделены голубым фоном.

3.  Для перехода между результатами поиска используйте значки и под строкой поиска.

Чтобы использовать расширенные возможности поиска по странице, перейдите в режим редактирования.

# Как искать по странице в режиме редактирования

В режиме редактирования можно искать на странице текст с учетом регистра и точного совпадения с поисковым запросом. Также вы можете заменить найденные фразы: [Как найти и заменить текст](https://yandex.ru/support/wiki/ru/page-management/search-by-page#replace).

1.  Откройте страницу и в правом верхнем углу нажмите кнопку .

2.  Чтобы вызвать строку поиска, нажмите сочетания клавиш:

    -   Windows и Linux — **Ctrl** + **F**;
    -   macOS — **⌘** + **F**.
3.  В строку поиска введите слово или фразу, которую хотите найти.

    При поиске без дополнительных опций будут найдены все совпадения введенной фразы с текстом страницы, включая совпадения с частями слов, без учета регистра (заглавных и строчных букв). Найденные фрагменты будут выделены голубым фоном.

4.  Чтобы использовать расширенные возможности, справа от строки поиска нажмите значок :

    -   Включите опцию **С учетом регистра**, чтобы при поиске различать заглавные и строчные буквы.

        Если опция включена, по запросу «Текст» найдется слово «Текст», но не «текст» или «ТЕКСТ».

    -   Включите опцию **Точное совпадение**, чтобы искать отдельные слова и фразы, которые совпадают с введенным запросом, но не искать совпадающие части других слов.

        Например, при поиске слова «текст» без этой опции будет также найдено совпадение в слове «текстовый», а с включенной опцией — только отдельное слово «текст».

5.  Для перехода между результатами поиска используйте значки и в конце строки поиска.

# Как найти и заменить текст

Чтобы найти в тексте страницы слово или фразу и вставить вместо нее другой текст, используйте функцию замены:

1.  Откройте страницу и в правом верхнем углу нажмите кнопку .

2.  Чтобы вызвать строку поиска, нажмите сочетания клавиш:

    -   Windows и Linux — **Ctrl** + **F**;
    -   macOS — **⌘** + **F**.
3.  Справа от строки поиска нажмите значок .

4.  В поле **Найти** введите слово или фразу, которую хотите найти и заменить.

    Чтобы искать текст с учетом регистра или точного совпадения с поисковым запросом, включите опции поиска: [Как использовать расширенные возможности поиска](https://yandex.ru/support/wiki/ru/page-management/search-by-page#options).

5.  В поле **Заменить на** введите текст, который хотите вставить вместо найденного фрагмента.

6.  Чтобы заменить новым текстом только тот фрагмент, который выбран в результатах поиска, нажмите кнопку **Заменить**.

    Чтобы выбрать в результатах поиска другой фрагмент для замены, используйте значки и в конце строки поиска.

7.  Чтобы заменить новым текстом все найденные фрагменты, нажмите кнопку **Заменить все**.

    Если в поле **Заменить на** ничего не ввести, при замене выбранный фрагмент будет удален.

    Если вы ошиблись при замене текста, для отмены последнего действия нажмите сочетание клавиш **Ctrl** + **Z** (для Windos) или **⌘** + **Z** (для macOS).
