Вы можете добавить на страницу файл по ссылке или загрузить его с устройства. Максимальный размер одного загружаемого файла — 200 МБ.

# Вставить файл из буфера обмена

Вы можете вставить файл из буфера обмена как в визуальном режиме редактора, так и в режиме разметки:

1.  Скопируйте файл в буфер обмена на вашем компьютере.

2.  Вставьте в текст страницы файл из буфера обмена.

Файл будет автоматически загружен на Вики и появится в списке ресурсов страницы. [Управлять загруженными файлами](https://yandex.ru/support/wiki/ru/wysiwyg/file#resources)

# Добавить файл на страницу

### Шаг 1. Сохраните файл или скопируйте ссылку

Чтобы добавить на вики-страницу файл с другого сайта, правой кнопкой мыши нажмите на него и выберите **Копировать адрес ссылки**.

Чтобы получить ссылку на файл, который уже загружен на Вики:

1.  Перейдите на вики-страницу с нужным файлом.

2.  Откройте список всех файлов, загруженных на страницу: в правом верхнем углу нажмите **Действия** и выберите **Ресурсы страницы**.

3.  Справа от файла нажмите  →  **Скопировать код для вставки**.

Такой файл будет доступен только тем пользователям, у которых есть доступ к странице – источнику файла. [Как настроить доступ к странице](https://yandex.ru/support/wiki/ru/page-management/access-type)

### Шаг 2. Загрузите файл на вики-страницу

Визуальный редактор

Разметка Markdown

1.  На панели инструментов нажмите **Файл**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Выберите способ загрузки файла:

    -   Чтобы загрузить файл по ссылке, нажмите на вкладку **Добавить по ссылке**. Затем введите адрес расположения файла и укажите название, которое будет отображаться в тексте.
    -   Чтобы прикрепить файл с устройства, нажмите на вкладку **Загрузить с устройства** и выберите один или несколько файлов.
3.  Нажмите **Сохранить**.

Чтобы разместить на странице файл, добавьте код в формате:

```
{% file src="<ссылка>" name="<отображаемое имя>" type="<тип>" %}
```

Параметры разметки:

-   `src` — ссылка на файл.
-   `name` — имя, которое будет отображаться на странице.
-   `type` — MIME-тип файла, необязательный. [Что такое MIME-тип](https://ru.wikipedia.org/wiki/%D0%A1%D0%BF%D0%B8%D1%81%D0%BE%D0%BA_MIME-%D1%82%D0%B8%D0%BF%D0%BE%D0%B2)

Например:

```
{% file src="/users/user/1a0e17460826/.files/filename.zip" name="filename.zip" type="application/zip" %}
```

# Просмотреть загруженные изображения

Просматривать можно только изображения, файлы других типов не отобразятся в галерее.

1.  Откройте список всех файлов, загруженных на страницу: в правом верхнем углу нажмите **Действия** и выберите **Ресурсы страницы**.

2.  Чтобы просмотреть все изображения на странице в режиме галереи, нажмите на одно из них.

    -   Переключайтесь между изображениями с помощью стрелок на клавиатуре или нажимайте миниатюры внизу.

    -   Чтобы приблизить изображение, нажмите на его. Перетаскивайте увеличенное изображение мышью, чтобы нужные детали оказались в области просмотра.
        Чтобы вернуть изображение к прежнему масштабу, снова нажмите на него.

    -   Чтобы развернуть изображение на весь экран, нажмите значок **Открыть полноэкранный режим** справа вверху или сочетание клавиш **Shift** + **F**.

    -   Если нужно поделиться изображением, справа вверху нажмите **Скопировать ссылку**.

    -   Если нужно сохранить изображение, справа вверху нажмите **Скачать**. В зависимости от настроек вашего браузера, изображение будет загружено на компьютер или откроется в новой вкладке.

# Управлять загруженными файлами

Максимальный общий размер всех файлов, прикрепленных в Вики одной организации, составляет 5 Гбайт.

Чтобы увеличить объем хранимых файлов, вы можете подключить объектное хранилище [Yandex Object Storage](https://yandex.cloud/ru/docs/storage/operations/buckets/create). Чтобы подключить хранилище к Вики, напишите в [службу поддержки](https://yandex.ru/support/wiki/ru/feedback) и предоставьте [данные сервисного аккаунта](https://yandex.cloud/ru/docs/iam/operations/sa/create-access-key), имеющего доступ к созданному объектному хранилищу.

Откройте список всех файлов, загруженных на страницу: в правом верхнем углу нажмите **Действия** и выберите **Ресурсы страницы**.

-   Чтобы посмотреть только файлы определенного типа, используйте фильтры справа вверху: **Все**, **Файлы и изображения** или **Динамические таблицы**.
    Также можно найти файл по названию.

-   Чтобы добавить файл в ресурсы страницы, внизу нажмите кнопку **Выберите файл**.
    Максимальный размер одного загружаемого файла — 200 МБ.

-   Чтобы получить код для вставки файла на страницу, справа нажмите  →  **Скопировать код для вставки**.

    Если вы добавите на вики-страницу код для вставки файла изображения, вместо ссылки на файл отобразится само изображение.

-   Чтобы скачать файл, справа нажмите  →  **Скачать**.

-   Чтобы удалить файл, справа нажмите  →  **Удалить**.
