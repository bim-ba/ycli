В статичной таблице форматирование и порядок строк задаются вручную с помощью панели инструментов или элементов разметки.

В отличие от [динамических таблиц](https://yandex.ru/support/wiki/ru/wysiwyg/grid), статичные таблицы не поддерживают сортировку, фильтрацию и проверку типа данных в ячейках.

# Добавить таблицу

Визуальный редактор

Разметка Markdown

Чтобы добавить таблицу:

1.  На панели инструментов нажмите **Таблица** → **Статичная таблица**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Чтобы добавить строки или столбцы, наведите указатель на край таблицы и нажмите значок в том месте, куда нужно добавить новые элементы.

3.  Заполните ячейки. Текст в ячейках таблицы можно форматировать.

Чтобы редактировать таблицу, наведите на нее указатель и нажмите вверху столбца или в начале строки. В открывшемся меню выберите действие:

-   Добавьте строку или столбец.
-   Очистите ячейки строки или столбца.
-   Удалите строку или столбец.
-   Удалите таблицу.
-   Перетащите строку или столбец на новое место за значок .

В ячейке [многострочной таблицы](https://yandex.ru/support/wiki/ru/wysiwyg/tables-format#multiline) можно размещать текст из нескольких строк: списки, фрагменты кода, другие таблицы.

В ячейках [простых таблиц](https://yandex.ru/support/wiki/ru/wysiwyg/tables-format#simple) можно использовать только элементы строчного форматирования: оформление текста, изображения, ссылки. Также простая таблица поддерживает выравнивание текста в ячейках по левому, правому краю или по центру.

Простую таблицу можно добавить только в режиме разметки Markdown.

Чтобы изменить формат простой таблицы на [многострочный](https://yandex.ru/support/wiki/ru/wysiwyg/tables-format#multiline), в режиме визуального редактора выберите ячейку таблицы, нажмите значок и выберите **Преобразовать в таблицу YFM**.

## Многострочная таблица

Чтобы добавить многострочную таблицу, используйте разметку:

```
#|
|| **Заголовок 1** | **Заголовок 2** ||
||Текст
на двух строчках
| - Пункт 1
  - Пункт 2
  - Пункт 3 ||
|#
```

Чтобы выделить строку заголовка в таблице, вы можете применить [форматирование](https://yandex.ru/support/wiki/ru/wysiwyg/text-format) к тексту в первой строке. Например, выделить его жирным начертанием.

Результат

| **Заголовок 1** | **Заголовок 2** |
| --- | --- |
| Текст<br>на двух строчках | Пункт 1, Пункт 2, Пункт 3 |

## Простая таблица

Чтобы разместить в тексте простую таблицу, используйте разметку:

```
| Заголовок 1 | Заголовок 2 | Заголовок 3 |
| --- | --- | --- |
| ячейка 11 | ячейка 12 | ячейка 13 |
| ячейка 21 | ячейка 22 | ячейка 23 |
```

Результат

| Заголовок 1 | Заголовок 2 | Заголовок 3 |
| --- | --- | --- |
| ячейка 11 | ячейка 12 | ячейка 13 |
| ячейка 21 | ячейка 22 | ячейка 23 |

## Выравнивание текста

В [простой таблице](https://yandex.ru/support/wiki/ru/wysiwyg/tables-format#simple) можно выровнять содержимое столбца по левому, правому краю или по центру. Для этого используйте символ `:` в разделительной строке таблицы.

```
| По левому краю | По центру     | По правому краю |
| :---           | :----:        | ---:            |
| Текст          | Текст         | Текст           |
| Текст          | Текст         | Текст           |
```

Результат

| По левому краю | По центру | По правому краю |
| --- | --- | --- |
| Текст | Текст | Текст |
| Текст | Текст | Текст |

# Импортировать таблицу из файла

Вы можете добавить на страницу статичную таблицу, содержащую данные из файла CSV или TXT:

1.  Подготовьте файл в формате CSV или TXT, содержащий данные для таблицы. Значения ячеек в файле должны быть разделены запятой, точкой с запятой или символом табуляции.

    Например, вы можете сохранить файл Microsoft Excel в формате CSV.

2.  Откройте страницу или [создайте новую](https://yandex.ru/support/wiki/ru/create-page).

3.  В режиме визуального редактора или в режиме разметки на панели инструментов нажмите → **Импортировать таблицу из CSV**.

    В режиме визуального редактора вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

4.  В открывшемся окне нажмите кнопку **Выбрать файл** и укажите файл CSV или TXT.

5.  При необходимости укажите символы, которые используются в качестве разделителя ячеек. По умолчанию разделитель определяется автоматически.

6.  Включите опцию **Пропускать пустые строки**, чтобы не добавлять в таблицу пустые строки из файла.

7.  Проверьте предварительную версию таблицы и нажмите кнопку **Сохранить**.

На страницу будет добавлена многострочная таблица, содержащая данные из файла.
