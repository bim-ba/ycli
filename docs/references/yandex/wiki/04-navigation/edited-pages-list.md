# Посмотреть измененные мной страницы

Список всех страниц, которые вы редактировали, можно найти в разделе **История изменений**:

1.  На левой панели Вики нажмите **История изменений**.

2.  Справа от поля **Поиск по названию** выберите **Я редактор**.
