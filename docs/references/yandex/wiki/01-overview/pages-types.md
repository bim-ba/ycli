Помимо обычного текста на страницы Яндекс Вики можно добавить динамические таблицы. Также вы можете использовать шаблоны — заготовки для создания типовых страниц.

# Базовая страница

Страница, с текстом которой можно работать в [визуальном редакторе](https://yandex.ru/support/wiki/ru/wysiwyg/text-format) — так же, как в Microsoft Word или Google Docs. Если вам удобнее пользоваться разметкой Markdown, можно переключиться на нее. Вики поддерживает разметку YFM — расширенную версию Markdown с дополнительными элементами форматирования. [Документация Yandex Flavored Markdown](https://diplodoc.com/docs/ru/index-yfm)

Страницу, созданную в новом редакторе, нельзя конвертировать в страницу старого редактора.

# Шаблон

Страница, которую можно подготовить заранее для выполнения однотипных задач — например, для подготовки документации или для оформления результатов работы команды.

-   [Как настроить шаблоны](https://yandex.ru/support/wiki/ru/templates)

-   [Как создать страницу из шаблона](https://yandex.ru/support/wiki/ru/create-page#template)

# Динамическая таблица

На страницу можно добавить одну или несколько динамических таблиц. В таких таблицах можно задать тип данных в каждом столбце, отсортировать значения или сделать ячейку обязательной для заполнения. Динамические таблицы привязаны к страницам как ресурсы.

Чтобы создать динамическую таблицу, добавьте ее на страницу в режиме редактирования: [Как использовать динамические таблицы](https://yandex.ru/support/wiki/ru/wysiwyg/grid).

# Страница в старом редакторе

Страница с текстом, изображениями, таблицами, прикрепленными файлами и так далее. В старом редакторе частично поддержан [визуальный редактор разметки](https://yandex.ru/support/wiki/ru/wysiwyg/text-format), но преимущественно используется [разметка Markdown](https://yandex.ru/support/wiki/ru/static-markup).

Создать страницу в старом редакторе больше не получится. Вы можете конвертировать страницу, созданную в старом редакторе, в страницу нового редактора. Подробнее в разделе [Перевести страницу на новый редактор](https://yandex.ru/support/wiki/ru/page-management/convert-page).
