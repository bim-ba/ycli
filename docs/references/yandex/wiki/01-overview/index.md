Яндекс Вики — это сервис для создания корпоративной базы знаний, которую наполняют и обновляют пользователи — сотрудники компании.

На страницах в Вики можно хранить любую информацию, которая нужна сотрудникам для работы: памятки, полезные ссылки и контакты, рабочие инструкции, документацию проектов и личные заметки. Вики дает сотрудникам компании дополнительные возможности для совместной работы: они могут делиться информацией, искать ответы на частые вопросы, вести обсуждение в комментариях к странице.

# Доступ к Яндекс Вики

В Яндекс Вики могут работать пользователи организаций, зарегистрированные в сервисе [Яндекс 360 для бизнеса](https://admin.yandex.ru/). Для организации в Яндекс Вики создается своя база знаний, доступная только сотрудникам. Как подключить Яндекс Вики, читайте в разделе [Подключить Яндекс Вики](https://yandex.ru/support/wiki/ru/enable-wiki).

Чтобы получить доступ к Вики, войдите в аккаунт, который вы используете для работы в организации. [Как войти в Вики](https://yandex.ru/support/wiki/ru/login)

Если в компании есть система управления пользователями и доступом (например, Active Directory или Google Workspace), сотрудники могут использовать свои корпоративные аккаунты, чтобы войти в организацию Яндекс 360 для бизнеса и получить доступ к Вики через систему единого входа (Single Sign-On, SSO). О том, как [настроить SSO](https://yandex.ru/support/yandex-360/business/admin/ru/sso.html) и [выдать доступы](https://yandex.ru/support/yandex-360/business/admin/ru/admin.html) читайте в документации Яндекс 360 для бизнеса.

# Возможности Яндекс Вики

-   [Создавайте страницы и разделы](https://yandex.ru/support/wiki/ru/quick-guide), состоящие из текста, изображений, таблиц и ссылок.
    Максимальное количество страниц для одной организации — 10 000.

-   Оформляйте страницы [в визуальном редакторе](https://yandex.ru/support/wiki/ru/wysiwyg/text-format) или используйте разметку YFM — расширенную версию Markdown с дополнительными элементами форматирования. [Документация Yandex Flavored Markdown](https://diplodoc.com/docs/ru/index-yfm)

-   [Прикрепляйте файлы](https://yandex.ru/support/wiki/ru/wysiwyg/file) к странице.

    Максимальный общий размер всех файлов, прикрепленных в Вики одной организации, составляет 5 Гбайт.

    Чтобы увеличить объем хранимых файлов, вы можете подключить объектное хранилище [Yandex Object Storage](https://yandex.cloud/ru/docs/storage/operations/buckets/create). Чтобы подключить хранилище к Вики, напишите в [службу поддержки](https://yandex.ru/support/wiki/ru/feedback) и предоставьте [данные сервисного аккаунта](https://yandex.cloud/ru/docs/iam/operations/sa/create-access-key), имеющего доступ к созданному объектному хранилищу.

-   Отслеживайте правки, которые вносят пользователи на страницах, с помощью [истории изменений](https://yandex.ru/support/wiki/ru/history). Можно сравнить две версии страницы между собой или восстановить версию из истории.

-   Структурируйте информацию на Вики: создавайте дерево страниц и связывайте страницы перекрестными ссылками. [Как управлять структурой](https://yandex.ru/support/wiki/ru/structure)

-   Чтобы быстро находить информацию на Вики, используйте [поиск](https://yandex.ru/support/wiki/ru/search), подписывайтесь на страницы и добавляйте их в [избранное](https://yandex.ru/support/wiki/ru/notifications).

-   Настраивайте права доступа к страницам: можно открыть страницу для всех или некоторых сотрудников, ограничить возможность редактирования или запретить просмотр страницы. [Как настроить доступ к странице](https://yandex.ru/support/wiki/ru/page-management/access-type)

-   Интегрируйте Вики с сервисами Яндекс Трекер и Яндекс Формы, чтобы добавить:

    -   [списки задач из Трекера](https://yandex.ru/support/wiki/ru/tracker).

    -   [опросы и формы заявок из Форм](https://yandex.ru/support/wiki/ru/forms).
