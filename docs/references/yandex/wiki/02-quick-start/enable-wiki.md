Пользователи организаций, зарегистрированных на платформе Яндекс 360 для бизнеса, могут использовать сервис Яндекс Вики для создания корпоративной базы знаний. Подробнее о возможностях Яндекс Вики читайте в разделе [Обзор сервиса Вики](https://yandex.ru/support/wiki/ru/overview).

Если у вас нет организации Яндекс 360 для бизнеса, вы можете ее создать. О том, как это сделать, читайте в [документации Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/set-up/direct).

# Активировать Вики в существующей организации

Если у вас уже есть организация в Яндекс 360 для бизнеса, сервис Яндекс Вики будет автоматически активирован при первом входе любого пользователя организации:

1.  Перейдите на главную страницу Вики: [https://wiki.yandex.ru](https://wiki.yandex.ru/).

2.  [Войдите в аккаунт](https://yandex.ru/support/wiki/ru/login), который вы используете для работы в организации.

3.  Если ваш аккаунт зарегистрирован в нескольких организациях, выберите ту, в которой вы хотите активировать Яндекс Вики. Затем нажмите кнопку **Продолжить**.

Если ваш аккаунт не зарегистрирован в организации Яндекс 360 для бизнеса, при первом входе в Яндекс Вики будет создана [организация в Yandex Cloud](https://cloud.yandex.ru/ru/docs/organization/).

Для корректного подключения Вики используйте аккаунт в организации Яндекс 360 для бизнеса.

Если у вас не получается подключить Вики к организации Яндекс 360 для бизнеса, обратитесь [в службу поддержки](https://yandex.ru/support/wiki/ru/feedback).

# Мигрировать в Вики из Confluence

Если вы работаете в Confluence и хотите перейти на использование Яндекс Вики, вы можете перенести ваши статьи в Вики. Для этого вам понадобится бэкап базы знаний в формате XML.

Чтобы получить помощь в миграции, обратитесь в техническую поддержку через [форму обратной связи](https://yandex.ru/support/wiki/ru/feedback).
