[Динамическая таблица](https://yandex.ru/support/wiki/ru/pages-types#grid) — таблица с возможностью задать тип данных столбца, отсортировать значения или сделать ячейку обязательной для заполнения.

В новом редакторе Вики динамические таблицы привязаны к страницам как ресурсы. Чтобы создать динамическую таблицу, добавьте ее на страницу в режиме редактирования.

1.  Откройте страницу или [создайте новую](https://yandex.ru/support/wiki/ru/create-page).

2.  В режиме визуального редактора на панели инструментов нажмите → **Динамическая таблица**.

    В результате таблица будет добавлена на страницу. Если переключиться в режиме разметки, в тексте будет указан [код таблицы](https://yandex.ru/support/wiki/ru/wysiwyg/grid#embed).

    Созданная таблица станет [ресурсом текущей страницы](https://yandex.ru/support/wiki/ru/wysiwyg/grid#go-to-source).

3.  Чтобы изменить заголовок таблицы, нажмите на него и введите новый.

4.  Добавьте в таблицу столбцы и [настройте их параметры](https://yandex.ru/support/wiki/ru/wysiwyg/grid#column-params).

5.  [Заполните таблицу](https://yandex.ru/support/wiki/ru/wysiwyg/grid#edit-cell).

# Копировать динамическую таблицу

Чтобы создать копию динамической таблицы:

1.  Нажмите значок **Настройки таблицы** и выберите **Создать копию**.
2.  Введите название копии таблицы.
3.  Если требуется, отредактируйте адрес копии таблицы, созданный автоматически.
4.  Выберите раздел, в котором будет находиться копия таблицы.
5.  Если вы хотите скопировать таблицу вместе с содержимым, включите опцию **Копировать вместе с контентом**.
6.  Нажмите кнопку **Копировать**.

Если вы выделите и скопируете таблицу в визуальном редакторе или скопируете код вставки таблицы в режиме разметки, будет скопирована только ссылка на исходную таблицу с тем же идентификатором. В этом случае все изменения встроенной таблицы автоматически отразятся в исходной таблице и наоборот.

# Импортировать данные в таблицу

Таблицу можно создать из подготовленного файла `.csv`, `.txt`. Подробнее о об этом [в разделе Импорт из файла](https://yandex.ru/support/wiki/ru/import-page#dynamic-table).

Подробнее о работе с динамическими таблицами читайте в разделе [Динамическая таблица](https://yandex.ru/support/wiki/ru/wysiwyg/grid).
