В Яндекс Вики вы можете выбрать, кто будет просматривать и редактировать ваши страницы. Доступ можно настроить только для пользователей, которые состоят в вашей организации.

# Настройки по умолчанию

По умолчанию для верхнеуровневой страницы общего раздела, например wiki.yandex.ru/agency, выбран тип доступа  **Всем сотрудникам**.

Для верхнеуровневой страницы личного раздела, наприме wiki.yandex.ru/users/ivanivanov выбран тип доступа  **Некоторым сотрудникам**.

Все их подстраницы получат тип доступа  **Как у родительской**. Как устроена иерархия страниц, читайте в разделе [Структура Яндекс Вики](https://yandex.ru/support/wiki/ru/structure).

Изменить настройки доступа могут автор и соавторы страницы, а также администратор организации.

# Выбрать тип доступа

Тип доступа — это базовая настройка страницы и определяет круг пользователей, которые смогут ее просмотреть. Вы можете открыть доступ сразу всем сотрудникам или сделать страницу приватной — тогда ее увидят только пользователи, которых вы выберете. Для подстраниц по умолчанию включено наследование настроек от родительской страницы.

1.  Вверху страницы нажмите кнопку с типом доступа, например  **Всем сотрудникам**.

    Администратор организации может изменить настройки страницы, даже если к ней нет доступа: нажмите кнопку **Открыть настройки**.

2.  В разделе **Доступ к странице** выберите вариант:

    -    **Всем сотрудникам** — страницу смогут просмотреть все сотрудники организации.

    -    **Некоторым сотрудникам** — доступ к странице останется только у пользователей из списков **Персональный** и **По ссылке-приглашению**. Авторы могут добавить новых пользователей или группы, которым нужен доступ к странице. [Настроить возможности отдельных пользователей на вики-странице](https://yandex.ru/support/wiki/ru/page-management/access-setup)

    -    **Как у родительской** — доступ к странице получат пользователи, которые добавлены в список **Персональный** на странице верхнего уровня: [Как работает наследование](https://yandex.ru/support/wiki/ru/page-management/access-inheritance). При этом можно открыть доступ и другим пользователям.

        Этот тип доступа можно установить только для страниц второго уровня и ниже: [Структура Яндекс Вики](https://yandex.ru/support/wiki/ru/structure).
