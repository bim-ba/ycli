Если вам нужно периодически выдавать новым пользователям доступ к странице, вы можете создать для них ссылку-приглашение. Когда коллега перейдет по ссылке, доступ для него откроется автоматически.

# Ограничения

-   Ссылка-приглашение работает только для сотрудников организации.

-   Пользователи с доступом по ссылке не увидят структуру раздела, им будет доступна только одна страница.

-   Когда ссылка станет недействительной, у приглашенных пользователей сохранится доступ к странице, они смогут открыть ее по прямой ссылке.

# Создать ссылку-приглашение

1.  Вверху страницы нажмите кнопку с типом доступа, например  **Всем сотрудникам**.

2.  В разделе **Ссылка-приглашение** выберите роль для всех приглашенных пользователей:

    -   **Читатель** — сможет только просмотреть страницу и подстраницы.

    -   **Редактор** — сможет отредактировать страницу и просмотреть подстраницы.

    -   **Редактор +** — сможет отредактировать или удалить страницу, а также создать подстраницу.

3.  Нажмите кнопку  **Создать**.

Ссылка автоматически скопируется в буфер обмена. Чтобы снова скопировать ее, нажмите  **Скопировать**.

# Выбрать срок ссылки-приглашения

Пока ссылка действует, ее срок можно изменить в любой момент.

1.  Нажмите текущий срок, например **3 марта 2026, 18:08** .
2.  Выберите новый срок: **День**, **Неделя**, **Месяц**, **3 месяца** или **Год**.

# Удалить пользователя с доступом по ссылке

Приглашенных пользователей можно посмотреть в настройках доступа, в списке **По ссылке-приглашению**.

Чтобы закрыть доступ для пользователя, нажмите его роль, например **Редактор** , и в выпадающем списке выберите **Удалить**.

Если нужно закрыть доступ для всех приглашенных пользователей, справа от списка нажмите  →  **Удалить всех**.
