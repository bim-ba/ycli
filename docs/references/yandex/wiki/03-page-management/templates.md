Чтобы быстро создавать однотипные страницы, настройте для них шаблоны. О том, как создать страницу из шаблона, читайте в разделе [Использовать шаблон](https://yandex.ru/support/wiki/ru/create-page#template).

# Шаг 1. Создайте шаблон

1.  Перейдите по ссылке [https://wiki.yandex.ru/\_templates](https://wiki.yandex.ru/_templates).
2.  В правом верхнем углу страницы нажмите **Создать шаблон**.
3.  Укажите название и описание шаблона. Вы также можете загрузить свою обложку шаблона: оно будет отображаться в списке шаблонов вместо стандартного.
4.  Нажмите **Создать**.

# Шаг 2. Заполните шаблон

После создания шаблон откроется в режиме редактирования: наполните его информацией. Используйте [язык разметки Yandex Flavored Markdown](https://yandex.ru/support/wiki/ru/wysiwyg/text-format).

-   Чтобы выбрать фон, который отобразится под заголовком шаблона, вверху нажмите  **Действия** → **Добавить обложку**.
-   Чтобы открыть список файлов, которые есть на шаблоне, : вверху нажмите **Действия** → **Ресурсы страницы**.

Когда закончите, вверху нажмите **Сохранить**.

# Редактировать шаблон

1.  Перейдите по ссылке [https://wiki.yandex.ru/\_templates](https://wiki.yandex.ru/_templates).

2.  Выберите шаблон и нажмите на него. Откроется страница предпросмотра шаблона.

3.  Нажмите кнопку **Редактировать**.

4.  Когда закончите, вверху нажмите **Сохранить**.

# Применить шаблон

1.  Перейдите по ссылке [https://wiki.yandex.ru/\_templates](https://wiki.yandex.ru/_templates).

2.  Наведите указатель на шаблон и нажмите **Использовать**.

3.  Если нужно, внесите изменения и нажмите **Опубликовать**.

Также вы можете выбрать шаблон в режиме создания страницы: как это сделать, рассказали в разделе [Использовать шаблон](https://yandex.ru/support/wiki/ru/create-page#template).

# Настроить доступ к шаблону

По умолчанию шаблон виден только его автору. Чтобы другие пользователи могли использовать шаблон, настройте к нему доступ:

1.  Перейдите по ссылке [https://wiki.yandex.ru/\_templates](https://wiki.yandex.ru/_templates).

2.  Выберите шаблон и нажмите на него. Откроется страница предпросмотра шаблона.

3.  Вверху страницы нажмите кнопку с типом доступа, например  **Всем сотрудникам**.

4.  В разделе **Доступ к шаблону** выберите вариант:

    -    **Всем сотрудникам** — шаблон станет доступен всем сотрудникам организации.
    -    **Некоторым сотрудникам** — укажите пользователей или группы, которым нужно открыть доступ.
5.  Чтобы добавить пользователя в список доступа, в разделе **Добавьте сотрудника или группу** начните вводить имя или название группы.

6.  В выпадающем списке справа выберите роль:

    -   **Читатель** — сможет применить шаблон.
    -   **Соавтор** — сможет отредактировать шаблон.

Изменения сохранятся автоматически.
