# Создать копию страницы

Вы можете создать копию любой страницы Вики:

1.  В правом верхнем углу страницы нажмите **Действия** и выберите **Создать копию**.

2.  Заголовок страницы можно изменить или оставить таким же.

3.  Выберите, в каком разделе будет создана копия страницы.

4.  Поле **Адрес страницы** заполнится автоматически.

5.  Нажмите кнопку **Копировать**.
