# Скачать файл по ID




Скачать файл по постоянному идентификатору


## Request






GET


    
        
```
https://api.wiki.yandex.net/v1/pages/{idx}/attachments/{file_id}/download
```


        
            
            
        
    




### Path parameters



| Name | Description |
| --- | --- |
| file_id | Type: integer |
| idx | Type: integer |


## Responses




## 200 OK



OK
