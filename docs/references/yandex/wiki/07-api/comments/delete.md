# Удалить комментарий




## Request






DELETE


    
        
```
https://api.wiki.yandex.net/v1/pages/{idx}/comments/{comment_id}
```

| Name | Description |
| --- | --- |
| comment_id | Type: integer |
| idx | Type: integer |

## 200 OK



OK
