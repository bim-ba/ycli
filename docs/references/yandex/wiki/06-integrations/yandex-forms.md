[Яндекс Формы](https://forms.yandex.ru/cloud/admin) — это сервис, где вы можете проводить опросы, тесты и квизы, собирать отзывы и принимать заявки. Подробнее о возможностях сервиса читайте в [документации Яндекс Форм](https://yandex.ru/support/forms/).

# Добавить ответ на страницу Вики

Вы можете сохранять ответы пользователей, которые заполнили форму, на странице Вики. Для этого настройте интеграцию с Вики в форме: [Добавить ответ на Вики](https://yandex.ru/support/forms/send-wiki.html).

# Вставить магическую ссылку на форму

Магическая ссылка на форму содержит иконку сервиса и название формы. Чтобы добавить магическую ссылку, вставьте в текст Вики-страницы полный адрес формы, например:

```
https://forms.yandex.ru/cloud/u/1a2b345cd6s/
```

# Встроить форму на страницу Вики

Чтобы вставить форму на страницу:

Визуальный редактор

Разметка Markdown

1.  [Скопируйте ссылку](https://yandex.ru/support/forms/publish.html#section_link) на форму, которую хотите вставить на страницу.

2.  На панели инструментов нажмите **Другие действия**, затем выберите **Яндекс Формы**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

3.  Вставьте скопированный адрес формы и нажмите **Сохранить**.

Чтобы вставить форму в режиме разметки Markdown, используйте код:

```
{% forms src="<ссылка на форму>" %}
```
