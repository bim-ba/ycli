[Яндекс Трекер](https://tracker.yandex.ru/) — это сервис для управления проектами и процессами. Подробнее о возможностях сервиса читайте в [Справке Трекера](https://yandex.ru/support/tracker).

Пользователи Яндекс Трекера могут размещать на страницах Вики *магические ссылки* на список задач или отдельные сущности: задачи, очереди, компоненты, проекты, портфели, цели и дашборды. Внешний вид таких ссылок будет изменяться в зависимости от того, что происходит с сущностью: кто ее исполнитель, какой у нее статус и так далее. Подробнее о магических ссылках читайте на странице [Ссылки](https://yandex.ru/support/wiki/ru/wysiwyg/links).

# Ссылка на задачу

Чтобы добавить в Вики ссылку на задачу, скопируйте ее ключ и вставьте в текст страницы. Такая ссылка содержит логотип Трекера, ключ, название, статус задачи и имя исполнителя, если он назначен. [Что такое ключ задачи](https://yandex.ru/support/tracker/user/create-ticket.html#key)

# Ссылка на другую сущность в Трекере

Чтобы добавить в Вики магическую ссылку, скопируйте полный адрес проекта, портфеля, цели, дашборда, очереди или компонента и вставьте в текст страницы. Такая ссылка содержит логотип Трекера, значок типа сущности и название. Ссылка на некоторые сущности содержит и другие элементы, например, статус и дедлайн.

```
https://tracker.yandex.ru/pages/projects/1234
```

# Ссылка на список задач

Чтобы разместить на странице автоматически сформированный фильтр задач или список задач очереди:

Визуальный редактор

Разметка Markdown

1.  На панели инструментов нажмите **Другие действия**, затем выберите **Список задач**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2.  Укажите ключ очереди или ссылку на фильтр задач из адресной строки браузера.

Чтобы вставить список задач в режиме разметки Markdown, используйте код:

```
{% tasks url="<ключ очереди или ссылка на фильтр>" %}
```

В списке может отображаться не более 50 задач.

# Список задач с параметрами

С помощью динамических таблиц вы можете разместить на странице Вики список задач и их основные параметры:

1.  [Создайте](https://yandex.ru/support/wiki/ru/wysiwyg/grid#add) динамическую таблицу.

2.  [Добавьте столбец](https://yandex.ru/support/wiki/ru/wysiwyg/grid#column-params) с типом данных **Задача в Трекер**.

3.  Добавьте необходимое количество строк и перечислите в них ключи задач. [Что такое ключ задачи](https://yandex.ru/support/tracker/user/create-ticket.html#key)

4.  Создайте дополнительные столбцы. В качестве типа данных выберите **Параметры задачи**.

    Доступные параметры задачи:

    -   Заголовок
    -   Тип
    -   Исполнитель
    -   Автор
    -   Статус
    -   Приоритет
    -   Дата создания
    -   Дата обновления
    -   Первоначальная оценка
    -   Исправить в версиях
    -   Компоненты
    -   Story Points
    -   Дедлайн
    -   Описание
    -   Дата завершения
    -   Оценка времени
    -   Наблюдатели
    -   Последний комментарий (дата обновления)
    -   Родительская задача
    -   Нужен ответ пользователя
    -   Проект
    -   Очередь
    -   Резолюция
    -   Дата резолюции
    -   Спринт
    -   Дата начала
    -   Статус изменён
    -   Тип статуса
    -   Теги
    -   Голоса

5.  Сохраните таблицу.
