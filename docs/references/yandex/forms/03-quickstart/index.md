1.  [Add questions to your form to collect users' answers](https://yandex.ru/support/forms/en/quick-guide#create-form).

2.  [Publish your form and ask users to fill it out](https://yandex.ru/support/forms/en/quick-guide#publish).

3.  [Get a table with user answers](https://yandex.ru/support/forms/en/quick-guide#get-answers).

4.  [Set up access to the form](https://yandex.ru/support/forms/en/quick-guide#access).

# Step 1. Create a form

1.  Open the desired version of Yandex Forms: in the upper-left corner of the page, select Personal forms or Forms for business. To learn more about their differences, see [Forms for personal use and for business](https://yandex.ru/support/forms/en/go-to-forms).

2.  On the top panel, click **Create form**.

3.  Under **Select a question**, click **Show all questions** and arrange the questions in the following order:

# Step 2. Publish the form

To allow users to fill out the form, you need to publish it:

1.  Click **Publish**.

4.  Send users a link to the form.

# Step 3. Get the answers to questions

To get a table with user answers to form questions:

1.  Go to the **Answers** tab.

2.  Above the question list, select the **Feed** view mode.

3.  Specify the period for which to export answers:

    -   Click **All time** .
    -   In the pop-up window, go to the **Other** tab.
    -   Select **This month**.
4.  Specify the questions for which to export answers:

    -   Above the question list, click **All questions**.
    -   Keep only the **Last name** and **Gender** options selected.
5.  Specify the output file format:

    -   Click **XLSX** .
    -   In the pop-up window, select **CSV**.
6.  To the right of the format selection button, click **Download**.

# Step 4. Set up access to the form

By default, only the author can edit a form. If you are using Forms for business, you can give your colleagues access to edit the form or groups of forms: [Configuring access to a form](https://yandex.ru/support/forms/en/access).
