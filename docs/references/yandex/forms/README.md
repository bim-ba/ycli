# Yandex Forms — Reference

Normalized 1:1 mirror of the Yandex Forms API + product documentation (HTML→MD), relocated from the
`yandex-360-forms` skill in sub-project G/M2. Leaf files keep their vendor filenames (URL-traceable);
navigate via [`index/docs.md`](index/docs.md) or `rg` over this tree.

## Layout

- `01-overview/` … `09-api/` — the vendor docs by topic section (9 directories; `08-questions/` =
  the 26 question types, `09-api/` = the public API reference under `09-api/reference/`).
- [`index/docs.md`](index/docs.md) — curated navigation guide to all 110 doc files.
