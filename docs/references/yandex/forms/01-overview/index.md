Yandex Forms is a service for running surveys. For example, you can use it to collect feedback and accept applications.

In Yandex Forms, you have access to a wide variety of questions to easily configure any survey or test. Forms can be placed on a website or shared via a link. You can view answers to your questions in the service interface or have them sent to your email.

Yandex Forms can be a handy tool for personal use — for example, you can run a survey among your friends or compose a menu for your New Year's party. You can also use Forms for your work tasks or to receive orders for your business.

If you want to use the Forms together with your colleagues, create an organization in Yandex 360 for Business and connect the Forms for business. You can allow other users from your organization to edit your forms, view responses, and set up integration with Tracker and Wiki. For more information, see [About Yandex Forms for Business](https://yandex.ru/support/forms/en/go-to-forms#business-features).

# How to create and set up a form

Use the form builder to add questions and configure their parameters. In Yandex Forms, you can use various question types with specific answer formats, such as single or multiple choices from a list, text answers, numbers, dates, and email addresses.

-   [How to create your first form](https://yandex.ru/support/forms/en/quick-guide)

-   [All question parameters with examples](https://yandex.ru/support/forms/en/blocks-ref/blocks-reference)

# Question and answer logic

In Yandex Forms, you can set conditions for showing questions and restrict responses:

-   [How to make a question required](https://yandex.ru/support/forms/en/add-questions#params). If a user skips a required question, they won't be able to submit the form.

-   [How to configure when a question appears based on the user's answers to previous questions](https://yandex.ru/support/forms/en/add-questions#conditions). For example, you can configure a field for the email address to appear only if the user agreed to subscribe to your newsletter.

-   [How to limit the number of respondents or set a timeframe for submitting a response](https://yandex.ru/support/forms/en/restrictions).

# How to publish a form

You can publish a form in several ways:

-   Via a link. Send a link to the form in a messenger or post it on your socials.
-   Embed the form in a website using HTML code. Add a feedback form to your company's website.
-   Embed the form in a Wiki page. This option is available to Yandex 360 for Business organization users.

For more information about publishing forms, see [Publishing a form](https://yandex.ru/support/forms/en/publish).

# How to get responses to a form

There are several ways to get user answers:

-   View answers in the Yandex Forms interface.
-   Download a file with answers.
-   Upload the file with answers to Yandex Disk.
-   Forward responses via email.

For more information about exporting answers, see [Getting responses](https://yandex.ru/support/forms/en/answers).
