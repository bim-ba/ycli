# Setting the interface language

You can use Yandex Forms in English or Russian:

1.  In the panel on the left, click  **Settings**.

2.  Under **Language and region**, choose your preferred language.

# Customizing the appearance

1.  In the panel on the left, click  **Settings**.

2.  In the  **Interface** section, you can set up:

    -   **Interface theme**. You can select the light, dark, or system theme.
    -   **Contrast**. You can set up the standard or maximum contrast.
