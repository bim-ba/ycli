You can configure a form to pre-fill fields with the user's previous answers when they reopen it. This is useful if the form is supposed to be completed multiple times or if a user accidentally closes the tab without submitting their response.

As the user fills out the form, their answers are saved automatically, even if they haven't submitted them yet. When they reopen the form, everything they entered will remain in place.

To save previous answers:

1.  Select a form and go to **Settings** → **Additional**.

2.  Enable ![](https://yandex.ru/support/forms/docs-assets/support-forms/rev/r19697197/en/_assets/enabled-switch-blue.png) **Autofill the form with previous user answers**.

3.  Click **Save**.

The user can view previous answers only if they fill out the form using the same Yandex account. You can see all answers on the answers page: [Getting responses](https://yandex.ru/support/forms/en/answers).
