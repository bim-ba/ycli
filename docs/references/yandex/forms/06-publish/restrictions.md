When publishing a form, you can limit the period for submitting responses and the total number of responses. You can also restrict access by only allowing responses from employees in your Яндекс 360 для бизнеса organization.

# Set a date and time to close the form

To limit the period during which users can fill out the form:

1.  Select a form and go to **Settings** → **Additional**.

2.  Under **Timeframe for accepting responses**, enable the **Limited time** option.

3.  Set the date and time range for when you want the form to be active. These restrictions will apply in the context of your time zone and current time.

4.  Click **Save**.

# Limit the number of respondents

To limit the total number of respondents that can fill out the form:

1.  Select a form and go to **Settings** → **Additional**.

2.  Under **Other**, enable ![](https://yandex.ru/support/forms/docs-assets/support-forms/rev/r19697197/en/_assets/enabled-switch-blue.png) **Limit the total number of answers in the form** and enter a number. When the limit is reached, access to the form is closed.

3.  Click **Save**.

To disable form resubmission, [generate unique keys](https://yandex.ru/support/forms/en/publish#personal-link). If a user follows a unique link key, they can only fill out the form once.

# Only allow responses from employees

By default, any user can fill out the form. If you're using Forms for business, you can restrict access to only allow employees in your organization to fill out the form:

1.  Select the form and open the **Settings** → **Access** tab.

2.  Under **Who can fill out the form**, select:

    -   **Staff only**.

    -   **Selected employees**. Only the listed employees can edit the form.

    You can also specify the name of the group from your Яндекс 360 для бизнеса organization to grant access to multiple employees at once.

3.  Click **Save**.
