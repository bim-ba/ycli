You can view responses in the Yandex Forms interface, download them as a file, or save them to Yandex Disk.

To have responses sent to your mailbox, [set up integration with Yandex Mail](https://yandex.ru/support/forms/en/send-mail).

# Viewing responses

1.  Select a form and open the **Answers** tab.

2.  Select the display format:

    Statistics

    Feed

    Table

    The tab displays the questions and answer statistics. You can see how many answers each question has. For multiple-choice questions, you can see the vote distribution. You can see the statistics only for the whole survey period.

    The tab displays a sequence of responses. Responses load as you scroll down the page. You can collapse or expand a response by clicking or .

    To share a response, click to copy the link. The link is available to:

    -   Authorized users.
    -   Form creators and users with editing rights to the form.
    -   Author of the response.

    The tab displays a table with responses: rows correspond to the survey ID, while columns correspond to questions in the form.

3.  To select responses for a specific period, click **For all time** , set the start and end of the period, then click **Apply**. The data on the  **Feed** and  **Table** tabs will be updated. There is no filtering on the  **Statistics** tab, so statistics will be shown for all time.

4.  To select answers to certain questions, click **All questions**, select the questions you need from the list and click **Save**. The data in the  **Statistics** and  **Feed** tabs will be updated.

# Getting form attachments

Files attached to a form can be viewed in the list of responses in the **Feed** tab or downloaded to Yandex Disk:

View a file in Yandex Forms

Files uploaded to Yandex Disk

1.  Open the list of responses as described in [Viewing responses](https://yandex.ru/support/forms/en/answers#view).

    Files attached to a response are available via links only to the employees who have edit rights to the form. These files can't be downloaded automatically using robots or scripts.

2.  Find the response you need in the  **Feed** tab and click the link with the name of the attached file. You can view the file in a browser or download it to your computer.

    If you send a file link to another user, they will need to [log in to their Yandex account](https://passport.yandex.com/auth) to view the file.

    Attached files are stored on the Yandex Forms server for 3 months. After that, the files are deleted. We recommend [saving files to Yandex Disk](https://yandex.ru/support/forms/en/answers#download) or downloading them to your computer.

Save responses to Yandex Disk as described in [Download](https://yandex.ru/support/forms/en/answers#download). You can find the attached files at `Yandex.Forms/<Form_ID>/Files`

Yandex Disk stores files for an indefinite time. To download or share a file, select it and click  **Download** or  **Share** in the top panel.

# Archiving responses

Form responses are automatically archived if you haven't viewed or downloaded them in more than three months. Responses in Forms for Business are not archived.

After archiving, you can [view the list of responses, download them in a file, or save them to Yandex Disk](https://yandex.ru/support/forms/en/answers#download). Note that it will take several minutes to retrieve the responses from the archive.

# Deleting responses

You can't delete responses in Yandex Forms. If you want to clear all of the received responses and use the same form again, create a copy of the form:

1.  On the Yandex Forms top panel, select **My forms**.

2.  Select a form and hover over it.

3.  Click the and select **Copy**. All [questions](https://yandex.ru/support/forms/en/add-questions) and [settings](https://yandex.ru/support/forms/en/appearance) will be moved to the new form, but without the old responses.

4.  At the top of the page, you'll see a notification that the form has been copied. Click **Go to form**.

5.  [Share](https://yandex.ru/support/forms/en/publish) a new link to the form.
