You can use Forms to make a test or quiz. You can test people's knowledge on some topic or make a humorous quiz that can be shared on social media. Users earn points for correct answers and can see their score after finishing the test.

# Adding questions for a test

To create a test, add question blocks from the **Tests and quizzes** category to your form:

1.  Create a new form or open an existing one.

2.  In the form builder, create a test question using one of the following methods:

    -   In the **Form builder** tab, click **Show all questions** and select a question from the **Test (Quiz)** column.

    -   Create a simple question for the test, then click **Score** under **Answer**. For a list of suitable question types, see [Tests and quizzes](https://yandex.ru/support/forms/en/blocks-ref/tests).

3.  Specify the question parameters:

    -   Enter your question. If needed, add a comment or attach an image.

    -   For the **One answer** and **Multiple answers** question types, set the answer options. For other question types, specify the correct answer.

    -   Specify how many points users should get for answering correctly.

        The **One answer** and **Multiple answers** question types can have multiple correct answers. The user receives points only if they select all the correct answers and don't pick any incorrect ones.

    -   Under **Settings**, configure answer validation or sorting if needed.

        For more information about configuring question parameters, see [Add questions to a form](https://yandex.ru/support/forms/en/add-questions).

4.  Add other questions to your form by following the same steps.

5.  To change the position of a question or an answer option, drag it with .

6.  Set up rules for scoring the test.

7.  Publish your test using one of the following methods: [Publishing a form](https://yandex.ru/support/forms/en/publish).

# Setting up scoring

After the user completes the test, you can show them their scored points and results. You can calculate test results using one of the following methods:

-   Two-level: Pass or fail.

-   Multi-level: Results labeled in segments. For example: professional, amateur, and beginner.

To set up rules for scoring:

1.  Select a form and go to **Settings** → **Tests and quizzes**.

2.  Enable **Show test results** ![](https://yandex.ru/support/forms/docs-assets/support-forms/rev/r19697197/en/_assets/enabled-switch-blue.png).

    Note: If you show test results, you can't [redirect users to a website](https://yandex.ru/support/forms/en/success-page#redirect) or [display a message](https://yandex.ru/support/forms/en/success-page#message) when they submit the form.

3.  Select the scoring method:

    -   **Segments**: For multi-level scoring. If you select this option, set the number of segments (scoring levels). The number of points that corresponds to each segment is determined automatically.

    -   **Pass/Fail**: For two-level scoring. If you select this option, specify the minimum number of points that constitutes a passing score.

4.  Enter a message to display to the user for each assessment:

    -   Specify a header like You're an avid traveler!

    -   Write a comment. For example, suggest materials that the user can read to improve their result. To format the text of a comment, use [Markdown markup](https://yandex.ru/support/forms/en/appearance#text-formatting).

    -   To add a picture to an answer option, click **Add an image**.

5.  Click **Save**.

Avoid merging questions from the **Tests and quizzes** category into a [series](https://yandex.ru/support/forms/en/blocks-ref/series), as this prevents scoring from working.

# Show correct and incorrect answers

Once the user completes the test, you can show them which answers were right or wrong:

1.  Select a form and go to **Settings** → **Tests and quizzes**.

2.  Enable **Show test results** ![](https://yandex.ru/support/forms/docs-assets/support-forms/rev/r19697197/en/_assets/enabled-switch-blue.png).

3.  Enable **Show correct and incorrect answers** ![](https://yandex.ru/support/forms/docs-assets/support-forms/rev/r19697197/en/_assets/enabled-switch-blue.png).

4.  Click **Save**.

After completing the test, users can click **See correct answers**. This opens a page showing the user's score, with correct and incorrect answers highlighted.

# View user answers

When the test is submitted, you can see which questions were answered correctly and which were wrong in the [**Answers**](https://yandex.ru/support/forms/en/answers) tab.
