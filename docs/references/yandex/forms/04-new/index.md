To conduct a survey, collect votes, accept requests, or take orders, create a form:

1.  Open the desired version of Yandex Forms: in the upper-left corner of the page, select Personal forms or Forms for business. To learn more about their differences, see [Forms for personal use and for business](https://yandex.ru/support/forms/en/go-to-forms).

2.  Select a template for your form or click **Create blank form** in the top panel.
3.  To rename the form, click the `New form` title.
4.  In the **Constructor** tab, add questions that the user will need to answer.
    To learn how to configure question parameters, see [Add questions to a form](https://yandex.ru/support/forms/en/add-questions).
5.  In the **Theme** tab, configure the background, text color, and button names: [Customizing the appearance of a form](https://yandex.ru/support/forms/en/appearance).
6.  See what your form will look like when you publish it by clicking **Preview**.
7.  To limit the number of respondents or set a timeframe for submitting a response, go to the **Settings** tab and follow the instructions provided on the [Restricting form completion](https://yandex.ru/support/forms/en/restrictions) page.
8.  Publish the form: click **Publish** above the list of questions and share the link.
    For information about different publication methods, see [Publishing a form](https://yandex.ru/support/forms/en/publish).
9.  If you're using Forms for business, you can set up access to the form for other employees from your organization: [Configuring access to a form](https://yandex.ru/support/forms/en/access).

# Copying a form

To create a new form based on an existing one, copy the form and edit it:

1.  Open the desired version of Yandex Forms: in the upper-left corner of the page, select Personal forms or Forms for business. To learn more about their differences, see [Forms for personal use and for business](https://yandex.ru/support/forms/en/go-to-forms).

2.  Select a form under **List of forms and groups**.

3.  Hover over it and click → **Copy**.
4.  A success message will appear at the bottom of the page. Inside that message, click **Go to form**.
5.  Edit questions and adjust the settings for the new form.

# Using a template

The service offers templates for forms most commonly created by users. To create a form based on a template:

1.  Open the desired version of Yandex Forms: in the upper-left corner of the page, select Personal forms or Forms for business. To learn more about their differences, see [Forms for personal use and for business](https://yandex.ru/support/forms/en/go-to-forms).

2.  Select a template under **Create form**:

    -   **Feedback form**: Collect user reviews.
    -   **Questionnaire**: Conduct surveys on any topic.
    -   **Application**: Accept orders and requests for services.
    -   **Registration for an event**: Accept applications for participating in an event.

    To create a form from scratch, select **Create blank form**.

3.  Edit the template as needed: you can change the texts and add or delete questions.

4.  Publish the form: click **Publish** above the list of questions and share the link.
