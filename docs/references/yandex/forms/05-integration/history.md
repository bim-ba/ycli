To view the history of completed actions, select a form, go to **Integration**, and click **Completed integrations**.

To filter the list of actions performed, use the fields above the list.

Data on actions performed is stored for 90 days and then permanently deleted.

# Integration errors

If there's something wrong with an integration when fetching responses to your form, and the [set actions](https://yandex.ru/support/forms/en/notifications#add-integration) can't be completed, you'll see an error message appear in the action settings card.

1.  Check the action settings and make any necessary changes.

2.  To view the list of responses on which the action failed, click **Show**.

3.  To retry the actions, select the lines with the **Error** status and click **Restart**.

For more information, see:

-   [Troubleshooting mail integration issues](https://yandex.ru/support/forms/en/send-mail#troubleshooting)

-   [Troubleshooting Yandex Tracker integration issues.](https://yandex.ru/support/forms/en/create-task#troubles)

-   [Troubleshooting HTTP request sending issues](https://yandex.ru/support/forms/en/send-request#filters)

# Set up error notifications

To have notifications about integration issues sent to an email address:

1.  Select a form and go to **Settings** → **Additional**.

2.  Under **Notify about integration errors**, set the frequency of notifications.

    If you select an interval, a single notification is sent with a list of all errors that occurred during this interval.

3.  If you are using [Yandex Forms for Business](https://yandex.ru/support/forms/en/go-to-forms#business-features), specify the users who will receive emails in the **Add recipients** field.
