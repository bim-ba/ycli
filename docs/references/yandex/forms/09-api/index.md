The Yandex Forms API enables web services and applications to interact with your organization's forms on behalf of users. When making API requests on behalf of a specific user, they carry the same access permissions as that user has in Yandex Forms. For example, if the user doesn't have permissions to receive form responses, the user can't make API requests to retrieve them with this token.
