Вы можете сформировать отчет по количеству времени, затраченного исполнителями на выполнение задач из выбранного списка. В отчет попадают только задачи, для которых ведется [учет времени](https://yandex.ru/support/tracker/ru/user/time-spent). Отчет сохраняется в виде файла в формате XLSX.

Чтобы создать отчет по трудозатратам:

1. На панели слева нажмите  **Дашборды и отчёты** и перейдите на вкладку **Отчёты**.

2. В правом верхнем углу нажмите **Создать** и выберите **Отчёт по трудозатратам**.

    Вы также можете выгрузить отчет по задачам на странице [очереди](https://yandex.ru/support/tracker/ru/user/queue), [проекта](https://yandex.ru/support/tracker/ru/manager/project-list) или в [фильтре задач](https://yandex.ru/support/tracker/ru/user/default-filters). Подробнее об этом читайте в разделе [Отчет по трудозатратам](https://yandex.ru/support/tracker/ru/user/reports#time-spent-report).

3. Введите название отчета.

4. Укажите источник задач:

    - **Фильтр**: вы можете выбрать один из доступных вам фильтров. [Как найти задачи по любым параметрам](https://yandex.ru/support/tracker/ru/user/create-filter)
    - **Язык запросов**: составьте запрос для выбора задач. [Как использовать язык запросов](https://yandex.ru/support/tracker/ru/user/query-filter)
    - **Параметры**: вы можете добавить параметры для поиска задач.
5. Укажите параметры задач, которые хотите сохранить в отчет: начните вводить название параметра, затем выберите его в списке.

    [Локальные поля](https://yandex.ru/support/tracker/ru/local-fields) объединены в группы, обозначенные ключом очереди, к которой они относятся.

6. При необходимости выберите опцию **Разбить трудозатраты по дням**. В этом случае отчет будет сформирован в виде таблицы с двумя листами:

    - **Табель (по тикетам)**: список задач и данные по затраченному времени с разбивкой по дням.
    - **Табель (по очередям)**: список очередей и данные по затраченному времени с разбивкой по дням.
7. Укажите период, за который вы хотите получить отчет.

8. Укажите исполнителей, которые должны попасть в отчет:

    - **Все**: в отчет попадут все исполнители задач, соответствующих фильтру.
    - **Указанные сотрудники**: в отчет попадут выбранные вами исполнители задач, соответствующих фильтру.
9. Нажмите **Сформировать отчет**.

10. Подождите, пока отчет сформируется, и нажмите кнопку **Скачать**.
