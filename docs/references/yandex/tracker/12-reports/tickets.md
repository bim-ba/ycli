Отчет по задачам представлен в виде списка задач с выбранными параметрами.

Чтобы создать отчет по задачам:

1. На панели слева нажмите  **Дашборды и отчёты** и перейдите на вкладку **Отчёты**.

2. В правом верхнем углу нажмите **Создать** и выберите **Отчёт**.

    Вы также можете выгрузить отчет по задачам на странице [очереди](https://yandex.ru/support/tracker/ru/user/queue), [проекта](https://yandex.ru/support/tracker/ru/manager/project-list) или в [фильтре задач](https://yandex.ru/support/tracker/ru/user/default-filters). Подробнее об этом читайте в разделе [Отчет по задачам](https://yandex.ru/support/tracker/ru/user/reports#ticket-report).

3. Введите название отчета.

4. Укажите параметры задач, которые хотите сохранить в отчет: начните вводить название параметра, затем выберите его в списке.

    [Локальные поля](https://yandex.ru/support/tracker/ru/local-fields) объединены в группы, обозначенные ключом очереди, к которой они относятся.

5. Выберите формат: **XML**, **CSV** или **XLSX**.

6. Укажите источник задач:

    - **Фильтр**: вы можете выбрать один из доступных вам фильтров. [Как найти задачи по любым параметрам](https://yandex.ru/support/tracker/ru/user/create-filter)
    - **Язык запросов**: составьте запрос для выбора задач. [Как использовать язык запросов](https://yandex.ru/support/tracker/ru/user/query-filter)
    - **Параметры**: вы можете добавить параметры для поиска задач.
7. Нажмите **Сформировать отчет**.

8. Подождите, пока отчет сформируется, и нажмите кнопку **Скачать**.
