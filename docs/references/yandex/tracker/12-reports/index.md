Отчет в Яндекс Трекере — это документ, в котором содержатся сведения о задачах, отобранных по заданному условию.

Чтобы создать отчет:

1. На панели слева нажмите  **Дашборды и отчёты** и перейдите на вкладку **Отчёты**.

2. В правом верхнем углу нажмите **Создать** и выберите:

    - **Отчёт**, чтобы создать сформировать список задач с выбранными параметрами. Подробнее в разделе [Отчет по задачам](https://yandex.ru/support/tracker/ru/user/ticket-report).
    - **Отчёт по трудозатратам**, чтобы сформировать отчет по количеству времени, затраченного на выполнение задач. Подробнее в разделе [Отчет по трудозатратам](https://yandex.ru/support/tracker/ru/user/time-spent-report).

Вы также можете сформировать отчет странице [очереди](https://yandex.ru/support/tracker/ru/user/queue), [проекта](https://yandex.ru/support/tracker/ru/manager/project-list) или в [фильтре задач](https://yandex.ru/support/tracker/ru/user/default-filters). Подробнее читайте в разделе [Как выгрузить отчет по задачам, которые вы нашли с помощью фильтра](https://yandex.ru/support/tracker/ru/user/reports).

# Найти отчет

Чтобы найти отчет:

1. На панели слева нажмите  **Дашборды и отчёты** и перейдите на вкладку **Отчёты**.

2. Чтобы отфильтровать отчеты, вверху списка выберите один из вариантов:

    - **Созданные мной**;
    - **Избранные**;
    - **Недавно просмотренные**.
3. Чтобы найти отчет в списке, введите часть названия отчета в поле **Поиск по названию**.

Отчеты представлены в виде списка, где указаны наименование отчета, его автор и статус.

В списке также отображаются отчеты, созданные в [очередях](https://yandex.ru/support/tracker/ru/user/queue), [проектах](https://yandex.ru/support/tracker/ru/manager/project-list) или [фильтрах задач](https://yandex.ru/support/tracker/ru/user/default-filters).

# Добавить отчет в избранное

Чтобы добавить отчет в избранное, рядом с названием отчета в списке нажмите значок .

# Скачать отчет

Для скачивания доступны отчеты со статусом «Готов». Если при формировании отчета произошла ошибка, отчет имеет статус «Не сформирован». Попробуйте сформировать отчет повторно.

Чтобы скачать отчет:

1. Найдите нужный отчет в списке и нажмите на соответствующую строку.

2. В правом верхнем углу страницы нажмите **Скачать**.

# Ограничить выгрузку задач в отчеты

Если вы хотите, чтобы информация о задачах не попадала в отчеты, вы можете ограничить выгрузку задач в [настройках очереди](https://yandex.ru/support/tracker/ru/manager/edit-queue-general).

Для этого выберите одно из значений опции **Ограничить выгрузку задач в отчёты**:

- **Без ограничений** — в отчет попадут все выбранные параметры задач.
- **Исключить описание задач** — для задач вашей очереди в отчете будет скрыто описание.
- **Запретить выгрузку задач** — задачи вашей очереди не попадут в отчет.
