Вы можете автоматизировать работу с задачами в Трекере с помощью триггеров, автодействий и макросов. Эти инструменты помогут вам минимизировать время, затрачиваемое на рутинные операции: например, изменение статуса задачи, призыв сотрудника или создание подзадачи с определенными параметрами.

# Триггеры

Действия над задачами очереди, которые выполняются при наступлении определенных событий. Например, если изменился статус задачи или если на задачу подписался определенный пользователь, триггер может изменить параметры задачи, оставить комментарий или отправить HTTP-запрос для обращения к API других сервисов и настройки интеграций.

# Автодействия

Действия над задачами очереди, которые запускаются автоматически с заданной периодичностью. При помощи автодействий можно настроить периодические обновления задач в очереди: например, проверять задачи с определенными компонентами и назначать исполнителя, если он не назначен, или создавать задачи на резервное копирование данных.

Действия, которые можно запустить по кнопке на странице задачи. Макросы позволяют автоматизировать рутинные действия: изменять параметры задачи и создавать типовые комментарии.

# Управлять автоматизациями

## Просмотреть автоматизации очереди

Чтобы открыть список всех автоматизаций, которые настроены в очереди:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. На панели слева выберите **Автоматизация**.

4. Настройте отображение списка автоматизаций:

    - Чтобы отфильтровать список по типам автоматизаций, нажмите **Тип автоматизации** и выберите типы из списка.

    - Чтобы отфильтровать список по типам действий, которые выполняет автоматизация, нажмите **Тип действия** и выберите действия из списка.

    - Чтобы найти автоматизацию в списке, введите ее название или идентификатор в поле поиска.

## Изменить автоматизации

- Чтобы изменить настройки автоматизации, нажмите на нее.

- Чтобы отключить или включить автоматизацию, измените положение переключателя справа от нее.

- Чтобы удалить автоматизацию без возможности восстановления, нажмите →  **Удалить**.

После удаления автоматизации она может отображаться в списке еще несколько секунд.

## Изменить владельца автоматизации

1. Выберите автоматизацию в списке и нажмите на нее.

2. В левом верхнем углу страницы наведите курсор на имя владельца и нажмите кнопку  **Изменить**.

3. В строке поиска введите имя или логин пользователя.

4. Нажмите **Сохранить**.
