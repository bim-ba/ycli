# Закрыть задачу и уведомить пользователя

Предположим, что сотрудники службы поддержки регистрируют обращения пользователей в Трекере. После того как работа по обращению выполнена, задачу нужно закрыть и отправить пользователю уведомление о решении его обращения. Настроим макрос, который будет выполнять эти действия:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. На панели слева выберите **Автоматизация**.

4. В правом верхнем углу нажмите кнопку **Создать** → **Макрос**.

5. Задайте название макроса.

6. Напишите текст комментария. Вы можете добавить в письмо параметры задачи с помощью кнопки  **Переменные**.

7. Чтобы макрос закрывал задачу, в блоке **Изменить значение в поле** выберите **Статус** → **Установить значение** → **Закрыт**.

8. Нажмите **Создать макрос**.

Чтобы выполнить созданный макрос:

1. Откройте любую задачу в очереди, в которой вы создали макрос.

2. В поле для ввода комментария нажмите  **Макросы** и выберите название вашего макроса.

3. Нажмите кнопку **Выполнить**. Будет добавлен комментарий, а задача перейдет в статус **Закрыт**.
