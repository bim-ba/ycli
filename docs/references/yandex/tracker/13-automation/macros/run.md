Чтобы выполнить макрос:

1. Откройте страницу задачи.

2. Нажмите кнопку  **Макросы**. На странице задачи кнопка расположена в двух областях:

    - В нижней части блока для ввода комментария.
    - В шапке задачи в правом верхнем углу.
3. Выберите макрос из раскрывающегося списка.
    Вы можете выбрать несколько макросов одновременно. Если макросы изменяют один и тот же параметр, к параметру будет применен макрос, который выбран последним.

4. При необходимости отредактируйте комментарий, который будет добавлен макросом, и нажмите кнопку **Выполнить**.
