Макрос в Трекере — это запрограммированный набор операций, который можно запустить на странице задачи. Используйте макросы, чтобы автоматизировать рутинные действия. Макросы позволяют в одно нажатие изменять параметры задачи, создавать типовые комментарии.

У каждой очереди в Трекере свой набор макросов. Чтобы создать для очереди новый макрос:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. На панели слева выберите **Автоматизация**.

4. В правом верхнем углу нажмите кнопку **Создать** → **Макрос**.

5. Введите название макроса.
    Ниже названия вы можете добавить описание.

6. В разделе  **При запуске макроса:** введите текст комментария, который будет добавлен в задачу при выполнении макроса:

    - в текст комментария можно подставлять [значения полей задачи](https://yandex.ru/support/tracker/ru/user/vars). Для этого нажмите кнопку  **Переменные** и выберите одно или несколько значений. В поле ввода появится конструкция вида `{{issue.<ключ_поля>}}`;

    - также вы можете использовать готовые [шаблоны комментариев](https://yandex.ru/support/tracker/ru/user/create-template). Для этого нажмите кнопку и выберите один или несколько шаблонов из раскрывающегося списка.

    Если вы не хотите, чтобы макрос создавал комментарий, оставьте поле пустым.

7. В разделе  **Изменить значение в поле** выберите, какие параметры задачи будет изменять макрос, и укажите их новые значения. Если вы не хотите, чтобы макрос изменял значения параметров задачи, переходите к следующему шагу.

    Чтобы найти [локальное поле очереди](https://yandex.ru/support/tracker/ru/local-fields), перед названием поля введите ключ очереди, где вы настраиваете автоматизацию, и точку (например, `DEVS.Тестировщик`).

8. Нажмите кнопку **Создать макрос**.

    Макрос появится в списке автоматизаций через несколько секунд.
