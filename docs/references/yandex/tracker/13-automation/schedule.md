При помощи автодействий вы можете создавать задачи с определенными параметрами с заданной периодичностью. Например, каждую неделю создавать задачу на резервное копирование данных.

Задачи будут создаваться в очереди, в которой настроено автодействие. Автором задачи будет *Робот сервиса Трекер*.

Убедитесь, что у робота Робот сервиса Трекер есть права на создание задач в выбранной очереди.

# Настроить создание задач

Для настройки автодействий требуются [права доступа «Настройки очереди»](https://yandex.ru/support/tracker/ru/manager/queue-access). В одну очередь можно добавить не более 100 автодействий.

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. На панели слева выберите **Автоматизация**.

4. В правом верхнем углу нажмите кнопку **Создать** → **Автодействие**.

5. Выберите тип автодействия **Создание задач**.

6. Задайте название для автодействия.
    Ниже названия вы можете добавить описание.

7. Настройте  **График срабатывания** — периодичность создания задач:

    1. Выберите, в каких единицах будет задан период создания задач:

        - **По часам**;
        - **По дням**;
        - **По неделям**.
    2. Укажите период создания задач в выбранных единицах. Для этого в поле **Повторять раз в** введите число от 1 до 1000.

        - Например, если вы укажете период «Каждый 4 день», задача будет создаваться раз в четыре дня.

        - Если вы задали период создания задач в днях, вы можете выбрать вариант **Каждый рабочий день** и [график работы](https://yandex.ru/support/tracker/ru/manager/schedule).

        - Если вы задали период создания задач в неделях, выберите дни недели, в которые будут создаваться задачи.

    3. Укажите даты и время, когда автоматическое создание задач начнет и закончит действовать. Если вы не укажете даты начала и окончания, автоматическое создание задач будет действовать постоянно.

8. В разделе  **Создать задачу с заданными параметрами** заполните поля шаблона новой задачи.
    Вы можете настроить автоматическое создание нескольких задач.

9. Нажмите кнопку **Создать автодействие**.

После добавления новой автоматизации она появится в списке через несколько секунд.

# Изменить время срабатывания автодействия

Чтобы изменить время автоматического создания задач:

1. Откройте [список автоматизаций очереди](https://yandex.ru/support/tracker/ru/automation#go-to-automation) и нажмите на автодействие, которое хотите изменить.

2. В поле **Начать** введите ближайшие дату и время в будущем, когда должна быть создана следующая задача.

3. Нажмите кнопку **Сохранить**.

    Теперь автодействие будет срабатывать по обновленному расписанию.
