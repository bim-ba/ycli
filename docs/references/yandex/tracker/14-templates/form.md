Вы можете настроить интеграцию Трекера с сервисом [Яндекс Формы](https://forms.yandex.ru/cloud/admin) и использовать формы как шаблоны для задач. Форма поможет пользователям создавать задачи по определенному шаблону, не отвлекаясь на лишние поля и параметры. Если нужно, чтобы автор задачи указал определенную информацию, поля формы можно сделать обязательным для заполнения.

Чтобы привязать форму к странице создания задачи в *очереди*, создайте форму с помощью встроенного конструктора в Трекере: [Как создать форму в интерфейсе Трекера](https://yandex.ru/support/tracker/ru/user/forms-template).

На странице создания задачи пользователь сможет выбрать нужную форму и заполнить ее — в результате в очереди будет создана задача: [Как создать задачу в Трекере](https://yandex.ru/support/tracker/ru/user/create-ticket).
