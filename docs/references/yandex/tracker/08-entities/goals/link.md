Вы можете связать цель с сущностями Трекера: с задачей, проектом, портфелем или другой целью, они появятся на вкладке **Связи**. Еще к цели можно прикрепить виджеты Трекера, они появятся на вкладке **Цели и прогресс**, в разделе  **Метрики**.

*Как создать связь с задачей*

# Добавить связь с проектом или портфелем

Привяжите к цели проекты и портфели, в которых работа направлена на достижение цели.

1. На странице цели перейдите на вкладку **Связи**.

2. Нажмите  **Связь** → **С проектом или портфелем**.

3. Выберите, какой проект или портфель вы хотите привязать:

    - **Новый**: выберите тип **Портфель** или **Проект**. Введите название, укажите дедлайн и нажмите кнопку **Создать**.
    - **Существующий**: начните вводить название проекта или портфеля и выберите подходящий вариант из списка.

# Добавить связь с другой целью

С помощью связей можно выстроить иерархию целей. Например, ключевые цели компании разбить на подцели подразделений и команд.

1. На странице цели перейдите на вкладку **Связи**.

2. Нажмите  **Связь** → **С целью**.

3. Выберите тип связи:

    - **Зависит от** — цель, с которой связана текущая.
    - **Блокирует** — цель, выполнение которой блокирует текущая.
    - **Родительская цель** — цель высокого уровня, для которой текущая цель становится подцелью. Родительская цель может быть только одна.
    - **Подцель** — дочерняя цель для текущей.
4. Выберите цель, с которой нужно создать связь:

    - Чтобы создать новую цель, выберите **Новая**. Введите название цели, укажите дедлайн и нажмите **Создать**.

        Чтобы открыть полную страницу создания цели для детальной настройки параметров, нажмите значок .

    - Чтобы добавить существующую цель, выберите **Существующая**. Начните вводить название цели и выберите подходящий вариант из списка.

# Добавить связь задачей

1. На странице цели перейдите на вкладку **Связи**.

2. Нажмите  **Связь** → **С задачей**.

3. Выберите, какую задачу привязать:

- **Новая**: введите название, выберите очередь и нажмите **Создать**.

- **Существующая**: начните вводить название или ключ задачи и выберите подходящий вариант из списка.

# Изменить тип связи

Справа от связанного объекта нажмите → **Изменить тип связи** и выберите новый тип.

# Удалить связь

Справа от связанного объекта нажмите → **Удалить связь**.

# Добавить метрики

На страницу цели можно встраивать метрики — [виджеты Трекера](https://yandex.ru/support/tracker/ru/user/widgets). Они будут отображаться в отдельном блоке  **Метрики**.

Чтобы добавить метрику:

1. На дашборде выберите виджет и в правом верхнем углу нажмите  →  **Скопировать ссылку для iframe**.

2. Откройте страницу сущности и нажмите  **Метрика**.

3. Укажите название метрики. Оно будет отображаться в заголовке виджета.

4. Ниже вставьте ссылку на виджет.

5. Нажмите **Добавить**.

Добавленные метрики можно редактировать или удалить. Для этого в правом верхнем углу метрики нажмите и выберите нужный пункт меню.
