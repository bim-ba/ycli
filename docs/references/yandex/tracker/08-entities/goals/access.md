По умолчанию настройки доступа к цели могут поменять только автор или ответственный пользователь. Чтобы такая возможность появилась у другого сотрудника, установите для него тип доступа «Полный доступ».

Особенности настроек доступа для каждого объекта отображаются вверху экрана:

-  **Не только участникам** — означает, что цель доступна сотрудникам, которые не указаны в ее параметрах. По умолчанию цель могут отредактировать все сотрудники и роботы вашей организации. Закройте для них доступ, если сущность содержит персональные или другие чувствительные данные.

-  **Только участникам** — означает, что цель могут просмотреть только сотрудники, которые указаны в параметрах «Автор», «Ответственный», «Участники» или «Наблюдатели».

Если вы создаете новый объект (например, проект) с помощью кнопки **Связь**  на странице цели, настройки доступа для проекта будут скопированы с цели. Вы сможете изменить их в любой момент.

# Настроить доступ к цели

1. Откройте страницу цели.

2. Вверху экрана нажмите название текущих настроек доступа: **Только участникам** или **Не только участникам**.

3. Чтобы добавить пользователя или группу, начните вводить имя или название в строку поиска.

4. Справа от имени или названия группы нажмите кнопку со значком и выберите тип доступа:

    - **Просмотр** — возможность открыть цель.

    - **Редактирование** — возможность отредактировать любые параметры цели, кроме настроек доступа.

    - **Полный доступ** — возможность просматривать и редактировать цель, а также управлять настройками доступа для других пользователей.

    - **Закрыть доступ** — нажмите, чтобы удалить пользователя или группу из списка.

5. Нажмите **Сохранить**.

# Привязать настройки доступа к родителю

Настройки доступа для подцели можно привязать к настройкам основной цели. Настройки наследуются от объекта, который выше только на один уровень.

1. Откройте страницу подцели.

2. Вверху экрана нажмите название текущих настроек доступа: **Только участникам** или **Не только участникам**.

3. В специальном разделе в окне настроек нажмите **Привязать**.

    Вы можете посмотреть различия между доступами родительской цели и подцели и выбрать, хотите ли вы менять настройки. Для этого нажмите **Сравнить**.

Чтобы отключить наследование настроек доступа, в том же разделе нажмите **Отвязать**.

Чтобы наследование настроек включилось автоматически, создайте подцель на странице основной цели: в разделе **Подцели**  нажмите  **Создать связь** → **Новая**.

# Выбрать тип доступа по умолчанию для новых целей

Администратор Трекера может выбрать, какой тип доступа будет использоваться по умолчанию для всех новых целей в Трекере: только участникам или другим пользователям. После создания цели настройки доступа можно будет изменить.

1. На панели слева нажмите **Администрирование** →  **Цели**.

2. В списке **Доступ к новым целям по умолчанию** выберите тип доступа.
