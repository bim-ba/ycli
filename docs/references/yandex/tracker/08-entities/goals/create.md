Для работы с целью доступны такие возможности:

- [Добавить ключевые результаты](https://yandex.ru/support/tracker/ru/goals/goals-settings#key-results) и настроить способ измерения для каждого из них.

- [Менять статус выполнения цели](https://yandex.ru/support/tracker/ru/goals/goals-settings#goal-status).

- [Посмотреть историю изменения цели](https://yandex.ru/support/tracker/ru/manager/history).

# Создать цель

1. На панели слева откройте  **Цели**, затем в правом верхнем углу нажмите кнопку **Создать цель** или перейдите по ссылке [https://tracker.yandex.ru/createGoal](https://tracker.yandex.ru/createGoal) .

2. Укажите название цели.

3. Если новая цель — это подцель для уже существующей, под заголовком нажмите  **Указать родительскую цель**. Начните вводить название цели и выберите подходящий вариант из списка.

4. Ниже названия введите описание цели. Из описания должно быть понятно, какого результата вы ожидаете после завершения работы.

5. [Добавьте **Ключевые результаты**](https://yandex.ru/support/tracker/ru/goals/goals-settings#key-results) цели. Для каждого ключевого результата можно указать исполнителя, дедлайн и способ измерения.

6. Заполните поля в блоке справа:

    - **Дедлайн** — крайний срок достижения цели. Вы можете указать конкретную дату или квартал.
    - **Ответственный** — сотрудник, ответственный за достижение цели. По умолчанию в полях **Ответственный** и **Автор** указан пользователь, создавший цель.
    - **Заказчики** — сотрудники, которые поставили цель для компании или подразделения.
    - **Участники** — сотрудники, причастные к достижению цели.
    - **Теги** — метки, по которым можно фильтровать цели.
7. При необходимости [настройте связи цели](https://yandex.ru/support/tracker/ru/goals/goals-settings#links) или прикрепите файлы.

8. Нажмите кнопку **Сохранить**.

По умолчанию новая цель доступна всем сотрудникам организации. [Как ограничить доступ к цели](https://yandex.ru/support/tracker/ru/goals/goal-access)

# Добавить ключевые результаты

Ключевые результаты — это количественные показатели, привязанные ко времени. Они позволяют оценить ход достижения цели.

1. Ниже описания цели в разделе **Ключевые результаты** нажмите .

2. Введите название ключевого результата.

3. Настройте **Способ измерения** прогресса:

    По значению

    По факту

    Этот способ измерения подходит для количественных результатов. Достижение ключевого результата можно наглядно отследить на полосе прогресса. Чтобы прогресс отобразился, заполните обязательные значения:

    - **На старте** — значение, с которого начинается выполнение. Например, в момент создания цели в вашей команде работали 2 специалиста поддержки.

    - **Цель** — значение, которого нужно достичь. Например, вы планируете расширить команду до 10 специалистов поддержки.

    - **Сейчас** — значение в данный момент. Например, 3 новых специалиста поддержки сейчас на испытательном сроке, текущее значение ключевого результата — 5 членов команды.

    Чтобы изменить значения, нажмите на ключевой результат.

    Прогресс ключевого результата может быть отрицательным, если метрика ухудшилась по сравнению с исходным значением, или, наоборот, превысить 100%, если целевой показатель превзойден.

    Этот способ измерения подходит для результатов, которые могут иметь только два значения — «Достигнут» или «Не достигнут».

    Вы можете установить **Результат достигнут** сразу или сделать это позже.

4. Укажите ответственного за ключевой результат и дедлайн его выполнения.

5. Нажмите **Сохранить**.

# Следить за прогрессом

Чтоб оценить, насколько команда приблизилась к достижению цели, используйте индикатор **Прогресс**. Значение прогресса рассчитывается в процентах как среднее арифметическое от прогресса по подцелям и ключевым результатам.

**Пример расчета**:

> Предположим, у вас есть цель, которая содержит два ключевых результата и две подцели. Каждый из этих четырех элементов вносит в общий прогресс цели 25%: 100/4 = 25100 / 4 = 25
>
> Пример расчета общего прогресса цели:
>
> - Один из ключевых результатов полностью достигнут и добавил 25% к общему прогрессу цели.
> - Одна из подцелей выполнена на 13% и добавила 3% к общему прогрессу цели: 0,13×0,25≈0,030,13 × 0,25 ≈ 0,03 (или 3%).
> - Над вторым ключевым результатом и второй подцелью еще не начинали работать, они добавили 0% к общему прогрессу.
>
> Суммируя эти значения, получаем общий прогресс цели: 28%.

# Обновить статус цели

Рекомендуем поддерживать актуальный статус цели и периодически добавлять комментарии о ходе работы.

## Изменить статус

Чтобы обновить статус цели:

1. На панели справа нажмите на поле **Статус**. Откроется окно **Обновление статуса цели**.

2. Выберите в списке новый статус.

    Доступные статусы

    - **Новая** — цель создана, но работа по ней еще не началась.
    - **По плану** — цель актуальна, прогресс достижения цели соответствует плановым срокам.
    - **Есть риски** — возможно превышение срока достижения цели или цель может не быть достигнута.
    - **Заблокирована** — цель не может быть достигнута: существуют обстоятельства, от которых зависит достижение результата.
    - **Достигнута** — выполнены все ключевые результаты, цель достигнута полностью.
    - **Частично достигнута** — выполнены некоторые ключевые результаты.
    - **Не выполнена** — никакие ключевые результаты не выполнены.
    - **Перевыполнена** — цель достигнута полностью с превышением ожидаемого результата.
    - **Отменена** — цель не актуальна.

3. При необходимости измените дедлайн.

4. В области редактирования напишите ваш комментарий.

    В комментариях вы можете использовать [разметку текста](https://yandex.ru/support/tracker/ru/user/markup), а также прикреплять к ним изображения и файлы.

5. Нажмите кнопку **Обновить статус**. Текст комментария появится на вкладке **Обновления**.

Также вы можете обновить статус цели при отправке комментария на вкладке **Обновления**.

1. На странице цели откройте вкладку **Обновления**.

2. В области редактирования напишите ваш комментарий.

    В комментариях вы можете использовать [разметку текста](https://yandex.ru/support/tracker/ru/user/markup), а также прикреплять к ним изображения и файлы.

3. Чтобы изменить статус цели при отправке комментария, выберите новый статус над областью редактирования.

4. Чтобы пригласить других пользователей к обсуждению цели:

    1. Внизу нажмите кнопку  **Призвать**.

    2. Начните вводить логин или имя и в выпадающем списке выберите нужного пользователя. Чтобы добавить еще одного, снова нажмите кнопку  **Призвать**.

    Вы можете настроить каналы уведомления о призыве в комментарии: [Как настроить подписки](https://yandex.ru/support/tracker/ru/user/notification-constructor).

5. Нажмите кнопку **Отправить**.

Чтобы изменить порядок комментариев, справа над областью редактирования нажмите кнопку  **Сначала новые** или  **Сначала старые**.

## Ответить на комментарий

1. Наведите указатель на комментарий и нажмите кнопку  **Ответить**. Комментарий, на который вы отвечаете, будет добавлен в ответ в виде цитаты.
    Чтобы процитировать в ответе только часть комментария, выделите фрагмент текста и нажмите кнопку  **Ответить**.

2. Напишите ответ в поле ввода.

3. Выберите тип уведомления для пользователя, на комментарий которого вы отвечаете:

    - По умолчанию автор комментария указан внизу в поле **Ответить**. Он получит уведомление об ответе.

    - Если вы не хотите уведомлять пользователя об ответе, удалите его из поля **Ответить**.

    - Если нужно привлечь внимание пользователя к задаче и сообщить, что вы ждете его ответ, перетащите его имя влево — после этого поле **Ответить** сменится на **Призвать**. Пользователь получит уведомление о призыве и сможет найти задачу в списке своих задач, по фильтру «Ждут ответа».

4. Нажмите кнопку **Отправить**.

Если в комментарий добавлена цитата с помощью кнопки  **Ответить**, вы можете перейти к исходному комментарию. Для этого нажмите на текст цитаты.

Также вы можете настроить каналы уведомления об ответе на ваш комментарий: [Как настроить подписки](https://yandex.ru/support/tracker/ru/user/notification-constructor).

## Добавить итоговый комментарий по подцелям

Если у цели есть подчиненные цели, можно сформировать автоматический комментарий, в котором будут собраны обновления из всех подцелей:

1. На вкладке **Обновления** над областью редактирования нажмите кнопку  **Итог по подцелям**.

    В области редактирования появится новый комментарий, который содержит список подцелей. Для каждой цели будут указаны ее статус, дата и текст последнего комментария.

    В итоговый комментарий не попадут:

    - комментарии, добавленные более месяца назад;
    - ответы на предыдущие комментарии в подцелях.

2. При необходимости отредактируйте текст итогового комментария.

    В комментариях вы можете использовать [разметку текста](https://yandex.ru/support/tracker/ru/user/markup), а также прикреплять к ним изображения и файлы.

3. Нажмите кнопку **Отправить**.

# Удалить цель

1. Откройте страницу цели.

2. В правом верхнем углу нажмите  **Действия** →  **Удалить цель**.
