Каждый проект в Трекере имеет доску задач типа «Простая». Доска задач проекта создается автоматически при создании проекта. Такая доска позволяет распределить задачи по колонкам в зависимости от их статуса, но не поддерживает такие *методологии Agile*, как Скрам и Канбан.

У доски, которая была создана вместе с проектом, настройки доступа такие же, как у проекта.

Чтобы перейти к доске задач проекта:

1. На панели слева в разделе  **Проекты** выберите проект.

2. Перейдите на вкладку **Задачи** и выберите представление **Доска**.

Вы также можете открыть доску задач проекта в разделе  **Доски задач** на панели слева. По умолчанию такая доска имеет название «Доска проекта <название\_проекта>».

Подробнее о всех доступных операциях читайте в разделе [Как работать с задачами на доске](https://yandex.ru/support/tracker/ru/manager/agile-issues).

# Добавить задачи на доску

Все задачи проекта автоматически отображаются на доске, связанной с этим проектом. Вы можете добавить задачи на доску двумя способами:

- Добавьте задачу на доску проекта — после этого она автоматически добавится в проект. [Добавить задачу на доску проекта](https://yandex.ru/support/tracker/ru/manager/agile-set-board#add-task)

- Добавьте задачу на странице проекта — после этого она появится на доске. [Добавить задачу в проект](https://yandex.ru/support/tracker/ru/manager/create-project#add-tickets)

# Удалить доску

Доску проекта нельзя удалить, пока существует проект.

Если удалить проект, доска задач проекта останется в разделе  **Доски задач** на панели слева. В этом случае вы можете работать с такой доской так же, как с обычной доской задач, в том числе [удалить ее](https://yandex.ru/support/tracker/ru/manager/agile-create#delete-board).
