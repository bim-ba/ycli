На вкладке **Задачи** отображаются все задачи, которые [добавлены](https://yandex.ru/support/tracker/ru/manager/create-project#add-tickets) в проект. Список отображает структуру проекта: вы можете выстроить иерархию работ в виде дерева подзадач, ранжировать задачи вручную или отсортировать их по одному из полей.

Задачи можно выгрузить в виде [отчета по задачам](https://yandex.ru/support/tracker/ru/user/reports#ticket-report) или [отчета по трудозатратам](https://yandex.ru/support/tracker/ru/user/reports#time-spent-report).

Чтобы открыть список задач проекта:

1. На панели слева выберите  **Проекты** или перейдите по ссылке [https://tracker.yandex.ru/pages/projects](https://tracker.yandex.ru/pages/projects) и откройте страницу проекта.

2. Перейдите на вкладку **Задачи**.

# Изменить представление списка задач

Информацию о задачах проекта можно посмотреть в четырех разных представлениях:

- **Список**. Вариант по умолчанию. Как изменить внешний вид таблицы со списком рассказали на странице [Как настроить список результатов поиска задач](https://yandex.ru/support/tracker/ru/user/actions-on-filter).
- **Календарь**. На нем отображаются полосы с названиями задач, каждая полоса тянется от даты начала до даты завершения задачи.
    Как работать с календарным представлением рассказали на странице [Календарь для фильтра задач](https://yandex.ru/support/tracker/ru/user/list-view-calendar).
- **Гант**. На диаграмме отображаются полосы с названиями задач, каждая полоса тянется от даты начала до даты завершения задачи. Если задача не закрыта к дедлайну, полоса становится красной. Связи типа «Зависит от — Блокирует» обозначены стрелками. Слева от диаграммы есть список задач, который можно настраивать также, как в представлении «Список».
    Как работать с диаграммой Ганта рассказали на странице [Диаграмма Ганта в проектах Трекера](https://yandex.ru/support/tracker/ru/gantt/project).
- **Доска**. Виртуальная доска с карточками, на которой удобно отслеживать статусы задач проекта. Подробнее читайте в разделе [Доска задач проекта](https://yandex.ru/support/tracker/ru/manager/boards-project).
    Также доску проекта можно найти в разделе  **Доски задач** на панели слева. Она называется «Доска проекта `<имя_проекта>`».

# Действия с задачами

В представлениях **Список** и **Гант** можно открыть меню действий с задачей. Для этого в конце строки с описанием задачи нажмите  **Действия**.

В меню доступны действия:

-  **Скопировать ссылку**;
-  **Перенести наверх списка** (только при ручной сортировке);
-  **Перенести вниз списка** (только при ручной сортировке);
-  **Преобразовать в [веху](https://yandex.ru/support/tracker/ru/manager/milestones) или задачу**.
-  **Удалить из проекта**.

Также вы можете [изменить параметры](https://yandex.ru/support/tracker/ru/manager/bulk-change) сразу нескольких задач из списка или [перенести задачи в другой основной проект](https://yandex.ru/support/tracker/ru/manager/create-project#update-project).

# Изменить связи задач

Чтобы изменить вид списка задач, выберите  **Иерархия**.

Вложенность одних задач в другие обозначает [связи](https://yandex.ru/support/tracker/ru/user/ticket-links) типа «Родительская задача — Подзадача».

- Чтобы ранжировать (перемещать) задачи относительно других, слева от задачи зажмите и перетащите ее на нужную позицию.

- Чтобы создать подзадачу, напротив задачи нажмите кнопку  **Добавить подзадачу**:

  - Чтобы создать новую задачу, перейдите на вкладку **Новая задача**. Введите название и нажмите клавишу **Enter**.
  - Если задача уже существует, перейдите на вкладку **Существующая задача** и укажите ее *ключ* или название, затем выберите задачу из списка. Найти ключ можно на странице задачи над ее названием (например, `TEST-1234`).
- Чтобы изменить связь, слева от подзадачи зажмите , сдвиньте указатель вправо и перетащите задачу под ту, которую хотите назначить родительской.

- При выстраивании иерархии задач вы можете вкладывать одну задачу в другую или выносить подзадачу на верхний уровень. Чтобы вынести задачу на уровень выше, слева от подзадачи зажмите и сдвиньте указатель влево.

    Ручное перемещение задач доступно, если в поле **Сортировка** не выбран параметр сортировки. По умолчанию для списка задач выбран ручной режим сортировки: вы можете перетаскивать задачи в списке.

## Импортировать задачи по фильтру

1. Откройте страницу проекта.

2. В верхнем правом углу нажмите **Импорт задач**.

3. Нажмите  **Добавить параметры** и задайте условие для выбора задач.

4. Нажмите **Импортировать** и дождитесь окончания импорта задач.

Если у задачи есть основной проект, текущий проект станет для нее дополнительным. Если задача не добавлена в другие проекты, то проект станет для нее основным.
