# Создать проект

Вы можете создать полностью новый проект или взять за основу задачу.

## Новый проект

Чтобы создать проект:

1. Перейдите на любую страницу, с которой можно создать проект:

    - На панели слева выберите  **Проекты**, затем нажмите **Создать** → **Проект**.
    - В [списке портфелей и проектов](https://yandex.ru/support/tracker/ru/manager/my-projects) на вкладке **Список** под списком нажмите **Создать проект**.
2. Введите название проекта. Лучше, если оно будет коротким и понятным — так с проектом будет проще работать.

3. На вкладке **О проекте** добавьте информацию:

    - **Описание проекта**: над чем вы работаете и каких целей хотите достичь.

    -  **Файл**: добавьте рабочие материалы проекта.

    -  **Метрика**: если у вас есть чарт DataLens, с помощью которого вы отслеживаете важные для проекта показатели, встройте его на страницу проекта. Подробнее о добавлении метрики см. в [инструкции](https://yandex.ru/support/tracker/ru/manager/create-project#add-metrics).

    -  **Связь**: добавьте связь с другими проектами, портфелями или целями.

    -  **Чеклист**: укажите список значимых этапов или целей проекта. Работать с чеклистом проекта можно так же, как с чеклистом задачи: см. [Как создать чеклист](https://yandex.ru/support/tracker/ru/user/checklist).

    - На панели справа задайте параметры проекта.

        Описание параметров проекта

        - **Статус**: укажите, на каком этапе находится проект.
        - **Дата начала** и **Дедлайн**.
        - **Ответственный**, **Заказчики**, **Наблюдатели** и **Участники**: начните вводить имя или логин сотрудника и выберите подходящий вариант из списка.
        - **Входит в портфель**: укажите [портфель](https://yandex.ru/support/tracker/ru/manager/portfolio), в который входит проект.
        - **Теги**: добавьте или выберите теги, с помощью которых будет проще найти нужный проект.

4. [Добавьте](https://yandex.ru/support/tracker/ru/manager/create-project#add-tickets) в проект задачи. Вы можете добавить задачи со страницы проекта или со страницы задачи, а также при помощи операции [массового редактирования](https://yandex.ru/support/tracker/ru/manager/bulk-change).

    Проект не привязан к очереди задач, поэтому в него можно добавить задачи из любой очереди, к которой у вас есть доступ. Доступ к задачам проекта зависит от [настроек доступа](https://yandex.ru/support/tracker/ru/user/queue) очереди, к которой относится задача.

    В проект можно добавить не более 2000 задач.

По умолчанию новый проект доступен всем сотрудникам организации. [Как ограничить доступ к проекту](https://yandex.ru/support/tracker/ru/manager/project-access)

## Конвертировать задачу в проект

Конвертируемая задача будет добавлена в проект, а в новом проекте отобразятся ее параметры:

- название, описание, чеклист;
- дата начала и завершения;
- автор, исполнитель и наблюдатели.

Комментарии к задаче сконвертируются в комментарии к проекту и отобразятся на вкладке **О проекте**.

Чтобы создать проект на основе задачи:

1. Откройте страницу задачи. Задача не должна принадлежать другому проекту. Чтобы удалить задачу из проекта, очистите поле **Проект** на панели справа.

2. В правом верхнем углу выберите **Действия** → **Конвертировать в проект** и нажмите **Конвертировать**.

# Добавить задачи в проект

Задача может принадлежать нескольким проектам. Основным может быть только один проект, остальные — дополнительные. В дополнительных проектах с задачей можно [работать](https://yandex.ru/support/tracker/ru/manager/project-list) так же, как и в основном проекте: она будет отображаться в списке задач и на диаграмме Ганта.

На других страницах Трекера (например, в настройках виджета, на странице очереди или в фильтре задач) при фильтрации по параметру **Проект** задачи отбираются только по основному проекту. Чтобы отбирать задачи по всем проектам, в которые они входят, при настройке фильтра по проектам включите опцию **Показывать задачи, для которых проект дополнительный**. Подробнее о фильтрах задач читайте в разделе [Как найти задачи по любым параметрам](https://yandex.ru/support/tracker/ru/user/create-filter).

Задача может быть добавлена не больше, чем в 40 проектов, включая основной.

## Со страницы проекта

1. Перейдите на вкладку **Задачи** и нажмите  **Добавить задачу**.

2. Выберите, какую задачу вы хотите привязать:

    Новая задача

    Существующая задача

    1. Нажмите **Новая**.
    2. Укажите название задачи, выберите очередь и нажмите клавишу **Enter**. Проект станет для задачи основным.

    1. Нажмите **Существующая**.
    2. Начните вводить *ключ* или название задачи и выберите подходящий вариант из списка.

    Если у задачи есть основной проект, текущий проект станет для нее дополнительным. Если задача не добавлена в другие проекты, то проект станет для нее основным.

## Со страницы задачи

1. Откройте страницу задачи.

2. Нажмите на поле **Проект** на панели справа. Если поля **Проект** нет, добавьте его с помощью кнопки **Добавить параметры**.

3. В поле **Основной** или **Дополнительные** начните вводить название проекта и выберите подходящий вариант из списка. Нажмите **Сохранить**.

## Добавить несколько задач

1. Отберите нужные задачи с помощью [фильтра](https://yandex.ru/support/tracker/ru/user/create-filter).

2. Выберите задачи, которые вы хотите добавить в проект.

3. На панели снизу нажмите и выберите **Добавить в проект**.

4. Начните вводить название проекта и выберите подходящий вариант из списка.

5. Дождитесь окончания обработки задач.

Если у задачи есть основной проект, текущий проект станет для нее дополнительным. Если задача не добавлена в другие проекты, то проект станет для нее основным.

## Перенести задачи в другой проект

Вы можете изменить основной проект для всех или некоторых задач проекта. Дочерние задачи будут также добавлены в новый основной проект.

1. Откройте страницу проекта.

2. Перейдите на вкладку **Задачи**.

3. Поставьте отметку возле задач, для которых вы хотите изменить основной проект.

    Если вы хотите выбрать сразу все задачи проекта, поставьте отметку над списком задач.

4. Нажмите кнопку под списком задач и выберите **Изменить основной проект**.

5. Начните вводить название проекта и выберите подходящий вариант из списка.

6. Дождитесь окончания обработки задач.

# Удалить проект

Удалить проект может его автор и пользователь, указанный в поле **Ответственный**.

Чтобы удалить проект:

1. На панели слева выберите  **Проекты** или перейдите по ссылке [https://tracker.yandex.ru/pages/projects/list](https://tracker.yandex.ru/pages/projects/list) и откройте страницу проекта.

2. В правом верхнем углу страницы нажмите и выберите **Удалить проект**.
