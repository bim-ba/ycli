Проектом можно назвать любую работу, которая имеет установленные цели и временные рамки.

Проект в Трекере — это набор задач, которые направлены на достижение общего результата. Проект не привязан к очереди задач, поэтому с помощью проектов удобно группировать задачи нескольких команд, работающих над общей целью. Несколько проектов можно объединить в [портфель проектов](https://yandex.ru/support/tracker/ru/manager/portfolio).

# Начало работы

Чтобы начать работу над проектом в Трекере, [cоздайте](https://yandex.ru/support/tracker/ru/manager/create-project) проект и добавьте в него задачи. В проект могут входить задачи из разных очередей.

Планируйте работу и управляйте сроками задач с помощью [диаграммы Ганта](https://yandex.ru/support/tracker/ru/gantt/project). Используйте [вехи](https://yandex.ru/support/tracker/ru/manager/milestones), чтобы отслеживать прогресс по проекту и контролировать сроки.

# Страница проекта

В новом интерфейсе Трекера все доступные вам проекты можно открыть из навигационной панели слева: нажмите  **Проекты** или перейдите по ссылке [https://tracker.yandex.ru/pages/projects/list](https://tracker.yandex.ru/pages/projects/list) и выберите проект из списка.

На странице проекта собраны сведения о команде, целях и задачах проекта:

- Вкладка **О проекте**. Описание проекта, статус, сроки работы над проектом, автор и ответственный за проект, список участников команды, комментарии, заказчики, [вехи](https://yandex.ru/support/tracker/ru/manager/milestones), [связи](https://yandex.ru/support/tracker/ru/manager/project-links) с другими проектами и портфелями, а также теги.

- Вкладка **Задачи**. Здесь можно выбрать способ представления списка задач. [Изменить представление списка задач](https://yandex.ru/support/tracker/ru/manager/project-list#issues-list)

В правом верхнем углу на полосе **Задачи** отображается прогресс проекта: сколько задач выполнено из их общего количества.

Чтобы зафиксировать изменения в работе над проектом, [обновите статус проекта](https://yandex.ru/support/tracker/ru/manager/update-project-status).

Чтобы ограничить доступ к проекту, в правом верхнем углу страницы нажмите значок замка и выберите **Только участникам**. Тогда проект будет доступен только тем пользователям, которые указаны в полях **Участники**, **Автор**, **Заказчики** и **Ответственный**.

# Настроить список параметров проекта

Чтобы настроить список параметров (полей), отображаемых на боковой панели справа, нажмите кнопку **Изменить список параметров** и выберите нужные.

Особенности:

- Если поле заполнено, оно всегда отображается на боковой панели. Вы можете скрывать только те параметры, для которых не указано значение.

- Некоторые параметры нельзя скрыть: **Входит в портфель**, **Статус**, **Дата начала**, **Дедлайн**, **Автор** и **Ответственный**.

- Настройки отображения списка сохраняются индивидуально для каждого пользователя и применяются ко всем проектам, которые он просматривает.
