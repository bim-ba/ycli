По умолчанию настройки доступа к проекту могут поменять только автор или ответственный пользователь. Чтобы такая возможность появилась у другого сотрудника, установите для него тип доступа «Полный доступ».

Особенности настроек доступа для каждого проекта отображаются вверху экрана:

-  **Не только участникам** — означает, что проект доступен сотрудникам, которые не указаны в его параметрах. По умолчанию проект могут отредактировать все сотрудники и роботы вашей организации. Закройте для них доступ, если проект содержит персональные или другие чувствительные данные.

-  **Только участникам** — означает, что проект могут просмотреть только сотрудники, которые указаны в параметрах «Автор», «Ответственный», «Участники» или «Наблюдатели».

Если вы создаете новый объект (например, цель) с помощью кнопки **Связь**  на странице проекта, настройки доступа для цели будут скопированы с проекта. Вы сможете изменить их в любой момент.

# Настроить доступ к проекту

1. Откройте страницу проекта.

2. Вверху экрана нажмите название текущих настроек доступа: **Только участникам** или **Не только участникам**.

3. Чтобы добавить пользователя или группу, начните вводить имя или название в строку поиска.

4. Справа от имени или названия группы нажмите кнопку со значком и выберите тип доступа:

    - **Использование** — возможность открыть проект, а также добавить в него задачу или комментарий.

    - **Редактирование** — возможность отредактировать любые параметры проекта, кроме настроек доступа.

    - **Полный доступ** — возможность просматривать и редактировать проект, а также управлять настройками доступа для других пользователей.

    - **Закрыть доступ** — нажмите, чтобы удалить пользователя или группу из списка.

5. Нажмите **Сохранить**.

# Привязать настройки доступа к родителю

Настройки доступа для вложенного проекта можно привязать к настройкам родительского портфеля. Настройки наследуются от объекта, который выше только на один уровень.

1. Откройте страницу вложенного проекта.

2. Вверху экрана нажмите название текущих настроек доступа: **Только участникам** или **Не только участникам**.

3. В специальном разделе в окне настроек нажмите **Привязать**.

    Вы можете посмотреть различия между доступами родительского и вложенного объекта и выбрать, хотите ли вы менять настройки. Для этого нажмите **Сравнить**.

Чтобы отключить наследование настроек доступа, в том же разделе нажмите **Отвязать**.

Чтобы наследование настроек включилось автоматически, создайте вложенный проект на странице портфеля: перейдите на вкладку **Проекты** и внизу нажмите  **Добавить проект** → **Новый**.

# Выбрать тип доступа по умолчанию для новых проектов

Администратор Трекера может выбрать, какой тип доступа будет использоваться по умолчанию для всех новых проектов в Трекере: только участникам или другим пользователям. После создания проекта настройки доступа можно будет изменить.

1. На панели слева нажмите **Администрирование** →  **Проекты и портфели**.

2. В списке **Доступ к новым проектам по умолчанию** выберите тип доступа.
