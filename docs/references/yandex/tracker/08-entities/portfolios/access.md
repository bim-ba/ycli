По умолчанию настройки доступа к портфелю могут поменять только автор или ответственный пользователь. Чтобы такая возможность появилась у другого сотрудника, установите для него тип доступа «Полный доступ».

Особенности настроек доступа для каждого портфеля отображаются вверху экрана:

-  **Не только участникам** — означает, что портфель доступен сотрудникам, которые не указаны в его параметрах. По умолчанию портфель могут отредактировать все сотрудники и роботы вашей организации. Закройте для них доступ, если портфель содержит персональные или другие чувствительные данные.

-  **Только участникам** — означает, что портфель могут просмотреть только сотрудники, которые указаны в параметрах «Автор», «Ответственный», «Участники» или «Наблюдатели».

Если вы создаете новый объект (например, цель) с помощью кнопки **Связь**  на странице портфеля, настройки доступа для цели будут скопированы с портфеля. Вы сможете изменить их в любой момент.

# Настроить доступ к портфелю

1. Откройте страницу портфеля.

2. Вверху экрана нажмите название текущих настроек доступа: **Только участникам** или **Не только участникам**.

3. Чтобы добавить пользователя или группу, начните вводить имя или название в строку поиска.

4. Справа от имени или названия группы нажмите кнопку со значком и выберите тип доступа:

    - **Просмотр** — возможность открыть портфель.

    - **Редактирование** — возможность отредактировать любые параметры портфеля, кроме настроек доступа.

    - **Полный доступ** — возможность просматривать и редактировать портфель, а также управлять настройками доступа для других пользователей.

    - **Закрыть доступ** — нажмите, чтобы удалить пользователя или группу из списка.

5. Нажмите **Сохранить**.

# Привязать настройки доступа к родителю

Настройки доступа для вложенного портфеля можно привязать к настройкам родительского портфеля. Настройки наследуются от объекта, который выше только на один уровень.

1. Откройте страницу вложенного портфеля.

2. Вверху экрана нажмите название текущих настроек доступа: **Только участникам** или **Не только участникам**.

3. В специальном разделе в окне настроек нажмите **Привязать**.

    Вы можете посмотреть различия между доступами родительского и вложенного портфеля и выбрать, хотите ли вы менять настройки. Для этого нажмите **Сравнить**.

Чтобы отключить наследование настроек доступа, в том же разделе нажмите **Отвязать**.

Чтобы наследование настроек включилось автоматически, создайте вложенный портфель на странице основного: перейдите на вкладку **Проекты** и внизу нажмите  **Добавить портфель** → **Новый**.

# Выбрать тип доступа по умолчанию для новых портфелей

Администратор Трекера может выбрать, какой тип доступа будет использоваться по умолчанию для всех новых портфелей в Трекере: только участникам или другим пользователям. После создания портфеля настройки доступа можно будет изменить.

1. На панели слева нажмите **Администрирование** →  **Проекты и портфели**.

2. В списке **Доступ к новым портфелях по умолчанию** выберите тип доступа.
