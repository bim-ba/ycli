# Как изменить основные параметры очереди

- По умолчанию настраивать очередь может [только ее владелец](https://yandex.ru/support/tracker/ru/manager/queue-access).
- *Ключ очереди* изменить нельзя.

Чтобы настроить основные параметры очереди:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Основные**.

4. Настройте параметры очереди.

    - Основные параметры:

        - **Название очереди**.

        - **Описание**. Описание отображается на странице очереди под ее названием.

        - **Сообщение при отсутствии доступа**. Отображается у пользователя, если у него нет доступа к задаче или очереди.

        - **Отображать пользователей, которые просматривают задачу** — опция включает отображение пользователей, которые просматривают задачу в данный момент. Когда опция включена, на странице задачи отображается индикатор . Если навести на него указатель, можно увидеть, кто просматривает задачу одновременно с вами. Индикатор также виден в списке задач.

    - В разделе **Страница задачи**:

        - **Всегда показывать поля в задаче** — параметры, которые будут отображаться на странице задачи вне зависимости от [настроек пользователя](https://yandex.ru/support/tracker/ru/user/edit-ticket#edit-fields).
        - **Приоритет по умолчанию** — приоритет, в котором по умолчанию будут создаваться задачи.
        - **Ограничить выгрузку задач в отчёты** — частично или полностью ограничивает выгрузку задач в [отчёты](https://yandex.ru/support/tracker/ru/user/dashboard-reports#restrict).
        - **Реакции в задачах** — разрешить или запретить пользователям оставлять реакции на комментарии в задачах очереди.
        - **Показывать кнопки перехода из текущего статуса под названием задачи** — показ кнопок изменения статуса задачи.
        - **Не связывать с задачами других очередей по ссылке** — не добавлять связь, если в комментарий или в описание задачи вставлен ключ задачи из другой очереди.
        - **Копировать задачи внутри очереди и перемещать из других очередей в эту** — если в очереди разрешено создание задач только через [форму](https://yandex.ru/support/tracker/ru/user/forms-template#display-form), эта опция позволяет копировать и перемещать задачи в очередь всем пользователям с доступом к созданию задач.
5. Нажмите кнопку **Сохранить**.
