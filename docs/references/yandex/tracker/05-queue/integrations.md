# Как настроить интеграции очереди

Чтобы управлять интеграциями очереди Трекера с другими сервисами:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Интеграции**.

В Трекере доступны следующие интеграции:

- **Формы** — позволяет использовать формы как шаблоны для задач: когда пользователь заполняет форму, автоматически создается задача в Трекере, а данные из полей формы записываются в параметры задачи. [Как настроить интеграцию с Формами](https://yandex.ru/support/tracker/ru/manager/about-forms-integration)
- **Почта** — позволяет создавать задачи из писем, отправленных на почтовый адрес очереди, и вести переписку с внешними пользователями со страницы задачи. Например, это полезно, чтобы регистрировать обращения пользователей в службу поддержки. [Как настроить интеграцию с Почтой](https://yandex.ru/support/tracker/ru/manager/queue-mail)
- **Коммиты** — позволяет привязывать к задаче коммиты в репозитории. [Как настроить интеграцию с репозиторием](https://yandex.ru/support/tracker/ru/user/add-repository).
