# Как удалить очередь в Трекере

Удалить очередь может ее [владелец](https://yandex.ru/support/tracker/ru/manager/queue-team) и администраторы организации, а также пользователи, которые имеют [право `Настройки очереди`](https://yandex.ru/support/tracker/ru/manager/queue-access#permissions).

Создать новую очередь с тем же ключом будет нельзя. После удаления восстановить очередь и ее задачи можно только с помощью [запроса к API](https://yandex.ru/support/tracker/api-ref/queues/restore-queue.html).

Чтобы удалить очередь и все входящие в нее задачи:

1. Откройте [страницу очереди](https://yandex.ru/support/tracker/ru/user/queue).

2. Перед удалением очереди убедитесь, что вы [перенесли важные задачи](https://yandex.ru/support/tracker/ru/user/move-ticket) в другие очереди.

3. В правом верхнем углу страницы нажмите  **Настройки очереди**.

4. В правом верхнем углу страницы нажмите →  **Удалить очередь**.

5. Подтвердите удаление.
