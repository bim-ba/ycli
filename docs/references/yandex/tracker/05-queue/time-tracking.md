# Расширенный учет времени

Для гибкой работы с [записями о затраченном времени](https://yandex.ru/support/tracker/ru/user/time-spent) включите расширенный учет времени в настройках очереди.

В расширенном варианте учета времени вы можете:

- Изменить или удалить запись о затраченном времени без использования API.
- Включить автоматический расчет затраченного времени.
- Добавить полосу прогресса задачи.
- Изменить формат отображения времени.
- Указать время целым или дробным числом.

# Включите опцию

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди** и перейдите в раздел **Учёт времени**.
3. Включите опцию **Расширенный учёт времени**.
4. Заполните обязательный параметр **График работы**.
5. Нажмите **Сохранить**.

Другие параметры можно настроить позже.

Вы можете переключаться между базовым и расширенным учетом времени. Данные о затраченном времени в задачах сохранятся.

# Настройте учет времени

- **Разрешить редактирование своих записей**. Включите эту опцию, и автор записи сможет изменить или удалить свою запись [в окне **История учёта времени**](https://yandex.ru/support/tracker/ru/user/time-spent#records-history). По умолчанию отредактировать запись о затраченном времени можно только [запросом к API](https://yandex.ru/support/tracker/api-ref/issues/patch-worklog.html).

- **Рассчитывать затраченное время автоматически**. С этой опцией затраченным временем считается промежуток между [статусами](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit#status-types) типов  и . Учитывается только рабочее время по графику, указанному в параметре **График работы**.

    Пример автоматического расчета

    > Для очереди настроен график `Будни, 8:00–17:00`.
    >
    > В пятницу 1 июня в 9:00 задачу перевели из статуса **Открыт** в статус **В работе**. А в понедельник 4 июня в 14:00 задачу перевели в статус **Закрыт**.
    >
    > Трекер учтет только два отрезка времени: 1 июня с 9:00 до 17:00 и 4 июня с 8:00 до 14:00. 2 и 3 июня не учитываются, потому что суббота и воскресенье — выходные.
    >
    > По этой логике на задачу затрачено 14 часов.

- **Отображать поле «Осталось времени»**. Включите эту опцию и указывайте, сколько времени вы планируете продолжать работу над задачей. На странице задачи в меню **Учёт времени** появится полоса прогресса.

- **Отображать поле «Общая оценка задачи»**. Включите эту опцию и укажите общее время, которое планируете потратить на выполнение задачи. На странице задачи в меню **Учёт времени** появится полоса прогресса.

    Как изменяются значения **Осталось времени** и **Общая оценка задачи**

    Значения полей **Осталось времени** и **Общая оценка задачи** связаны друг с другом:

    `Затрачено времени + Осталось времени = Общая оценка задачи`

    Если оба поля заполнены, при изменении одного из них другое поле изменится на ту же величину.

- **График работы**. Укажите график работы исполнителей. Эти данные нужны для автоматического расчета затраченного времени. Если вам не подходят предложенные варианты, [создайте свой график](https://yandex.ru/support/tracker/ru/manager/schedule).

- **Формат отображения времени**. По умолчанию затраченное время отображается в формате `1н 2д 3ч 4м 5с`: указано количество рабочих недель, дней, часов, минут и секунд. Вы можете выбрать другой формат.

- **Единицы измерения по умолчанию**. Выберите предпочтительную единицу измерения, чтобы [указывать время без буквенных обозначений](https://yandex.ru/support/tracker/ru/user/time-spent#add-extended-time-spent).
