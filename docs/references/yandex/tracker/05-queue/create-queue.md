Каждая задача входит в одну из очередей задач. Обычно в очередь группируют задачи, объединенные общей тематикой. Это могут быть задачи проекта, отдела или команды.

Создать очередь в Трекере можно тремя способами:

- [С помощью шаблона](https://yandex.ru/support/tracker/ru/manager/create-queue#create-from-template).
- [С нуля](https://yandex.ru/support/tracker/ru/manager/create-queue#create-manual).
- [Копируя другую очередь](https://yandex.ru/support/tracker/ru/manager/create-queue#create-from-copy).

## Придумайте ключ очереди

Для создания очереди вам потребуется придумать ключ и название. Старайтесь использовать ключи, которые отражают назначение очереди. Например, ключ `HR` для задач отдела кадров или `SUPPORT` для задач службы поддержки.

Ключ очереди — это уникальный код, по которому можно идентифицировать очередь. Каждой задаче, входящей в очередь, присваивается ключ задачи, который состоит из ключа очереди и порядкового номера.

К ключу очереди есть несколько требований:

- Он должен состоять только из латиницы, без пробелов и специальных символов.
- Он должен быть уникальным: новой очереди нельзя присвоить ключ, который принадлежал ранее удаленной очереди.
- Он должен быть разрешенным: есть несколько ключей, которые нельзя использовать для очереди, например, `ADMIN` или `SETTINGS`.

Ключ очереди можно использовать:

- Для поиска задач — указывать ключ очереди в [условиях фильтров](https://yandex.ru/support/tracker/ru/user/create-filter) и в [языке запросов](https://yandex.ru/support/tracker/ru/user/query-filter).
- Для прямого доступа к очереди по адресу: `(https://tracker.yandex.ru/ключ_очереди)`.

# Как создать очередь с помощью шаблона

1. На панели слева нажмите  **Очереди** → **Создать очередь**.

2. Выберите подходящий шаблон очереди. Подробнее о шаблонах и их настройках: [Шаблоны очередей](https://yandex.ru/support/tracker/ru/manager/work-process).

3. Придумайте название и ключ новой очереди.

4. Укажите, у кого будет возможность просматривать задачи очереди:

    - **Все сотрудники** — задачи очереди будут доступны всем сотрудникам организации.
    - **Я и участники задач** — задачи очереди будут доступны только владельцу очереди и пользователям, которые указаны в полях **Автор**, **Исполнитель**, **Наблюдатели** и **Доступ**.
5. Нажмите кнопку **Продолжить**. Новая очередь появится в разделе  **Очереди** на панели слева.

# Как создать и настроить очередь самостоятельно

Если для ваших задач не подходит ни один из заготовленных шаблонов, вы можете задать все настройки новой очереди самостоятельно:

1. На панели слева нажмите  **Очереди** → **Создать очередь**.

2. Выберите вариант  **С нуля**.

3. Придумайте название и ключ новой очереди.

4. Укажите, у кого будет возможность просматривать задачи очереди:

    - **Все сотрудники** — задачи очереди будут доступны всем сотрудникам организации.
    - **Я и участники задач** — задачи очереди будут доступны только владельцу очереди и пользователям, которые указаны в полях **Автор**, **Исполнитель**, **Наблюдатели** и **Доступ**.
5. Выберите рабочий процесс очереди — набор статусов задачи и правил перехода между ними. Подробнее: [Рабочие процессы: как настроить статусы, переходы и типы задач в очереди](https://yandex.ru/support/tracker/ru/manager/workflow)

6. Нажмите кнопку **Продолжить**. Новая очередь появится в разделе  **Очереди** на панели слева.

# Как скопировать очередь

Если вы хотите использовать настройки существующей очереди, скопируйте ее:

1. На панели слева нажмите  **Очереди** → **Создать очередь**.

2. Выберите вариант  **Копировать другую очередь**.

3. Введите ключ или название очереди, настройки которой будут скопированы.

4. Придумайте название и ключ новой очереди.

5. Нажмите кнопку **Продолжить**. Новая очередь появится в разделе  **Очереди** на панели слева.
