Каждая задача в Трекере входит в одну из [очередей задач](https://yandex.ru/support/tracker/ru/queue-intro). Обычно к одной очереди относят задачи с общей тематикой. Это могут быть задачи проекта, отдела или команды.

Чтобы просмотреть все задачи очереди, откройте ее страницу:

1. На панели слева выберите  **Очереди**.

2. Выберите фильтр для отображения списка очередей:

    - **Мои очереди**.
    - **Я владелец**.
    - **Избранные**.
    - **Недавно просмотренные**.
3. Если отобразились не все нужные очереди, откройте полный список:

    - На панели слева в нижней части страницы нажмите кнопку **Полный список...** для выбранного фильтра.

    - Чтобы открыть все очереди, которые доступны вам в Трекере, в нижней части окна нажмите кнопку **Все очереди организации** или перейдите по ссылке [https://tracker.yandex.ru/queues](https://tracker.yandex.ru/queues) .

4. Нажмите на название нужной очереди.

По умолчанию на странице очереди отображаются только активные задачи (опция **Резолюция: Без значения**). Вы можете настроить отображение задач с помощью кнопок [фильтров по параметрам](https://yandex.ru/support/tracker/ru/manager/quick-filters) над списком задач.

Чтобы быстро найти задачу в списке, который сформирован фильтром, введите текст в строку **Поиск по названию задачи**.

Список с результатами поиска можно настроить: отсортировать или сгруппировать задачи, выбрать столбцы с параметрами. Как это сделать, рассказали на странице [Как настроить список результатов поиска задач](https://yandex.ru/support/tracker/ru/user/actions-on-filter).

Откройте список задач с расширенными возможностями поиска: нажмите  **Задачи** → **Все задачи** или перейдите по ссылке [https://tracker.yandex.ru/issues](https://yandex.ru/support/tracker/ru/https:/tracker.yandex.ru/issues) .

Чтобы искать по локальному полю конкретной очереди, перед названием поля введите ключ очереди и точку (например, `DEVS.Тестировщик`). Что такое локальное поле рассказали на странице [Локальные поля задач](https://yandex.ru/support/tracker/ru/local-fields).

Если вам нужны данные для отчета, вы можете сохранить значения параметров задач в формате таблицы: в правом верхнем углу нажмите **Выгрузить** → **Отчёт по задачам** → **XLSX**.

1. В правом углу таблицы нажмите  **Настройки**.
2. В выпадающем списке нажимайте на параметры, чтобы выбрать их или снять выделение.
3. Когда настроите список, нажмите **Применить**.

# Добавить очередь в избранное

Если вам нужен быстрый доступ к определенной очереди, добавьте ее в избранное:

1. Откройте страницу очереди.

2. Вверху страницы над названием очереди нажмите на значок  **Добавить в избранное**.

Чтобы открыть список избранных очередей:

1. На панели слева выберите  **Очереди**.

2. В списке справа выберите фильтр **Избранные**.

# Диаграмма Ганта для задач очереди

Диаграмма Ганта в Трекере — это инструмент для составления календарного плана работ над задачами. На диаграмме Ганта отображаются все задачи и связи между ними. [Подробнее о диаграмме Ганта для очереди задач](https://yandex.ru/support/tracker/ru/gantt/queue)
