Компоненты помогают группировать задачи [очереди](https://yandex.ru/support/tracker/ru/user/queue), относящиеся к одной тематике: продукту, процессу, ответственному сотруднику и так далее. В очереди можно создать несколько компонентов.

Например, с помощью компонентов можно классифицировать обращения в службу поддержки: [Группировать обращения по темам](https://yandex.ru/support/tracker/ru/support-process-group).

# Создать компонент

Чтобы создать новый компонент очереди:

1. На панели слева нажмите  **Очереди** и выберите из списка нужную очередь.

2. В правом верхнем углу страницы выберите  **Действия над очередью** →  **Компоненты**.

3. Нажмите кнопку **Создать компонент**.

4. Введите **Название** компонента.

5. При необходимости выберите ответственного и заполните описание компонента.

6. Выберите опцию **Назначать исполнителем по умолчанию**, если вы хотите, чтобы новые задачи с этим компонентом автоматически назначались на ответственного.

7. Нажмите кнопку **Создать**.

# Изменить компонент

Чтобы изменить существующий компонент очереди:

1. На панели слева нажмите  **Очереди** и выберите из списка нужную очередь.

2. В правом верхнем углу страницы выберите  **Действия над очередью** →  **Компоненты**.

3. Наведите курсор на компонент.

4. Выберите → **Редактировать**.

5. Внесите изменения и нажмите кнопку **Сохранить**.

# Подписаться на компонент

Если вы хотите получать уведомления об изменениях задач, связанных с определенным компонентом, вы можете подписаться на него:

1. На панели слева нажмите  **Очереди** и выберите из списка нужную очередь.

2. В правом верхнем углу страницы выберите  **Действия над очередью** →  **Компоненты**.

3. Наведите курсор на компонент.

4. Выберите → **Подписаться на задачи с этим компонентом**.

# Настроить доступ к задачам с компонентом

Изменить [права доступа к задачам с компонентом](https://yandex.ru/support/tracker/ru/manager/queue-access#access-component) можно в настройках очереди:

1. На панели слева нажмите  **Очереди** и выберите из списка нужную очередь.

2. Перейдите в  **Настройки очереди** → **Права доступа** → **Задачи с компонентом**.

В этом разделе вы также можете управлять компонентами: изменять, удалять и создавать новые.

# Просмотреть задачи компонента

Вы можете просмотреть список задач, относящихся к определенному компоненту:

1. На панели слева нажмите  **Очереди** и выберите из списка нужную очередь.

2. В правом верхнем углу страницы выберите  **Действия над очередью** →  **Компоненты**.

3. Нажмите на название компонента.

# Удалить компонент

Чтобы удалить компонент очереди:

1. На панели слева нажмите  **Очереди** и выберите из списка нужную очередь.

2. В правом верхнем углу страницы выберите  **Действия над очередью** →  **Компоненты**.

3. Наведите курсор на компонент.

4. Выберите → **Удалить**.

5. Подтвердите удаление.
