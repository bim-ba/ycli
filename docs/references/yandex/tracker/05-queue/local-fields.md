Если нужно добавить в задачи новый параметр, которого нет среди системных полей в Трекере, вы можете добавить локальные поля в вашу очередь. Список системных глобальных полей можно посмотреть на странице [Настройки Трекера](https://tracker.yandex.ru/admin/fields).

Локальное поле можно использовать только в задачах той очереди, к которой оно привязано. Преимущество локальных полей в том, что владелец очереди может управлять такими полями без риска повлиять на процессы работы в других очередях. Пользователи, которые работают в других очередях, не будут видеть это поле в своих задачах.

# Создать локальное поле

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Локальные поля**.

4. Нажмите кнопку **Создать**.

5. Выберите тип поля и нажмите кнопку **Продолжить**.

6. Задайте параметры нового поля.

    Общие параметры:

    - **Название**. Старайтесь давать полям короткие и емкие названия.
        При необходимости добавьте описание поля.

    - **Название на английском**. Это название видно в английском интерфейсе Трекера.

    - **Категория**. Все поля в Трекере группируются по категориям. Начните вводить название категории, которая лучше всего подходит. Например: `Системные`, `Учёт Времени`, `Agile`, `Email`, `SLA`.
        Подробнее о полях и категориях читайте в разделе [Стандартные поля задач](https://yandex.ru/support/tracker/ru/user/create-param#default-fields).

    - **Ключ** генерируется автоматически по названию на английском.

    Специальные параметры:

    - **Множественный выбор**. Включите эту опцию, и пользователь сможет ввести несколько значений поля.
        Доступен только для полей типов «Список пользователей» и «Выпадающий список».

    - **Тип поля**. Задайте формат значения поля.
        Доступен только для полей типов «Число», «Дата» и «Поле ввода».

    - **Значения в списке**. Укажите возможные значения поля и их порядок.
        Доступен только для поля типа «Выпадающий список». В поле «Выпадающий список» можно добавить до 3000 значений. При нажатии на поле отображается не более 10 элементов.

7. Нажмите кнопку **Создать**.

Вы можете добавить ограниченное количество полей. Если вам нужно увеличить лимит, обратитесь в [службу технической поддержки](https://yandex.ru/support/tracker/ru/feedback).

# Скопировать локальное поле

Чтобы создать копию уже существующего локального поля:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Локальные поля**.

4. Выберите поле и справа от него нажмите  →  **Скопировать**.

    Откроется окно создания нового поля с уже заполненными параметрами исходного поля. Некоторые параметры нужно изменить, чтобы не было повторений: они будут подсвечены красным.

5. Нажмите **Создать**.

# Редактировать локальное поле

Вы можете изменить свойства локального поля несколькими способами.

### В настройках очереди

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Локальные поля**.

4. Выберите поле и справа от него нажмите  →  **Редактировать**.

    Откроется окно с параметрами поля: поменяйте текущее значение на новое и нажмите **Сохранить**.

5. Чтобы изменить категорию локального поля, нажмите  →  **Сменить категорию**.

    Начните вводить название новой категории и выберите нужный вариант из списка.

### С помощью HTTP-запроса

Также можно отредактировать свойства, категорию или видимость поля с помощью [запроса к API Яндекс Трекера на изменение локального поля](https://yandex.ru/support/tracker/api-ref/queues/edit-local-field.html).

# Удалить локальное поле

Удалить локальное поле невозможно, но можно скрыть его из интерфейса Трекера. Скрытое поле нельзя добавить в задачу.

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Локальные поля**.

4. Выберите поле и справа от него нажмите  →  **Удалить**.

Также можно настроить видимость глобального поля с помощью [запроса к API Яндекс Трекера на изменение локального поля](https://yandex.ru/support/tracker/api-ref/queues/edit-local-field.html):

- Чтобы скрыть поле, для параметра `hidden` установите значение `true`.
- Чтобы восстановить поле, для параметра `hidden` установите значение `false`.

# Особенности использования локальных полей

Локальные поля используются так же, как и глобальные, но есть особенности, которые стоит учитывать:

- При выборе [параметра для фильтрации задач](https://yandex.ru/support/tracker/ru/user/create-filter#set-conditions) можно выполнить поиск локального поля только в одной очереди. Для этого перед названием поля введите *ключ очереди* и точку (например, `DEVS.Тестировщик`). Это поможет избежать путаницы, если в разных очередях вы используете локальные поля с одинаковыми названиями.

- Чтобы искать задачи по локальному полю с помощью [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter), введите ключ очереди, точку и название поля на русском или английском языке. Затем добавьте двоеточие и значение локального поля. Например: `DEVS.Тестировщик: "Иван Иванов"`. Если название поля состоит из нескольких слов, укажите название в кавычках.

- При [переносе](https://yandex.ru/support/tracker/ru/user/move-ticket) и [копировании](https://yandex.ru/support/tracker/ru/user/clone) задачи с локальными полями в другую очередь значения локальных полей будут удалены.

- При использовании [макросов](https://yandex.ru/support/tracker/ru/manager/create-macroses), [триггеров](https://yandex.ru/support/tracker/ru/user/create-trigger) или [автодействий](https://yandex.ru/support/tracker/ru/user/create-autoaction), чтобы подставить значение локального поля в [комментарий](https://yandex.ru/support/tracker/ru/user/set-action#create-comment), [формулу](https://yandex.ru/support/tracker/ru/user/set-action#section_calc_field) или [HTTP-запрос](https://yandex.ru/support/tracker/ru/user/set-action#create-http) с помощью [переменной](https://yandex.ru/support/tracker/ru/user/vars#local-fields), используйте формат записи `{{issue.local.<ключ_поля>}}`.
