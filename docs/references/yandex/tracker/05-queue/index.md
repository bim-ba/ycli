Каждая задача в Трекере входит в одну из очередей. Очередь — это пространство для задач, объединенных общим процессом или продуктом. Также очередь можно представить как список задач для определенной команды или отдела.

Очереди помогают упорядочить задачи и понять, кто отвечает за их выполнение. Например, можно создать отдельные очереди для отдела кадров, команды проекта и службы поддержки.

В каждой очереди можно настроить свой процесс работы с задачами. Чтобы настроить рабочий процесс, в очереди нужно задать этапы выполнения задач (статусы) и последовательность этих этапов — [рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow). Для распространенных процессов в Трекере предусмотрены [шаблоны очередей](https://yandex.ru/support/tracker/ru/manager/work-process).

Чтобы узнать, как можно адаптировать очередь для вашего процесса, прочитайте [пример настройки очереди для службы поддержки](https://yandex.ru/support/tracker/ru/support-process).

Чтобы сделать работу с задачами более эффективной и адаптировать ее к вашему рабочему процессу, используйте расширенные возможности очереди. Например, автоматическое изменение параметров задач, интеграцию с почтой и так далее.

Вы можете:

- Настроить для задач очереди автоматизацию рутинных действий, таких как изменение значений полей или отправка типовых комментариев. Для этого создайте [триггеры](https://yandex.ru/support/tracker/ru/user/create-trigger), [автодействия](https://yandex.ru/support/tracker/ru/user/create-autoaction) и [макросы](https://yandex.ru/support/tracker/ru/manager/create-macroses).

- [Настроить почтовый адрес очереди](https://yandex.ru/support/tracker/ru/manager/queue-mail), чтобы создавать задачи из входящих писем и отвечать на письма пользователей со страницы задачи. Эта функция поможет регистрировать и обрабатывать обращения пользователей, например в службе поддержки.

- [Встроить на страницу создания задач форму из сервиса Яндекс Формы](https://yandex.ru/support/tracker/ru/manager/attach-form), чтобы использовать ее в качестве шаблона для заполнения полей задачи.

- [Настроить компоненты](https://yandex.ru/support/tracker/ru/manager/components), чтобы группировать задачи очереди по компонентам продукта или по другим общим признакам.

- [Настроить версии](https://yandex.ru/support/tracker/ru/manager/versions), чтобы отмечать версии продукта, к которым относятся задачи очереди.

- [Настроить SLA](https://yandex.ru/support/tracker/ru/sla-head), чтобы контролировать скорость выполнения задач очереди. Эта функция полезна, если важно реагировать на обращения пользователей за определенное время, например в службе поддержки.
