Резолюция — это атрибут задачи, который обозначает результат работы: была ли задача выполнена, отменена или отложена. Например, задача может быть закрыта, потому что она выполнена (резолюция «Решен») или потому что она дублирует другую задачу (резолюция «Дубликат»).

Для каждого *типа задач* в рабочем процессе можно определить свой набор резолюций:

- [Что такое рабочие процессы](https://yandex.ru/support/tracker/ru/manager/workflow)
- [Как настроить типы задач](https://yandex.ru/support/tracker/ru/manager/add-ticket-type)

Редактировать резолюции в рабочих процессах очереди может владелец очереди и пользователи, которым он выдал [доступ к настройкам очереди](https://yandex.ru/support/tracker/ru/manager/queue-access).

Рекомендуем настроить обязательное заполнение поля **Резолюция** для всех переходов в конечный статус, например **Закрыт**: [как настроить экран перехода](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit#screen). Резолюция может влиять на учет закрытых задач и поиск по фильтрам.

В Трекере есть системные резолюции — их список доступен в [настройках Трекера](https://tracker.yandex.ru/admin/resolutions). Эти резолюции можно использовать в любых рабочих процессах. Если среди системных резолюций не нашлось подходящей, [администратор](https://yandex.ru/support/tracker/ru/role-model#admin) Трекера может создать новую резолюцию. Она появится в общем списке резолюций, и пользователи смогут использовать ее в своих очередях.

# Добавить резолюцию в рабочий процесс

Для каждого типа задач в рабочем процессе можно задать свой набор резолюций:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**. Здесь вы увидите список рабочих процессов в очереди.

4. Чтобы добавить в рабочий процесс резолюцию:

    1. Выберите на карточке процесса тип задач.
    2. Наведите курсор на столбец **Резолюции** и нажмите появившийся значок .
    3. Выберите резолюцию из списка.

# Удалить резолюцию из процесса

У каждого типа задач в рабочем процессе свой набор резолюций. Чтобы удалить резолюцию для определенного типа задач:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**. Выберите рабочий процесс, в котором содержится тип задач, из которого вы хотите удалить резолюцию.

4. Наведите курсор на строку типом задач и нажмите на крестик рядом с удаляемой резолюцией.

5. Если в очереди есть задачи, в которых указана удаляемая резолюция, появится окно с предложением изменить резолюцию для этих задач. Выберите новую резолюцию и нажмите **Сохранить и продолжить**.

# Создать новую резолюцию

Создавать новые резолюции может только [администратор](https://yandex.ru/support/tracker/ru/role-model#admin). Созданную резолюцию нельзя удалить или отредактировать.

Создать новую резолюцию можно на странице **Резолюции** в настройках Трекера или на странице **Рабочие процессы** в очереди.

Страница «Резолюции»

Страница «Рабочие процессы»

1. Убедитесь, что вы авторизованы в Яндекс Трекере как [администратор](https://yandex.ru/support/tracker/ru/role-model#admin).

2. На панели слева выберите  **Администрирование** → **Резолюции**.

3. Нажмите кнопку **Создать резолюцию**.

4. Заполните поля:

    - **Название** — укажите название создаваемой резолюции на русском.
    - **Название на английском** — будет сформировано автоматически из названия на русском.
    - **Ключ** — будет сгенерирован автоматически из названия на русском.
5. Нажмите **Создать**.

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**. Здесь вы увидите список рабочих процессов в очереди. Выберите рабочий процесс, в который хотите добавить новую резолюцию.

4. Наведите курсор на часть строки с резолюциями. Нажмите на появившийся значок , начните вводить название новой резолюции и нажмите на кнопку создания.

5. Заполните поля:

    - **Название** — укажите название создаваемой резолюции на русском.
    - **Название на английском** — будет сформировано автоматически из названия на русском.
    - **Ключ** — будет сгенерирован автоматически из названия на русском.
6. Нажмите **Создать**.

Новая резолюция будет сразу же добавлена в рабочий процесс текущей очереди, но использовать ее можно будет и в других очередях.
