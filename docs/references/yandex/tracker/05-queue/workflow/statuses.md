Статус — это атрибут задачи, который обозначает, на каком этапе находится ее выполнение. Например: «Открыт», «В работе», «Тестируется», «Закрыт».

В *очереди задач* можно добавить один или несколько *рабочих процессов* и в каждом процессе настроить свой набор статусов и переходов между ними.

Список статусов, которые можно использовать в рабочих процессах, найти в [настройках Трекера](https://tracker.yandex.ru/admin/statuses). Если среди доступных статусов не нашлось подходящих, [администратор](https://yandex.ru/support/tracker/ru/role-model#admin) может создать новые: [Как создать новый статус](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit#create-status). Новый статус появится в общем списке, и пользователи смогут добавлять его в свои рабочие процессы.

# Добавить статус в рабочий процесс

Чтобы добавить статус в рабочий процесс:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы** и нажмите на название рабочего процесса. Откроется визуальный редактор рабочих процессов.

4. В правом верхнем углу нажмите **Добавить статус**, выберите нужный и нажмите его название или перетащите статус на схему процесса.

    По умолчанию в Трекере доступны самые популярные статусы. Если нужного вам статуса среди них нет, администратор может [создать его](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit#create-status).

5. Соедините добавленный статус переходами с другими статусами в процессе: [Настроить переходы между статусами в рабочем процессе](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit).

6. Если нужно, измените настройки статуса.

# Изменить настройки статуса

Чтобы настроить статус в рабочем процессе:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы** и нажмите на название рабочего процесса, статусы которого вы хотите редактировать.
    Откроется визуальный редактор рабочих процессов.

4. Чтобы настроить статус, выберите его на схеме рабочего процесса — откроется панель с настройками статуса.

## Начало рабочего процесса

Начало рабочего процесса — статус, в котором находится только что созданная задача. В визуальном редакторе рабочих процессов статус, который является началом рабочего процесса, отмечен флажком.

Чтобы сделать статус началом рабочего процесса, выберите его на схеме и на панели справа в правом верхнем углу нажмите значок .

В рабочем процессе обязательно должен быть один статус, который является началом рабочего процесса. Началом рабочего процесса может быть статус любого типа.

## Типы статусов

В рабочем процессе для статуса можно задать тип. Все статусы одного типа окрашиваются в определенный цвет. Задачи со статусами типа «Завершен» и «Отменен» считаются закрытыми: в списке задач очереди *ключ* таких задач отображается зачеркнутым.

Чтобы задать тип статуса, выберите его на схеме и на панели справа в поле **Тип статуса** выберите значение:

- — задачу создали и еще не взяли в работу.
- — задачу взяли в работу.
- — работу над задачей приостановили.
- — задачу выполнили и закрыли.
- — задачу не выполнили и закрыли.

Настройка **Смена статуса при комментарии** позволяет изменить статус после добавления в задачу комментария. Такая настройка пригодится в линейных процессах, например, для службы поддержки.

1. На схеме выберите статус, из которого должен быть выполнен переход при появлении в задаче комментария.

2. На панели справа нажмите **Смена статуса при комментарии**.

3. Выберите из списка, в какой статус должен выполниться переход после добавления комментария. В списке содержатся переходы для настраиваемого статуса, которые уже добавлены на схему рабочего процесса. Пример переходов в списке:

    - В предыдущий статус — задача будет переведена в предшествующий статус;
    - Переход «Закрыть» — задача будет переведена в статус типа «Завершен»;
    - Переход «Нужна информация» — задача будет переведена в статус типа «На паузе»;
    - Переход «Переоткрыть» — задача будет переведена в статус типа «Начальный».
4. При необходимости включите опции **Назначить исполнителя из предыдущего статуса** и **Только если комментарий оставил исполнитель**.

5. Нажмите кнопку **Сохранить**.

## Разрешить переходы из любого статуса

Если требуется добавить в рабочий процесс статус, который достижим из любого другого статуса, используйте опцию **Разрешить переходы из любого статуса**. Тогда вам не придется вручную настраивать переходы для каждого статуса. [Что такое переходы между статусами](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit)

1. На схеме выберите нужный статус.

2. На панели справа включите опцию **Разрешить переходы из любого статуса** — на схеме для этого статуса будет изображен метапереход **Любой статус**.

3. Чтобы настроить переход **Любой статус**, выберите его на схеме процесса: [Как настроить переход](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit#set-transition).

## Копирование переходов

Вы можете копировать существующие переходы и использовать их для других статусов. [Что такое переходы между статусами](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit)

1. На схеме выберите нужный статус и на панели справа нажмите .
2. Нажмите  **Скопировать переходы в другой статус** или  **Вставить переходы из другого статуса**.
3. Выберите из списка статус для вставки или копирования переходов.

# Удалить статус из рабочего процесса

При удалении статуса будут удалены все связанные с ним переходы. Если вы удаляете статус — начало рабочего процесса, на схеме возникнут ошибки, потому что рабочий процесс не может быть без начала.

Чтобы удалить статус из рабочего процесса:

1. На странице очереди в верхнем правом углу нажмите  **Настройки очереди**.

2. Перейдите на вкладку **Рабочие процессы**. Откройте в редакторе рабочий процесс, из которого хотите удалить статус.

3. Нажмите на удаляемый статус и нажмите на клавиатуре **Delete** или перейдите в настройки статуса и нажмите → **Убрать из процесса**.

4. Если в очереди есть задачи, которые находятся в удаляемом статусе, появится окно с предложением изменить статус этих задач. Выберите новый статус и нажмите **Сохранить и продолжить**.

# Создать новый статус

Создавать новые статусы задач может только [администратор](https://yandex.ru/support/tracker/ru/role-model#admin). Созданный статус нельзя удалить или отредактировать.

Страница «Статусы задач»

Редактор рабочего процесса

1. Убедитесь, что вы авторизованы в Яндекс Трекере как [администратор](https://yandex.ru/support/tracker/ru/role-model#admin).

2. На панели слева выберите  **Администрирование** → **Статусы задач**.

3. Нажмите кнопку **Создать статус**.

4. Заполните поля:

    - **Название** — укажите название статуса на русском.
    - **Название на английском** — будет сформировано автоматически из названия на русском.
    - **Ключ** — будет сгенерирован автоматически из названия на русском.
5. Нажмите **Создать**.

Новый статус будет сразу же добавлен в рабочий процесс текущей очереди, но использовать его можно будет и в других очередях.

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**. Здесь вы увидите список рабочих процессов в очереди. Выберите рабочий процесс, в который хотите добавить новый статус, и нажмите на его название. Откроется визуальный редактор рабочих процессов.

4. На верхней панели визуального редактора процессов нажмите **Добавить статус**. Начните вводить название нового статуса и нажмите на кнопку создания.

5. Заполните поля:

    - **Название** — укажите название статуса на русском.
    - **Название на английском** — будет сформировано автоматически из названия на русском.
    - **Ключ** — будет сгенерирован автоматически из названия на русском.
6. Выберите из списка подходящий для статуса тип.

7. Нажмите **Создать**.

Новый статус будет сразу же добавлен в рабочий процесс текущей очереди, но использовать его можно будет и в других очередях.
