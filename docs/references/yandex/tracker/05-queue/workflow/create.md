В каждой *очереди* по умолчанию используется один из стандартных *рабочих процессов*, который владелец очереди выбирает при ее создании. Если стандартный рабочий процесс в очереди вам не подходит или вы хотите изменить его настройки, вы можете создать новый рабочий процесс или скопировать существующий.

Чтобы упростить создание рабочего процесса и избежать ошибок при настройке, рекомендуем скопировать процесс, который настроен в очереди по умолчанию, и добавить недостающие элементы.

# Создать копию существующего процесса

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы** и на карточке стандартного рабочего процесса нажмите кнопку **Дублировать**.

    Если на карточке стандартного рабочего процесса нажать кнопку **Редактировать**, автоматически будет создана его копия и откроется редактор процесса.

4. Чтобы отредактировать созданную копию процесса, на его карточке нажмите кнопку **Редактировать**, откроется редактор процесса:

    - [Добавить статус в рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit#add-status)
    - [Добавить переход между статусами](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit#add-action)
5. Настройте для процесса типы задач и резолюции:

    - [Как настроить типы задач](https://yandex.ru/support/tracker/ru/manager/add-ticket-type)
    - [Как настроить резолюции](https://yandex.ru/support/tracker/ru/manager/create-resolution)

# Скопировать процесс из другой очереди

Чтобы скопировать рабочий процесс из другой очереди:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. На вкладке **Рабочие процессы** в правом верхнем углу нажмите **Копировать рабочий процесс из другой очереди**.

4. В открывшемся окне:

    - Выберите очередь, из которой нужно скопировать процесс.
    - Выберите процесс для копирования.
    - Введите название нового процесса в вашей очереди.
5. Нажмите **Скопировать**.

При копировании рабочего процесса из другой очереди будет перенесена схема процесса со всеми статусами, переходами и их настройками. Типы задач и резолюции из другой очереди не переносятся.

# Создать новый рабочий процесс

Чтобы создать рабочий процесс:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы** и в правом верхнем углу нажмите **Создать рабочий процесс**. Откроется визуальный редактор рабочих процессов.

4. В редакторе рабочих процессов добавьте статусы и переходы между ними:

    - [Добавить статус в рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit#add-status)
    - [Добавить переход между статусами](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit#add-action)

    Для всех переходов в конечный статус, например **Закрыт**, рекомендуем настроить экран перехода с обязательным заполнением *резолюции*: [Как настроить экран перехода](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit#screen). Резолюция может влиять на учет закрытых задач и поиск по фильтрам.

5. Закончив настройку процесса, в правом верхнем углу нажмите кнопку **Сохранить**.

6. В открывшемся окне добавьте в рабочий процесс *типы задач* и *резолюции*:

    1. Нажмите **Добавить тип задачи**, затем выберите тип из списка.
    2. Для каждого типа задачи добавьте резолюции: рядом с типом задачи в колонке **Резолюция** нажмите и выберите нужные из списка.
    3. Нажмите кнопку **Применить**.

# Удалить рабочий процесс

Чтобы удалить рабочий процесс:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**.

4. Удалите из процесса, который хотите удалить, *резолюции* и *типы задач*.

5. Удалите сам процесс: на карточке процесса нажмите .
