Работа отдела или команды обычно состоит из потока похожих задач, для выполнения которых сотрудники используют определенную последовательности действий или этапов. Чтобы вашим сотрудникам было удобно выполнять задачи в Трекере, рабочий процесс команды нужно перенести в Трекер.

В Трекере рабочий процесс связан с *очередью задач*. Он может включать несколько типов задач (например, заявки, разработку новых функций, исправление ошибок), этапы работы над задачами (*статусы*) и последовательность прохождения статусов.

Рабочий процесс действует в пределах очереди, в которой он настроен. В каждую очередь можно добавить несколько рабочих процессов, если нужно настроить разные наборы статусов для разных типов задач.

*Рабочий процесс в Трекере: статусы и переходы между ними*

На схеме в визуальном редакторе рабочих процессов статусы — это прямоугольные блоки, раскрашенные цветами, соответствующими [типам статусов](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit#status-types), а стрелки между блоками — переходы.

# Из чего состоит рабочий процесс

Рабочий процесс характеризуется следующими сущностями Трекера:

- *Статусы задач* — набор статусов, которые задачи могут проходить в процессе работы.

- Переходы между статусами — определяют, можно ли перейти из одного статуса в другой. Также с помощью переходов можно настроить автоматические действия, которые будут выполняться при изменении статуса, и экраны переходов, чтобы пользователи заполняли некоторые поля задачи.

- Типы задач — рабочие процессы действуют для выбранных типов задач, например «Новая возможность», «Улучшение» или «Ошибка». Для каждого типа задачи можно выбрать набор допустимых *резолюций*.

    Для разных типов задач в очереди можно создать несколько рабочих процессов, чтобы учитывать особенности выполнения задач каждого типа.

# При создании очереди нужно сразу создавать рабочий процесс?

Нет, при создании очереди используется шаблон со стандартным рабочим процессом. Этот рабочий процесс сразу начинает действовать в задачах очереди. В редакторе рабочих процессов владелец очереди может посмотреть на схеме, как устроен рабочий процесс, скорректировать его или создать новые процессы для новых типов задач.

- [Как создать очередь](https://yandex.ru/support/tracker/ru/manager/create-queue)
- [Шаблоны очередей со стандартными процессами](https://yandex.ru/support/tracker/ru/manager/work-process)

# Как управлять рабочими процессами

Управлять рабочими процессами в очереди может ее владелец и пользователи, которым он выдал [доступ к настройкам очереди](https://yandex.ru/support/tracker/ru/manager/queue-access).

Чтобы настроить рабочий процесс в очереди:

1. Создайте новый рабочий процесс или скопируйте стандартный процесс: [Как создать рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow-create)
2. Добавьте на схему процесса нужные статусы: [Как настроить статусы задач](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit)
3. Настройте переходы между статусами: [Как настроить переходы](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit)
4. Добавьте в рабочий процесс типы задач: [Как добавить типы задач](https://yandex.ru/support/tracker/ru/manager/add-ticket-type)
5. Добавьте к типам задач в процессе резолюции: [Как добавить резолюции](https://yandex.ru/support/tracker/ru/manager/create-resolution)
