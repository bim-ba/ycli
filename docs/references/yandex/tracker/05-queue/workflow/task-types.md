Для задач в *очереди* можно назначать разные типы, например «Новая возможность», «Улучшение» или «Ошибка». Типы задач помогают при разделении работ внутри команды по направлениям деятельности («Новая возможность», «Ошибка», «Улучшение») или при декомпозиции задач («Epic», «Story», «Задача»). Если у вашей команды простой процесс работы, можно использовать один тип — «Задача».

Чтобы использовать в очереди какой-либо тип задач, добавьте этот тип в настройки рабочего процесса — тогда все задачи этого типа будут проходить последовательность *статусов*, заданную в процессе. [Что такое рабочие процессы](https://yandex.ru/support/tracker/ru/manager/workflow)

Редактировать настройки рабочих процессов в очереди может владелец очереди и пользователи, которым он выдал [доступ к настройкам очереди](https://yandex.ru/support/tracker/ru/manager/queue-access).

В Трекере есть системные типы задач — их список доступен в [настройках Трекера](https://tracker.yandex.ru/admin/types). Эти типы задач можно использовать в любых рабочих процессах. Если среди системных типов задач не нашлось подходящего, [администратор](https://yandex.ru/support/tracker/ru/role-model#admin) может создать новый тип задачи. Он появится в общем списке типов задач, и пользователи смогут использовать его в своих очередях.

# Добавить тип задачи в рабочий процесс

Чтобы добавить в рабочий процесс тип задачи:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**. Здесь вы увидите список рабочих процессов в очереди, а также типы задач и резолюции, которые определены для каждого из них.

4. Чтобы добавить в процесс тип задачи, в блоке с этим процессом нажмите **Добавить тип задачи** и выберите тип задачи из списка.

Если нужный тип задачи уже используется в другом рабочем процессе в вашей очереди, сначала удалите его из другого процесса. Не рекомендуем создавать новый тип задач с таким же названием, это может вызвать путаницу.

# Назначить тип задачи по умолчанию

Тип задач по умолчанию автоматически назначается для всех новых задач, создаваемых в очереди. Вы можете его изменить:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**.

4. Вверху страницы в поле **Тип задачи** выберите один из типов.

# Перенести тип задач из одного процесса в другой

Если нужно изменить рабочий процесс для одного из типов задач в вашей очереди:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**.

4. Найдите рабочий процесс, в котором содержится тип задач, который вы хотите перенести в другой процесс.

5. Наведите указатель на строку типом задач, нажмите → **Перенести в другой процесс** и выберите другой рабочий процесс в вашей очереди.

В результате все задачи этого типа в вашей очереди перейдут на новый рабочий процесс.

# Удалить тип задачи из процесса

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**. Здесь вы увидите список рабочих процессов в очереди. Выберите рабочий процесс, в котором содержится тип задач, который вы хотите удалить.

4. На карточке процесса наведите указатель на строку с удаляемым типом задач и нажмите → **Удалить из очереди**.

    Невозможно удалить тип задач, который [выбран для очереди по умолчанию](https://yandex.ru/support/tracker/ru/manager/add-ticket-type#default).

5. Если в очереди есть задачи, которые относятся к удаляемому типу, появится окно с предложением изменить тип для этих задач. Выберите новый тип и нажмите **Сохранить и продолжить**.

# Создать новый тип задачи

Создавать новые типы задач может только [администратор](https://yandex.ru/support/tracker/ru/role-model#admin). Созданный тип задачи нельзя удалить или отредактировать.

Создать новый тип задач можно на странице **Типы задач** в настройках Трекера или на странице **Рабочие процессы** в очереди.

Страница «Типы задач»

Страница «Рабочие процессы»

1. Убедитесь, что вы авторизованы в Яндекс Трекере как [администратор](https://yandex.ru/support/tracker/ru/role-model#admin).

2. На панели слева выберите  **Администрирование** → **Типы задач**.

3. Нажмите кнопку **Создать тип задачи**.

4. Заполните поля:

    - **Название** — укажите название создаваемого типа задач на русском.
    - **Название на английском** — будет сформировано автоматически из названия на русском.
    - **Ключ** — будет сгенерирован автоматически из названия на русском.
5. Нажмите **Создать**.

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Рабочие процессы**. Здесь вы увидите список рабочих процессов в очереди. Выберите рабочий процесс, в который хотите добавить новый тип задач, и в строке этого рабочего процесса нажмите .

4. Нажмите **Добавить тип задачи**, начните вводить название нового типа задач и нажмите на кнопку создания.

5. Заполните поля:

    - **Название** — укажите название создаваемого типа задач на русском.
    - **Название на английском** — будет сформировано автоматически из названия на русском.
    - **Ключ** — будет сгенерирован автоматически из названия на русском.
6. Нажмите **Создать**.

Новый тип задачи будет сразу же добавлен в рабочий процесс текущей очереди, но использовать его можно будет и в других очередях.
