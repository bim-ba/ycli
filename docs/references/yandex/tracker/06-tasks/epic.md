В *гибких методологиях разработки* эпики и истории (User story) используют для декомпозиции задач.

Например, если команда разрабатывает приложение для работы с электронными документами, эпиком может быть добавление модуля для редактирования таблиц. Эпик может включать такие истории, как возможность добавления строк и столбцов, возможность выбрать границы и цвет ячеек и так далее. Каждую историю можно разбить на задачи исполнителей — дизайнера, разработчика, тестировщика.

Чтобы создавать эпики и истории, в Трекере предусмотрены типы задач Epic и Story. Чтобы использовать эти типы задач, добавьте их в рабочий процесс вашей очереди: [Как настроить рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow).

У задач типа Epic есть несколько особенностей:

- У эпика не может быть родительской задачи.
- Чтобы добавить задачи в эпик, используется тип связи «Эпик — Подэпик».
- Эпик не может быть подэпиком другого эпика.

О связях читайте на странице [Как изменить связи задачи](https://yandex.ru/support/tracker/ru/user/ticket-links).

# Создать эпик на доске задач

1. На доске нажмите кнопку  **Создать задачу**.
2. Перейдите на страницу полной формы создания задачи. Для этого нажмите (**Открыть полную форму**).
3. Заполните все необходимые поля задачи. В поле **Тип** укажите `Epic`.
4. Нажмите кнопку **Создать задачу**.

# Добавить задачу в эпик

Вы можете добавить задачу в эпик с помощью [связи](https://yandex.ru/support/tracker/ru/user/ticket-links) одним из двух способов: со страницы эпика или со страницы задачи.

Задача может входить только в один эпик.

## На странице эпика

1. На странице эпика в блоке **Связанные задачи** нажмите **Добавить связь**.

2. Выберите тип связи **Подэпик**.

3. Укажите *ключ задачи*.

## На странице задачи

1. На странице задачи в блоке **Связанные задачи** нажмите **Добавить связь**.

2. Выберите тип связи **Epic**.

3. Укажите *ключ эпика*.

# Создать новую задачу в эпике

1. На странице эпика в блоке **Задачи эпика** нажмите  **Добавить**.
2. Заполните необходимые поля и сохраните задачу.

# Удалить задачу из эпика

Удалить задачу из эпика можно одним из двух способов: на странице задачи или на доске.

## На странице задачи

На странице задачи в блоке **Связанные задачи** в секции **Epic** удалите связь с эпиком.

## На доске задач

На доске [сгруппируйте задачи по эпику](https://yandex.ru/support/tracker/ru/manager/epic#group-by-epic) и перетащите карточку задачи в раздел **Без эпика**.

# Сгруппировать задачи по эпикам

Вы можете сгруппировать задачи по эпикам на доске, в фильтре задач или на странице очереди:.

1. В списке задач или на доске в правом верхнем углу нажмите кнопку .
2. В списке опций выберите **Epic**.

# Отфильтровать задачи по эпику

Вы также можете отфильтровать задачи в очереди или на странице задач с помощью [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter):

1. В правом верхнем углу страницы нажмите  **Язык запросов**. Все текущие параметры поиска, которые были заданы с помощью быстрых фильтров и условий, отобразятся в строке запроса.

2. Добавьте в строку условия для фильтрации по эпику. Например:

    - Отобразить все задачи, у которых есть эпик:

        ```
        epic: notEmpty()
        ```

    - Отобразить все задачи из эпика с ключом `EPIC-1`:

        ```
        epic: "EPIC-1"
        ```
