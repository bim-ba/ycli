Чтобы создать задачу по почте, отправьте письмо с описанием задачи на [адрес очереди](https://yandex.ru/support/tracker/ru/manager/queue-mail):

1. Убедитесь, что у очереди настроен [почтовый адрес](https://yandex.ru/support/tracker/ru/manager/queue-mail) для создания задач.

2. Убедитесь, что у вас есть [доступ к очереди](https://yandex.ru/support/tracker/ru/manager/queue-access).

3. Создайте новое письмо.

4. Укажите название задачи в поле **Тема**.

5. Чтобы автоматически назначить исполнителя для новой задачи, укажите почту сотрудника в поле письма **Копия**. Если в списке несколько пользователей, исполнителем станет первый из них.

6. Опишите задачу в теле письма.

7. Задайте приоритет письма, если это позволяет ваш почтовый клиент — в зависимости от приоритета письма будет установлен приоритет задачи: [Как задать приоритет задачи](https://yandex.ru/support/tracker/ru/user/create-ticket-by-mail#priority).

8. Отправьте письмо на адрес, указанный в [настройках очереди](https://yandex.ru/support/tracker/ru/manager/queue-mail).

В ответном письме вы получите уведомление о создании новой задачи.

Подробнее об алгоритме создания задачи или комментария из письма читайте в разделе [Почта](https://yandex.ru/support/tracker/ru/manager/queue-mail).

Создавайте новое письмо для каждой задачи. Если вы ответите на письмо от Трекера или повторно отправите уже существующее, такое письмо станет комментарием к задаче.

# Как задать приоритет задачи

В некоторых почтовых клиентах, например Microsoft Outlook, можно задать приоритет письма при отправке. В этом случае в письмо добавляется служебный заголовок `X‑Priority`.

Если в Трекер поступает такое письмо, задаче будет задан соответствующий приоритет.

Соответствие между приоритетами в письме и в Трекере

| Значение X-Priority | Приоритет задачи |
| --- | --- |
| 1 (Highest) | Блокер |
| 2 (High) | Критичный |
| 3 (Normal) | Средний |
| 4 (Low) | Низкий |
| 5 (Lowest) | Незначительный |

# Возможные проблемы с созданием задачи

- Трекер ежедневно обрабатывает большое количество информации, поэтому создание задачи из письма может продлиться до 1 часа.
- Если адрес очереди настроен в почтовом сервисе, который не входит в Яндекс 360, Трекер не будет обрабатывать входящие письма, размер которых превышает 30 МБ (с вложениями).

Если проблему не получилось решить самостоятельно, обратитесь в [техническую поддержку](https://yandex.ru/support/tracker/ru/feedback).
