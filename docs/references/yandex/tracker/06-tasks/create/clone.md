Чтобы создать новую задачу на основе существующей, используйте опцию копирования. Задачу можно скопировать в любую доступную вам очередь.

1. Откройте задачу, копию которой вы хотите создать.

2. В правом верхнем углу выберите **Действия**  → **Скопировать задачу**.

3. Выберите очередь, в которой вы хотите создать копию задачи.

4. Настройте опции копирования задачи:

    - Чтобы сохранить значения параметров задачи, включите опцию **Скопировать значения параметров**. Откроется редактор задачи: вы сможете выбрать, какие значения оставить, а какие очистить или изменить. [Локальные поля](https://yandex.ru/support/tracker/ru/local-fields) не сохранятся при переносе в другую очередь.
    - Чтобы добавить в новую задачу вложенные файлы из оригинальной задачи, включите опцию **Скопировать файлы и вложения**.
    - Чтобы задача и ее копия были связаны, включите опцию **Связать задачи после копирования**.
        В разделе **Связанные задачи** появится особый тип связи: скопированная задача будет отмечена как «Копия» на странице основной, а основная задача — как «Оригинал» на странице скопированной.
5. Нажмите кнопку **Скопировать**.

6. Чтобы быстро перейти к новой задаче, нажмите ссылку в уведомлении внизу страницы.
