# Таблицы

Визуальный редактор

Разметка Markdown

Чтобы добавить таблицу:

1. На панели инструментов нажмите **Таблица**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2. Чтобы добавить строки или столбцы, поместите курсор в таблицу и нажмите значок рядом с правым или нижним краем таблицы.

3. Заполните ячейки. Текст в ячейках таблицы можно форматировать.

Чтобы редактировать таблицу, выберите ячейку и используйте кнопки вверху столбца или в начале строки. Вы можете:

- Добавить строки или столбцы до или после выбранной ячейки.

- Удалить выбранную строку или столбец.

- Удалить таблицу.

В ячейке [многострочной таблицы](https://yandex.ru/support/tracker/ru/wysiwyg/tables-format#multiline) можно размещать текст из нескольких строк: списки, фрагменты кода, другие таблицы.

В ячейках [простых таблиц](https://yandex.ru/support/tracker/ru/wysiwyg/tables-format#simple) можно использовать только элементы строчного форматирования: оформление текста, изображения, ссылки. Также простая таблица поддерживает выравнивание текста в ячейках по левому, правому краю или по центру.

Простую таблицу можно добавить только в режиме разметки Markdown.

Чтобы изменить формат простой таблицы на [многострочный](https://yandex.ru/support/tracker/ru/wysiwyg/tables-format#multiline), в режиме визуального редактора выберите ячейку таблицы, нажмите значок и выберите **Преобразовать в таблицу YFM**.

## Многострочная таблица

Чтобы добавить многострочную таблицу, используйте разметку:

```
#|
|| **Заголовок 1** | **Заголовок 2** ||
||
Текст
на двух строчках
|
- Пункт 1
- Пункт 2
- Пункт 3
||
|#
```

Чтобы выделить строку заголовка в таблице, вы можете применить [форматирование](https://yandex.ru/support/tracker/ru/user/syntax-yfm) к тексту в первой строке. Например, выделить его жирным начертанием.

Результат:

| Заголовок 1 | Заголовок 2 |
| --- | --- |
| Текст<br>на двух строчках | Пункт 1, Пункт 2, Пункт 3 |

## Простая таблица

Чтобы разместить в тексте простую таблицу, используйте разметку:

```

| Заголовок 1 | Заголовок 2 | Заголовок 3 |
| --- | --- | --- |
| ячейка 11 | ячейка 12 | ячейка 13 |
| ячейка 21 | ячейка 22 | ячейка 23 |

```

Результат

| Заголовок 1 | Заголовок 2 | Заголовок 3 |
| --- | --- | --- |
| ячейка 11 | ячейка 12 | ячейка 13 |
| ячейка 21 | ячейка 22 | ячейка 23 |

## Выравнивание текста

В [простой таблице](https://yandex.ru/support/tracker/ru/wysiwyg/tables-format#simple) можно выровнять содержимое столбца по левому, правому краю или по центру. Для этого используйте символ `:` в разделительной строке таблицы.

```

| По левому краю | По центру     | По правому краю |
| :---           | :----:        | ---:            |
| Текст          | Текст         | Текст           |
| Текст          | Текст         | Текст           |

```

Результат

| По левому краю | По центру | По правому краю |
| --- | --- | --- |
| Текст | Текст | Текст |
| Текст | Текст | Текст |
