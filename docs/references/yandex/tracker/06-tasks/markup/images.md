# Вставить изображение из буфера обмена

Изображение из буфера обмена можно добавить как в визуальном режиме редактора, так и в режиме разметки:

1. Скопируйте изображение в буфер обмена:

    - скопируйте рисунок из графического редактора или сделайте снимок экрана;
    - скопируйте рисунок с веб-страницы;
    - скопируйте файл с изображением из файлового менеджера на вашем компьютере.
2. Вставьте в текст изображение из буфера обмена.

Изображение будет автоматически загружено в Трекер и появится в списке [вложений к задаче](https://yandex.ru/support/tracker/ru/user/attach-file).

# Загрузить изображение

1. В режиме визуального редактора или в режиме разметки на панели инструментов нажмите **Image**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2. Выберите вкладку **Загрузить с устройства** и выберите один или несколько файлов. Рисунок будет добавлен в текст.

3. Чтобы изменить параметры изображения:

    - В режиме визуального редактора наведите указатель на изображение и нажмите → **Редактировать**.

    - В режиме разметки вы можете отредактировать атрибуты изображения, например:

        ```
        ![<Альтернативный_текст>](https://yandex.ru/support/tracker/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E%20%22%3C%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%3E%22%20=%3C%D0%A8%D0%B8%D1%80%D0%B8%D0%BD%D0%B0%3Ex%3C%D0%92%D1%8B%D1%81%D0%BE%D1%82%D0%B0%3E)
        ```

# Добавить изображение по ссылке

Визуальный редактор

Разметка Markdown

1. На панели инструментов нажмите **Image**.

    Вы также можете использовать меню быстрого доступа: введите символ `/` и выберите команду из списка.

2. Выберите вкладку **Добавить по ссылке**:

3. В поле **Ссылка** вставьте адрес изображения или ссылку на один из прикрепленных файлов.

4. Добавьте подпись к рисунку. Подпись будет отображаться при наведении указателя на изображение.

5. Введите альтернативный текст. Текст будет отображаться, если не удастся загрузить изображение.

6. Укажите размер изображения в пикселях. Изображение масштабируется пропорционально, поэтому значение высоты можно задать приблизительно.

7. Нажмите **Сохранить**.

8. Чтобы изменить параметры рисунка, в режиме редактирования наведите на него указатель и нажмите → **Редактировать**.

Чтобы разместить изображение в тексте, добавьте код в формате:

```
![<Альтернативный_текст>](https://yandex.ru/support/tracker/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E%20%22%3C%D0%9F%D0%BE%D0%B4%D0%BF%D0%B8%D1%81%D1%8C%3E%22%20=%3C%D0%A8%D0%B8%D1%80%D0%B8%D0%BD%D0%B0%3Ex%3C%D0%92%D1%8B%D1%81%D0%BE%D1%82%D0%B0%3E)
```

Параметры разметки:

- `<Альтернативный_текст>` будет отображаться, если не удастся загрузить изображение.
- `<Адрес_изображения>`: URL-адрес рисунка в интернете или ссылку на один из прикрепленных файлов.
- `<Подпись>` будет отображаться при наведении указателя на изображение.
- `<Ширина>` и `<Высота>` в пикселях. Изображение масштабируется пропорционально, поэтому значение высоты можно задать приблизительно.

# Вставить изображение, которое уже загружено в Трекер

Если вы вставите изображение из задачи с ограниченным доступом, его не смогут увидеть пользователи, которые не имеют доступа к исходной задаче.

1. Откройте задачу или комментарий, в которые добавлено изображение.
2. Нажмите на изображение и выберите  **Скопировать ссылку**.
3. Используйте полученную ссылку, чтобы [добавить изображение в текст](https://yandex.ru/support/tracker/ru/wysiwyg/images#add-link).

# Вставить ссылку на скачивание изображения

Чтобы при нажатии на изображение его можно было скачать, используйте разметку:

```
[<Текст_ссылки>](https://yandex.ru/support/tracker/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E)
```

Пример

```
[Логотип Яндекса](https://img.yandex.net/i/logo95x37x8.png)
```

Результат:

[Логотип Яндекса](https://img.yandex.net/i/logo95x37x8.png)

# Сделать изображение ссылкой

Вы можете сделать изображение ссылкой, чтобы при нажатии на изображение открывалась страница или файл. Для этого в элемент разметки ссылки вместо текста вставьте изображение:

```
[![<Альтернативный_текст>](https://yandex.ru/support/tracker/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D0%B8%D0%B7%D0%BE%D0%B1%D1%80%D0%B0%D0%B6%D0%B5%D0%BD%D0%B8%D1%8F%3E)](https://yandex.ru/support/tracker/%3C%D0%90%D0%B4%D1%80%D0%B5%D1%81_%D1%81%D1%81%D1%8B%D0%BB%D0%BA%D0%B8%3E)
```

Пример

```
[![Логотип Яндекса](https://img.yandex.net/i/logo95x37x8.png)](https://ya.ru)
```
