# Как выгрузить задачу в DOC

Вы можете сохранить задачу из Трекера в формате DOC. Для этого:

1. Откройте страницу задачи.

2. В правом верхнем углу нажмите **Действия**  → **Выгрузить в DOC**.

В файл будут добавлены описание задачи, значения параметров и комментарии.
