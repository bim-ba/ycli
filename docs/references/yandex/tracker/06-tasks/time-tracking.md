В Трекере можно вести учет времени, затраченного на выполнение задачи. Учет времени помогает точнее планировать сроки и бюджеты проектов, выявлять проблемные места при работе над задачами.

Доступны два варианта учета времени:

- [Базовый](https://yandex.ru/support/tracker/ru/user/time-spent#limited-spent-time).
- [Расширенный](https://yandex.ru/support/tracker/ru/user/time-spent#extended-spent-time).

# Базовый учет времени

В базовом варианте учета времени доступны три параметра оценки трудозатрат:

- **Первоначальная оценка**. Рекомендуем в начале работы указать время, которое вы планируете потратить на задачу.
- **Оценка**. Используйте это поле для оценки времени, на протяжении которого вы планируете продолжать работу над задачей.
- **Затрачено времени**. В этом поле отображается сумма всех записей о затраченном времени.

Как меняется значение поля **Оценка**

Если поле **Оценка** заполнено, его значение будет меняться при добавлении записей о затраченном времени:

- Если поле **Первоначальная оценка** не заполнено: каждый раз, когда вы фиксируете время, значение поля **Оценка** будет уменьшаться на указанную величину.

- Если поле **Первоначальная оценка** заполнено:

    Когда значение **Затрачено времени** станет больше, чем **Первоначальная оценка**, значение поля **Оценка** уменьшится на разницу между двумя другими полями.

    После этого каждый раз, когда вы фиксируете время, значение поля **Оценка** будет уменьшаться на указанную величину.

## Указать затраченное время

1. В правом верхнем углу задачи выберите **Действия**  → **Указать затраченное время**.

2. Заполните поле **Затрачено времени**.

    Единицы изменения времени можно указывать с помощью русских или английских сокращений. Если опустить единицы измерения, будет использована единица по умолчанию, указанная в [настройках очереди](https://yandex.ru/support/tracker/ru/manager/queue-spent-time#settings). Например:

    - 1 неделя и 3 дня — `1н 3д`, `1w 3d`.
    - 3 часа 20 минут 30 секунд — `3ч 20м 30с`, `3h 20m 30s`.

При необходимости заполните другие поля:

- **Дата записи**. Укажите дату и время в вашем часовом поясе.
- **Комментарий**. Добавьте пояснение к записи о затраченном времени. Комментарий будет виден в [истории изменений задачи](https://yandex.ru/support/tracker/ru/user/history), в [истории записей по учёту времени](https://yandex.ru/support/tracker/ru/user/time-spent#records-history) и в [отчете по трудозатратам](https://yandex.ru/support/tracker/ru/user/reports#time-spent-report).
    Набор доступных параметров зависит от [настроек учета времени в очереди](https://yandex.ru/support/tracker/ru/manager/queue-spent-time#settings).

1. Нажмите **Сохранить**.

Можно добавить несколько записей, внесенное время будет суммироваться. В режиме базового учёта запись о затраченном времени можно изменить только с помощью [запроса к API](https://yandex.ru/support/tracker/ru/api-ref/issues/patch-worklog).

Указать затраченное время может не только исполнитель, но и другие пользователи с доступом к задаче. В [отчете по трудозатратам](https://yandex.ru/support/tracker/ru/user/reports#time-spent-report) для каждого сотрудника, указавшего время в задаче, отобразится отдельная сумма трудозатрат.

## Посмотреть затраченное время

Затраченное время можно посмотреть на странице задачи в параметрах категории **Учёт Времени** или в [отчете по трудозатратам](https://yandex.ru/support/tracker/ru/user/reports#time-spent-report).

Если в задаче не отображаются параметры **Учёт Времени**, добавьте их:

1. Внизу раздела с параметрами задачи нажмите **Изменить список параметров**.

2. В категории **Учёт Времени** выберите **Затрачено времени** и **Оценка**.

# Расширенный учет времени

В расширенном варианте учета времени вы можете:

- Изменить или удалить запись о затраченном времени без использования API.
- Включить автоматический расчет затраченного времени.
- Добавить полосу прогресса задачи.
- Изменить формат отображения времени.
- Указать время целым или дробным числом.

Чтобы использовать расширенный учет времени, включите [опцию в настройках очереди](https://yandex.ru/support/tracker/ru/manager/queue-spent-time).

## Указать затраченное время

1. Откройте блок для учета времени одним из способов:

    - В правом верхнем углу задачи выберите **Действия**  → **Указать затраченное время**.

    - На панели справа нажмите **Учёт времени**.

2. Заполните поле **Затрачено времени**.

    Единицы изменения времени можно указывать с помощью русских или английских сокращений. Если опустить единицы измерения, будет использована единица по умолчанию, указанная в [настройках очереди](https://yandex.ru/support/tracker/ru/manager/queue-spent-time#settings). Например:

    - 1 неделя и 3 дня — `1н 3д`, `1w 3d`.
    - 3 часа 20 минут 30 секунд — `3ч 20м 30с`, `3h 20m 30s`.

    - 4 часа 30 минут (если настроена единица измерения **минуты**) — `270`.
    - 4 часа 30 минут (если настроена единица измерения **часы**) — `4,5` или `4.5`.
3. При необходимости заполните другие поля:

    - **Дата записи**. Укажите дату и время в вашем часовом поясе.
    - **Комментарий**. Добавьте пояснение к записи о затраченном времени. Комментарий будет виден в [истории изменений задачи](https://yandex.ru/support/tracker/ru/user/history), в [истории записей по учёту времени](https://yandex.ru/support/tracker/ru/user/time-spent#records-history) и в [отчете по трудозатратам](https://yandex.ru/support/tracker/ru/user/reports#time-spent-report).
        Набор доступных параметров зависит от [настроек учета времени в очереди](https://yandex.ru/support/tracker/ru/manager/queue-spent-time#settings).
4. Нажмите **Сохранить**.

## Посмотреть или изменить историю записей

- Чтобы просмотреть записи учета времени в задаче, на панели справа наведите указатель на **Учёт времени** и нажмите **История записей по учёту времени**.

- Чтобы отредактировать значения параметров **Затрачено времени** или **Комментарий**, наведите указатель на запись и нажмите **Редактировать**. Изменить запись о затраченном времени может только ее автор.

- Чтобы посмотреть историю изменения записи, наведите указатель на значок , который появится после первого редактирования.

- Чтобы удалить запись из истории, наведите на нее указатель и нажмите → **Удалить**.
