Любым проектом или процессом проще управлять, если работа структурирована. Основные способы навести порядок в работе — это декомпозиция и группировка задач.

Декомпозиция — это разделение крупных частей проекта на отдельные задачи и подзадачи. Когда работа разбита на небольшие задачи, гораздо проще оценить их сложность, необходимые ресурсы, распределить задачи по исполнителям и запланировать сроки. В Трекере можно декомпозировать задачи с помощью [связей](https://yandex.ru/support/tracker/ru/user/ticket-links). Например, для реализации новой возможности продукта нужно выполнить несколько небольших задач. Тогда можно создать родительскую задачу типа «Новая возможность» и привязывать к ней подзадачи.

Группировать задачи полезно, например, чтобы определить объем работы на разных этапах проекта или обозначить зоны ответственности команд и отдельных сотрудников.

В Трекере есть несколько способов структурировать задачи. Вы можете использовать их по отдельности или сочетать.

Очереди задач

[Очередь](https://yandex.ru/support/tracker/ru/queue-intro) — это пространство для задач, объединенных общим процессом или продуктом. Также очередь можно представить как список задач для определенной команды или отдела.

Очереди помогают упорядочить задачи и понять, кто отвечает за их выполнение. Например, можно создать отдельные очереди для отдела кадров, команды проекта и службы поддержки.

В каждой очереди можно настроить свой процесс работы с задачами. Чтобы настроить рабочий процесс, в очереди нужно задать этапы выполнения задач (статусы) и последовательность этих этапов — [рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow). Для распространенных процессов в Трекере предусмотрены [шаблоны очередей](https://yandex.ru/support/tracker/ru/manager/work-process).

Связи между задачами

в Трекере можно связывать задачи друг с другом. Связи помогают декомпозировать задачи и обозначить зависимость задач друг от друга. [Как редактировать связи задачи](https://yandex.ru/support/tracker/ru/user/ticket-links)

Эпики и истории

В *гибких методологиях разработки* эпики и истории (User story) — это крупные части работы, которые разбивают на более мелкие задачи. Чтобы создавать эпики и истории, в Трекере используются типы задач Epic и Story. [Как использовать эпики и истории](https://yandex.ru/support/tracker/ru/manager/epic)

Проекты

В проект можно объединять задачи, у которых есть общий дедлайн и ответственный сотрудник. В проект могут входить задачи из разных очередей. [Как работать с проектами](https://yandex.ru/support/tracker/ru/manager/project-new)

Компоненты

Компоненты помогают группировать задачи очереди, относящиеся к одной тематике. Для задач с компонентами можно настроить исполнителя по умолчанию и [права доступа](https://yandex.ru/support/tracker/ru/manager/queue-access#access-component). [Как настроить компоненты](https://yandex.ru/support/tracker/ru/manager/components)

Версии

Версии помогают группировать задачи очереди, относящиеся к одной версии продукта. [Как настроить версии](https://yandex.ru/support/tracker/ru/manager/versions)

Теги

Тег — это произвольная метка, которую можно добавить к задаче. С помощью тегов удобно группировать задачи по любому признаку, а затем искать задачи с определенными тегами. Чтобы добавить теги к задаче, [отредактируйте параметр **Теги**](https://yandex.ru/support/tracker/ru/user/edit-ticket#edit-fields).

Редактирование и удаление тега через веб-интерфейс Трекера не поддерживается. Чтобы удалить тег, используйте [запрос к API Яндекс Трекера](https://yandex.ru/support/tracker/api-ref/queues/delete-tag.html).
