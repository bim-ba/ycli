## Системные

| Поле задачи | Описание |
|---|---|
| QA-инженер | Пользователь, который назначен тестировать задачу. |
| Автор | Пользователь, который создал задачу. |
| Возможно спам | Признак спама для задач, созданных через сервисы, с которыми настроена [интеграция](https://yandex.ru/support/tracker/ru/manager/queue-mail). |
| Дата завершения | Дата окончания работы над задачей. |
| Дата начала | Дата начала работы над задачей. |
| Дедлайн | Дата, к которой задача должна быть решена. |
| Доски | Список досок, на которые добавлена задача. |
| Доступ | Список пользователей, которые имеют доступ к задаче на чтение и редактирование, но не получают уведомлений о ее изменениях. Правила доступа к задачам зависят от [настроек очереди](https://yandex.ru/support/tracker/ru/manager/queue-access). |
| Задача | Название задачи. |
| Автор изменения | Пользователь, который последним внес изменения в задачу. |
| Исполнитель | Пользователь, который будет работать над задачей. |
| Исправить в версиях | Версия продукта, к которой относится задача. Список доступных [версий](https://yandex.ru/support/tracker/ru/manager/versions) определяется настройками очереди. |
| Ключ | *Уникальный идентификатор* задачи в рамках очереди. Создается автоматически. |
| Комментариев без сообщения | Количество комментариев к задаче, созданных в сервисе Трекер. |
| Комментариев с сообщением | Количество комментариев к задаче, созданных через [почту](https://yandex.ru/support/tracker/ru/manager/queue-mail). |
| Компоненты | Метки, с помощью которых можно размечать и сортировать задачи внутри очереди. Список доступных [компонентов](https://yandex.ru/support/tracker/ru/manager/components) определяется настройками очереди. |
| Наблюдатели | Список пользователей, подписанных на задачу. По умолчанию они имеют доступ на чтение и редактирование, получают уведомления о любых изменениях в задаче. Правила доступа к задачам зависят от [настроек очереди](https://yandex.ru/support/tracker/ru/manager/queue-access). |
| Найдено в версиях | [Версия продукта](https://yandex.ru/support/tracker/ru/manager/versions), к которой относится задача. Список доступных версий определяется настройками очереди. |
| Нужен ответ пользователя | Список пользователей, которых [призывали в комментариях](https://yandex.ru/support/tracker/ru/user/comments#call-comment). Как только пользователь отвечает на комментарий, его имя исчезает из этого поля. |
| Обновлено | Дата и время последнего [изменения в задаче](https://yandex.ru/support/tracker/ru/user/history). |
| Описание | Постановка задачи: описание того, что нужно сделать. |
| Очередь | *Ключ очереди*, в которую входит задача. |
| Последний комментарий | Дата и время последнего комментария в задаче. |
| Приоритет | Значение, которое определяет важность задачи. |
| Проголосовали | Список пользователей, проголосовавших в задаче. |
| Проголосовало | Количество пользователей, [проголосовавших за задачу](https://yandex.ru/support/tracker/ru/user/votes). |
| Проект | Названия [проектов](https://yandex.ru/support/tracker/ru/manager/project-new), к которым относится задача. |
| Решен | Дата и время, когда была проставлена [резолюция](https://yandex.ru/support/tracker/ru/manager/create-resolution). |
| Рассылки | Команды и отделы, подписанные на задачу. По умолчанию они имеют доступ к задаче на чтение и редактирование, получают уведомления о любых ее изменениях. Правила доступа к задачам зависят от [настроек очереди](https://yandex.ru/support/tracker/ru/manager/queue-access). |
| **Резолюция** | Причина закрытия задачи. |
| Решивший | Пользователь, который проставил резолюцию в задаче. |
| Создано | Дата и время создания задачи. |
| Статус | Этап выполнения задачи. Например: «Открыт», «В работе», «Тестируется». Подробнее читайте в разделе [Настроить статусы](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit). |
| Статус изменен | Дата и время изменения статуса задачи. |
| Теги | Текстовые метки, которые облегчают поиск и сортировку задач. Подробнее читайте в разделе [Структурировать задачи](https://yandex.ru/support/tracker/ru/structure). |
| Тип | Тип задачи, например: «Новая возможность», «Ошибка», «Улучшение». Подробнее читайте в разделе [Добавить типы задач в рабочий процесс](https://yandex.ru/support/tracker/ru/manager/add-ticket-type). |

## Учёт Времени

| Поле задачи | Описание |
|---|---|
| Затрачено времени | Время, которое исполнитель [потратил на решение задачи](https://yandex.ru/support/tracker/ru/user/time-spent). |
| Оценка | Время, которое пользователь планирует потратить на решение задачи. Значение в поле уменьшается при указании [затраченного времени](https://yandex.ru/support/tracker/ru/user/time-spent#show-time-spent). |
| Первоначальная оценка | Первоначальная оценка времени, необходимого для решения задачи. |

## Agile

| Поле задачи | Описание |
|---|---|
| Story Points | Трудоемкость задачи в баллах Story Points. Подробнее читайте в разделе [Основные понятия гибкой разработки](https://yandex.ru/support/tracker/ru/manager/agile#dlen_sp). |
| Спринт | Название [спринта](https://yandex.ru/support/tracker/ru/manager/create-agile-sprint), к которому относится задача. |

## Email

| Поле задачи | Описание |
|---|---|
| Кому | Список всех адресов электронной почты, которые пользователь указал в поле **Кому** при отправке письма. |
| Копия | Адрес электронной почты, который пользователь указал в поле **Копия** при отправке письма. |
| От | Адрес электронной почты отправителя письма. |
| Создано по письму на адрес | Адрес электронной почты, на который было отправлено письмо для создания задачи. |

## SLA

| Поле задачи | Описание |
|---|---|
| SLA | Таймер, который отсчитывает время для обработки задач очереди. Например, можно задать время, за которое исполнитель должен отреагировать на новую задачу. Подробнее читайте в разделе [SLA](https://yandex.ru/support/tracker/ru/sla-head). |
