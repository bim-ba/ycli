# Как посмотреть рабочий процесс на странице задачи

Трекер позволяет просматривать [рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow) очереди прямо на странице задачи. Если у пользователя есть права на [просмотр задач очереди](https://yandex.ru/support/tracker/ru/manager/queue-access#acces-types), то он сможет увидеть набор статусов, а также посмотреть переходы, но только те, которые доступны в рамках настроенного процесса.

Чтобы посмотреть рабочий процесс, на странице задачи, на панели справа, в поле **Статус**, нажмите → **Посмотреть рабочий процесс**.
