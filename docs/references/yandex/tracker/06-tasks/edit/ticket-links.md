Задачу можно связать с другими задачами, чтобы сгруппировать задачи с общей темой или обозначить их зависимость друг от друга. Число связей задачи не ограничено. Список связанных задач отображается под описанием задачи.

В Трекере есть несколько типов связи:

Родительская задача — Подзадача

Используйте этот тип связи, чтобы декомпозировать задачи — разбивать крупные части проекта на отдельные задачи и подзадачи.

Например, для реализации новой возможности продукта нужно выполнить несколько небольших задач. Тогда можно создать родительскую задачу типа «Новая возможность» и привязывать к ней подзадачи.

Связанная задача

Используйте этот тип связи, чтобы добавлять ссылки на задачи с общей темой.

Зависимая задача — Блокирующая задача

Используйте этот тип связи, если начало одной задачи зависит от выполнения другой. Например, разработку новой возможности приложения можно начинать только после того, как готов дизайн интерфейса.

Дублирующая задача

Используйте этот тип связи, чтобы сгруппировать одинаковые по смыслу задачи. Например, если создано несколько задач типа «Ошибка», которые описывают одну и ту же проблему.

Эпик — Подэпик

Используйте этот тип связи для декомпозиции задач, если работаете по методологии Скрам. [Как сгруппировать задачи в эпик](https://yandex.ru/support/tracker/ru/manager/epic)

Оригинал — Копия

Такая связь добавится автоматически, если вы скопируете задачу с опцией «Связать задачи после копирования». [Как скопировать задачу](https://yandex.ru/support/tracker/ru/user/clone)

Также к задаче можно привязать [коммит в репозиторий](https://yandex.ru/support/tracker/ru/user/ticket-links#section_commit).

# Добавить связь

Чтобы создать связь одной задачи с другой:

1. Под описанием задачи нажмите  **Связь с задачей**.

2. Чтобы задать тип связи, нажмите название текущего типа и выберите нужный вариант из списка.

3. Выберите, какую задачу вы хотите привязать:

    Новая задача

    Существующая задача

    1. Выберите очередь, в которой хотите создать задачу.

    2. Введите название и нажмите клавишу **Enter**.

    Чтобы создать новую задачу, вы также можете в правом верхнем углу страницы выбрать **Действия** → **Создать связанную задачу**. Заполните поля так же, как при [создании новой задачи](https://yandex.ru/support/tracker/ru/user/create-ticket).

    Выберите вкладку **Существующая** и укажите ее *ключ* или название, затем выберите задачу из списка. Найти ключ можно на странице задачи над ее названием (например, `TEST-1234`).

Чтобы добавить связь сразу с несколькими задачами, используйте [массовое редактирование задач](https://yandex.ru/support/tracker/ru/manager/bulk-change#add-links).

# Создать подзадачу

Сложные задачи можно разбить на более простые подзадачи и отслеживать их выполнение по отдельности. После создания подзадачи вы можете изменить тип связи.

1. Откройте страницу задачи, к которой вы хотите добавить подзадачу.

2. В правом верхнем углу выберите **Действия** → **Добавить подзадачу**.

3. Заполните поля так же, как при [создании новой задачи](https://yandex.ru/support/tracker/ru/user/create-ticket).

4. Нажмите кнопку **Создать задачу**. Вверху страницы над названием подзадачи отобразится ссылка на родительскую задачу.

# Изменить тип связи

Чтобы изменить тип связи между задачами:

1. Откройте страницу одной из двух связанных задач.

2. В списке **Связанные задачи** под описанием задачи выберите связь, тип которой требуется изменить.

3. Напротив связанной задачи нажмите → **Изменить тип связи** и выберите новый тип.

# Удалить связь

Чтобы удалить связь между задачами:

1. Откройте страницу одной из двух связанных задач.

2. В списке **Связанные задачи** под описанием задачи выберите связь, которую требуется удалить.

3. Напротив связанной задачи нажмите →  **Удалить связь**.

Через меню Действия

Под описанием задачи нажмите  **Связь с задачей** и выберите **Родительская**.

- Чтобы создать новую родительскую задачу, выберите вкладку **Новая**, введите название и нажмите **Создать**.
- Чтобы создать связь с уже существующей родительской задачей, выберите вкладку **Существующая** и укажите ключ или название родительской задачи, затем выберите задачу из списка. Найти ключ можно на странице задачи над ее названием (например, `TEST-1234`).

# Изменить родительскую задачу

Чтобы изменить родительскую задачу:

1. Откройте страницу подзадачи.

2. В списке **Связанные задачи** напротив родительской задачи нажмите →  **Изменить родителя**.

    - Чтобы создать новую родительскую задачу, выберите вкладку **Новая**, введите название и нажмите **Создать**.
    - Чтобы создать связь с уже существующей родительской задачей, выберите вкладку **Существующая** и укажите ключ или название родительской задачи, затем выберите задачу из списка.

# Удалить связь с родительской задачей

Чтобы удалить связь с родительской задачей:

1. Откройте страницу подзадачи.

2. В списке **Связанные задачи** напротив родительской задачи нажмите кнопку →  **Удалить связь**.

# Связать коммит с задачей

Вы можете привязать к задаче коммит в репозиторий, который подключен к Трекеру: [Как настроить репозиторий](https://yandex.ru/support/tracker/ru/user/add-repository).

Чтобы привязать к задаче коммит в репозитории, укажите *ключ задачи* в комментарии к коммиту. Например: `Исправление ошибки TEST-123`.

Привязанные коммиты можно просмотреть:

- на странице задачи на вкладке **Коммиты**;
- на странице коммитов очереди. Чтобы перейти на страницу коммитов со страницы очереди, в правом верхнем углу нажмите → **Коммиты**.

# Список связанных задач

Если у задачи настроены связи, список связанных задач появляется на странице задачи. Он находится под ее описанием и чеклистом, если чеклист был создан.

Список представлен в виде таблицы, в которой связанные задачи сгруппированы по типу связи.

Чтобы открыть список или любую из групп в новом окне, наведите курсор на название списка или группы и нажмите появившийся справа значок .

Таблицу со списком связанных задач можно настроить: отсортировать задачи, а также выбрать столбцы с параметрами задач.

## Настройка списка связанных задач

Вы можете добавить в таблицу столбцы с параметрами или удалить лишние:

1. В правом углу таблицы нажмите  **Настройки**.
2. В выпадающем списке нажимайте на параметры, чтобы выбрать их или снять выделение.
3. Когда настроите список, нажмите **Применить**.

Внутри выпадающего списка тоже доступны несколько действий. Чтобы их увидеть, наведите указатель на параметр:

- Чтобы прочитать краткое описание параметра задачи, нажмите .
- Чтобы выбранный параметр всегда был в быстром доступе, нажмите .
    Вверху выпадающего списка появится категория **Закреплённые**.
- Чтобы изменить порядок выбранных столбцов, перетаскивайте их в списке за значок .
- Чтобы скрыть из списка завершенные задачи, внизу выпадающего списка включите опцию **Скрыть решённые задачи** и нажмите **Применить**.

## Изменить значение параметра задачи, тип связи или удалить связь

Вы можете редактировать параметры, которые отображаются в ячейках таблицы.

- Чтобы изменить статус или приоритет задачи, ответственного пользователя (например исполнителя) или дату (например «Дедлайн»), нажмите текущее значение и выберите новое в выпадающем списке.
- Чтобы изменить название задачи или другое текстовое поле (например «Story Points»), наведите на него указатель и справа нажмите .
- Чтобы изменить тип связи или удалить связь, нажмите справа в строке выбранной задачи. В появившемся подменю выберите **Изменить тип связи** и нужный тип из списка или **Удалить связь**.

## Отсортировать список задач

По умолчанию список задач отсортирован по дате обновления. Чтобы задать новый параметр сортировки (например, по убыванию даты начала), используйте кнопку вверху страницы:

- Нажмите значок , чтобы изменить направление сортировки: по убыванию или по возрастанию.
- Справа от значка нажмите название текущего параметра сортировки и в выпадающем списке выберите новый.

Можно быстро отсортировать список по параметру из таблицы: наведите указатель на столбец и нажмите значок .
