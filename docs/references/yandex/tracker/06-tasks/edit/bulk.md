Вы можете изменить статусы и параметры сразу нескольких задач. Чтобы открыть список задач, перейдите на страницу очереди или фильтра.

# Изменить статус

Чтобы изменить статус задач:

1. Откройте список задач.

2. Поставьте отметку возле задач, которые вы хотите изменить.

    Если вы хотите выбрать сразу все задачи на странице очереди или фильтра, поставьте отметку над списком задач.

3. Нажмите кнопку **Изменить cтатус** под списком задач и выберите статус.

    Доступны только те переходы между статусами, которые разрешены в [рабочем процессе](https://yandex.ru/support/tracker/ru/manager/workflow). Если вы выберете переход, который доступен только для части задач, статус изменится только у них.

4. После выполнения операции в правом нижнем углу отобразится уведомление о количестве задач, для которых успешно изменен статус.

    Чтобы открыть список задач, для которых невозможно выполнить переход в выбранный статус, нажмите кнопку **Подробнее** в уведомлении.

# Перенести задачи в другую очередь

Чтобы изменить очередь задач:

1. Откройте список задач.

2. Поставьте отметку возле задач, которые вы хотите перенести.

    Если вы хотите выбрать сразу все задачи на странице очереди или фильтра, поставьте отметку над списком задач.

3. Нажмите кнопку **Переместить** под списком задач.

4. Выберите очередь, в которую будут перемещены задачи.

5. После выполнения операции в правом нижнем углу отобразится уведомление о количестве задач, которые успешно перемещены в другую очередь.

    Чтобы открыть список задач, для которых невозможно выполнить перенос, нажмите кнопку **Подробнее** в уведомлении. Перенос невозможен для задач, которые уже существуют в выбранной очереди.

После переноса в другую очередь задачам будет присвоен новый ключ. Ссылки на задачу со старым ключом останутся рабочими. При переходе по такой ссылке задача автоматически откроется в новой очереди. Однако по старому ключу задачу нельзя будет найти с помощью [фильтра](https://yandex.ru/support/tracker/ru/manager/quick-filters) или [запроса](https://yandex.ru/support/tracker/ru/user/query-filter#query-format).

Чтобы добавить комментарий сразу к нескольким задачам:

1. Откройте список задач.

2. Поставьте отметку возле задач, для которых вы хотите добавить связанную задачу.

    Если вы хотите выбрать сразу все задачи на странице очереди или фильтра, поставьте отметку над списком задач.

3. Нажмите кнопку под списком задач и выберите **Добавить комментарий**.

# Добавить связь

Чтобы добавить связь сразу нескольким задачам:

1. Откройте список задач.

2. Поставьте отметку возле задач, для которых вы хотите добавить связанную задачу.

    Если вы хотите выбрать сразу все задачи на странице очереди или фильтра, поставьте отметку над списком задач.

3. Нажмите кнопку **Добавить связь** под списком задач, выберите [тип связи](https://yandex.ru/support/tracker/ru/user/ticket-links) и создайте связь:

    - Чтобы создать новую задачу, выберите вкладку **Новая задача**. Введите название и нажмите клавишу **Enter**.

    - Если задача уже существует, выберите вкладку **Существующая задача** и укажите ее *ключ* или название, затем выберите задачу из списка. Найти ключ можно на странице задачи над ее названием (например, `TEST-1234`).

# Добавить задачи на доску или в проект

Чтобы добавить задачи на доску или в проект:

1. Откройте список задач.

2. Поставьте отметку возле задач, которые вы хотите добавить на доску или в проект.

    Если вы хотите выбрать сразу все задачи на странице очереди или фильтра, поставьте отметку над списком задач.

3. Нажмите кнопку под списком задач.

    - Чтобы добавить задачи на доску, выберите **Добавить на доску**. Выберите одну или несколько досок и нажмите **Применить**.

    - Чтобы добавить задачу в проект, выберите **Добавить в проект**. Все подзадачи также будут добавлены в проект.

# Изменить параметры

Чтобы изменить параметры задач:

1. Откройте список задач.

2. Поставьте отметку возле задач, которые вы хотите изменить.

    Если вы хотите выбрать сразу все задачи на странице очереди или фильтра, поставьте отметку над списком задач.

3. Нажмите кнопку под списком задач и выберите **Редактировать параметры**.

4. Выберите нужные параметры. Если нужных полей нет в списке, добавьте их с помощью кнопки **Изменить список параметров**.

5. Задайте значения.

    Некоторые поля могут содержать список значений (например, поля «Наблюдатели», «Рассылки» или «Теги»). По умолчанию новые значения дописываются в конец списка. Чтобы перезаписать поле, включите опцию **Удалить значения**.

    Если нужно удалить одно значение из поля, содержащего список значений, вы можете использовать автодействие. Для этого настройте действие **Изменить значение поля** → **Удалить из списка**.

    Подробнее об автодействиях читайте в разделе [Как настроить автоматическое обновление задач](https://yandex.ru/support/tracker/ru/user/create-autoaction).

6. Если вы хотите, чтобы наблюдатели задач получили уведомления об изменениях, включите опцию **Отправить уведомление наблюдателям**. По умолчанию уведомления отключены.

7. Нажмите кнопку **Применить**.

# Стать участником задач

Чтобы добавить или удалить себя из полей **Исполнитель** или **Наблюдатели** в задачах:

1. Откройте список задач.

2. Поставьте отметку возле задач, которые вы хотите изменить.

    Если вы хотите выбрать сразу все задачи на странице очереди или фильтра, поставьте отметку над списком задач.

3. Нажмите кнопку под списком задач и выберите вариант:

    - Чтобы стать участником задачи, выберите **Добавить меня в наблюдатели** или **Назначить меня исполнителем**.

    - Чтобы отменить свое участие в задаче, выберите **Удалить меня из поля...** и укажите вариант: **Наблюдатели**, **Исполнитель** или **Из обоих полей**.
