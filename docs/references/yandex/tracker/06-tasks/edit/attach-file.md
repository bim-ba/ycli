Вы можете прикрепить к задаче несколько файлов любого формата. Размер одного файла должен быть не больше 128 МБ.

Файлы, добавленные в Трекер, не занимают место на Яндекс Диске. При этом в Трекере нет ограничений на объем хранимых данных.

Вы можете прикрепить изображение или файл к описанию задачи одним из способов:

- Чтобы прикрепить файл, перетащите его в область ввода описания или воспользуйтесь кнопкой  **Файл** под описанием задачи.

- Чтобы добавить изображение в текст описания, вставьте ссылку на него или воспользуйтесь кнопкой  **Изображение** на панели инструментов.

Таким же образом можно [прикрепить файл к комментарию](https://yandex.ru/support/tracker/ru/user/comments#sec_file).

Список прикрепленных файлов отобразится под описанием задачи. Чтобы настроить вид списка файлов, справа от него нажмите **Действия**, затем:

- Чтобы отобразить вложения в виде карточек, выберите  **Карточный вид**.

- Чтобы отобразить вложения в виде таблицы, выберите  **Табличный вид**.

Чтобы скачать все вложения, нажмите  **Скачать всё**.
