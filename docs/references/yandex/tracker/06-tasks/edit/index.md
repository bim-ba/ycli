Чтобы изменить задачу, перейдите на ее страницу. Страницы задач обновляются в реальном времени. Если кто-то изменит или прокомментирует задачу, страница которой открыта, вы увидите уведомление об этом в правом нижнем углу страницы.

Изменить задачу могут все, у кого есть доступ к ее редактированию. Доступ к задаче может быть ограничен несколькими способами:

- Для всех задач в *очереди*: [Права доступа к очереди](https://yandex.ru/support/tracker/ru/manager/queue-access#manage-access)
- Для отдельных ролей в задаче, таких как исполнитель или наблюдатель: [Роли в задачах](https://yandex.ru/support/tracker/ru/manager/queue-access#task-role).
- Для задач с некоторыми компонентами: [Задачи с компонентом](https://yandex.ru/support/tracker/ru/manager/queue-access#access-component).

Если у вас не хватает прав для редактирования задачи, запросите их у владельца очереди или [администратора](https://yandex.ru/support/tracker/ru/role-model) вашей организации.

# Изменить название задачи

Нажмите на название задачи. Отредактируйте текст и нажмите клавишу **Enter**.

# Изменить описание задачи

Справа от описания задачи нажмите значок и отредактируйте текст. Чтобы сохранить изменения, нажмите кнопку **Сохранить**.

В описании вы можете:

- Форматировать текст с помощью [разметки YFM](https://yandex.ru/support/tracker/ru/user/markup).

- Добавить в описание задачи [изображения или файлы](https://yandex.ru/support/tracker/ru/user/attach-file).

- Указать *ключ* любой другой задачи — тогда Трекер автоматически создаст с ней связь. Ключ задачи необходимо вводить заглавными буквами, например: `TEST-1234`.

# Указать исполнителя задачи

1. Откройте страницу задачи и на панели справа нажмите параметр **Исполнитель**.
2. Начните вводить имя сотрудника в поле. Чтобы быстро назначить себя исполнителем, ниже нажмите **Назначить меня**.

Для каждой задачи можно назначить только одного исполнителя. Есть несколько способов организовать работу нескольких человек:

- Если над задачей последовательно работает несколько человек, изменяйте исполнителя в процессе выполнения задачи.
- Если над задачей работает несколько человек одновременно, разбейте ее на подзадачи и укажите для каждой своего исполнителя.
- Создайте глобальное поле с типом  **Список пользователей** и используйте его в задачах. Например, назовите это поле «Соисполнители» и добавляйте в него остальных исполнителей задачи. Также вы можете создать отдельные поля для каждой роли, например, «Аналитик», «Тестировщик» и «Дизайнер». Подробнее о создании новых полей: [Как добавить поле задачи](https://yandex.ru/support/tracker/ru/user/create-param)

Если вы поменяете исполнителя, предыдущий пользователь будет добавлен в список наблюдателей задачи.

# Изменить параметры задачи

[Параметры задачи](https://yandex.ru/support/tracker/ru/user/create-param##default-fields) отображаются на панели справа. Чтобы изменить значение параметра, нажмите на его название и выберите новое значение.

Если вы не видите на панели справа нужных параметров, добавьте их с помощью кнопки **Изменить список параметров**.

Чтобы изменить параметры сразу нескольких задач, используйте [массовые операции](https://yandex.ru/support/tracker/ru/manager/bulk-change#change-parameters).

## Настроить отображение панели

Вы можете свернуть или развернуть панель с параметрами задачи с помощью кнопки в правом верхнем углу.

Чтобы изменить ширину панели с параметрами задачи, перетащите ее левую границу.

# Изменить статус задачи

Изменить статус задачи можно двумя способами:

- На панели справа выберите значение в поле **Статус**.

- В шапке задачи вверху страницы нажмите значок статуса и выберите значение.

Чтобы изменить статус сразу у нескольких задач, используйте [массовые операции](https://yandex.ru/support/tracker/ru/manager/bulk-change#change-status).

# Настроить отображение задачи

Чтобы вам было удобнее работать в Трекере, настройте внешний вид страницы задачи: тему и язык интерфейса, отображение кнопок и другие опции. Для этого перейдите в  **Настройки** →  **Интерфейс**. [Персональные настройки](https://yandex.ru/support/tracker/ru/user/personal).

Настройки, которые установлены для компьютерной версии, автоматически применяются для мобильного приложения.
