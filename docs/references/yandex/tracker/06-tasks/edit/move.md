# Как перенести задачу в другую очередь

Когда вы переносите задачу, ее подзадачи остаются в исходной очереди. Если в задаче указаны значения [локальных полей](https://yandex.ru/support/tracker/ru/local-fields), при переносе в другую очередь они будут удалены.

Чтобы перенести задачу:

1. Убедитесь, что у вас есть [доступ для создания задач](https://yandex.ru/support/tracker/ru/manager/queue-access) в той очереди, в которую хотите перенести задачу.

2. Откройте задачу, которую хотите перенести.

3. В правом верхнем углу выберите **Действия** → **Изменить очередь**.

4. Укажите очередь, в которую вы хотите перенести задачу и нажмите кнопку **Сохранить**.

Чтобы перенести сразу несколько задач в другую очередь, используйте [массовые операции](https://yandex.ru/support/tracker/ru/manager/bulk-change#change-queue).

После переноса в другую очередь задаче будет присвоен новый ключ. Ссылки на задачу со старым ключом останутся рабочими. При переходе по такой ссылке задача автоматически откроется в новой очереди. Однако по старому ключу задачу нельзя будет найти с помощью [фильтра](https://yandex.ru/support/tracker/ru/manager/quick-filters) или [запроса](https://yandex.ru/support/tracker/ru/user/query-filter#query-format).
