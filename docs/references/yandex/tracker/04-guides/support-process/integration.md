Если нужно интегрировать Трекер со сторонними системами, например CRM-системой или программным обеспечением для колл-центров, используйте API Яндекс Трекера. Например, через API можно создавать задачи в Трекере и добавлять в них информацию из сторонней системы. Подробнее о возможностях API Яндекс Трекера читайте в [Справочнике API](https://yandex.ru/support/tracker/ru/api-ref/about-api).

Если нужно передавать информацию из Трекера в другую систему, например оповещения в мессенджер, можно [использовать триггеры](https://yandex.ru/support/tracker/ru/user/create-trigger). Примеры настройки триггеров приведены в разделе [Интеграция с мессенджерами](https://yandex.ru/support/tracker/ru/messenger).
