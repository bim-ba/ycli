Чтобы обработать обращения пользователей в Трекере, из них нужно создать задачи. Большинство пользователей привыкло отправлять обращения по почте или через сайт. К тому же у пользователей, которые не являются сотрудниками вашей организации, нет доступа к Трекеру.

Поэтому рекомендуем настроить прием обращений по почте или через форму, созданную в сервисе [Яндекс Формы](https://forms.yandex.ru/cloud/admin).

# Принимать обращения по почте

Чтобы принимать обращения пользователей по почте, [настройте почтовый ящик для очереди](https://yandex.ru/support/tracker/ru/manager/queue-mail#get-mail), в которой будут создаваться задачи по обращениям пользователей. Из всех писем, которые поступят на этот адрес, будут автоматически создаваться задачи в Трекере.

Если задача создана из письма, вы можете отвечать пользователю со страницы задачи, например, запросить дополнительную информацию или сообщить о решении проблемы. Ответы пользователей, отправленные на адрес очереди, попадут в комментарии к задаче.

# Принимать обращения через форму

Принимать обращения через форму удобно, если нужно получить от пользователя определенные данные. В форме можно задать список вопросов, указать, какие из них обязательны, и сохранить ответы на вопросы в параметрах задачи в Трекере.

1. Перейдите в сервис [Яндекс Формы](https://forms.yandex.ru/cloud/admin) и создайте новую форму.

2. Добавьте на страницу вопросы, чтобы пользователь мог сообщить информацию, которая нужна для регистрации обращения.

3. Настройте для формы [интеграцию с Трекером](https://yandex.ru/support/forms/create-task.html):

    1. Укажите очередь и другие параметры задачи.

    2. В поле **Описание задачи** добавьте ответы на вопросы формы.

    3. Чтобы сохранить в параметрах задачи ответ на определенный вопрос формы, добавьте поле задачи, нажмите **Переменные** → **Ответ на вопрос** и выберите вопрос.

    4. Сохраните параметры интеграции.

4. [Опубликуйте](https://yandex.ru/support/forms/publish.html#section_link) форму — встройте ее в сайт или открывайте по ссылке.

Подробно пример настройки триггера, который после создания задачи через форму будет оправлять пользователю письмо с информацией о регистрации обращения, описан в разделе [Отправлять уведомление о создании задачи через форму](https://yandex.ru/support/tracker/ru/manager/trigger-examples#notify_form).
