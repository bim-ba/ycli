Рассмотрим пример, как организовать в Трекере работу службы поддержки.

Работать с обращениями пользователей в Трекере удобно, потому что в этом случае служба поддержки может более тесно взаимодействовать с другими подразделениями, которые используют Трекер. Например, призывать в комментарии разработчиков для решения сложных вопросов, создавать связи с задачами, от которых зависит решение обращений, и так далее.

Для службы поддержки создадим в Трекере отдельную [очередь](https://yandex.ru/support/tracker/ru/queue-intro), в которой будут создаваться задачи по обращениям пользователей. В этой очереди настроим дополнительные возможности, которые позволят эффективно работать с обращениями:

- [Принимать обращения от пользователей, у которых нет доступа к Трекеру](https://yandex.ru/support/tracker/ru/support-process-mail-forms).
- [Вести переписку с пользователями со страницы задачи](https://yandex.ru/support/tracker/ru/support-process-send-mail).
- [Группировать обращения по темам](https://yandex.ru/support/tracker/ru/support-process-group).
- [Отслеживать время обработки обращений](https://yandex.ru/support/tracker/ru/support-process-sla).
- [Собирать статистику по обращениям](https://yandex.ru/support/tracker/ru/support-process-dashboards).
- [Настроить интеграцию со сторонними системами](https://yandex.ru/support/tracker/ru/support-process-integration).
