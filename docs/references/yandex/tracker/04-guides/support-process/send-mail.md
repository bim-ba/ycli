Если нужно ответить на обращение пользователя, можно отправить ему письмо прямо со страницы задачи в Трекере. Если пользователь ответит на письмо, его ответ попадет в комментарии к задаче. Это позволяет хранить всю историю общения с пользователем в задаче и не тратить время на отправку писем из отдельного почтового клиента.

Алгоритм настройки очереди для отправки писем со страницы задачи:

# Шаг 1. Настройте в очереди интеграцию с почтой

[Настройте почтовый ящик для очереди](https://yandex.ru/support/tracker/ru/manager/queue-mail#send-mail).

Все письма, которые поступают на выбранный почтовый ящик, становятся задачами в очереди. Сотрудники службы поддержки смогут отправлять письма пользователям со страницы задачи, а ответы пользователей, отправленные на адрес очереди, попадут в комментарии к задаче.

# Шаг 2. Отправьте письма со страницы задачи

1. Откройте любую задачу в очереди службы поддержки.

2. Над полем комментария выберите вкладку **Письмо** и укажите адрес получателя.

    Если задача была [создана из письма пользователя](https://yandex.ru/support/tracker/ru/support-process-send-mail#mail), в поле **Кому** будет автоматически подставлена почта автора обращения.

    Если вы [принимаете обращения пользователей через форму](https://yandex.ru/support/tracker/ru/support-process-send-mail#form), в ней можно запросить почту пользователя и сохранить ответ в поле задачи «От». В этом случае почта пользователя также подставится в поле **Кому** автоматически.

3. Нажмите кнопку **Отправить**.

# Шаг 3. Добавьте автоматизацию

- Чтобы быстро отправлять со страницы задачи письма с шаблонным текстом, [настройте макросы](https://yandex.ru/support/tracker/ru/manager/create-macroses).

- Чтобы автоматически отправлять пользователям уведомления при наступлении определенных событий, [используйте триггеры](https://yandex.ru/support/tracker/ru/manager/trigger-examples#notify_mail).
