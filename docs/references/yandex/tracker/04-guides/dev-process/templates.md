Используйте [шаблоны](https://yandex.ru/support/tracker/ru/user/ticket-template), чтобы упростить [создание типовых задач](https://yandex.ru/support/tracker/ru/user/create-ticket), например ошибок или задач на тестирование. В шаблоне можно задать известные заранее параметры задачи и добавить подсказки для описания задачи, чтобы пользователи не забывали указать необходимую информацию.

Чтобы создать шаблон задачи для вашей очереди и разрешить использовать его участникам команды:

1. На панели слева нажмите  **Настройки** ⟶  **Шаблоны** или перейдите по ссылке [https://tracker.yandex.ru/settings/templates](https://tracker.yandex.ru/settings/templates) .

2. В правом верхнем углу страницы нажмите  **Создать** ⟶ **Шаблон задачи**.

3. Задайте название и описание шаблона.

4. Чтобы шаблон можно было использовать только в вашей очереди, включите опцию **Отображать шаблон только в конкретной очереди**, а затем выберите очередь из предложенного списка. В этом случае участники команды очереди автоматически получат доступ к шаблону на чтение.

5. Заполните поля шаблона и сохраните его. Заданные значения полей будут автоматически подставляться в задачи, созданные с помощью шаблона.

6. Чтобы настроить доступ к шаблону, нажмите **Действия над шаблоном** ⟶ **Настроить доступ** и добавьте нужные группы или пользователей.

7. Чтобы участники вашей команды могли использовать шаблон для создания задач:

    - У сотрудников должен быть доступ к шаблону на чтение.

    - Сотрудники должны подключить шаблон. Для этого нужно перейти на страницу управления шаблонами и включить шаблон с помощью переключателя.

Если вам нужен шаблон задачи, который по умолчанию смогут использовать все пользователи, [настройте форму для создания задачи](https://yandex.ru/support/tracker/ru/manager/forms-integration) в сервисе Яндекс Формы. Созданную [форму можно использовать вместо стандартной страницы создания задачи](https://yandex.ru/support/tracker/ru/manager/attach-form) в вашей очереди.
