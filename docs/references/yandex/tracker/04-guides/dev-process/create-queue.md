У каждой команды есть сложившийся процесс планирования работы, выполнения задач, выпуска версий продукта. Чтобы настроить привычный рабочий процесс в Трекере, используйте [очередь задач](https://yandex.ru/support/tracker/ru/queue-intro). Очередь — это пространство для задач, объединенных общим процессом или продуктом.

Для каждой команды разработки рекомендуется создавать отдельную очередь. Вы можете создать несколько очередей, если хотите разделить работу на несколько потоков. Например, если в вашей команде несколько рабочих групп, которые занимаются независимыми друг от друга задачами, можно создать отдельную очередь для каждой группы.

Чтобы создать очередь для команды разработки:

1. Если ваша организация еще не работает в Трекере, [подключите сервис](https://yandex.ru/support/tracker/ru/enable-tracker).

2. [Создайте очередь задач](https://yandex.ru/support/tracker/ru/manager/create-queue). Для очереди выберите [шаблон](https://yandex.ru/support/tracker/ru/manager/work-process) с типами задач и статусами, которые лучше подходят для вашего рабочего процесса:

    - «Разработка» — этот шаблон содержит типы задач и статусы, которые часто используют при разработке программ и приложений. При выборе этого шаблона автоматически создается [доска «С бэклогом и спринтами»](https://yandex.ru/support/tracker/ru/dev-process-agile#instrumenty-na-skram-doske).

    - «Управление проектами» — этот шаблон оптимизирован для работы нескольких команд. При выборе этого шаблона для каждого нового проекта создается [простая доска задач](https://yandex.ru/support/tracker/ru/dev-process-agile#board_types).

    - «Базовый шаблон» — универсальный шаблон, который вы сможете настроить самостоятельно под ваши задачи. При выборе этого шаблона для каждого нового проекта создается [простая доска задач](https://yandex.ru/support/tracker/ru/dev-process-agile#board_types) с таким же названием, как у очереди.

    Если вы выбрали шаблон очереди без доски задач, доску можно [создать позже](https://yandex.ru/support/tracker/ru/manager/agile-create).

3. Если вы хотите изменить возможные статусы задач в вашей очереди, в настройках очереди скопируйте [базовый рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow) и [отредактируйте его](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit).

4. Добавьте сотрудников, которые будут работать над вашим продуктом, в [команду очереди](https://yandex.ru/support/tracker/ru/manager/queue-team).

5. Если требуется, настройте [права доступа к очереди](https://yandex.ru/support/tracker/ru/manager/queue-access). Например, определенным группам пользователей можно запретить создавать или просматривать задачи в очереди.
