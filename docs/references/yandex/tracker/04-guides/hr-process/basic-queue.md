# Создать очередь для управления персоналом

Чтобы сотрудники HR-отдела могли планировать и отслеживать общие задачи по управлению персоналом, создайте очередь и пригласите в нее сотрудников отдела:

1. Создайте очередь:
    1. На панели слева нажмите  **Очереди** → **Создать очередь**.

    2. Выберите шаблон очереди **Подбор персонала**.
    3. Задайте имя, например `HR Tasks`.
    4. Нажмите кнопку **Создать**.
2. Добавьте сотрудников HR-отдела в [команду очереди](https://yandex.ru/support/tracker/ru/manager/queue-team).
3. Если требуется, настройте [права доступа к очереди](https://yandex.ru/support/tracker/ru/manager/queue-access). Например, определенным пользователям можно запретить создавать или просматривать задачи в очереди.
4. Если вопросами найма и ведением сотрудника в процессе трудовой деятельности занимаются разные специалисты, вы можете создать несколько очередей и разграничить к ним доступ так, чтобы сотрудники одного отдела не видели задачи другого.
5. Создайте тестовую задачу:
    1. Нажмите кнопку  **Создать задачу** на панели слева.
    2. В открывшейся форме в поле **Название задачи** введите название задачи, например `Обзорное совещание по управлению текущими задачами в Трекере`.
    3. Подтвердите создание и нажмите **Создать задачу**.
