Чтобы кандидаты на вакансию могли самостоятельно подать заявку, создайте очередь, форму заявки и настройте автоматическую отправку письма подтверждения.

# Создайте очередь для кандидатов

1. [Создайте очередь](https://yandex.ru/support/tracker/ru/manager/create-queue) с помощью шаблона «Подбор персонала».
2. Укажите название очереди, например `Candidates Queue`.
3. Настройте [рабочий процесс](https://yandex.ru/support/tracker/ru/manager/work-process#hire) или создайте [новый](https://yandex.ru/support/tracker/ru/manager/workflow).
4. Добавьте в рабочий процесс завершающие статусы **Принят** и **Не принят**.
5. Для рабочего процесса укажите тип задачи, например `Кандидаты`.

# Настройте форму заявки

## Создайте форму

1. На панели слева нажмите кнопку  **Создать задачу**.
2. В разделе **Создавайте задачи быстрее с Яндекс Формами** нажмите кнопку **Создать форму**.
3. Создайте новую форму:
    - Укажите название `Кандидат`;
    - Добавьте описание, например `Форма заявки на вакансию`;
    - Нажмите кнопку **Продолжить**.
4. Дождитесь загрузки страницы и выберите виджет **Текст**.
5. В поле **Вопрос** введите `ФИО`.
6. Нажмите кнопку  **Добавить вопрос** и выберите опцию **Текст**.
7. В карточке нового вопроса в поле **Вопрос** введите `Вакансия`.
8. Аналогично добавьте еще один вопрос `О себе`. Измените тип этого вопроса с `Короткий ответ` на `Длинный ответ`.
9. Нажмите кнопку  **Добавить вопрос** и выберите опцию **Почта**.
10. В карточке нового вопроса в поле **Вопрос** введите `Email`.
11. Добавьте другие вопросы, если нужно.

## Настройте интеграцию с Трекером

1. Нажмите кнопку **Настроить интеграции** и дождитесь загрузки страницы.
2. В поле **Тип задачи** выберите `Кандидаты`.
3. В поле **Заголовок** нажмите и выберите **Ответ на вопрос**. В появившемся окне в поле **Вопрос** выберите `ФИО` и нажмите кнопку **Сохранить**.
4. В поле **Описание** нажмите и выберите **Ответы на вопрос**. В появившемся окне нажмите кнопку **Выбрать все**, в поле **Форматирование ответа** выберите **Новое форматирование**. Нажмите кнопку **Сохранить**.

# Настройте отправку письма

1. На странице настройки интеграций ниже нажмите кнопку  **Добавить группу действий**.
2. В появившейся карточке **Группа действий #2** выберите виджет **Почта**.
3. В поле **Кому** нажмите и выберите **Ответ на вопрос**. В появившемся окне в поле **Вопрос** выберите `Email` и нажмите кнопку **Сохранить**.
4. В поле **Тема** введите `Отклик на вакансию`.
5. В поле **Текст** введите текст письма, например `Спасибо! Ваша заявка принята к рассмотрению`.
6. На странице ниже нажмите кнопку **Сохранить** и кнопку **Опубликовать**.

## Создайте тестовую задачу

1. На странице создания новой задачи справа вверху в поле **Разрешить создание задач без формы** выберите опцию **никогда**.
2. Выберите виджет с названием `Кандидат`.
3. Заполните форму. В качестве адреса почты укажите свой адрес.
4. Нажмите кнопку **Отправить**.
5. Проверьте, что к вам на почту пришло письмо подтверждения.
