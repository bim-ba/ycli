Чтобы сотрудники компании могли заранее легко и понятно оформлять отпуска и больничные, создайте очередь, форму заявки и настройте автоматическую проверку статуса заявок с отправкой напоминания сотрудникам отдела кадров в случае, если заявка вовремя не взята в работу.

# Создайте очередь

1. [Создайте очередь](https://yandex.ru/support/tracker/ru/manager/create-queue) с помощью шаблона **Кадровые процессы**.
2. Укажите название очереди, например `Vacations Queue`.
3. Настройте рабочий процесс для типа задачи `Отпуск`.
4. Если нужно, создайте дополнительные типы задач и рабочие процессы.

# Настройте форму заявки

## Создайте форму

1. На панели слева нажмите кнопку  **Создать задачу**.
2. В разделе **Создавайте задачи быстрее с Яндекс Формами** нажмите кнопку **Создать форму**.
3. Создайте новую форму:
    - Укажите название `Заявка на отпуск`;
    - Добавьте описание, например `Форма заявки на отпуск`;
    - Нажмите кнопку **Продолжить**.
4. Дождитесь загрузки страницы и нажмите кнопку **Полная версия Яндекс Форм**.
5. Создайте форму заявки, например со следующими полями:
    - `ФИО` (короткий текст, обязательное поле);
    - `Отдел` (короткий текст, обязательное поле);
    - `Тип отпуска` (выпадающий список, обязательное поле). Добавьте опции в список, например:
        - «Оплачиваемый отпуск»;
        - «Неоплачиваемый отпуск»;
        - «Декретный отпуск»;
        - «Больничный».
    - `Начало` (Дата, обязательное поле);
    - `Конец` (Дата, обязательное поле);
6. Добавьте другие поля, если нужно.

## Настройте интеграцию с Трекером

1. Нажмите кнопку **Настроить интеграции** и дождитесь загрузки страницы.
2. В поле **Тип задачи** выберите `Отпуск`.
3. В поле **Заголовок** нажмите и выберите **Ответ на вопрос**. В появившемся окне в поле **Вопрос** выберите опцию **Тип отпуска** и нажмите кнопку **Сохранить**.
4. В поле **Описание** нажмите и выберите **Ответы на вопрос**. В появившемся окне нажмите кнопку **Выбрать все**, в поле **Форматирование ответа** выберите **Форматированный**. Нажмите кнопку **Сохранить**.
5. Внизу нажмите кнопку **Добавить параметры задачи** и с помощью поля поиска выберите опцию **Дедлайн**.
6. В поле **Дедлайн** добавьте ответ на вопрос `Начало`.
7. Сохраните форму, нажав кнопку **Сохранить**.
8. Вернитесь в конструктор формы, нажав вверху страницы кнопку **В конструктор**.
9. Нажмите кнопку **Опубликовать** и в появившемся окне скопируйте ссылку на форму.
10. Вернитесь в настройки очереди `Vacations Queue` и нажмите **Интеграция форм**.
11. Нажмите **Добавить форму** и заполните появившуюся форму, указав в поле **Ссылка на форму** полученную выше ссылку.
12. Сохраните интеграцию формы, нажав кнопку **Сохранить**.

# Настройте автодействие

Для выполнения регулярных действий в очереди, в Трекере предусмотрены [автодействия](https://yandex.ru/support/tracker/ru/user/create-autoaction). Настройте регулярную проверку очереди `Vacations Queue` на наличие не взятых в работу заявок с помощью автодействия. Чтобы не перегружать сотрудников, ответственных за оформление отпусков, частыми напоминаниями, настройте отправку напоминаний раз в сутки и не раньше, чем за две недели до указанного в заявке начала отпуска.

1. На странице очереди `Vacations Queue` в правом верхнем углу нажмите  **Настройки очереди**.

2. На панели слева выберите **Автоматизация**.

3. В правом верхнем углу нажмите кнопку **Создать** → **Автодействие**.

4. В поле **Название** введите название автодействия, например `Напоминание об отпуске`. Ниже названия вы можете добавить описание.

5. В поле **Тип автодействия** активируйте **Обновление задач**.

6. В разделе  **График срабатывания** настройте обновление раз в день (для целей тестирования лучше установить раз в час).

7. В заголовке блока  **Когда задача соответствует** выберите **QL-запросу**.

8. Используя [язык запросов](https://yandex.ru/support/tracker/ru/user/query-filter), введите в поле ниже:

    ```
    Deadline: <= today() +14D Status: Новый
    ```

    Условие сработает для задачи, у которой дата начала отпуска наступает через две недели или менее, а статус остается в состоянии «Новый».

9. В разделе  **Выполнить действия** выберите **Добавить комментарий к задаче**.

10. В блоке комментария нажмите  **Призвать** и выберите сотрудников, которые занимаются оформлением отпусков.

11. В поле комментария добавьте текст:

     ```
     Отпуск не оформлен! Дедлайн: "{{issue.dueDate}}".
     ```

12. Чтобы сохранить автодействие, нажмите **Сохранить**.

# Проверьте работу автодействия

1. На странице создания новой задачи справа вверху в поле **Разрешить создание задач без формы** выберите опцию **никогда**.
2. Выберите виджет с названием `Отпуск`.
3. Заполните форму. В поле **Начало** укажите дату через неделю от сегодняшней.
4. Отправьте форму.
5. Убедитесь, что по истечении установленного в автодействии срока в задаче появился настроенный выше комментарий.
