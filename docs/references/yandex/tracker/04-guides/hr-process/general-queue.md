Для решения текущих вопросов, поступающих от сотрудников компании в отдел кадров, создайте отдельную очередь, доступную всем сотрудникам, и настройте добавление формы обратной связи по факту закрытия задачи.

# Создайте очередь

1. [Создайте очередь](https://yandex.ru/support/tracker/ru/manager/create-queue) с помощью базового шаблона.
2. В качестве имени укажите, например `General Questions`.
3. Если нужно, создайте дополнительные [типы задач](https://yandex.ru/support/tracker/ru/manager/add-ticket-type) и [рабочие процессы](https://yandex.ru/support/tracker/ru/manager/workflow).

# Настройте форму обратной связи

1. [Создайте форму](https://yandex.ru/support/forms/new-form.html) обратной связи. Например, это может быть форма с названием «Оцените нашу работу» и с одним вопросом типа **Список**. В качестве пунктов списка можно задать:
    - «Отлично»;
    - «Хорошо»;
    - «Средне»;
    - «Плохо».
2. При необходимости настройте интеграцию формы, например, с [вашим API](https://yandex.ru/support/forms/send-request.html) сбора статистики.

# Настройте триггер для добавления формы

Чтобы формы обратной связи автоматически добавлялась по факту закрытия задачи, добавьте в действия триггера создание комментария со встроенной формой:

1. На странице очереди `General Questions` в правом верхнем углу нажмите  **Настройки очереди**.

2. На панели слева выберите **Автоматизация**.

3. В правом верхнем углу нажмите кнопку **Создать** → **Триггер**.

4. В поле **Название** введите название триггера. Ниже названия вы можете добавить описание.

5. В разделе  **При условии** укажите **Статус** → **стало равно** → **Закрыт**.
    Подробнее про условия срабатывания триггеров читайте [здесь](https://yandex.ru/support/tracker/ru/user/set-condition).

6. В разделе  **Выполнить действия** выберите **Добавить комментарий к задаче**.

7. В текст комментария вставьте код:

    ```
    /iframe/(src="https://forms.yandex.ru/cloud/admin/<идентификатор_формы>/?iframe=1" frameborder=0 width=100% height=660px scrolling=no)
    ```

    Где `<идентификатор_формы>` — уникальный код (например `123a4bc5d678901e2345678f`), который содержится в ссылке на форму.

8. В блоке комментария нажмите  **Призвать** → **Автор**.

9. Включите опцию **Отправлять от имени робота**.

10. Чтобы сохранить триггер, нажмите кнопку **Создать**.

## Выдайте доступ роботу

Для корректной вставки формы [выдайте доступ к очереди](https://yandex.ru/support/tracker/ru/manager/queue-access#main) роботу сервиса Формы `yndx-forms-cnt-robot@`.

После закрытия задачи робот будет создавать комментарий с формой и призывать автора.

# Проверьте работу триггера

1. На странице очереди `General Questions` создайте задачу.
2. Измените статус задачи на **Закрыт**.
3. Убедитесь, что появился комментарий с формой обратной связи.
