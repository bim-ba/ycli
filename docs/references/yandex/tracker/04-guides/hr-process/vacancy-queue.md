Чтобы сотрудники других отделов вашей компании могли оставлять заявки на поиск новых специалистов, создайте очередь для менеджмента вакансий и настройте форму описания вакансии.

# Создайте очередь

1. [Создайте очередь](https://yandex.ru/support/tracker/ru/manager/create-queue) с помощью шаблона **Подбор персонала**.
2. Укажите название очереди, например `Vacancy Queue`.

# Настройте рабочие процессы

Шаблоны очередей включают предустановленные рабочие процессы — наборы статусов и правил перехода между ними. Рабочие процессы позволяют автоматизировать рутинные операции по работе с задачами.
В одной очереди можно настроить несколько рабочих процессов для разного типа задач. Например, вакансии на должности, не требующие высокой квалификации, могут проводиться по упрощенной схеме.

## Настройте предустановленный процесс

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди** и выберите **Рабочие процессы**.
3. Выберите предустановленный рабочий процесс **Documents**.
4. На странице процесса поменяйте название на **Квалифицированные кадры**.
5. Укажите тип задач, к которым применим этот процесс. Для этого нажмите справа от названия процесса и введите имя нового типа задачи, например `Специалисты`.
6. Нажмите появившуюся ниже опцию  **Добавить тип задачи** и в открывшемся окне после заполнения полей нажмите **Создать**.
7. Сохраните процесс:
    1. Справа вверху нажмите **Сохранить**.
    2. В следующем окне нажмите **Применить**.

## Скопируйте и настройте новый процесс

1. Вернитесь на страницу рабочих процессов.
2. На карточке рабочего процесса «Квалифицированные кадры» нажмите кнопку .
3. Дождитесь появления карточки процесса «Квалифицированные кадры (1)» и нажмите кнопку редактирования .
4. На странице рабочего процесса «Квалифицированные кадры (1)» поменяйте название на **Неквалифицированные кадры**.
5. Укажите тип задач, к которым применим этот процесс, создав тип `Неспециалисты`, как описано выше.
6. Удалите из процесса этап согласования. Для этого на схеме процесса нажмите статус **Согласование результата** и на панели настроек справа вверху нажмите . Выберите опцию **Убрать из процесса**.
7. Сохраните процесс, как описано выше.

# Создайте шаблоны задач

Для упрощения создания типовых задач в очереди вы можете использовать Яндекс Формы.

## Создайте форму для первого процесса

1. На панели слева нажмите кнопку  **Создать задачу**.
2. В разделе **Создавайте задачи быстрее с Яндекс Формами** нажмите кнопку **Создать форму**.
3. Создайте новую форму:
    - Укажите название `Специалист`;
    - Добавьте описание, например `Форма вакансии для квалифицированных сотрудников`;
    - Нажмите кнопку **Продолжить**.
4. Дождитесь загрузки страницы и выберите виджет **Текст**.
5. В поле **Вопрос** введите `Название`.
6. Нажмие кнопку  **Добавить вопрос**.
7. В карточке нового вопроса в поле **Вопрос** введите `Отдел`.
8. Аналогично добавьте еще один вопрос `Описание`. Измените тип этого вопроса с `Короткий ответ` на `Длинный ответ`.
9. Добавьте другие вопросы, если нужно.

## Настройте интеграцию формы

1. Нажмите кнопку **Настроить интеграции** и дождитесь загрузки страницы.
2. В поле **Тип задачи** выберите `Специалисты`.
3. В поле **Заголовок** нажмите и выберите **Ответ на вопрос**. В появившемся окне в поле **Вопрос** выберите опцию **Название** и нажмите кнопку **Сохранить**.
4. В поле **Описание** нажмите и выберите **Ответы на вопрос**. В появившемся окне нажмите кнопку **Выбрать все**, в поле **Форматирование ответа** выберите **Форматированный**. Нажмите кнопку **Сохранить**.
5. На странице ниже нажмите кнопку **Сохранить** и кнопку **Опубликовать**.

## Настройте доступ к форме

Если вы хотите ограничить доступ к форме:

1. На странице создания новой задачи наведите курсор на виджет с названием нужной вам формы, например `Специалист`.
2. Нажмите и выберите опцию  **Редактировать форму**.
3. Внизу на странице перейдите по ссылке **Полная версия Яндекс Форм**.
4. На вкладке **Настройки** в разделе **Кто может заполнять форму** активируйте опцию **Только сотрудники организации**.
5. Нажмите кнопку **Сохранить**.

## Создайте форму для второго процесса

Аналогично создайте и настройте форму для вакансий, не требующих квалификации.
Для этого на странице создания новой задачи нажмите кнопку **Создать новую форму** и повторите описанные выше действия с соответствующими второму рабочему процессу значениями.

## Создайте тестовые задачи и сгруппируйте по типу

1. На странице создания новой задачи справа вверху в поле **Разрешить создание задач без формы** выберите опцию **никогда**.
2. Выберите виджет с названием нужной вам формы, например `Специалист`.
3. Заполните форму и нажмите кнопку **Отправить**.
4. Аналогично создайте задачу с типом `Неспециалист`.
5. Включите группировку задач по типу. Для этого на доске задач нажмите **Без группировки** и выберите опцию **По типу задачи**.
