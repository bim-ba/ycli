Прохождение новым сотрудником испытательного срока связано с рутинными действиями, трекинг которых можно автоматизировать.

# Настройте автоматическое назначение окончания испытательного срока

Чтобы дата окончания испытательного срока выставлялась автоматически, создайте триггер на событие создания задачи:

1. На странице очереди кандидатов `Employment Queue` в правом верхнем углу нажмите  **Настройки очереди**.
2. На панели слева выберите **Автоматизация**.
3. В правом верхнем углу нажмите кнопку **Создать** → **Триггер**.
4. Введите название триггера, например `Окончание испытательного срока`.
5. В разделе  **При условии** укажите два условия:
    - **Тип** → **равно** → **Испытательный срок** (статус, который вы создали в рабочем процессе очереди кандидатов).
    - **Событие** → **Создана задача**.
        Подробнее про условия срабатывания триггеров читайте [здесь](https://yandex.ru/support/tracker/ru/user/set-condition).
6. В разделе  **Выполнить действия** выберите **Вычислить значение**.
7. В появившемся поле введите формулу:

    ```
    now()+3M
    ```

8. Чтобы сохранить триггер, нажмите кнопку **Создать**.

# Настройте автоматическое создание чеклиста

Чтобы не упустить важные моменты при вводе нового сотрудника в рабочий процесс, добавьте в действия триггера создание чеклиста:

1. В разделе **Выполнить действия** выберите **Создать чеклист**.
2. В появившейся форме нажмите кнопку  **Добавить пункт** и введите описание первого пункта, например `Назначить куратора`.
3. Аналогично добавьте другие пункты в чеклист.
4. Чтобы сохранить триггер, нажмите кнопку **Создать**.

# Настройте автоматическое изменение статуса задачи

Чтобы перевести задачу в следующий статус по факту заполнения чеклиста, создайте новый триггер:

1. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

2. На панели слева выберите **Автоматизация**.

3. В правом верхнем углу нажмите кнопку **Создать** → **Триггер**.

4. В поле **Название** введите название триггера, например `Контроль на испытательном сроке`. Ниже названия вы можете добавить описание.

5. В разделе  **При условии** укажите два условия срабатывания триггера:

    - **Чеклист**.
    - **Тип** → **равно** → **Испытательный срок** (статус, который вы создали в рабочем процессе очереди кандидатов).
6. В разделе  **Выполнить действия** выберите **Изменить статус задачи** и укажите статус, например **В работе**.

    Статус задачи не изменится, если при переходе в указанный статус есть обязательные для заполнения поля.
    Например, статус «В работе» предусматривает обязательный комментарий, поэтому его нельзя использовать в данном действии.

7. Чтобы сохранить триггер, нажмите кнопку **Создать**.

# Проверьте действие триггеров

1. На странице очереди новых сотрудников `Employment Queue` выберите задачу типа `Новый сотрудник`.
2. Измените статус на **В работе**.
3. Убедитесь, что в очереди появились все необходимые подзадачи.
4. Зайдите в подзадачу типа `Испытательный срок` и убедитесь, что:
    - в поле **Дедлайн** указана дата через три месяца;
    - присутствует **Чеклист** с необходимыми пунктами.
5. Активируйте все пункты чеклиста и перезагрузите страницу. Убедитесь, что статус задачи изменился.
