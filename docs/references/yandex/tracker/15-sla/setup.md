# Создать правило

Правило будет применено ко всем новым задачам в очереди. Таймер SLA не появится в задачах, созданных раньше, чем правило.

В одну очередь вы можете добавить не более 30 правил SLA.

Чтобы создать новое правило SLA:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Правила SLA**.

4. Нажмите кнопку  **Создать правило**.

5. Введите название правила.

6. Выберите график работы. График работы устанавливает время, когда правило активно. В нерабочие часы отсчет времени идти не будет. Если подходящего графика нет, его можно создать: см. [Создать график работы](https://yandex.ru/support/tracker/ru/manager/schedule#create-schedule).

7. Добавьте группы задач, попадающих под правило.

    - Чтобы создать группу задач, нажмите  **Добавить группу задач** и введите название группы задач.

    - Чтобы отфильтровать задачи, которые попадут в группу, нажмите и выберите поле. Вы можете выбрать несколько полей фильтрации.

    - Чтобы удалить группу задач, нажмите .

    - Чтобы отменить удаление группы задач, нажмите .

8. Для каждой группы задач задайте сроки выполнения задач в формате `0ч 0м`:

    - **Время до предупреждения** (необязательный параметр) — по истечении этого срока Трекер отправит предупреждение, что время обработки задачи на исходе.

    - **Время на выполнение** — предельное время на обработку задачи. По истечении этого времени Трекер отправит уведомление о срыве срока.

9. Добавьте оповещения о превышении времени. По умолчанию оповещения выключены.

    - Чтобы настроить предупреждение о превышении времени, в блоке **Предупреждения** выберите опцию **Отправить письмо** и укажите логины в Трекере или имена получателей.

    - Чтобы настроить оповещение о срыве срока, в блоке **Срыв срока** выберите опцию **Отправить письмо** и укажите логины в Трекере или имена получателей.

10. Задайте условия, при которых таймер будет запускаться, приостанавливаться или останавливаться:

     -  **Старт** — таймер запустится, если выполнено любое из перечисленных условий. Если таймер стоял на паузе, отсчет времени будет возобновлен.

     -  **Пауза (опционально)** — таймер приостановится, если выполнено любое из перечисленных условий. Таймер запустится, когда будет выполнено условие из списка **Старт**.

         Если в качестве условия для паузы выбрано "Пока задача находится в статусе", таймер запустится, как только задача будет переведена в любой другой статус.

     -  **Остановка** — таймер остановится, если выполнено любое из перечисленных условий.

     Возможные условия:

     | Условие | Режим таймера | Описание |
     | --- | --- | --- |
     | Удалён исполнитель | **Старт**, **Остановка** | Условие считается выполненным, когда в задаче удаляют исполнителя. |
     | Назначен исполнитель | **Старт**, **Остановка** | Условие считается выполненным, когда задаче назначают нового исполнителя. |
     | Получен ответ заказчика | **Старт**, **Остановка** | Условие считается выполненным, когда задачу прокомментировал пользователь, не входящий в [команду очереди](https://yandex.ru/support/tracker/ru/manager/queue-team). |
     | Создана задача | **Старт** | Таймер запустится сразу после создания задачи. |
     | Задача переведена в статус | **Старт**, **Остановка** | Условие считается выполненным, когда задачу переводят в один из указанных в нем статусов. |
     | Удалена резолюция | **Старт** | Условие считается выполненным, когда из задачи удаляют проставленную ранее резолюцию. |
     | Пока задача находится в статусе | **Пауза** | Таймер будет приостановлен, пока задача находится в одном из указанных статусов. После изменения статуса таймер автоматически запустится. |
     | Выбрана резолюция | **Остановка** | Условие считается выполненным, когда в задаче проставляют одну из указанных в нем резолюций. |
     | Получен ответ от команды очереди | **Остановка** | Условие считается выполненным, когда задачу прокомментировал пользователь, входящий в [команду очереди](https://yandex.ru/support/tracker/ru/manager/queue-team). |
     | У задачи есть исполнитель | **Пауза** | Таймер будет приостановлен, пока в задаче указан исполнитель. После удаления исполнителя таймер автоматически запустится. |
     | У задачи нет исполнителя | **Пауза** | Таймер будет приостановлен, пока в задаче не указан исполнитель. После назначения исполнителя таймер автоматически запустится. |

11. Чтобы запустить таймер снова, если условия для его старта повторятся, включите опцию **Перезапускаемый таймер**.

12. Нажмите кнопку **Создать правило**.

## Пример

Создадим правило для контроля времени реакции на новые задачи. Таймер правила запустится, как только задаче будет назначен исполнитель, и остановится, когда исполнитель возьмет задачу в работу. Если за 15 минут исполнитель не отреагирует на задачу, вы получите оповещение по почте.

Чтобы создать правило:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Правила SLA**.

4. Нажмите кнопку  **Создать правило**.

5. Введите название правила.

6. Выберите [график работы](https://yandex.ru/support/tracker/ru/manager/schedule).

7. Добавьте группу задач.

8. В разделе **Группа задач** установите предельное время реакции на задачу:

    - Поле **Время до предупреждения** оставьте пустым.

    - В поле **Время на выполнение** введите время реакции, например, `15м`.

9. Настройте оповещение о срыве срока:

    - В блоке **Срыв срока** выберите опцию **Отправить письмо**.

    - Укажите ваш логин в Трекере.

10. Настройте таймер:

     - **Старт** — Назначен исполнитель.

     - **Остановка** — Задача переведена в статус «В работе».

     - Блок **Пауза** оставьте пустым.

11. Нажмите кнопку **Создать правило**.

# Просмотреть и отредактировать правила

Чтобы просмотреть список правил SLA, действующих в очереди:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Правила SLA**.

4. Чтобы просмотреть параметры правила, нажмите  справа от его названия.

5. Внесите изменения в настройки правила.

6. Чтобы сохранить изменения, нажмите **Сохранить**.
