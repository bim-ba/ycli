График работы позволяет установить время, когда активно [правило SLA](https://yandex.ru/support/tracker/ru/manager/sla). В нерабочие часы таймер SLA работать не будет. Вы можете выбрать для правила один из стандартных графиков или создать свой.

Если таймер SLA должен работать без выходных и праздничных дней, выберите системный график **Москва. Круглосуточно**.

# Создать график работы

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

    По умолчанию настраивать очередь может только ее владелец. Подробнее: [Как настроить права доступа в очереди](https://yandex.ru/support/tracker/ru/manager/queue-access)

3. Выберите **Графики работы**.

4. Нажмите кнопку  **Создать**.

5. Введите название графика.

6. Выберите часовой пояс.

7. Укажите режим работы.

8. Выберите **Праздники и переносы выходных**. Для этого:

    - Выберите из списка страну, чтобы применить производственный календарь вашего региона.

    - Укажите год.

9. Если ваш график работы отличается от производственного, вы можете добавить праздники и переносы выходных, которые будут отличаться от основного графика работы. Для этого нажмите кнопку  **Добавить исключения** и задайте параметры:

    - **Дата**.
    - **Тип** — выходной или рабочий день.
    - **Описание**.
    - Для рабочего дня задайте **Часы работы**.
10. Нажмите кнопку **Создать**.

# Редактировать график работы

Сейчас настройки графика работы доступны только пользователю, который его создал. Если пользователя больше нет в команде очереди, изменить график не получится — нужно создать новый.

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Выберите **Графики работы**.

4. Чтобы просмотреть параметры графика, нажмите  справа от его названия.

5. Чтобы редактировать график, нажмите  → **Редактировать**.

6. Чтобы скопировать график, нажмите  → **Копировать**.

7. Чтобы удалить график, нажмите  → **Удалить**.
