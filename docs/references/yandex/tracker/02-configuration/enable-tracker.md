# Как подключить Яндекс Трекер

Вы можете подключить Трекер к существующей организации Яндекс 360 для бизнеса или создать новую организацию:

1. Выберите, какой из тарифов Трекера вам подходит:

    - Тариф с сервисами Яндекс 360 для бизнеса и Трекером для всех сотрудников организации: [Трекер для всех сотрудников организации](https://yandex.ru/support/tracker/ru/pricing#full).

    - Тариф с сервисами Яндекс 360 для бизнеса для всех сотрудников организации и дополнительная опция Трекера для отдельных сотрудников или подразделений: [Трекер для отдельных сотрудников или подразделений организации](https://yandex.ru/support/tracker/ru/pricing#addons).

    - Тариф, включающий только Трекер для всех сотрудников организации: [Только Трекер без сервисов Яндекс 360 для бизнеса](https://yandex.ru/support/tracker/ru/pricing#tracker-only).

        Также сотрудники смогут использовать сервисы Яндекс Вики и Яндекс Формы, другие сервисы Яндекс 360 для бизнеса будут доступны в ограниченном режиме.

    Тариф, включающий только Трекер, доступен для новых пользователей Яндекс 360 для бизнеса или для организаций, в которых не было активного тарифа в течение последних 30 дней.

2. Войдите в [аккаунт на Яндексе](https://id.yandex.ru/), который вы будете использовать для работы в Яндекс 360 для бизнеса.

    Если у вас еще нет аккаунта, создайте его. Подробнее читайте в [Справке Яндекс ID](https://yandex.ru/support/id/ru/authorization/registration.html).

3. Выберите, хотите ли вы подключить Трекер к существующей организации или создать новую:

    Существующая организация

    Новая организация

    1. Перейдите в [кабинет организации](https://admin.yandex.ru/).

    2. Если у вас несколько организаций, выберите ту, сотрудники которой будут работать в Трекере.

    3. Подключите выбранный тариф с Трекером. Подробнее читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/upgrade/tracker).

        Чтобы подключить Трекер, потребуются права администратора организации.

    1. Перейдите по ссылке [https://360.yandex.ru/business/tracker/](https://360.yandex.ru/business/tracker/) и нажмите кнопку **Подключить**.

    2. Выберите подходящий тариф с Трекером.

    3. При выборе организации нажмите **Создать новую организацию**.

    4. Завершите создание организации и подключение тарифа. Подробнее читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/set-up/direct).

4. Добавьте в организацию сотрудников, которые будут использовать Трекер. Как это сделать, читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/users.html).

5. Перейдите в [Трекер](https://tracker.yandex.ru/) или откройте мобильное приложение и выполните первичную настройку:

    1. Войдите в аккаунт администратора вашей организации.

    2. Выберите организацию, в которой вы подключили тариф с Трекером.

    3. Создайте первую очередь: выберите для нее шаблон, название и настройки доступа. Позже вы сможете изменить настройки очереди.

Теперь можно настроить Трекер для вашей команды: подробнее в разделе [Как настроить процессы в Трекере](https://yandex.ru/support/tracker/ru/quick-start).
