Яндекс Трекер — сервис для управления проектами и процессами в составе [Яндекс 360 для бизнеса](https://360.yandex.ru/business/).

Чтобы использовать Трекер, в организации Яндекс 360 для бизнеса выберите один из тарифов:

- Тариф с сервисами Яндекс 360 для бизнеса и Трекером для всех сотрудников организации: [Трекер для всех сотрудников организации](https://yandex.ru/support/tracker/ru/pricing#full).

- Тариф с сервисами Яндекс 360 для бизнеса для всех сотрудников организации и дополнительная опция Трекера для отдельных сотрудников или подразделений: [Трекер для отдельных сотрудников или подразделений организации](https://yandex.ru/support/tracker/ru/pricing#addons).

- Тариф, включающий только Трекер для всех сотрудников организации: [Только Трекер без сервисов Яндекс 360 для бизнеса](https://yandex.ru/support/tracker/ru/pricing#tracker-only).

    Также сотрудники смогут использовать сервисы Яндекс Вики и Яндекс Формы, другие сервисы Яндекс 360 для бизнеса будут доступны в ограниченном режиме.

Ежемесячный платеж за использование сервиса списывается со счета, привязанного к организации. Как пополнить счет, читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/pay/how-to-pay).

При отсутствии средств на счете организации или при смене тарифа Трекер автоматически перейдет в [режим Чтение](https://yandex.ru/support/tracker/ru/access#readonly) для всех сотрудников.

# Трекер для всех сотрудников организации

Вы можете подключить тариф, включающий сервисы Яндекс 360 для бизнеса и Трекер для всех сотрудников организации. В этом случае каждый сотрудник, который [добавлен в организацию](https://yandex.ru/support/tracker/ru/add-users), получает полный доступ к Трекеру.

Общая стоимость сервиса будет зависеть от общего количества пользователей, добавленных в организацию. Подробнее о тарифах и их стоимости читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/plans).

# Трекер для отдельных сотрудников или подразделений организации

Вы можете подключить для всей организации тариф, включающий только сервисы Яндекс 360 для бизнеса, и дополнительно добавить Трекер только для выбранных сотрудников или подразделений. В этом случае общая стоимость использования Трекера будет рассчитываться исходя из количества пользователей, которые имеют доступ к сервису.

Подробнее о тарифах и их стоимости читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/plans).

Чтобы подключить Трекер для сотрудников или подразделений:

1. Перейдите в [кабинет организации Яндекс 360](https://admin.yandex.ru/).

2. Выберите раздел **Сотрудники**.

3. Выберите пользователя и подключите ему дополнительную опцию для работы в Яндекс Трекере. Выбрать несколько пользователей одновременно нельзя.

    Об управлении пользователями читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/users.html).

4. Если в Трекере работают несколько сотрудников или целые отделы вашей организации, вы можете объединить их в подразделение и подключить для него дополнительную опцию для работы в Трекере.

    Об управлении подразделениями читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/units.html).

Сотрудники, для которых Трекер не подключен как дополнительная опция, будут иметь [доступ Чтение](https://yandex.ru/support/tracker/ru/access#readonly).

# Только Трекер без сервисов Яндекс 360 для бизнеса

Если вам не требуются полные возможности сервисов Яндекс 360 для бизнеса, вы можете подключить для всех сотрудников организации тариф, включающий только Трекер. В этом случае сотрудники также смогут бесплатно использовать сервисы Яндекс Вики и Яндекс Формы. Другие сервисы Яндекс 360 для бизнеса будут доступны в ограниченном режиме.

Общая стоимость сервиса Трекер будет зависеть от общего количества пользователей, добавленных в организацию. Подробнее о возможностях, входящих в состав тарифа, читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/plans).

Тариф, включающий только Трекер, доступен для новых пользователей Яндекс 360 для бизнеса или для организаций, в которых не было активного тарифа в течение последних 30 дней.

Чтобы подключить только Трекер без полных возможностей Яндекс 360 для бизнеса:

1. Войдите в [аккаунт на Яндексе](https://id.yandex.ru/). Если у вас еще нет аккаунта, создайте его. Подробнее читайте в [Справке Яндекс ID](https://yandex.ru/support/id/ru/authorization/registration.html).

2. Перейдите по ссылке [https://360.yandex.ru/business/tracker/](https://360.yandex.ru/business/tracker/) и нажмите кнопку **Подключить**.

3. На странице с тарифами выберите **Подключить Трекер отдельно**.

4. Создайте новую организацию Яндекс 360 для бизнеса или выберите существующую.

    При выборе организации убедитесь, что в ней не было активного тарифа в течение последних 30 дней.

5. Завершите создание организации и подключение тарифа. Подробнее читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/purchase/ru/set-up/direct).
