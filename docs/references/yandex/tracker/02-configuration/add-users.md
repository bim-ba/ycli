Трекер — сервис в составе [Яндекс 360 для бизнеса](https://360.yandex.ru/business/). Чтобы пользователи получили возможность работать в Трекере, добавьте сотрудников в организацию.

# Добавить пользователей в организацию Яндекс 360 для бизнеса

Вы можете добавить сотрудников в организацию Яндекс 360 для бизнеса несколькими способами:

- Пригласить пользователей со своими аккаунтами на Яндексе. Подробнее читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/invite-users-mail.html).

- Настроить федерацию удостоверений. Подробнее читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/sso.html).

    Федерация удостоверений — это технология, которая позволяет реализовать систему единого входа (Single Sign-On, SSO) и использовать для авторизации в Яндекс Трекере корпоративные аккаунты в Active Directory, Google Workspace или других SAML-совместимых системах управления учетными записями пользователей.

- Создать аккаунты пользователей на домене организации. Подробнее читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/add-users.html).

    Чтобы [войти в Трекер](https://yandex.ru/support/tracker/ru/user/login), сотруднику с аккаунтом на домене нужно будет ввести полный почтовый адрес (например, `login@example.com`) и пароль.

# Добавить пользователей в организацию Yandex Cloud

Если ранее вы подключили сервис Трекер к организации Yandex Cloud, вы можете пригласить пользователей в интерфейсе Трекера или использовать для управления пользователями сервис Yandex Cloud Organization.

### Пригласить пользователей с аккаунтом на Яндексе

1. Откройте [Трекер](https://tracker.yandex.ru/) и [войдите в аккаунт администратора](https://yandex.ru/support/tracker/ru/user/login).

2. На панели слева нажмите кнопку **Добавить пользователя** (если вы не видите данного раздела, нажмите кнопку **Еще**).

3. В появившемся окне перечислите через запятую почтовые адреса сотрудников (например, `login@yandex.ru`) и нажмите кнопку **Отправить приглашение**.

    Приглашения можно отправлять на любые адреса электронной почты. Каждый пользователь получит письмо с предложением вступить в организацию. Приглашенным сотрудникам нужно будет перейти по ссылке из письма и выбрать аккаунт на Яндексе для входа.

### Добавить пользователей в Yandex Cloud Organization

В сервисе Yandex Cloud Organization вы можете:

- Пригласить в организацию пользователей с аккаунтом на Яндексе. Подробнее в [Справке Yandex Cloud Organization](https://yandex.cloud/ru/docs/organization/operations/add-account#useraccount).

- Настроить федерацию удостоверений, чтобы использовать систему единого входа (Single Sign-On, SSO). Подробнее в [Справке Yandex Cloud Organization](https://yandex.cloud/ru/docs/organization/operations/manage-federations).

# Удалить аккаунт пользователя

Чтобы удалить аккаунт пользователя из Трекера, исключите сотрудника из организации. Подробнее в Справке:

- [Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/users.html#sec_delete).

- [Yandex Cloud Organization](https://yandex.cloud/ru/docs/organization/operations/edit-account).
