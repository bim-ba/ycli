# Удалить пользователя из Трекера

Чтобы удалить аккаунт пользователя из Трекера, исключите сотрудника из организации. [Яндекс 360: Как удалить аккаунт сотрудника](https://yandex.ru/support/yandex-360/business/admin/ru/users.html#sec_delete)

# Отключить только Трекер

Если вы хотите использовать другие сервисы Яндекс 360 для бизнеса, но отключить Трекер, поменяйте тариф в кабинете администратора организации: [Яндекс 360: Изменить тариф](https://yandex.ru/support/yandex-360/business/purchase/ru/upgrade/plan)

# Отключить Яндекс 360 для бизнеса

Если вы хотите полностью отказаться от сервисов Яндекс 360 для бизнеса, создайте обращение: [Яндекс 360: Связаться со службой поддержки](https://yandex.ru/support/yandex-360/business/purchase/ru/support/troubleshooting)

Чтобы восстановить организацию спустя время, также обратитесь в службу поддержки Яндекс 360 для бизнеса.

# Если на счету нет денег

Когда на счету организации не хватает средств для оплаты тарифа, Трекер переходит в режим «Чтение»: сотрудники не смогут создавать, изменять или удалять объекты, но смогут просматривать любую информацию. Чтобы вернуть полный доступ, оплатите Трекер.

Если никто из ваших сотрудников не заходил в Трекер в течение месяца, автоматические процессы в Трекере, например ваши триггеры и автодействия, будут отключены, но все задачи и настройки сохранятся.

Если у вас остались вопросы, напишите нам: [Как связаться со службой поддержки](https://yandex.ru/support/tracker/ru/feedback)
