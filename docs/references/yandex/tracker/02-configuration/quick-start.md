Настройте рабочие процессы в Трекере и создайте свои первые задачи.

# Шаг 1. Создайте рабочий процесс

Чтобы начать работать в Трекере, необходимо создать [очередь](https://yandex.ru/support/tracker/ru/queue-intro) — общее пространство, в котором будут находиться все ваши задачи.

Для работы с задачами удобно использовать [доски](https://yandex.ru/support/tracker/ru/manager/agile) — наглядный способ отслеживать состояние задач, которые относятся к одной или нескольким очередям. Задачи на доске размещаются в колонках, которые соответствуют разным статусам. Работа с досками задач в Трекере похожа на работу с обычными досками со стикерами: чтобы изменить статус задачи просто переместите ее из одной колонки в другую.

В Трекере вы можете [создать очередь](https://yandex.ru/support/tracker/ru/manager/create-queue) с помощью одного из доступных [шаблонов](https://yandex.ru/support/tracker/ru/manager/work-process) или [настроить рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow) вручную.

Чтобы создать очередь с помощью шаблона, преднастроенного для определенного рабочего процесса:

1. На стартовой странице [**Моя страница**](https://tracker.yandex.ru/pages/my), на виджете **Шаблоны рабочих процессов**, нажмите кнопку **Выбрать шаблон**.
2. Выберите **Базовый шаблон** и нажмите кнопку **Продолжить**.
3. Укажите параметры очереди:
    - Название очереди задач;
    - *Ключ очереди*;
    - Права доступа.
4. Нажмите кнопку **Продолжить**.

Будет создана очередь с базовым набором [типов и статусов](https://yandex.ru/support/tracker/ru/manager/workflow) задач и [простая доска задач](https://yandex.ru/support/tracker/ru/manager/agile-create#basic).

# Шаг 2. Создайте первые задачи

Задачи — это основа Трекера. Чтобы работать эффективнее, старайтесь разбить любую работу на отдельные задачи с понятными критериями выполнения.

В Трекере вы можете создавать задачи разными способами. Например, вы можете в пару кликов создать задачу сразу на доске или использовать полную форму создания задачи.

## Создать задачу на доске

Самый быстрый способ создать задачу — сделать это прямо на доске. При этом вам нужно будет придумать только название задачи, все остальные параметры вы сможете настроить позже.

1. Чтобы создать новую задачу, нажмите кнопку **Создать задачу**.

2. В открывшемся окне в поле **Название задачи** введите название задачи. Лучше, если название будет емким, чтобы задачу легко можно было найти в списке, например: «Найти ответ на главный вопрос жизни, вселенной и всего остального».

3. Нажмите кнопку **Создать** или клавишу **Enter**.

Новая задача появится на доске, на странице очереди и на [главной странице Трекера](https://tracker.yandex.ru/) в списке ваших задач.

## Создать задачу с помощью полной формы

Чтобы сразу задать все нужные параметры задачи, воспользуйтесь полной формой.

1. Нажмите кнопку  **Создать задачу** на панели слева.

2. В левом верхнем углу страницы выберите очередь, в которой будет создана задача, например, «QUEUE».

    Если создать задачу со страницы очереди, поле очередь будет уже заполнено.

3. Вам будет предложено заполнить стандартную форму с преднастроенным списком параметров.

    1. В поле **Название задачи** введите название задачи. Лучше, если название будет емким, чтобы задачу легко можно было найти в списке, например: «Найти ответ на главный вопрос жизни, вселенной и всего остального».

    2. При желании добавьте описание задачи. Для этого нажмите `Добавьте описание, чтобы исполнителю было понятно, что нужно сделать в этой задаче` и опишите задачу в открывшемся текстовом редакторе.

    3. Если нужно, загрузите файлы, кликнув на кнопку **Прикрепить файлы**.

    4. Также вы можете добавить чекпоинты в **Чеклист**, кликнув на кнопку **Добавить пункт** и заполнив открывшуюся форму.

    5. На панели справа внесите необходимые данные по задаче, например:

        - в поле **Исполнитель** укажите себя как исполнителя, нажав кнопку **Назначить меня**;
        - в поле **Дедлайн** задайте произвольный дедлайн.
    6. При необходимости, измените список отображаемых полей задачи. Для этого нажмите кнопку **Изменить список параметров** и выберите нужные параметры.

4. Нажмите кнопку **Создать задачу**.

Новая задача готова. Она появится на доске, на странице очереди и на [главной странице Трекера](https://tracker.yandex.ru/) в списке ваших задач.
