Возможность создавать и редактировать задачи в Яндекс Трекере зависит от прав доступа пользователей.

Пользователи с полным доступом могут использовать все возможности Трекера, однако можно дополнительно ограничить доступ к отдельным очередям задач, компонентам, дашбордам и фильтрам. Подробнее читайте в разделе [Роли и права доступа в Трекере](https://yandex.ru/support/tracker/ru/role-model).

Пользователи с [доступом «Чтение»](https://yandex.ru/support/tracker/ru/access#readonly) не могут создавать, изменять или удалять объекты.

Администраторы Трекера и организации Яндекс 360 для бизнеса могут управлять правами доступа пользователей и групп пользователей:

- Настроить доступ к Трекеру для пользователей и групп в разделе **Администрирование** — если для всей организации Яндекс 360 для бизнеса подключен тариф с Трекером. [Подробнее о настройке доступа к Трекеру](https://yandex.ru/support/tracker/ru/access#full)

- Настроить полный доступ для отдельных сотрудников или подразделений через кабинет организации Яндекс 360 для бизнеса. [Подробнее о настройке доступа через кабинет организации](https://yandex.ru/support/tracker/ru/access#addon)

- Настроить видимость для групп пользователей в Трекере. [Подробнее о настройке видимости групп](https://yandex.ru/support/tracker/ru/access#visibility)

# Настроить доступ для пользователей и групп

Если в организации Яндекс 360 для бизнеса [подключен тариф с Трекером](https://yandex.ru/support/tracker/ru/pricing#full), то после добавления в организацию все сотрудники по умолчанию получают полный доступ к сервису.

В этом случае [администратор Трекера](https://yandex.ru/support/tracker/ru/role-model#admin) может управлять правами доступа отдельных пользователей или групп пользователей, созданных в организации Яндекс 360 для бизнеса. Например, настроить режим [«Чтение»](https://yandex.ru/support/tracker/ru/access#readonly) для пользователей, у которых не должно быть возможности создавать или изменять задачи.

Подробнее об управлении группами читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/projects.html).

Настроить доступ для пользователей

Настроить доступ для групп

1. Откройте [Трекер](https://tracker.yandex.ru/) и войдите в аккаунт администратора: см. [Как войти в Трекер](https://yandex.ru/support/tracker/ru/user/login).

2. На панели слева нажмите **Администрирование** → **Пользователи**.

3. Для пользователей, которые будут работать с задачами, в столбце **Доступ к Трекеру** выберите **Полный** или **Чтение**.

1. Откройте [Трекер](https://tracker.yandex.ru/) и войдите в аккаунт администратора: см. [Как войти в Трекер](https://yandex.ru/support/tracker/ru/user/login).

2. На панели слева нажмите **Администрирование** → **Группы**.

3. Для каждой группы в столбце **Доступ к Трекеру** выберите **Полный** или **Чтение**

Права пользователя в Трекере определяются максимальным уровнем доступа из назначенных индивидуально или через группы, в которые входит пользователь.

Например, если пользователь с доступом Чтение вступит в группу с доступом Полный, его уровень доступа изменится на Полный.

# Настроить доступ к Трекеру через кабинет организации

Если в организации Яндекс 360 для бизнеса сервис Трекер подключен для сотрудников или подразделений, они получат полный доступ. Все пользователи и участники подразделений, для которых не подключен Трекер, будут иметь доступ в [режиме Чтение](https://yandex.ru/support/tracker/ru/access#readonly).

В этом случае изменить права доступа пользователей можно через кабинет организации Яндекс 360 для бизнеса. Настройка прав доступа через интерфейс Трекера недоступна.

[Подробнее о подключении Трекера для отдельных сотрудников или подразделений](https://yandex.ru/support/tracker/ru/pricing#addon).

# Режим Чтение

Режим Чтение устанавливается по умолчанию для тех сотрудников организации, для которых [не подключен сервис Трекер](https://yandex.ru/support/tracker/ru/pricing#addon). Если [администратор](https://yandex.ru/support/tracker/ru/role-model#admin) имеет доступ к Трекеру в режиме Чтение, он может изменить параметры доступа для своей учетной записи самостоятельно.

В режиме Чтение пользователи не могут совершать действия по созданию, изменению и удалению объектов, например:

- создавать задачи с помощью интерфейса Трекера;

- изменять параметры задач, их статусы и резолюции;

- комментировать задачи;

- подписываться на изменения задач.

При этом пользователям доступны все возможности Трекера, связанные с просмотром задач:

- просматривать задачи, [дашборды](https://yandex.ru/support/tracker/ru/user/dashboard) и [доски задач](https://yandex.ru/support/tracker/ru/manager/agile);

- искать задачи с помощью [конструктора фильтров](https://yandex.ru/support/tracker/ru/user/create-filter) и [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter);

- просматривать [страницы очередей](https://yandex.ru/support/tracker/ru/manager/quick-filters).

- настраивать [интерфейс сервиса](https://yandex.ru/support/tracker/ru/user/personal) и [уведомления](https://yandex.ru/support/tracker/ru/user/notifications).

# Настроить видимость для групп пользователей

Если в вашей организации Яндекс 360 для бизнеса есть несколько групп пользователей, которые должны работать изолированно друг от друга, вы можете задать для каждой группы настройки видимости.

Если для пользователя ограничена возможность просматривать данные группы, он не сможет добавить участников такой группы в поля задачи, призвать в комментарии или просмотреть данные участников группы, которые уже добавлены в задачу, например назначены исполнителем.

[Администраторы Трекера](https://yandex.ru/support/tracker/ru/role-model#admin) могут видеть данные всех пользователей Трекера вне зависимости от того, в какие группы они входят.

Чтобы настроить видимость для групп пользователей:

1. Откройте [Трекер](https://tracker.yandex.ru/) и войдите в аккаунт администратора: см. [Как войти в Трекер](https://yandex.ru/support/tracker/ru/user/login).
2. На панели слева нажмите **Администрирование** → **Группы**.
3. Для каждой группы в столбце **Видимость участников** выберите одно из значений.

Для системной группы **Все пользователи** установлена видимость **С ограничениями**, изменить ее нельзя.

| Настройка видимости группы | Кому видны данные участников группы | Какие данные видят участники группы |
|---|---|---|
| **Без ограничений** | Пользователям всех групп | Данные всех групп, в том числе закрытых |
| **С ограничениями** | Пользователям всех групп | Данные всех групп, кроме закрытых |
| **Закрытая** | Пользователям групп с видимостью **Без ограничений** | Данные своей группы и данные других групп, кроме закрытых |

> Например, вы хотите пригласить сотрудников организации–подрядчика использовать Трекер вместе с вами. Но при этом нужно скрыть логины и почту подрядчиков от сотрудников вашей организации.
>
> Для этого в кабинете организации объедините подрядчиков в группу. Затем в Трекере для этой группы установите видимость **Закрытая**. Остальные сотрудники, которые входят в группу **Все пользователи** с типом видимости **С ограничениями**, не будут видеть данные подрядчиков.
>
> Сотрудников отдела кадров можно объединить в группу с видимостью **Без ограничений**, чтобы они могли видеть данные всех пользователей Трекера, в том числе из закрытых групп.
>
> Подробнее об управлении группами читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/projects.html).

# Дать сотруднику право приглашать новых пользователей

Чтобы пользователь мог пригласить новых сотрудников в организацию, он должен обладать [правами администратора](https://yandex.ru/support/yandex-360/business/admin/ru/admin.html) в сервисе Яндекс 360 для бизнеса. Подробнее читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/invite-users-mail.html).
