Список задач, который вы сформировали с помощью *фильтра*, можно сохранить в виде отчета или скопировать в буфер обмена. Этот инструмент есть на страницах поиска задач, *очередей* и *проектов*.

На странице поиска задач

На странице очереди

На странице проекта

1. Откройте список задач с расширенными возможностями поиска: нажмите  **Задачи** → **Все задачи** или перейдите по ссылке [https://tracker.yandex.ru/issues](https://tracker.yandex.ru/issues)
2. Настройте критерии, по которым будут отобраны задачи для отчета. Как это сделать, подробно рассказали в разделе [Добавить условия поиска](https://yandex.ru/support/tracker/ru/user/create-filter#set-conditions).
3. В правом верхнем углу нажмите **Выгрузить** → **Отчёт по задачам**.

4. Выберите формат файла: **XML**, **CSV** или **XLSX**.

5. Внизу страницы появится оповещение с названием отчета: нажмите на ссылку внутри него.

    Чтобы скачать отчет еще раз, на панели слева нажмите  **Дашборды и отчёты**, перейдите на вкладку **Отчёты** и выберите последний.

6. Подождите, пока отчет сформируется, и нажмите кнопку **Скачать**.

Похожим способом формируется отчет по времени, которое затратили исполнители на задачи из вашего списка: нажмите **Выгрузить** → **Отчёт по трудозатратам** → **Сформировать отчёт**. Он сохранится в формате XLSX.

# Скопировать список задач в буфер обмена

На странице поиска задач

На странице очереди или проекта

1. Откройте список ваших задач и настройте фильтр: как это сделать, рассказали выше.
2. В правом верхнем углу нажмите **Выгрузить** → **Копировать список задач**.

1. Откройте список задач вашей очереди или проекта и настройте фильтр: как это сделать, рассказали выше.
2. В правом верхнем углу нажмите →  **Выгрузить** → **Копировать список задач**.

В буфер обмена будет скопирован список задач, который содержит их ключи и названия. Список можно вставить в комментарии или на страницу Яндекс Вики.
