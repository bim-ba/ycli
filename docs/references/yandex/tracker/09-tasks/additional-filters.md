Фильтр в Трекере — это инструмент для поиска задач по параметрам. С его помощью вы можете задать любые критерии: например, найти задачи конкретного автора с критичным приоритетом.

Последние условия поиска, которые вы настраивали, применятся и в следующий раз, когда вы откроете страницу поиска задач. Если вы часто добавляете одни и те же настройки фильтра, сохраните их.

# Шаг 1. Откройте список задач

Чтобы настроить фильтр, откройте список задач с расширенными возможностями поиска: нажмите  **Задачи** → **Все задачи** или перейдите по ссылке [https://tracker.yandex.ru/issues](https://tracker.yandex.ru/issues) .

# Шаг 2. Добавьте условия поиска

1. Разверните меню с кнопками для поиска задач: в правом верхнем углу страницы нажмите  **Параметры**.
    Если вам нужно сравнить условия или объединить с помощью логических операторов, вместо кнопок используйте [Язык запросов](https://yandex.ru/support/tracker/ru/user/query-filter).

2. Нажмите  **Добавить поле для фильтрации**.

3. Выберите параметр для поиска задач, задайте его значение и нажмите **Сохранить**.

4. Чтобы отобразить только завершенные или только незавершенные задачи, нажмите **Задачи: Все доступные** и выберите новый вариант.

5. Если ошиблись или передумали, очистите условия поиска:

    - Чтобы удалить один параметр из условий поиска, нажмите справа от него.
    - Чтобы удалить все условия поиска, которые вы настроили, нажмите кнопку  **Сбросить**.

*Все незавершенные задачи Ивана Иванова с типом «Ошибка». Список отсортирован по убыванию приоритета задач.*

- Чтобы быстро найти задачу в списке, который сформирован фильтром, введите текст в строку **Поиск по названию задачи**.

- Чтобы искать по локальному полю конкретной очереди, перед названием поля введите ключ очереди и точку (например, `DEVS.Тестировщик`). Что такое локальное поле рассказали на странице [Локальные поля задач](https://yandex.ru/support/tracker/ru/local-fields).

- Список с результатами поиска можно настроить: отсортировать или сгруппировать задачи, выбрать столбцы с параметрами. Как это сделать, рассказали на странице [Как настроить список результатов поиска задач](https://yandex.ru/support/tracker/ru/user/actions-on-filter).

# Шаг 3. Сохраните фильтр

Чтобы использовать фильтр в будущем:

1. В строке с параметрами поиска нажмите  **Сохранить**.
2. Задайте название фильтра и выберите папку для сохранения.
3. Нажмите кнопку **Сохранить**.

Фильтр появится в списке вверху страницы.

Если вам нужны данные для отчета, вы можете сохранить значения параметров задач в формате таблицы: в правом верхнем углу нажмите **Выгрузить** → **Отчёт по задачам** → **XLSX**.
