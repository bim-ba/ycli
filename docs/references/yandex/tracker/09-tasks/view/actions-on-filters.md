Список с результатами поиска можно настроить: отсортировать или сгруппировать задачи, а также выбрать столбцы с параметрами найденных задач.

# Изменить список столбцов таблицы

Результаты поиска оформлены в виде таблицы с параметрами задачи, например, «Ключ», «Задача» и «Исполнитель». Вы можете добавить в таблицу столбцы с параметрами или удалить лишние:

1. В правом углу таблицы нажмите  **Настройки**.
2. В выпадающем списке нажимайте на параметры, чтобы выбрать их или снять выделение.
3. Когда настроите список, нажмите **Применить**.

Внутри выпадающего списка тоже доступны несколько действий. Чтобы их увидеть, наведите указатель на параметр:

- Чтобы прочитать краткое описание параметра задачи, нажмите .

- Чтобы выбранный параметр всегда был в быстром доступе, нажмите .
    Вверху выпадающего списка появится категория **Закреплённые**.

- Чтобы изменить порядок выбранных столбцов, перетаскивайте их в списке за значок .

# Изменить значение параметра задачи

Вы можете редактировать параметры, которые отображаются в ячейках таблицы с результатами поиска.

- Чтобы изменить статус или приоритет задачи, ответственного пользователя (например исполнителя) или дату (например «Дедлайн»), нажмите текущее значение и выберите новое в выпадающем списке.
- Чтобы изменить название задачи или другое текстовое поле (например «Story Points»), наведите на него указатель и справа нажмите .

# Отсортировать список задач

По умолчанию список задач отсортирован по дате обновления. Чтобы задать новый параметр сортировки (например, по убыванию даты начала), используйте кнопку вверху страницы:

- Нажмите значок , чтобы изменить направление сортировки: по убыванию или по возрастанию.
- Справа от значка нажмите название текущего параметра сортировки и в выпадающем списке выберите новый.

Можно быстро отсортировать список по параметру из таблицы: наведите указатель на столбец и нажмите значок .

# Сгруппировать список задач

Задачи в результатах поиска можно разделить на группы, например по исполнителям. Для этого вверху нажмите  **Без группировки** и в выпадающем списке выберите параметр группировки.
