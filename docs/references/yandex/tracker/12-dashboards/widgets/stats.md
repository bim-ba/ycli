Виджет отображает распределение задач по значениям определенного параметра.

Не рекомендуется использовать в поле **Ключевой параметр** значение **Задача**, так как виджеты с такими настройками скоро будут отключены. [Подробнее](https://yandex.ru/support/tracker/ru/faq#widgets).

Чтобы настроить виджет, задайте параметры:

- **Название виджета** — название, которое отображается в заголовке виджета.

- **Источник данных** — фильтр, на основе которого формируется список задач. Вы можете выбрать [системный](https://yandex.ru/support/tracker/ru/user/default-filters) или [созданный ранее](https://yandex.ru/support/tracker/ru/user/create-filter) фильтр из списка или задать фильтр с помощью [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter) или параметров.

- **Задач на странице** — максимальное количество строк диаграммы, которые отображаются в виджете. Если строк окажется больше, вы сможете воспользоваться кнопкой **Показать все** в нижней части виджета.

- **Ключевой параметр** — параметр задач, по которому собирается статистика.

- **Сортировка** — порядок сортировки столбцов диаграммы.

- **Автообновление** — выберите, с какой периодичностью будет обновляться информация в виджете.
