С помощью виджета «Производительность команды» можно отобразить на диаграмме количество работы, которое команда выполняет за период времени. Метрика производительности помогает прогнозировать, сколько задач или *историй* команда может выполнить за один *спринт* или другой выбранный период. А динамика производительности позволяет оценить, как изменения в процессах повлияли на эффективность работы команды.

Метрику производительности можно рассчитывать несколькими способами:

- По значению выбранного числового поля задачи.
- По количеству задач, которые были завершены за период.
- По времени, в течение которого задачи находились в заданных *статусах*.

Чтобы настроить виджет, задайте параметры:

- **Заголовок** — введите название, которое отображается в заголовке виджета.

- **Источник данных** — укажите фильтр, на основе которого формируется выборка задач для диаграммы. Вы можете выбрать один из стандартных или созданных ранее фильтров из списка. Либо вы можете задать фильтр с помощью языка запросов или параметров задач. [Как найти задачи по любым параметрам](https://yandex.ru/support/tracker/ru/user/create-filter)

- **Период** — укажите период времени для построения диаграммы. Чтобы при обновлении виджета период построения диаграммы рассчитывался от текущей даты, на вкладке **Основные** или **Другие** выберите динамический диапазон дат, например **Последний месяц**.

- **Интервалы внутри периода** — укажите период времени, которому будет соответствовать один столбец диаграммы. В качестве шага можно выбрать дни, недели, месяцы или *спринты*.

- **Автоматическое обновление** — включите опцию, чтобы диаграмма перестраивалась автоматически. Периодичность обновления зависит от параметра **Интервалы внутри периода**.

- **Считать объём работы по** — выберите и настройте способ расчета метрики производительности:

    Значению поля

    Количеству задач

    Времени задачи в статусе

    В каждом столбце диаграммы будет указано суммарное значение, рассчитанное по выбранному полю задачи.

  - Выберите поле задачи с числовым значением (по умолчанию *Story Points*).

  - Выберите, как будет рассчитана метрика по значению поля:

    - **Последнему значению** — учитывается значение поля в конце шага диаграммы. Задача попадет в расчет при условии, что она перешла в конечный статус в течение текущего шага.
    - **Уменьшению** — учитывается разница между начальным и конечным значениями поля в течение шага диаграммы — при условии, что значение уменьшилось.
            Например, этот способ расчета можно использовать, если перед началом работы вы указываете оценку трудоемкости задачи и уменьшаете значение по мере выполнения работы.
    - **Увеличению** — учитывается разница между конечным и начальным значениями поля в течение шага диаграммы — при условии, что значение увеличилось.
            Например, этот способ расчета можно использовать, если вы указываете в поле затраченное на задачу время.

        При расчете по уменьшению или увеличению значения поля задача попадет в расчет, если в момент изменения значения:

    - статус задачи не был конечным;
    - задача находится в текущем спринте — если в качестве шага диаграммы выбран спринт.

  - В поле **Конечные статусы** выберите *статусы*, при переходе в которые задача считается завершенной.

    В столбцах диаграммы будет указано количество задач, завершенных на каждом шаге.

    В поле **Конечные статусы** выберите *статусы*, при переходе в которые задача считается завершенной.

    В каждом столбце диаграммы будет указано общее рабочее время, в течение которого задачи находились в выбранных статусах. Сумма будет округлена до .

  - Выберите один или несколько статусов, время пребывания в которых будет учитываться при расчете метрики.

  - Выберите график работы — при расчете метрики будет учитываться только рабочее время по графику.

# Показывать план спринта

Если вы используете *спринты* в качестве шагов диаграммы, на виджет можно добавить второй столбец с целевыми показателями и линию выполнения плана:

- **План** — это сумма значений выбранного поля в незавершенных задачах. Для расчета плана важно заполнить поле **Спринт** в задачах до завершения первого дня спринта.

- **Факт** — это сумма значений выбранного поля в задачах, которые были завершены в этом спринте. Важно проследить, чтобы дата завершения задачи входила в интервал, указанный в значении поля **Спринт**.

- **Процент выполнения плана** — линия, которая отображает выполнение плана в каждом спринте.

Чтобы добавить план на виджет:

1. В настройках виджета для параметра **Интервалы внутри периода** задайте значение **Спринт**.

2. Включите опцию **План**, которая появится в списке после добавления спринта.
