# Заметка

Используйте виджет «Заметка», чтобы добавить на дашборд комментарии или записывать свои идеи.

В записях можно использовать [разметку YFM](https://yandex.ru/support/tracker/ru/user/markup), в том числе добавлять таблицы, изображения или встраивать объекты. Например, можно добавить заметку со встроенным календарем. [Как встроить календарь](https://yandex.ru/support/tracker/ru/user/dashboard-calendar)
