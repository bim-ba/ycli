# Редактировать виджет

Чтобы изменить настройки виджета:

1. В правом верхнем углу виджета нажмите →  **Редактировать**.

2. Внесите изменения и нажмите **Сохранить**.

# Выбрать цвет виджета

Вы можете выделить виджет на дашборде одним из пяти цветов. По умолчанию цвет виджета не установлен.

Чтобы выбрать цвет виджета:

1. В правом верхнем углу виджета нажмите →  **Выбрать цвет**.

2. Выберите цвет из палитры. В верхней части виджета появится цветная полоса.

# Копировать виджет

Чтобы скопировать [виджет](https://yandex.ru/support/tracker/ru/user/widgets):

1. На панели слева нажмите  **Дашборды и отчёты** и выберите из списка дашборд с интересующим виджетом.

2. В правом верхнем углу виджета нажмите → **Копировать**.

3. Выберите дашборд, на который вы хотите скопировать виджет:

    - **Текущий дашборд**.
    - **Другой дашборд** — укажите название дашборда. Чтобы удалить оригинальный виджет после копирования, выберите **Удалить с текущего дашборда**.
4. Укажите название виджета.

5. Нажмите **Копировать**.

После копирования виджета в правом нижнем углу страницы появится всплывающее окно с кнопкой **Перейти на дашборд**.

# Открыть виджет на отдельной странице

Чтобы развернуть виджет на всю ширину страницы, в правом верхнем углу виджета нажмите →  **Открыть в новой вкладке**.

Вы можете скопировать ссылку на страницу виджета из адресной строки браузера.

Чтобы вернуться к дашборду, нажмите на название дашборда над заголовком виджета.

Чтобы поделиться виджетом с коллегами:

1. В правом верхнем углу виджета нажмите →  **Скопировать ссылку**.

2. Отправьте ссылку коллеге. При переходе по ссылке откроется дашборд, на котором виджет будет подсвечен голубым фоном.

Вы также можете [открыть виджет на отдельной странице](https://yandex.ru/support/tracker/ru/user/copy-widget#full-screen) и скопировать ссылку из адресной строки браузера.

# Встроить виджет через iframe

Вы можете встроить виджет через iframe в Трекер или в другие сервисы, например, в Яндекс Вики. Для этого:

1. В правом верхнем углу виджета нажмите →  **Копировать ссылку для iframe**.

2. Встройте виджет на нужную страницу. Подробнее читайте в разделе [Встроенный объект (iframe)](https://yandex.ru/support/tracker/ru/wysiwyg/embed-content).

# Свернуть виджет

Чтобы свернуть или развернуть виджет, нажмите на его заголовок. При повторном открытии дашборда Трекер сохранит текущее состояние виджетов для каждого пользователя.
