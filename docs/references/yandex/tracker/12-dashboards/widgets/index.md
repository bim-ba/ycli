Виджеты — это небольшие карточки с полезной информацией. Содержимое виджетов генерируется автоматически. Список задач, на основе которого формируется виджет, задается с помощью [фильтра](https://yandex.ru/support/tracker/ru/user/create-filter).

В Трекере доступны следующие виджеты:

- [Задачи](https://yandex.ru/support/tracker/ru/user/tasks)
- [Заметка](https://yandex.ru/support/tracker/ru/user/note)
- [Сводная таблица](https://yandex.ru/support/tracker/ru/user/summary-table)
- [Сводная таблица с суммой](https://yandex.ru/support/tracker/ru/user/summary-table-with-totals)
- [График событий](https://yandex.ru/support/tracker/ru/user/events)
- [Статистика по задачам](https://yandex.ru/support/tracker/ru/user/issues-stat)
- [График «Создано/Решено»](https://yandex.ru/support/tracker/ru/user/created-and-resolved)
- [Время цикла](https://yandex.ru/support/tracker/ru/user/cycle-time)
- [Поток](https://yandex.ru/support/tracker/ru/user/flow)
- [Производительность команды](https://yandex.ru/support/tracker/ru/user/velocity)

Примеры виджетов для дашборда службы поддержки можно найти в разделе [Собирать статистику по обращениям](https://yandex.ru/support/tracker/ru/support-process-dashboards).
