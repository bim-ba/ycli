Простая сводная таблица, которая позволяет просматривать статистику задач по двум любым параметрам. На пересечениях таблицы приводится количество задач, удовлетворяющих параметрам. С помощью такой таблицы вы можете, например, отслеживать количество и статусы задач определенной группы исполнителей.

Чтобы настроить виджет, задайте его параметры:

- **Заголовок** — название, которое отображается в заголовке виджета.

- **Источник данных** — фильтр, на основе которого формируется список задач. Вы можете выбрать [системный](https://yandex.ru/support/tracker/ru/user/default-filters) или [созданный ранее](https://yandex.ru/support/tracker/ru/user/create-filter) фильтр из списка или задать фильтр с помощью [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter) или параметров.

- **Столбцы** — параметр, по которому строятся столбцы таблицы.

- **Строки** — параметр, по которому строятся строки таблицы.

- **Задач на странице** — максимальное количество строк таблицы, которые отображаются в виджете. Если строк окажется больше, вы сможете воспользоваться кнопкой **Показать все** в нижней части виджета.

- **Сортировка** — порядок сортировки строк таблицы.

- **Показать сумму** — если опция включена, таблица содержит сумму значений по строкам и столбцам.

- **Автообновление** — выберите, с какой периодичностью будет обновляться информация в виджете.
