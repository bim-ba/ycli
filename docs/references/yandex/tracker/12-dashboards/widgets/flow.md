Виджет «Поток» отображает количество задач, проходящих разные этапы работы (соответствуют статусам в Яндекс Трекере) за период времени. С помощью накопительной диаграммы потока можно увидеть процессы, которые улучшают или ухудшают производительность команды.

Виджет «Поток» помогает построить диаграмму и увидеть количество тикетов в разных статусах с распределением по интервалам времени.

# Что покажет диаграмма

Диаграмма отражает стандартную для Agile информацию:

- общее количество незакрытых задач в разных статусах;
- количество решенных за интервал времени задач;
- время, за которое задачи проходят цикл от начального статуса до конечного.

# Настроить виджет

Добавьте на дашборд виджет **Поток** (см. [Как изменить дашборд](https://yandex.ru/support/tracker/ru/user/edit-dashboard)) и настройте его параметры:

- **Заголовок** — название, которое отображается в заголовке виджета.

- **Источник задач** — фильтр, по которому формируется список задач. Вы можете выбрать системный или собственный фильтр из списка или задать фильтр с помощью языка запросов или параметров. Подробнее на странице [Как найти задачи по любым параметрам](https://yandex.ru/support/tracker/ru/user/create-filter).

- **Статусы** — выберите вариант:

  - **По умолчанию** — порядок и цвета статусов будут выбраны автоматически.
  - **Свои настройки** — позволяет настроить порядок и цвета статусов:
    - Чтобы добавить новый статус на диаграмму, нажмите **Добавить статус**.
    - Чтобы изменить положение статуса на диаграмме, перетащите статус за значок .
    - Чтобы изменить цвет статуса на диаграмме, нажмите текущий цвет статуса и выберите новый из палитры.
- **Автоматическое обновление** — включите эту опцию, чтобы обновлять диаграмму с заданной периодичностью. Периодичность определяется параметром **Интервалы внутри периода**.

- **Учесть закрытые задачи** — включите эту опцию, чтобы учитывать на графике задачи, которые завершились до начала периода диаграммы.

- **Способ подсчета задач** — выберите вариант:

  - **Все статусы** — позволяет учитывать все изменения статусов задачи на каждом шаге диаграммы.
  - **Последний статус** — на каждом шаге диаграммы каждая задача будет учитываться только один раз (в том статусе, который был указан последним).
- **Период** — период времени, который отобразится на диаграмме. Чтобы при обновлении виджета период построения диаграммы рассчитывался от текущей даты, на вкладке **Основные** или **Другие** выберите динамический диапазон дат, например **Последний месяц**.

    Также период можно настроить и после построения графика. Для этого в правом верхнем углу виджета нажмите значок и укажите диапазон значений.

- **Интервалы внутри периода** — величина временного шага на оси с периодом. Шагом могут быть дни, недели, месяцы или спринты.

# Отображение

По умолчанию диаграмма строится следующим образом: открывающие статусы сверху, закрывающие снизу, а между ними — остальные статусы, которые соответсвуют этапам работы над задачами.
Статус определяется по рабочему процессу задач из выборки.

Вы можете изменить порядок статусов в настройках виджета.

Как настроить отображение данных на диаграмме:

- Актуальность данных видна по времени последнего обновления.
    Чтобы увидеть точное время, дату и автора виджета, наведите указатель на значок .

- Можно открыть список задач, которые образуют линию на графике в любой ее точке.
    Для этого нажмите на точку на линии и в подсказке выберите статус с ненулевым количеством задач. В новой вкладке откроется страница фильтра с предвыбранным списком ключей задач.

    Если количество задач в выбранном статусе окажется больше 100, то часть из них может не попасть в список из-за превышения максимальной длины URL.

- Можно изменять представление данных переключением пунктов под диаграммой с помощью клавиши **Ctrl** на Windows и **Command** на macOS. Например, отключать и включать отдельные полосы графиков.
    Чтобы посмотреть данные по отдельно выбранным статусам, нажмите название статуса под графиком.

- Чтобы увеличить область на диаграмме, выделите интересующий вас участок.

# Анализ

На виджет попадают задачи в разных статусах (соответствуют разноцветным полосам) — можно проследить переходы между этапами работы над задачами во времени.
Диаграмма строится по осям: X — шаги периода, Y — количество задач.

Графики можно читать детально, разбираясь в характерных паттернах. Например:

- Чем меньше угол наклона графика статуса, тем меньше задач в него переходит, чем больше угол — тем больше переходящих в данный статус задач. Горизонтальная линия графика говорит о том, что новые задачи не поступают или не завершаются.

- Чем шире слой одного цвета, тем больше задач в данном статусе накапливается в процессе.

- Увеличение разрыва между графиками открывающего и закрывающего статусов означает, что поток задач слишком большой для текущего процесса. Если эти два графика идут параллельно по восходящей линии без скачков, это значит, что поток задач и процесс в балансе.

- Все линии становятся горизонтальными в периоды, когда команда не работает по разным причинам. Если только одна линия становится горизонтальной, это значит, что на этом этапе что-то случилось.

- Предсказуемая форма графиков, например, ступеньки, показывает стабильную итеративность процесса.
