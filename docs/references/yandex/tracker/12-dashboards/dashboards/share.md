Вы можете поделиться своим дашбордом с другими пользователями. Для этого скопируйте ссылку на дашборд из адресной строки и отправьте ее коллеге. По умолчанию любой дашборд доступен для чтения всем пользователям.

Если с вами поделились дашбордом, добавьте его в избранное, чтобы всегда иметь его под рукой. Для этого справа от названия дашборда нажмите . Избранные дашборды можно посмотреть в разделе  **Дашборды и отчёты** по фильтру **Избранные** .

# Типы доступа к дашборду

Ограничить доступ к дашборду может только владелец дашборда или пользователь с типом доступа **Настройка прав**.

1. Откройте страницу дашборда.

2. В правом верхнем углу нажмите → **Настроить права доступа**.

3. Добавьте пользователей или группы, которым будет доступен дашборд.

    Чтобы добавить всех сотрудников организации, укажите группу `Все сотрудники`.

4. Отметьте действия, которые хотите разрешить пользователю или группе:

    - **Просмотр** — возможность открыть дашборд по ссылке.
    - **Изменение** — возможность отредактировать дашборд и сохранить изменения.
    - **Настройка прав** — возможность удалить дашборд и управлять настройками доступа для других пользователей.
    - **Закрыть доступ** — нажмите, чтобы удалить пользователя или группу из списка.
5. Нажмите **Сохранить**.

Если у пользователя есть доступа к дашборду, он увидит его в разделе  **Дашборды и отчёты** на панели слева.

# Изменить владельца дашборда

Изменить владельца дашборда может только текущий владелец.

1. Откройте страницу дашборда.
2. В правом верхнем углу нажмите → **Настроить права доступа**.
3. В окне настроек справа от имени нынешнего владельца нажмите и укажите нового владельца.
4. Нажмите **Сохранить**.
