По умолчанию отредактировать дашборд может только его владелец. [Измените настройки доступа](https://yandex.ru/support/tracker/ru/user/share-dashboard#access), чтобы позволить другим пользователям редактировать дашборд.

Чтобы отредактировать дашборд:

1. Откройте страницу дашборда.

2. В правом верхнем углу нажмите  **Редактировать**.

3. Чтобы создать виджет, в правом верхнем углу страницы нажмите **Добавить** и выберите тип виджета. Подробнее о виджетах и их настройках читайте в разделе [Виджеты](https://yandex.ru/support/tracker/ru/user/widgets).

4. Чтобы изменить положение виджета, перетащите его в нужную часть дашборда. Чтобы изменить размер виджета, потяните за правый нижний угол.

5. Чтобы удалить виджет, в правом верхнем углу нажмите →  **Удалить**.

6. Нажмите кнопку **Сохранить**.

# Как отредактировать виджет

Чтобы изменить настройки виджета:

1. В правом верхнем углу виджета нажмите →  **Редактировать**.

2. Внесите изменения и нажмите **Сохранить**.

# Как выбрать цвет виджета

Вы можете выделить виджет на дашборде одним из пяти цветов. По умолчанию цвет виджета не установлен.

Чтобы выбрать цвет виджета:

1. В правом верхнем углу виджета нажмите →  **Выбрать цвет**.

2. Выберите цвет из палитры. В верхней части виджета появится цветная полоса.

# Как удалить дашборд

Удалить дашборд может только его владелец. Чтобы удалить дашборд:

1. Откройте страницу дашборда.

2. В правом верхнем углу нажмите →  **Удалить**. Подтвердите удаление.

После удаления восстановить дашборд нельзя.
