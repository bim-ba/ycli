*Дашборды* позволяют отслеживать состояние важных задач на одной странице. На дашборде вы можете разместить [виджеты](https://yandex.ru/support/tracker/ru/user/widgets) — небольшие карточки с полезной информацией. Это могут быть списки задач, статистика их выполнения, сводные таблицы или заметки.

Содержимое виджетов генерируется автоматически. Список задач, на основе которого формируется виджет, задается с помощью [фильтра](https://yandex.ru/support/tracker/ru/user/create-filter). Примеры виджетов для дашборда службы поддержки можно найти в разделе [Собирать статистику по обращениям](https://yandex.ru/support/tracker/ru/support-process-dashboards).

На дашборд не попадут задачи, к которым у вас нет доступа.

Вы можете создать несколько дашбордов с разным набором виджетов и, при необходимости, переключаться между ними. Любой ваш дашборд вы можете [сделать стартовой страницей](https://yandex.ru/support/tracker/ru/user/startpage-dashboard) или [поделиться](https://yandex.ru/support/tracker/ru/user/share-dashboard) им с коллегой.
