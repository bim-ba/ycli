Чтобы следить за расписанием событий прямо в Трекере, можно встроить блок с Яндекс Календарем в описание задачи, проекта или в заметку на дашборде. Например, вы можете добавить на дашборд проекта заметку с календарем регулярных встреч команды.

Событие из Календаря может не отобразиться на дашборде, если для него включили опцию **Видимость** → **Участники**. Чтобы это исправить, включите видимость для всех.

# Шаг 1. Скопируйте код для вставки Яндекс Календаря

1. В Яндекс Календаре выберите календарь в списке **Мои календари** на левой панели. Вы можете создать несколько календарей и добавить на них разные события. [Яндекс Календарь: Работа с Календарем](https://yandex.ru/support/yandex-360/customers/calendar/web/ru/calendar-actions.html)

    Если панель слева не отображается, внизу экрана нажмите  **Развернуть боковую панель**.

2. Наведите указатель на название календаря и нажмите  →  **Открыть настройки**.

3. В настройках перейдите на вкладку **Доступ** и скопируйте код из поля **Код для вставки календаря на сайт**.

    *Как открыть настройки*

# Шаг 2. Вставьте код на дашборд, в виджет «Заметка»

1. Откройте дашборд в Яндекс Трекере и вверху нажмите **Редактировать**.

2. Создайте виджет: нажмите **Добавить**  → **Заметка**.

3. Добавьте блок с HTML-разметкой в поле для заметки: на панели инструментов нажмите  →  **HTML**.

4. Вставьте в блок код, который вы скопировали из Календаря, например:

    ```
    <iframe src="https://calendar.yandex.ru/embed/week?&layer_ids=24258742&tz_id=Europe/Moscow&layer_names=Мой календарь" width="800" height="450" frameborder="0" style="border: 1px solid #eee"></iframe>
    ```

    *Как добавить блок с HTML-разметкой*

# Шаг 3. Настройте внешний вид HTML-блока или виджета

Прежде чем сохранить виджет, вы можете проверить, как будет выглядеть блок с календарем.

1. Чтобы перейти в режим предпросмотра, внизу блока нажмите **Закрыть**.
    Чтобы выйти из режима, в правом верхнем углу блока нажмите  → **Редактировать**.

2. Если нужно, измените параметры блока. Например, задайте новый стиль рамки: `style="border: 2px dotted prange"`.

3. Когда закончите, нажмите **Добавить**. Виджет с календарем появится на дашборде.

4. Если блок с календарем больше, чем виджет, потяните виджет за значок ◢ справа внизу.

    *Пример дашборда со встроенным календарем*
