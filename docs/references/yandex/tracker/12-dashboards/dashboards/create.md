Вы можете создать несколько дашбордов с разным набором виджетов и, при необходимости, переключаться между ними. Любой ваш дашборд вы можете сделать стартовой страницей или поделиться им с коллегой.

Чтобы создать дашборд:

1. На панели слева нажмите  **Дашборды и отчёты** → **Создать**  и выберите **Дашборд**.

2. Введите название дашборда и нажмите **Создать**.

3. В правом верхнем углу нажмите **Редактировать** и из списка **Добавить**  по одному выбирайте и настраивайте виджеты. В Трекере доступны виджеты:

    - [Задачи](https://yandex.ru/support/tracker/ru/user/tasks)
    - [Заметка](https://yandex.ru/support/tracker/ru/user/note)
    - [Сводная таблица](https://yandex.ru/support/tracker/ru/user/summary-table)
    - [Сводная таблица с суммой](https://yandex.ru/support/tracker/ru/user/summary-table-with-totals)
    - [График событий](https://yandex.ru/support/tracker/ru/user/events)
    - [Статистика по задачам](https://yandex.ru/support/tracker/ru/user/issues-stat)
    - [График «Создано/Решено»](https://yandex.ru/support/tracker/ru/user/created-and-resolved)
    - [Время цикла](https://yandex.ru/support/tracker/ru/user/cycle-time)
    - [Поток](https://yandex.ru/support/tracker/ru/user/flow)
    - [Производительность команды](https://yandex.ru/support/tracker/ru/user/velocity)

    Виджеты позволяют просматривать аналитику по задачам. Задачи для виджетов отбираются с помощью [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter) или [фильтра](https://yandex.ru/support/tracker/ru/user/create-filter). Фильтр можно выбрать из списка преднастроенных и своих фильтров, а также задать вручную прямо на странице создания виджета.

4. Расположите виджеты в удобном порядке, подгоните размеры и нажмите кнопку **Сохранить**.
