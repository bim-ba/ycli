Вы можете использовать Трекер совместно с другими сервисами, чтобы автоматизировать рабочий процесс, организовать коммуникацию в команде и быть на связи с коллегами или клиентами, которые не используют Трекер.

- Интегрируйте Трекер с другими сервисами Яндекса:

  - [Создавайте задачи из писем, отправленных на почту, и отвечайте на письма комментарием к задаче](https://yandex.ru/support/tracker/ru/manager/queue-mail).

  - [Создавайте задачи на основе ответов из Яндекс Форм](https://yandex.ru/support/tracker/ru/manager/about-forms-integration).

  - [Добавляйте списки задач на страницы Яндекс Вики](https://yandex.ru/support/tracker/ru/user/wiki).

  - [Визуализируйте данные из Трекера в DataLens](https://yandex.ru/support/tracker/ru/tutorials/visualisation-in-datalens).

  - [Автоматизируйте работу в Трекере с сервисом Cloud Functions](https://yandex.ru/support/tracker/ru/tutorials/tracker-cloud-function).

- Подключите ваши репозитории к Трекеру, чтобы привязывать коммиты к задачам. Доступны сервисы:

  - [Bitbucket](https://yandex.ru/support/tracker/ru/user/bitbucket)

  - [GitHub](https://yandex.ru/support/tracker/ru/user/github)

  - [GitLab](https://yandex.ru/support/tracker/ru/user/gitlab)

- Настройте отправку уведомлений из Трекера в [чаты мессенджеров](https://yandex.ru/support/tracker/ru/messenger).

- Настройте связи с внешними приложениями с помощью [API Яндекс Трекера](https://yandex.ru/support/tracker/ru/external-links).
