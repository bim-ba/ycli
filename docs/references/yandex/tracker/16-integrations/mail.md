В Трекере вы можете привязать к очереди адрес электронной почты. Когда на такой адрес поступит письмо, в очереди будет автоматически создаваться задача. Комментарии к такой задаче можно отправить в виде письма на электронную почту пользователя, а его ответ также станет комментарием к исходной задаче. Например, это полезно, чтобы [регистрировать обращения пользователей в службу поддержки](https://yandex.ru/support/tracker/ru/support-process-send-mail).

О создании задачи из письма читайте в разделе [Как создать задачу по почте](https://yandex.ru/support/tracker/ru/user/create-ticket-by-mail).

Алгоритм создания задачи или комментария из письма

Алгоритм анализирует письма и решает, создать новую задачу или добавить комментарий к существующей. Чтобы определить, связано ли полученное письмо с существующей задачей, используются данные из заголовка и содержимого письма: ключ задачи, уникальный идентификатор текущего письма `Message-id` и другие параметры.

- Если задача с такими параметрами не найдена, создается новая задача.

- Если задача найдена, алгоритм проверяет, что задача в той же очереди, к которой относится почтовый ящик-получатель письма:

  - Если задача в той же очереди, то создается комментарий к задаче.
  - Если задача в другой очереди, создается новая задача в очереди, к которой относится почтовый ящик-получатель письма.

Также вы можете подключить к одной очереди несколько почтовых ящиков. Используйте эту возможность, если в вашей очереди обрабатываются обращения по разным продуктам или от разных групп пользователей. Для разных почтовых ящиков можно выбрать типы задач и компоненты, это поможет создать фильтры для поиска задач.

Для почтовых ящиков можно настроить дополнительные опции:

- [ограничить доступ сотрудников к задачам из почты](https://yandex.ru/support/tracker/ru/manager/queue-mail#access);
- [принимать обращения от внешних пользователей](https://yandex.ru/support/tracker/ru/manager/queue-mail#external-tasks);
- [отправлять письма со страницы задачи](https://yandex.ru/support/tracker/ru/manager/queue-mail#external-response).

# Добавить почтовый адрес

Вы можете настроить не более 200 почтовых адресов, привязанных к очередям в Трекере. Если вам нужно больше, обратитесь в [службу поддержки](https://yandex.ru/support/tracker/ru/feedback).

Настраивать очередь может ее [владелец](https://yandex.ru/support/tracker/ru/manager/queue-team) и администраторы организации, а также пользователи, которые имеют [право «Настройки очереди»](https://yandex.ru/support/tracker/ru/manager/queue-access#permissions).

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите в раздел **Интеграции** → **Почта**.

4. Нажмите **Настроить почтовые ящики** и выберите вариант настройки почтового ящика для вашей очереди:

    - **На произвольном почтовом сервере** — если вы используете почтовый сервис, не входящий в Яндекс 360: [Как настроить почтовый ящик на произвольном сервере](https://yandex.ru/support/tracker/ru/manager/queue-mail#third-party).

    - **На домене Яндекс 360** — если у вашей организации подключен домен: [Как настроить почтовый ящик на домене Яндекс 360](https://yandex.ru/support/tracker/ru/manager/queue-mail#domain).

## Как настроить почтовый ящик на произвольном сервере

Трекер не поддерживает интеграцию с почтовым сервисом Microsoft Exchange Online.

Рекомендуем завести новый почтовый ящик и использовать его только для работы с Трекером: все входящие письма станут задачами в вашей очереди.

### Настроить почтовый ящик для входящих писем

В разделе **Почта для получения писем** укажите почтовый ящик, который будет привязан к очереди. Письма, которые поступят на адрес этого почтового ящика, станут задачами в очереди. Если почтовый ящик очереди привязан к аккаунту пользователя, он будет автоматически назначен исполнителем в задаче.

1. В поле **Почта** укажите адрес почтового ящика. Например: `login@yandex.ru`. Поле **Логин** заполнится автоматически.

2. В поле **Пароль** укажите пароль для почтового ящика. Если выбранный почтовый сервер позволяет контролировать доступ с помощью пароля приложения, укажите в этом поле пароль приложения для почтовых клиентов. [Узнайте больше о паролях приложений в документации Яндекс ID](https://yandex.ru/support/id/authorization/app-passwords.html).

3. Заполните поля **Адрес IMAP-сервера** и **Порт** — это необходимо для сбора писем. Узнать эти данные можно в настройках почтового ящика.

4. Чтобы включить шифрование с помощью протокола SSL, активируйте опцию **Защищенное соединение (SSL)**.

5. Если требуется обрабатывать письма не только от сотрудников организации, но и от внешних пользователей, включите опцию **Принимать письма не только от сотрудников организации**.

6. Если требуется, настройте дополнительные параметры обработки входящих писем.

    Дополнительные параметры

    - **Папка для входящих** — укажите папку в вашем почтовом ящике, письма из которой нужно передавать для создания задач в Трекере. Задачи будут создаваться только из писем, поступающих в эту папку.
    - **Папка для архива** — укажите папку в вашем почтовом ящике для архивации писем, переданных в Трекер.
    - **Дата начала обработки писем** — укажите дату. Письма, пришедшие до указанной даты, не обрабатываются и автоматически попадают в **Папку для архива**. Если не указать дату, задачи из писем будут создаваться начиная со дня настройки почтового ящика.

    Используйте отдельные папки для сбора входящих писем и для их архивации.

7. Нажмите **Проверить подключение**.

    Если при проверке подключения возникла ошибка 422

    Если вы используете сервис Яндекс Почта, проверьте, активирована ли поддержка POP3 или IMAP для вашего ящика: [https://mail.yandex.ru/#/setup/client](https://mail.yandex.ru/#/setup/client). Включите протокол, которым вы планируете пользоваться, и сохраните изменения.

8. Укажите параметры для задач, которые будут создаваться при получении писем: *тип задачи* и *компоненты*.

    С помощью компонентов можно искать задачи или разграничить к ним доступ: [Как ограничить доступ к задачам, созданным из писем](https://yandex.ru/support/tracker/ru/manager/queue-mail#access).

9. Нажмите **Сохранить**. Почтовый адрес заработает в течение часа после создания.

### Настроить почтовый ящик для исходящих писем

С адреса почтового ящика для исходящих писем будут отправлены ответы пользователям со страницы задачи. Вы можете использовать тот же адрес, который [настроили для входящих писем](https://yandex.ru/support/tracker/ru/manager/queue-mail#get-mail).

1. В разделе **Почта для отправки ответов** нажмите  **Добавить адрес**.

2. В поле **Логин** укажите почту, с которой будут отправляться письма (комментарии к задаче). Например: `login@yandex.ru`. Вы можете выбрать тот же адрес электронной почты, который настроили для создания задач в очереди, или же использовать другой адрес для отправки ответов.

3. В поле **Пароль** укажите пароль для почтового ящика. Если выбранный почтовый сервис позволяет контролировать доступ с помощью пароля приложения, укажите в этом поле пароль приложения для почтовых клиентов. [Узнать больше о паролях приложений в документации Яндекс ID](https://yandex.ru/support/id/authorization/app-passwords.html).

4. Укажите **Адрес SMTP-сервера** и **Порт** — это необходимо для работы исходящей почты. Узнать эти данные можно в настройках почтового ящика.

5. Чтобы включить шифрование с помощью протокола SSL, активируйте опцию **Защищенное соединение (SSL)**.

    Если включена опция **Защищенное соединение (SSL)**, укажите порт для защищенного соединения, который использует ваш почтовый сервер (обычно порт 465). Не указывайте порт 587, так как в этом случаем невозможно будет установить соединение SSL.

6. Чтобы изменить подпись по умолчанию в отправляемых письмах, нажмите  **Добавить новую подпись**. Значение из поля **Псевдоним** отобразится у адресата как имя отправителя письма.

7. Проверьте, что все работает: нажмите  **Отправить тестовое письмо**.

## Как настроить почтовый ящик на домене Яндекс 360

Подключить почтовый ящике на домене Яндекс 360 можно, если домен подключен в кабинете вашей организации. Такой почтовый ящик можно использовать только для создания задач, комментариев и в качестве обратного адреса при [отправке писем](https://yandex.ru/support/tracker/ru/user/comments#send-comment) пользователям. В него нельзя войти как в обычный почтовый ящик, просмотреть или отправить письма.

Если у вашей организации не настроен домен, в Трекере вы увидите сообщение «Подключите домен». Как настроить домен, читайте в [Cправке Яндекс 360 для бизнеса](https://yandex.ru/support/business/domains.html).

Чтобы настроить почтовый ящик для приема и отправки писем на вашем домене:

1. В поле **Почта** введите адрес почтового ящика, который будет использоваться только для писем очереди. Вы можете выбрать любой подходящий адрес на вашем домене, имя домена чаще всего совпадает с адресом сайта вашей организации в интернете.

    Если ящик с указанным именем не существует, он будет создан автоматически.

2. Если требуется обрабатывать письма не только от сотрудников организации, но и от внешних пользователей, включите опцию **Принимать письма не только от сотрудников организации**.

3. Укажите параметры для задач, которые будут создаваться при получении писем: *тип задачи* и *компоненты*.

    С помощью компонентов можно искать задачи или разграничить к ним доступ: [Как ограничить доступ к задачам, созданным из писем](https://yandex.ru/support/tracker/ru/manager/queue-mail#access).

4. Чтобы изменить подпись в письмах, которые будут отправлены с почтового адреса очереди, нажмите  **Добавить новую подпись**. Значение из поля **Псевдоним** отобразится у адресата как имя отправителя письма.

5. Нажмите **Сохранить**. Почтовый адрес заработает в течение часа после создания.

# Как принимать обращения от внешних пользователей

На почтовый адрес очереди могут поступать письма как от сотрудников вашей организации, так и от внешних пользователей. Чтобы письма от пользователей, которые не являются сотрудниками организации, также становились задачами, при [настройке почтового ящика очереди](https://yandex.ru/support/tracker/ru/manager/queue-mail#settings) включите опцию **Принимать письма не только от сотрудников организации**.

# Как отправлять письма со страницы задачи

Если вам нужна возможность ответить на письмо пользователя со страницы задачи, настройте отправку исходящих писем:

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите в раздел **Интеграции** → **Почта**.

4. Если вы используете сторонний почтовый сервис, настройте почтовый ящик для исходящих писем: [инструкция](https://yandex.ru/support/tracker/ru/manager/queue-mail#send-mail).

5. Чтобы со страницы задачи можно было отправлять письма на почтовые адреса внешних пользователей, включите опцию **Разрешить отправку писем наружу**.

6. Если вы хотите сохранять номер обращения в переписке с пользователем, включите опцию **Добавлять номер задачи в тему письма**. В этом случае при ответе со страницы задачи в тему письма будет подставлен ее *ключ*. При необходимости вы можете отредактировать тему письма перед отправкой.

На странице задачи в разделе **Комментарии** появится вкладка **Письмо** для отправки электронного письма пользователю, который создал задачу. [Как отправлять письма со страницы задачи](https://yandex.ru/support/tracker/ru/user/comments#send-comment).

# Как изменить почтовые адреса очереди

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите в раздел **Интеграции** → **Почта**.

4. Нажмите **Настроить почтовые ящики**.

    - Чтобы добавить еще один почтовый ящик очереди, нажмите  **Добавить адрес**.

        Вы можете настроить не более 200 почтовых адресов, привязанных к очередям в Трекере. Если вам нужно больше, обратитесь в [службу поддержки](https://yandex.ru/support/tracker/ru/feedback).

    - Чтобы изменить настройки почтового ящика, нажмите и выберите  **Редактировать**.

    - Чтобы удалить почтовый ящик, нажмите и выберите  **Удалить**.

# Как ограничить доступ к задачам, созданным из писем

В одной очереди можно настроить несколько почтовых адресов для создания задач. Также в очереди могут быть и другие задачи, которые сотрудники организации создали обычным способом.

Чтобы разделить задачи и настроить к ним доступ для сотрудников организации, используйте компоненты. Для задач, в которых применены компоненты, можно ограничить доступ. В этом случае задачи, созданные из писем, будут доступны только определенным сотрудникам:

1. [Создайте компоненты](https://yandex.ru/support/tracker/ru/manager/components) для разных почтовых адресов очереди.

2. Укажите компоненты при настройке почтового ящика в блоке **Параметры задач**.

3. [Настройте доступ](https://yandex.ru/support/tracker/ru/manager/queue-access#access-component) пользователей к задачам с компонентом.

Если сотрудник, который имеет доступ к очереди, отправит письмо на ее почтовый адрес, он станет автором задачи и будет иметь соответствующие [права](https://yandex.ru/support/tracker/ru/manager/queue-access#task-role). Автором задач от сотрудников без доступа к очереди и от внешних пользователей назначается Робот сервиса Трекер.

# Возможные проблемы с обработкой писем

- Если вы настроили адрес очереди в почтовом сервисе, который не входит в Яндекс 360, Трекер не будет обрабатывать входящие письма, размер которых превышает 30 МБ (с вложениями). Такие письма будут помещены в папку для архива, указанную в настройках интеграции с почтовым ящиком: [Как настроить почтовый ящик на произвольном сервере](https://yandex.ru/support/tracker/ru/manager/queue-mail#third-party).

- Если спустя время письмо так и не было доставлено, обратитесь в [техническую поддержку](https://yandex.ru/support/tracker/ru/feedback).
