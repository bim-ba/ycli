Для быстрого оповещения сотрудников о важных событиях удобно использовать мессенджеры. Если у мессенджера есть API, в Трекере можно настроить триггер, который отправляет в API мессенджера HTTP-запросы при наступлении определенных событий. Например, если в очереди создается ошибка с критическим приоритетом. [Что такое REST API](https://yandex.cloud/ru/docs/glossary/rest-api).

Примеры настройки триггеров для отправки уведомлений в мессенджеры:

- [Telegram](https://yandex.ru/support/tracker/ru/telegram)

- [Яндекс Мессенджер](https://yandex.ru/support/tracker/ru/yamessenger)
