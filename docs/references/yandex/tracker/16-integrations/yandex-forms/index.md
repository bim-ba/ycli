Вы можете настроить интеграцию Трекера с сервисом [Яндекс Формы](https://forms.yandex.ru/cloud/admin) и использовать форму как шаблон для создания задачи в опреденной *очереди*. Данные из полей формы будут записаны в параметры задачи. Поля формы можно сделать обязательным для заполнения или опциональными.

Подключите форму к вашей *очереди* в Трекере одним из способов:

- Создайте форму в настройках вашей очереди с помощью встроенного конструктора в Трекере. Она также появится в списке ваших форм для бизнеса. [Как создать форму в интерфейсе Трекера](https://yandex.ru/support/tracker/ru/user/forms-template)

- Создайте форму в сервисе Яндекс Формы и позже привяжите ее к очереди. [Как создать форму в сервисе Яндекс Формы](https://yandex.ru/support/tracker/ru/manager/forms-integration)

Теперь, когда сотрудник будет создавать задачу в вашей очереди, он сможет выбрать нужную форму в качестве шаблона. [Как создать задачу в Трекере через форму](https://yandex.ru/support/tracker/ru/user/create-ticket)

Ссылку на форму можно разместить на вики-странице или на вашем сайте. Тогда создавать задачи в очереди смогут даже те пользователи, у которых нет доступа к Трекеру. Например, формы удобно использовать, чтобы пользователи обращались в службу поддержки или оставляли заявки на обслуживание: [Принимать обращения по почте и через форму](https://yandex.ru/support/tracker/ru/support-process-mail-forms).
