В Яндекс Трекере есть встроенный конструктор форм, интегрированный с сервисом Яндекс Формы. С помощью конструктора можно можно быстро создать форму, привязанную к вашей *очереди*. На странице создания задачи пользователь сможет выбрать нужную форму и заполнить ее — в результате в очереди будет создана задача: [Как создать задачу в Трекере](https://yandex.ru/support/tracker/ru/user/create-ticket).

Если очередь создана по [шаблону **Поддержка**](https://yandex.ru/support/tracker/ru/manager/work-process#support), в ней уже интегрирована форма для получения обращений от пользователей.

# Шаг 1. Перейдите в конструктор форм

1. На панели слева нажмите  **Очереди** и выберите очередь.

2. На странице очереди в правом верхнем углу нажмите  **Настройки очереди**.

3. Перейдите на вкладку **Интеграции** → **Формы**. Если к очереди уже подключены формы, нажмите **Перейти к списку форм**.

4. Нажмите **Добавить форму** →  **Создать новую**.

    Вы также можете добавить новую форму на странице создания задачи. Для этого выберите очередь в поле вверху страницы и нажмите кнопку **Создать форму**. [Как создать задачу](https://yandex.ru/support/tracker/ru/user/create-ticket)

5. Введите название и описание для формы и нажмите **Продолжить**.

# Шаг 2. Добавьте поля на форму

- Чтобы добавить первый вопрос, в области создания формы выберите тип вопроса из предложенных. Чтобы перейти к полному списку типов, нажмите **Все вопросы**.

- Чтобы добавить на страницу еще один вопрос, нажмите **Добавить вопрос** или наведите указатель на созданный вопрос и нажмите значок . Новый вопрос появится выше текущего, если навести указатель на верхнюю часть блока.

- Чтобы скопировать или удалить вопрос, нажмите или .

- Чтобы добавить иллюстрацию к тексту вопроса или варианту ответа, нажмите значок .

- Чтобы разбить форму на несколько страниц, под областью создания формы нажмите кнопку **Добавить страницу**.

Встроенный конструктор форм поддерживает только основные типы вопросов и настройки интеграции. Изменить внешний вид формы, добавить дополнительные вопросы и настроить логику их показа можно в полной версии конструктора в Яндекс Формах: [Справка Яндекс Форм](https://yandex.ru/support/forms).

Чтобы перейти в сервис Яндекс Формы, откройте форму и внизу страницы нажмите кнопку **Полная версия Яндекс Форм**.

# Шаг 3. Настройте создание задачи

1. Нажмите кнопку **Настроить интеграции**.

2. В разделе **Выполнять действия** укажите **всегда**.
    Если необходимо настроить условия, при выполнении которых будет создаваться задача, выберите **при условии**. Затем выберите вопрос и укажите ответ, при получении которого будет создана задача в Трекере.

3. Укажите *очередь*, в которой будет создана задача. Чтобы настроить для создаваемой задачи [связь](https://yandex.ru/support/tracker/ru/user/ticket-links) Родительская задача — Подзадача, выберите опцию **Сделать подзадачей** и введите *ключ* родительской задачи.

4. Выберите **Тип задачи** и **Приоритет** задачи. Доступные типы задач зависят от настроек очереди: [Типы задач в очереди](https://yandex.ru/support/tracker/ru/manager/add-ticket-type).

5. Введите название задачи в поле **Заголовок** и постановку задачи в поле **Описание**. Для форматирования текста используйте [разметку YFM](https://yandex.ru/support/tracker/ru/user/markup).

6. Чтобы назначить автора и исполнителя по умолчанию, введите логины пользователей без символа `@`. Если автор не указан, по умолчанию им будет назначен пользователь, который заполнил форму.

7. Чтобы добавить в задачу поле, которого нет в списке, выберите **Добавить параметр задачи** и начните вводить название, затем в подсказке выберите подходящий параметр.

8. Чтобы сохранить в параметрах задачи ответ на определенный вопрос формы, выберите поле задачи и нажмите значок , затем нажмите **Ответ на вопрос** и выберите вопрос.

    Подробнее о переменных читайте в [Справке Яндекс Форм](https://yandex.ru/support/forms/vars.html).

9. Чтобы передать в задачу вложения из формы, в поле **Прикреплять файлы из ответов на вопросы** выберите вопрос типа Файл.

10. Чтобы отображать ссылку на созданную задачу, включите опцию **Показать сообщение о результате действия пользователю**.

11. Также вы можете настроить интеграции с другими сервисами для совместной работы:

     - [Отправлять уведомление по почте](https://yandex.ru/support/forms/send-mail.html).

     - [Добавлять ответ пользователя на Вики](https://yandex.ru/support/forms/send-wiki.html).

     - [Отправлять HTTP-запрос](https://yandex.ru/support/forms/send-request.html).

12. Нажмите **Опубликовать**.

Созданная форма появится на странице создания задачи: [Как создать задачу в Трекере](https://yandex.ru/support/tracker/ru/user/create-ticket).

Управлять формами для создания задач можно на странице настроек очереди: [Управлять формами в очереди](https://yandex.ru/support/tracker/ru/manager/manage-forms).
