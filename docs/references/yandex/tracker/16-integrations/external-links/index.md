# Как настроить связи с внешним приложением

В Трекере можно добавлять в задачи связи с объектами во внешних приложениях, например системах контроля версий или сторонних трекерах задач.

- [Минимальная (базовая) функциональность связей](https://yandex.ru/support/tracker/ru/ext-app-setup#basic) с внешними приложениями позволяет добавлять и удалять связи на стороне Трекера через API, отображать в задаче значок приложения, ключ (идентификатор) объекта и ссылку на объект.

- Также доступна [расширенная функциональность связей](https://yandex.ru/support/tracker/ru/ext-app-setup#advanced), которая позволяет настроить отображение подробной информации о связанных объектах и требует поддержки на стороне внешнего приложения.

Чтобы обеспечить возможность создания связей:

1. Подготовьте ваше приложение к интеграции с Трекером:

    - Обеспечьте сетевой доступ и аутентификацию. См. раздел [Настроить базовую функциональность связей](https://yandex.ru/support/tracker/ru/ext-app-setup#basic).
    - При необходимости добавьте поддержку расширенной функциональности внешних связей. См. раздел [Получение информации о связанном объекте](https://yandex.ru/support/tracker/ru/ext-app-setup#object-info).
2. [Передайте команде Трекера данные для регистрации приложения](https://yandex.ru/support/tracker/ru/ext-app-info). Команда добавит ваше приложение в список доступных. После этого связи с приложением можно будет создавать во всех очередях Трекера.

3. Используйте API Яндекс Трекера для создания связей с вашим приложением:

    - [Получить список внешних приложений](https://yandex.ru/support/tracker/api-ref/issues/get-applications.html).
    - [Получить список внешних связей задачи](https://yandex.ru/support/tracker/api-ref/issues/get-external-links.html).
    - [Добавить внешнюю связь](https://yandex.ru/support/tracker/api-ref/issues/add-external-link.html).
    - [Удалить внешнюю связь](https://yandex.ru/support/tracker/api-ref/issues/delete-external-link.html).
