# Получить параметры задачи

- [Формат запроса](https://yandex.ru/support/tracker/ru/api-ref/issues/ru/api-ref/issues/get-issue#query)
- [Формат ответа](https://yandex.ru/support/tracker/ru/api-ref/issues/ru/api-ref/issues/get-issue#answer)

Запрос позволяет получить информацию о задаче.

GET

```
https://api.tracker.yandex.net/v3/issues/<id_задачи>
```

## Формат запроса

Перед выполнением запроса [получите доступ к API](https://yandex.ru/support/tracker/ru/api-ref/issues/ru/api-ref/access).

Для получения задачи используйте HTTP-запрос с методом `GET`:

```
GET /v3/issues/<id_задачи>
Host: api.tracker.yandex.net
Authorization: OAuth <OAuth-токен>
X-Org-ID или X-Cloud-Org-ID: <идентификатор_организации>
```

Заголовки

- `Host`: адрес узла, предоставляющего API.
- `Authorization`: токен для авторизации в одном из форматов:

  - `OAuth <OAuth-токен>` при авторизации по протоколу OAuth 2.0. [Читать подробнее](https://yandex.ru/support/tracker/ru/api-ref/issues/ru/api-ref/access#about_OAuth)
  - `Bearer <IAM-токен>` при авторизации с помощью IAM-токена — если к Трекеру привязана организация Yandex Cloud Organization. [Читать подробнее](https://yandex.ru/support/tracker/ru/api-ref/issues/ru/api-ref/access#iam-token)
- `X-Org-ID` или `X-Cloud-Org-ID`: идентификатор организации.

  - если к Трекеру привязана организация Яндекс 360 для бизнеса, используйте заголовок `X-Org-ID`,
  - если к Трекеру привязана организация Yandex Cloud Organization, используйте заголовок `X-Cloud-Org-ID`.

Чтобы узнать идентификатор организации, перейдите на страницу **Администрирование** → [**Организации**](https://tracker.yandex.ru/admin/orgs) и скопируйте значение поля **идентификатор**.

Ресурс

| Параметр | Описание | Тип данных |
| --- | --- | --- |
| <id_задачи> | Идентификатор или ключ текущей задачи. | Строка |

Параметры запроса
**Дополнительные параметры**

| Параметр | Описание | Тип данных |
| --- | --- | --- |
| fields | Поля задачи, которые будут включены в ответ. Используйте этот параметр, чтобы получить только необходимые поля и уменьшить размер ответа. Укажите названия полей через запятую, например: fields=status,assignee,summary. Если параметр не указан, в ответ включены все основные поля (кроме тех, которые можно добавить с помощью параметра expand). | Строка |
| expand | Дополнительные поля, которые будут включены в ответ: links — связанные задачи; comments — комментарии к задаче; transitions — доступные переходы в другие статусы; attachments — вложенные файлы. | Строка |

> Пример 1: Запрос одной задачи с указанием необходимых полей:
>
>
> - Используется HTTP-метод GET.
> - В ответе включено отображение вложенных файлов.
>
>
>  
>  
> ```
> GET https://api.tracker.yandex.net/v3/issues/JUNE-3?expand=attachments
> ```

> Пример 2: Запрос задачи с фильтрацией полей:
>
>
> - Используется HTTP-метод GET.
> - В ответе будут только поля `status`, `assignee` и `summary`.
>
>
>  
>  
> ```
> GET https://api.tracker.yandex.net/v3/issues/JUNE-3?fields=status,assignee,summary
> ```

Если запрос не был успешно обработан, API возвращает ответ с кодом ошибки:

401
Пользователь не авторизован. Проверьте, были ли выполнены действия, описанные в разделе [Доступ к API](https://yandex.ru/support/tracker/ru/api-ref/issues/ru/api-ref/access).

403
У вас не хватает прав на выполнение этого действия. Наличие прав можно перепроверить в интерфейсе Трекера — для выполнения действия при помощи API и через интерфейс требуются одинаковые права.

404
Запрошенный объект не был найден. Возможно, вы указали неверное значение идентификатора или ключа объекта.
