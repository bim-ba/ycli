В *гибких методологиях разработки* команды используют для совместной оценки задач покер планирования (Planning Poker). [Что такое покер планирования](https://ru.wikipedia.org/wiki/%D0%9F%D0%BE%D0%BA%D0%B5%D1%80_%D0%BF%D0%BB%D0%B0%D0%BD%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D1%8F)

Участники планирования оценивают трудоемкость задачи независимо друг от друга в относительных единицах Story Points. Затем участники планирования объявляют свои оценки, обсуждают их и приходят к окончательной оценке. Обычно для покера планирования используют специальные карты, на которые нанесены числа выбранной шкалы оценки.

В Трекере вы можете проводить командную оценку задач на доске в режиме покера планирования.

Покер планирования по умолчанию подключен на досках **С бэклогом и спринтами**. Если вы хотите оценивать задачи с помощью покера на **Простой доске**, [включите на ней бэклог](https://yandex.ru/support/tracker/ru/manager/backlog#add-backlog).

# Провести оценку задач

1. Чтобы перейти в режим покера, откройте вашу доску и на любой ее вкладке нажмите кнопку **Покер**.

2. В открывшемся окне скопируйте ссылку на покер и отправьте ее другим участникам команды. Все пользователи, которые перешли по ссылке, отобразятся на странице покера.

3. Добавить задачу в покер можно несколькими способами:

    - перетащить задачу в покер из спринта или бэклога;
    - на карточке задачи нажать → **Добавить в покер**.
4. Выберите подходящую оценку для задачи и дождитесь, когда остальные участники планирования выставят свои оценки — на карточке каждого участника должна отобразиться зеленая галочка.

5. Нажмите кнопку **Показать оценки**. Под именами участников планирования появятся значения оценок, которые они выбрали.

    Итоговая оценка будет [автоматически рассчитана](https://yandex.ru/support/tracker/ru/manager/poker#section_calc) и сохранена в поле **Оценка**. При необходимости вы можете изменить это значение.

6. Чтобы завершить оценку задачи, нажмите **Выставить итоговую**. Значение из поля **Оценка** будет скопировано в поле задачи **Story Points**, задача будет скрыта со страницы покера.

# Настроить шкалу оценки

Обычно шкала оценки для покера планирования включает числа Фибоначчи или подобную числовую последовательность. Чтобы изменить шкалу оценки:

1. Откройте вашу доску и в правом верхнем углу нажмите **Настройки** → **Покер**.

2. Чтобы добавить число в шкалу оценки, введите его в поле **Колода оценок**.

3. Чтобы удалить число из шкалы оценки, рядом с числом нажмите значок .

4. Нажмите кнопку **Сохранить**.

# Настроить расчет итоговой оценки

Вы можете выбрать, как будет определяться итоговая оценка трудоемкости задачи на основе оценок участников планирования. Для этого:

1. Откройте вашу доску и в правом верхнем углу нажмите **Настройки** → **Покер**.

2. В поле **Расчёт итоговой оценки** выберите функцию расчета. По умолчанию задано **Максимальное значение**.

3. Нажмите кнопку **Сохранить**.

# Скрывать задачи с выставленными Story Points

Чтобы в режиме покера скрывать задачи с заполненным полем **Story Points**:

1. На доске в меню → **Поля карточки** включите отображение поля **Story Points**.
2. В правом верхнем углу нажмите **Настройки** → **Покер** и убедитесь, что опция **Отображать оценённые задачи** отключена.

Если вы хотите продолжать видеть задачи с заполненным полем **Story Points** в режиме покера:

1. На доске в правом верхнем углу нажмите **Настройки** → **Покер**.
2. Включите опцию **Отображать оценённые задачи**.
