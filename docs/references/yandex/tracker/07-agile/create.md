# Как создать доску задач

1. На панели слева нажмите **Доски задач** → **Создать доску**.

2. Выберите тип доски:

    - **Простая доска** подойдет командам, которым нужно быстро обрабатывать поток входящих задач и распределять их между сотрудниками. Например, простую доску можно использовать для обработки обращений в службу поддержки.

    - **С бэклогом и спринтами** — доска для команд, которые используют *гибкие методологии управления проектами (Agile)*. Например, такая доска подойдет команде, которая занимается разработкой приложения.

    Вы можете начать работу с простой доской и подключить инструменты управления бэклогом и спринтами позже, если они понадобятся. [Как включить Agile-инструменты](https://yandex.ru/support/tracker/ru/manager/boards-instruments#add-backlog)

3. Нажмите **Создать**. Будет создана доска с названием «Новая доска».

4. Чтобы изменить название доски, нажмите на него и введите новое. Рекомендуем выбрать название, из которого понятно, какой команде или какому проекту принадлежит доска.

# Как удалить доску

Если доска задач больше не нужна, ее может удалить владелец или пользователи с полным доступом. [Как настроить права доступа к доске](https://yandex.ru/support/tracker/ru/manager/agile-access)

При удалении доски все задачи, которые были на нее добавлены, сохранятся в Трекере.

1. Перейдите на доску.

2. В правом верхнем углу нажмите и выберите **Удалить доску**.

3. Подтвердите удаление.

Если доска привязана к *проекту*, ее нельзя удалить, пока существует проект. [Что такое доска проекта](https://yandex.ru/support/tracker/ru/manager/boards-project)

Если удалить проект, доска задач проекта останется в разделе **Доски задач** на панели слева. В этом случае вы можете работать с такой доской так же, как с обычной доской задач, в том числе удалить ее.
