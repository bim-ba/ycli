Вы можете добавлять задачи на доску вручную или настроить автоматическое добавление задач по параметрам: [Как добавлять задачи автоматически](https://yandex.ru/support/tracker/ru/manager/agile-set-board#autoadd).

Если добавить задачу на простую доску, она попадет в колонку, которая соответствует статусу задачи, или в колонку с неразобранными задачами: [Как настроить колонки](https://yandex.ru/support/tracker/ru/manager/agile-columns). Если добавить задачу на доску с бэклогом, она попадет в бэклог: [Как использовать бэклог](https://yandex.ru/support/tracker/ru/manager/backlog).

На доску можно добавить не более 2000 задач.

# Как добавить задачи вручную

Чтобы добавить на доску существующую задачу, можно найти ее по названию или заполнить поле **Доски** на странице задачи.

Также на доске можно создать новую задачу: [Как создать задачу на доске](https://yandex.ru/support/tracker/ru/manager/agile-set-board#create-task).

## Со страницы доски

1. На панели слева выберите **Доски задач**, затем в списке выберите на нужную доску.

2. В крайней левой колонке нажмите значок и выберите **Существующая задача**.

3. Начните вводить ключ или название задачи и выберите подходящий вариант из списка.

## Со страницы задачи

1. Откройте страницу задачи.

2. На панели справа в поле **Доски** начните вводить название доски и выберите подходящий вариант из списка.

    Если поля **Доски** нет, добавьте его с помощью кнопки **Изменить список параметров**.

    Примечание

    Задача также будет добавлена на доску, если указать в поле **Спринт** название спринта на вашей доске. [Как использовать спринты](https://yandex.ru/support/tracker/ru/manager/create-agile-sprint).

## Как добавить несколько задач

На доску можно добавить несколько задач сразу, выбрав их на странице очереди или в фильтре задач: [Как искать задачи](https://yandex.ru/support/tracker/ru/user/default-filters).

1. Откройте страницу очереди или [страницу поиска задач](https://tracker.yandex.ru/issues) .

2. Выберите задачи, которые вы хотите добавить на доску.

3. На панели снизу нажмите и выберите **Добавить на доску**.

4. Поиском по названию найдите нужную доску и нажмите **Применить**.

# Как создать задачу на доске

Новую задачу можно создать прямо на доске. Для этого достаточно ввести название и указать очередь — остальные поля вы сможете заполнить позже.

1. На панели слева нажмите **Доски задач** и выберите доску

2. В крайней левой колонке нажмите значок и выберите **Новая задача**.

3. Введите название задачи.

4. В выпадающем списке выберите очередь, в которой будет создана задача.

5. Нажмите кнопку **Создать** или клавишу **Enter**.

# Как настроить автоматическое добавление задач

Если нужно добавлять на доску задачи с заданными параметрами, например все задачи очереди с определенным исполнителем, настройте *фильтр* для автоматического добавления задач:

1. В правом верхнем углу доски нажмите кнопку **Настройки**. Откроется страница **Автоматическое добавление и удаление задач**.

2. В разделе **Добавление задач на доску** нажмите **\+ Добавить параметры**. Выберите из списка параметр и укажите значение.

    Например, чтобы добавить на доску все задачи, в которых вы являетесь исполнителем, выберите параметр **Исполнитель** и укажите для него значение **Я**. Чтобы добавить дополнительные параметры, повторите этот шаг.

3. Нажмите **Сохранить**.

При сохранении фильтра на доску будут добавлены задачи, которые удовлетворяют заданным условиям, за исключением:

- задач, недоступных для редактирования пользователю, который настроил фильтр;
- уже добавленных на доску задач;
- задач, которые попадают под условия автоматического удаления с доски;
- задач, ранее добавленных на доску автоматически, но удаленных после вручную.

В дальнейшем на доску будут добавляться все задачи, подходящие под параметры фильтра, без учета перечисленных исключений.

# Автоматически удалять задачи с доски

Чтобы доска не переполнялась, достигнув лимита в 2000 задач, можно настроить автоматическое удаление задач с доски. Например, удалять все закрытые задачи или задачи, которые были закрыты несколько месяцев назад.

1. В правом верхнем углу доски нажмите кнопку **Настройки**. Откроется страница **Автоматическое добавление и удаление задач**.

2. В разделе **Удаление задач с доски** укажите статусы, которые будут условием удаления задач с доски.

3. Укажите время нахождения в указанных статусах, после которого задачи будут удалены.

Как только задача перейдет в один из указанных статусов и пробудет в нем заданное время, она будет удалена с доски.
