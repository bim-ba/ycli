Доска задач в Трекере похожа на пробковую или магнитную доску, разделенную на несколько вертикальных колонок. Каждая колонка соответствует этапу рабочего процесса. Задачи на доске обозначены карточками — аналогами бумажных стикеров. По положению карточек на доске можно понять, какие задачи завершены, какие задачи отстают, сколько работы осталось сделать:

- Задачи, которые еще не взяли в работу, находятся в крайней левой колонке.
- Когда работа начинается, задачу перемещают в следующую колонку, которая соответствует этапу выполнения задачи. Колонок на доске может быть несколько, в зависимости от количества этапов в вашем рабочем процессе.
- Крайняя правая колонка обычно соответствует завершению работы над задачей.

# Как посмотреть задачи на доске

1. Чтобы открыть страницу доски, на панели слева выберите **Доски задач**, затем в списке нажмите на нужную доску.

2. Если вы используете доску со *спринтами*, слева вверху нажмите **Все задачи на доске** и выберите спринт, задачи которого нужно отобразить.

    По умолчанию нельзя просмотреть задачи в завершенном спринте. Если вы хотите это сделать, сначала включите отображение спринта. [Показать завершенные спринты](https://yandex.ru/support/tracker/ru/manager/create-agile-sprint#show-finished)

3. Настройте удобный способ представления задач на доске:

    - Чтобы изменить порядок задач на доске, отранжируйте их вручную или включите сортировку по параметрам. [Как сортировать задачи на доске](https://yandex.ru/support/tracker/ru/manager/agile-issues#sorting)

    - Чтобы сгруппировать задачи, в верхней части доски нажмите **Без группировки** и выберите параметр группировки. [Как группировать задачи на доске](https://yandex.ru/support/tracker/ru/manager/agile-issues#group)

    - Чтобы отобразить на доске или скрыть задачи с определенными параметрами, настройте быстрые фильтры. [Как отфильтровать задачи](https://yandex.ru/support/tracker/ru/manager/agile-issues#filter)

    - Чтобы видеть на доске важные параметры задач, добавьте их на карточки. [Как настроить карточки задач](https://yandex.ru/support/tracker/ru/manager/agile-issues#cards)

# Как управлять задачами

Добавляйте задачи на доску и перемещайте их между колонками, чтобы было видно, на каком этапе находится каждая задача.

- Чтобы задачи появились на доске, добавьте их вручную или автоматически. [Как добавить задачи на доску](https://yandex.ru/support/tracker/ru/manager/agile-set-board)

    Если добавленные задачи не отобразились на доске, убедитесь, что их статусы привязаны к колонкам. Чтобы просмотреть список статусов, которые не используются на доске, рядом с крайней правой колонкой нажмите значок . [Как настроить колонки на доске](https://yandex.ru/support/tracker/ru/manager/agile-columns)

- Когда работа над задачей переходит на следующий этап, перетаскивайте карточку задачи в следующую колонку. Если статусы задач привязаны к колонкам, статус задачи изменится автоматически.

    Карточку нельзя перенести в колонку, если рабочий процесс очереди, к которой относится задача, не разрешает переход из текущего статуса в новый. [Как настроить переходы между статусами](https://yandex.ru/support/tracker/ru/manager/workflow-action-edit)

- Вы можете ранжировать задачи внутри колонки, например поместить более важные задачи сверху. Для этого перетащите карточку выше или ниже. Или наведите на карточку курсор, нажмите значок и выберите действие **Перенести наверх колонки** или **Перенести вниз колонки**.

- Чтобы перенести задачу в другой спринт, на карточке задачи нажмите → **Добавить в спринт** и выберите нужный. [Как использовать спринты](https://yandex.ru/support/tracker/ru/manager/create-agile-sprint)

- Чтобы удалить задачу с доски, в верхнем правом углу карточки нажмите значок и выберите **Убрать с доски**.

    Если удалить задачу с доски *проекта*, задача также будет удалена из списка задач проекта. [Что такое доска проекта](https://yandex.ru/support/tracker/ru/manager/boards-project)

- Чтобы изменить параметры или прокомментировать задачу, нажмите на карточку задачи.

# Добавить доску в избранное

Чтобы у вас всегда был быстрый доступ к доске, добавьте ее в избранное. Для этого перейдите на страницу доски и на верхней панели страницы нажмите значок справа от названия доски.

Чтобы найти избранные доски, на панели слева выберите **Доски задач** и отфильтруйте список досок по значению **Избранные**.

# Настроить карточки задач

Настройте внешний вид карточки задачи, чтобы видеть на доске важные для вас параметры или быстро искать задачи с определенными тегами и компонентами.

По умолчанию на карточке задачи отображаются значения полей ключ, название, исполнитель и некоторых других. Чтобы настроить отображение полей на карточке задачи:

1. На странице доски в правом углу панели поиска, сортировки и группировки нажмите кнопку → **Поля карточки**.

2. Отметьте поля задачи, которые будут отображаться на карточке. Можно добавить любые поля или убрать уже настроенные, кроме названия задачи (поле **Задача**).

3. Нажмите кнопку **Применить**.

4. Чтобы выделить определенные теги или компоненты задач цветами:

    1. Настройте карточку, чтобы на ней отображались поля **Теги** или **Компоненты**.

    2. На карточке задачи нажмите название тега или компонента и выберите цвет.

    Выбранный тег или компонент будет выделен цветом на всех карточках.

# Отобразить задачи спринта

1. Откройте вашу доску.

2. Нажмите **Все задачи на доске**.

3. Выберите спринт, задачи которого нужно отобразить.

По умолчанию нельзя просмотреть задачи в завершенном спринте. Если вы хотите это сделать, сначала включите отображение спринта: см. [Показать завершенные спринты](https://yandex.ru/support/tracker/ru/manager/create-agile-sprint#show-finished).

# Фильтровать задачи

Если задач на доске слишком много, скройте лишние с помощью фильтров. Вы можете выбрать один из сохраненных фильтров или создать новый. Также можно применить несколько фильтров одновременно.

Чтобы создать фильтр на доске:

1. В верхнем правом углу нажмите  **Фильтры**. Над колонками доски отобразится панель для настройки фильтра.

2. Нажмите значок . Выберите параметр, по которому будут отфильтрованы задачи, и задайте для него значение.

    Если требуется, добавьте в фильтр несколько параметров.

3. Чтобы отменить фильтр, нажмите  **Сбросить**.

4. Чтобы сохранить фильтр, нажмите  **Сохранить**:

    1. Задайте название фильтра.

    2. Выберите, для кого фильтр будет закреплен в верхней части доски для быстрого доступа: только для вас или для всех пользователей. Закрепленные фильтры отображаются в виде кнопок вверху доски.

    3. Нажмите кнопку **Сохранить**.

    Сохраненные фильтры будут доступны всем пользователям.

5. Сохраненные фильтры можно закрепить вверху доски для быстрого доступа.

    После создания фильтра закрепить его на доске можно только для себя. Чтобы фильтр начал отображаться у всех пользователей доски, его придется создать заново.

    1. На панели с фильтрами нажмите значок или в правом верхнем углу страницы нажмите и выберите **Управление фильтрами**.

    2. Выберите фильтры, которые должны отображаться на доске, и нажмите **Применить**.

6. Чтобы отредактировать или удалить сохраненный фильтр, в правом верхнем углу нажмите и выберите **Управление фильтрами**. Затем рядом с названием фильтра нажмите значок .

# Группировать задачи

Задачи на доске или в бэклоге (Подробнее: [Бэклог](https://yandex.ru/support/tracker/ru/manager/backlog)) можно сгруппировать по параметру. Каждая группа выглядит как горизонтальная дорожка с карточками задач. В методологии Канбан их называют *свимлейны*.

Чтобы сгруппировать задачи, в верхней части доски нажмите  **Без группировки** и выберите параметр группировки (например, `Исполнитель`). Все задачи, у которых совпадает значение выбранного параметра, будут объединены в группы.

Чтобы изменить порядок отображения задач в группе, нажмите  **Изменить порядок** и переставьте значения параметров в нужном порядке.

Вы можете задать максимальное количество задач, которое может содержаться в группе:

1. Справа от значения параметра группы нажмите → **Максимальное количество задач**.
2. Укажите лимит задач.
3. Нажмите **Сохранить**.

Вы можете добавить в группу любую задачу. Для этого под списком задач в группе нажмите кнопку **Добавить задачу**. Тогда в новой или существующей задаче будет установлено то значение поля, по которому выполняется группировка.

Ограничения:

- При группировке по очереди доступно только создание новой задачи.
- При группировке по автору, статусу или типу добавление задачи не доступно.

Задачи на доске или в бэклоге можно перетаскивать между группами. При переносе в задаче будет установлено новое значение поля в соответствии с параметром группировки.

# Сортировка задач на доске

Задачи на доске можно сортировать как вручную, так и по предзаданным параметрам, например, по приоритету, дедлайну или исполнителю. Чтобы сортировать задачи, в верхней части доски нажмите  **Сортировка** и выберите из списка нужный параметр. Рядом с кнопкой сортировки есть кнопка, которая позволяет управлять направлением сортировки.

# Массовое редактирование задач

На досках работает массовое редактирование задач. Для этого на доске, на карточке одной из задач, нажмите → **Выделить** и нажимайте на другие задачи, над которыми требуется совершить однотипное действие. Как только все задачи будут выбраны, на панели внизу доски выберите действие:

- переместить вверх или вниз колонки;
- изменить статус;
- перенести в спринт или в бэклог;
- изменить исполнителя или другие параметры задачи;
- убрать с доски.
