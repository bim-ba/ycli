Добавьте на доску колонки, чтобы обозначить этапы процесса или статусы задач и перемещать карточки между ними. Колонки на доске можно настроить двумя способами:

- По статусам: задачи на доске находятся только в колонках, которые соответствуют их статусам. Если задачу переместить в другую колонку, ее статус изменится.

- Произвольные: можно добавить любые колонки и перемещать по ним задачи все зависимости от статуса.

Для любого типа колонок можно ограничить максимальное количество задач или прикрепить к колонке заметку.

# Настроить колонки по статусам

По умолчанию на новой доске есть колонки с заголовками **Открыт**, **В работе** и **Закрыт**. Можно удалить эти колонки и добавить другие, чтобы видеть нужные статусы и перемещать задачи между ними.

Чтобы настроить колонкам по статусам:

1. На панели слева нажмите  **Доски задач** и выберите доску.

2. На верхней панели доски нажмите **Колонки** → **Колонки по статусам**.

## Как добавить колонку

Чтобы добавить колонку по статусу на доску задач:

1. На странице доски нажмите кнопку **Добавить колонку**.

2. В поле **Статусы в колонке** укажите один или несколько статусов, которые будут привязаны к колонке.

3. Введите название колонки.

4. Задайте максимальное число задач в колонке: [Как ограничить количество задач в колонке](https://yandex.ru/support/tracker/ru/manager/agile-columns#wip-limit).

5. Нажмите **Добавить**.

## Как найти неиспользуемые статусы

Чтобы просмотреть список статусов, которые не используются на доске:

1. Рядом с крайней правой колонкой нажмите значок .

2. Добавьте нужные статусы на доску: на карточке статуса нажмите , затем выберите **Создать колонку** или **Добавить в колонку**.

# Настроить произвольные колонки

Если используются произвольные колонки, на доске всегда есть колонка с неразобранными задачами — первая слева. Другие колонки можно произвольно создавать, перемещать и удалять. Также внутри произвольных колонок можно создавать задачи, перемещать их как внутри колонки, так и между колонками, параметры задач при этом не изменятся.

Чтобы настроить произвольные колонки:

1. На панели слева нажмите  **Доски задач** и выберите доску.

2. На верхней панели доски нажмите **Колонки** → **Произвольные колонки**.

Чтобы добавить произвольную колонку на доску задач:

1. На странице доски нажмите кнопку **Добавить колонку**.

2. Укажите название колонки.

3. Задайте максимальное число задач в колонке: [Как ограничить количество задач в колонке](https://yandex.ru/support/tracker/ru/manager/agile-columns#wip-limit).

4. Нажмите **Добавить**.

# Как ограничить количество задач в колонке

Для любой колонки можно установить ограничение на количество задач, или WIP-лимит (от выражения work in progress — незавершенная работа). Лимит поможет контролировать поток задач, чтобы нагрузка не превышала возможности команды.

Если количество задач в колонке превысит ограничение, вы сможете добавить в нее больше задач, но фон колонки станет желтым. Это поможет определить, на каком этапе рабочего процесса выполнение задач замедляется.

1. Наведите указатель на колонку и нажмите →  **Редактировать**.

2. Задайте максимальное число задач, которое может содержаться в колонке.

3. Нажмите **Сохранить**.

# Как добавить в колонку заметку

Вы можете прикреплять к колонкам доски свои заметки и комментарии, чтобы другим пользователям было проще на ней ориентироваться. Такие заметки не защищены от редактирования — изменить их сможет любой пользователь.

Чтобы прикрепить заметку к колонке:

1. Откройте страницу доски.

2. Вверху колонки нажмите значок и затем выберите  **Добавить заметку**.

3. Введите текст заметки. При необходимости отформатируйте текст с помощью кнопок на панели.

4. Сохраните изменения.

К каждой колонке можно прикрепить только одну заметку. Она появится в верхней части колонки и будет видна всем пользователям.

# Изменить колонку

Вы можете изменить параметры колонки и ее расположение на доске.

- Чтобы отредактировать название, максимальное количество задач в колонке или изменить статусы, наведите указатель на колонку и нажмите →  **Редактировать**.

- Чтобы изменить расположение колонки на доске, перетащите ее в нужное место.

- Чтобы отредактировать заметку с текстом, который отображается под названием колонки, наведите указатель на колонку и нажмите →  **Редактировать заметку**.

# Удалить колонку

Чтобы удалить колонку с доски, наведите указатель на колонку и нажмите →  **Удалить**.

Если в удаленной колонке были задачи:

- На доске с колонками по статусам задачи будут перенесены в раздел **Неиспользуемые статусы**. Чтобы просмотреть такие задачи, рядом с крайней правой колонкой нажмите значок , затем нажмите название статуса.

- На доске с произвольными колонками задачи будут перенесены в колонку **Неразобранные задачи**.
