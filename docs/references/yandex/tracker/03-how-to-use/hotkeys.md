Горячие клавиши — специальные комбинации кнопок на клавиатуре компьютера, которые ускоряют выполнение простых задач и сводят к минимуму использование мыши.

Чтобы увидеть список горячих клавиш в Трекере, нажмите сочетание **Shift** + **K** или на панели слева откройте  **Информация** → **Горячие клавиши**.

Ниже приведен перечень сочетаний клавиш для быстрых команд в Трекере:

# Общие действия

| Действие | Сочетание клавиш Windows | Сочетание клавиш Mac OS |
|---|---|---|
| Создать задачу | **N** | **N** |
| Открыть поиск | **Ctrl** + **S** | **⌘** + **S** |
| Перейти к следующему элементу списка | **↓** | **↓** |
| Перейти к предыдущему элементу списка | **↑** | **↑** |
| Отправить форму | **Ctrl** + **Enter** | **Ctrl** + **Enter** |
| Добавить в избранное/удалить из избранного | **F** | **F** |
| Перейти в конец страницы | **End** | **⌘** + **↓** |
| Перейти в начало страницы | **Home** | **⌘** + **↑** |
