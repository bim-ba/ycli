Чтобы познакомится с интерфейсом и возможностями Яндекс Трекера, пройдите интерактивное обучение. Шаг за шагом вы научитесь работать с основными сущностями сервиса: [задачами](https://yandex.ru/support/tracker/ru/about-tracker#zadacha), [очередями](https://yandex.ru/support/tracker/ru/queue-intro), [проектами](https://yandex.ru/support/tracker/ru/manager/project-new) и [портфелями](https://yandex.ru/support/tracker/ru/manager/portfolio).

Чтобы начать обучение или пройти его заново, на панели слева нажмите  **Информация** → **Краткое руководство по Трекеру**.

# Как пользоваться интерактивным руководством

На время обучения в правом нижнем углу страницы появится элемент управления  **Краткое руководство**. С его помощью можно:

- Следить за прогрессом обучения.

- Переключаться между модулями и проходить их в удобном для вас порядке.

- Приостановить обучение, нажав кнопку **Свернуть**.
    Чтобы вернуться к изучению руководства, снова нажмите на блок.

- Закончить обучение, нажав кнопку **Завершить**.

# Изучить курс по Трекеру

Если вы хотите более детально изучить возможности Яндекс Трекера, пройдите [бесплатный практический курс](https://360.yandex.ru/business/courses/tracker/).
