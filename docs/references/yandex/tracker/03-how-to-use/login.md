Яндекс Трекер доступен тем пользователям, которые состоят в организации [Яндекс 360 для бизнеса](https://admin.yandex.ru/). Сервис должен быть предварительно подключен к организации: [Как подключить Яндекс Трекер](https://yandex.ru/support/tracker/ru/enable-tracker).

Для начала работы в Трекере войдите в ваш аккаунт:

1. Перейдите в [Трекер](https://tracker.yandex.ru/). Нажмите кнопку **Войти в Трекер**.

2. Выберите аккаунт, который вы используете в Яндекс 360 для бизнеса. Для работы в Трекере можно использовать аккаунты нескольких типов. Уточните у администратора вашей организации, какой аккаунт следует использовать для входа:

    - Чтобы войти с помощью почтового адреса на Яндексе или на домене вашей организации, нажмите кнопку **Войти в Яндекс ID** и укажите ваш логин вида `login@yandex.ru` или `login@example.com`.

    - Если в вашей организации настроена система единого входа (Single Sign-On) через федерацию удостоверений, нажмите кнопку **Войти через SSO**, укажите идентификатор федерации и войдите в ваш рабочий аккаунт. Как настроить SSO, читайте в [Справке Яндекс 360 для бизнеса](https://yandex.ru/support/yandex-360/business/admin/ru/sso.html)

        Идентификатор федерации можно узнать у администратора вашей организации Яндекс 360 для бизнеса.

3. Если вы состоите в нескольких организациях, будет загружена последняя, с которой вы работали. После входа вы можете переключить аккаунт или организацию.

# Переключить организацию

Если вы состоите в нескольких организациях, будет загружена последняя, с которой вы работали. Чтобы переключить организацию:

1. На панели слева внизу нажмите фото профиля.

2. Выберите организацию из списка доступных.

# Переключить аккаунт пользователя

Чтобы переключить аккаунт в Яндекс Трекере:

1. На панели слева внизу нажмите фото профиля.

2. Нажмите кнопку **Войти в аккаунт**. Текущий аккаунт будет сохранен в **Истории входа** для быстрого переключения между ними.

Вы можете управлять добавленными аккаунтами:

- Чтобы удалить аккаунт из **Истории входа**, нажмите  **Удалить из истории**.

- Чтобы выйти из всех аккаунтов в Трекере, нажмите кнопку  **Выйти**.
