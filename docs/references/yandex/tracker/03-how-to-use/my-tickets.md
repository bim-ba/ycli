Найдите задачи, над которыми вы работаете:

1. На панели слева откройте  **Задачи**.

2. Чтобы найти задачи, в которых вы являетесь автором, исполнителем или наблюдателем, выберите фильтр **Все мои задачи**.

3. Если отобразились не все нужные задачи, откройте полный список:

    - На панели слева в нижней части страницы нажмите кнопку **Полный список задач по фильтру** или перейдите по [прямой ссылке](https://tracker.yandex.ru/issues/my-issues).

    - Чтобы открыть все задачи, которые доступны вам в Трекере, в нижней части окна нажмите кнопку **Все задачи** или перейдите по ссылке [https://tracker.yandex.ru/issues](https://tracker.yandex.ru/issues) .

Для поиска задач в списке используйте [стандартные фильтры](https://yandex.ru/support/tracker/ru/user/my-tickets#q-filters) или [добавьте условия поиска](https://yandex.ru/support/tracker/ru/user/default-filters#add-condition).

Чтобы быстро найти задачу в списке, который сформирован фильтром, введите текст в строку **Поиск по названию задачи**.

Список с результатами поиска можно настроить: отсортировать или сгруппировать задачи, выбрать столбцы с параметрами. Как это сделать, рассказали на странице [Как настроить список результатов поиска задач](https://yandex.ru/support/tracker/ru/user/actions-on-filter).

Откройте список задач с расширенными возможностями поиска: нажмите  **Задачи** → **Все задачи** или перейдите по ссылке [https://tracker.yandex.ru/issues](https://yandex.ru/support/tracker/ru/https:/tracker.yandex.ru/issues) .

Чтобы искать по локальному полю конкретной очереди, перед названием поля введите ключ очереди и точку (например, `DEVS.Тестировщик`). Что такое локальное поле рассказали на странице [Локальные поля задач](https://yandex.ru/support/tracker/ru/local-fields).

Если вам нужны данные для отчета, вы можете сохранить значения параметров задач в формате таблицы: в правом верхнем углу нажмите **Выгрузить** → **Отчёт по задачам** → **XLSX**.

1. В правом углу таблицы нажмите  **Настройки**.
2. В выпадающем списке нажимайте на параметры, чтобы выбрать их или снять выделение.
3. Когда настроите список, нажмите **Применить**.

# Стандартные фильтры

Чтобы отфильтровать список задач и оставить в нем только задачи с выбранными параметрами, используйте фильтры.

- На панели слева откройте  **Задачи** или перейдите по ссылке [https://tracker.yandex.ru/issues](https://tracker.yandex.ru/issues) , затем в списке выберите один из фильтров:

  - **Избранные задачи**.
  - **Все мои задачи**.
  - **Я автор**.
  - **Я исполнитель**.
  - **Я наблюдатель**.
  - **Ждут ответа**.
  - **Скоро дедлайн**.

    Чтобы открыть список задач на отдельной странице, нажмите **Полный список задач по фильтру**.

- Чтобы отобразить только завершенные, только незавершенные или все доступные по фильтру задачи, в левом углу нажмите **Задачи: Незавершенные** и выберите нужный вариант.

- Чтобы найти в списке задачи по названию, в поле **Поиск по названию задачи** введите текст для поиска.

- Чтобы использовать дополнительные параметры поиска, нажмите кнопку  **Добавить поле для фильтрации** и выберите поле. Подробнее о поиске задач читайте в разделе [Поиск по параметрам](https://yandex.ru/support/tracker/ru/user/default-filters#add-condition).

# Настроить отображение задач

Чтобы отфильтровать список задач и оставить в нем только задачи с выбранными параметрами, используйте кнопки фильтров над списком задач:

- Чтобы отобразить или скрыть параметры задач, справа над списком нажмите  **Настройки**, выберите параметры и нажмите кнопку **Применить**.

    Чтобы поменять расположение столбцов, справа от названия параметра зажмите значок и перетащите его.

- Чтобы сгруппировать задачи по определенному параметру, над списком нажмите  **Без группировки** и выберите параметр.

- Чтобы отсортировать список задач по какому-либо параметру, нажмите название параметра в заголовке столбца или выберите параметр для сортировки над списком рядом со значком .

- Чтобы свернуть панель со списком фильтров, в верхнем правом углу нажмите  **Параметры**.
