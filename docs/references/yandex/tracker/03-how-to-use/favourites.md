Вы можете добавить любую задачу, очередь, дашборд или доску задач в избранное, чтобы иметь к ним быстрый доступ. Список ваших избранных страниц доступен только вам.

По умолчанию вы не получаете уведомлений об изменениях избранных задач, но вы можете [изменить настройки уведомлений](https://yandex.ru/support/tracker/ru/user/notification-constructor).

# Как добавить задачу в избранное

Вы можете добавить важные задачи в избранное, чтобы всегда иметь их под рукой:

1. Откройте страницу задачи.

2. Вверху страницы над названием задачи нажмите на значок  **Добавить в Избранное**.

Чтобы открыть список избранных задач:

1. На панели слева откройте  **Задачи**.

2. В списке справа выберите фильтр **Избранные задачи**, затем в нижней части окна нажмите кнопку **Полный список задач по фильтру**.

Вы также можете открыть список избранных задач по ссылке [https://tracker.yandex.ru/issues/favorite](https://tracker.yandex.ru/issues/favorite) .

# Добавить очередь в избранное

Если вам нужен быстрый доступ к определенной [очереди](https://yandex.ru/support/tracker/ru/user/queue), добавьте ее в избранное:

1. Откройте страницу очереди.

2. Вверху страницы над названием очереди нажмите значок  **Добавить в Избранное**.

Чтобы открыть список избранных очередей:

1. На панели слева откройте  **Очереди**.

2. В списке справа выберите фильтр **Избранные**.

# Добавить дашборд в избранное

Чтобы добавить [дашборд](https://yandex.ru/support/tracker/ru/user/dashboard) в избранное:

1. Откройте дашборд.

2. Справа от названия дашборда нажмите значок  **Добавить в Избранное**.

Чтобы открыть список избранных дашбордов:

1. На панели слева откройте  **Дашборды и отчёты**.

2. В списке справа выберите фильтр **Избранные**.

# Добавить доску задач в избранное

Чтобы добавить [доску задач](https://yandex.ru/support/tracker/ru/manager/agile) в избранное:

1. Откройте страницу доски.

2. Вверху страницы справа от названия доски нажмите значок  **Добавить в Избранное**.

Чтобы открыть список избранных досок:

1. На панели слева откройте  **Доски задач**.

2. В списке справа выберите фильтр **Избранные**.
