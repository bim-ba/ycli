В этом разделе вы найдете основные термины и понятия, которые используются в Трекере и в этой Справке.

# А

Автодействие

Автодействие — это автоматическое обновление или создание задач в очереди с определенной периодичностью.
Например, можно каждую неделю создавать задачу на резервное копирование данных или призывать исполнителя, если статус задачи не меняется.

[Как настроить автоматическое обновление задач](https://yandex.ru/support/tracker/ru/user/create-autoaction), [Как создавать задачи по расписанию](https://yandex.ru/support/tracker/ru/user/ticket-schedule)

# Б

Бэклог

Бэклог — это список задач или требований к продукту, которые нужно выполнить в проекте. Обычно задачи в бэклоге упорядочены по приоритету. [Как использовать бэклог](https://yandex.ru/support/tracker/ru/manager/backlog)

# В

Версия

Версия — это параметр, который позволяет группировать задачи по версии продукта. Значения версий можно настроить на странице очереди. [Как создать версию в очереди](https://yandex.ru/support/tracker/ru/manager/versions#create-version)

Виджет

Виджет — это блок информации на дашборде, который автоматически получает данные о задачах и отображает их в виде списка, таблицы или графика. [Список доступных виджетов](https://yandex.ru/support/tracker/ru/user/widgets)

# Г

Гибкие методологии (Agile)

Гибкие методологии (Agile) — это подход к командной работе, когда задачи выполняются небольшими итерациями (спринтами). Одна из популярных гибких методологий — Скрам. [Что такое гибкие методологии разработки](https://yandex.ru/support/tracker/ru/manager/agile#sec_basics)

Глобальное поле

Глобальное поле — это поле задачи, которое доступно во всех очередях Трекера. Cоздать глобальное поле может администратор. [Как управлять глобальными полями](https://yandex.ru/support/tracker/ru/user/create-param#global-field)

# Д

Дашборд

Дашборд — это страница, на которой удобно отслеживать состояние важных задач и статистику. На дашборд можно добавить списки задач, таблицы, графики, заметки. [Как использовать дашборды](https://yandex.ru/support/tracker/ru/user/dashboard)

Диаграмма Ганта

Диаграмма Ганта — это инструмент визуализации проекта, который отображает задачи в виде горизонтальных полос на временной шкале для планирования и отслеживания прогресса. [Как использовать диаграмму Ганта](https://yandex.ru/support/tracker/ru/gantt/overview)

Доска задач

Доска задач — это инструмент, который позволяет наглядно отслеживать и изменять статусы задач. Задачи отображаются на доске в виде карточек, карточки распределены по столбцам доски в зависимости от их статуса. [Как использовать доски задач](https://yandex.ru/support/tracker/ru/manager/agile)

# З

Задача

Задача в Трекере — это инструмент, с помощью которого можно оформить задание, заявку или другую работу. У задачи есть название, исполнитель, сроки и другие параметры.

[Как создать задачу в Трекере](https://yandex.ru/support/tracker/ru/user/create-ticket), [Как работать с задачей](https://yandex.ru/support/tracker/ru/user/ticket-in-progress)

# И

История

См. [Story](https://yandex.ru/support/tracker/ru/glossary#story).

# К

Ключ задачи

Ключ задачи — это уникальный идентификатор задачи. Он состоит из ключа очереди и порядкового номера, например: `TEST-123`. С помощью ключа можно перейти к задаче по ссылке: `https://tracker.yandex.ru/TEST-123`.

Ключ очереди

Ключ очереди — это уникальный код из латинских букв, по которому можно идентифицировать очередь, например: `TEST`. С помощью ключа можно перейти к очереди по ссылке: `https://tracker.yandex.ru/TEST`.

[Как выбрать ключ для очереди](https://yandex.ru/support/tracker/ru/manager/create-queue#key)

Команда очереди

Команда очереди — это пользователи, которые создают и выполняют задачи в очереди. Для участников команды можно настроить особые права доступа к задачам этой очереди.

Компонент

Компонент — это параметр, который позволяет группировать задачи очереди по тематике: продукту, процессу, ответственному сотруднику и так далее. Компоненты можно настроить на странице очереди. [Как настроить компоненты](https://yandex.ru/support/tracker/ru/manager/components#create-component)

# Л

Локальное поле

Локальное поле — это поле задачи, которое доступно только в конкретной очереди Трекера. Cоздать локальное поле может владелец очереди. [Как управлять локальными полями](https://yandex.ru/support/tracker/ru/local-fields#add-local-field)

# М

Макрос

Макрос — это запрограммированный набор операций, который можно запустить на странице задачи. [Как настроить макрос](https://yandex.ru/support/tracker/ru/manager/create-macroses)

# О

Организация

Организация — это профиль компании в сервисе Яндекс 360, куда можно добавлять новых сотрудников и объединять их в подразделения и группы.

Очередь

Очередь — это пространство для задач, которые объединены общим процессом или продуктом. Также очередь можно представить как список задач для определенной команды или отдела. Очереди помогают упорядочить задачи и понять, кто отвечает за их выполнение. [Как настроить очередь](https://yandex.ru/support/tracker/queue-intro)

# П

Параметры задачи

Параметры задачи — это такие атрибуты, как «Исполнитель», «Дедлайн»,«Статус» и так далее. Параметры можно изменить на странице задачи. [Как изменить параметры задачи](https://yandex.ru/support/tracker/ru/user/edit-ticket#edit-fields)

Портфель

Портфель в Трекере — это набор проектов и других портфелей, которые объединены в одно направление. Портфели помогают структурировать проектную работу и управлять ей. [Как управлять портфелем](https://yandex.ru/support/tracker/ru/manager/portfolio)

Призвать в комментарии

Призвать пользователя в комментарии — значит указать имя пользователя при отправке комментария к задаче, чтобы обратить его внимание на этот комментарий. Выбранному пользователю придет оповещение с текстом комментария по почте и в **Уведомления** Трекера (если до этого пользователь открывал интерфейс Трекера). [Как призвать в комментарии](https://yandex.ru/support/tracker/ru/user/comments#call-comment)

Проект

Проект в Трекере — это набор задач, которые направлены на достижение общего результата в определенный срок. У проекта есть дедлайн и ответственный сотрудник. В проект могут входить задачи из разных очередей, поэтому с помощью проектов может быть удобно группировать задачи нескольких команд. [Как управлять проектами](https://yandex.ru/support/tracker/ru/manager/create-project)

# Р

Рабочий процесс

Рабочий процесс — это набор допустимых статусов задачи и правила перехода между статусами. В каждой очереди действуют свои рабочие процессы. [Как настроить рабочий процесс](https://yandex.ru/support/tracker/ru/manager/workflow)

Резолюция

Резолюция — это атрибут задачи, который обозначает результат работы: была ли задача выполнена, отменена или отложена. Например, задача может быть закрыта, потому что она выполнена (резолюция «Решен») или потому что она дублирует другую задачу (резолюция «Дубликат»). [Как настроить резолюции](https://yandex.ru/support/tracker/ru/manager/create-resolution)

# С

Связь

Связь — это ссылка из одной задачи на другую, которая показывает зависимость между этими задачами. Например, если одна задача подчинена другой или выполнение одной задачи зависит от результата другой задачи. [Как изменить связи задачи](https://yandex.ru/support/tracker/ru/user/ticket-links)

Спринт

В гибких методологиях (Agile) спринт — это итерация работы над проектом, обычно длится 1–4 недели. В Трекере можно работать со спринтами на доске задач типа «С бэклогом и спринтами». [Как использовать спринты](https://yandex.ru/support/tracker/ru/manager/create-agile-sprint)

Статус

Статус — это атрибут задачи, который обозначает, на каком этапе находится выполнение задачи. Например: «Открыт», «В работе», «Тестируется», «Закрыт». [Как настроить статусы](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit)

# Т

Тег

Тег — это произвольная метка, которую можно добавить к задаче. С помощью тегов удобно группировать задачи по любому признаку, а затем искать задачи с определенными тегами. Чтобы добавить теги к задаче, отредактируйте параметр **Теги**.

Тип задачи

Задачи в Трекере можно разделить на несколько типов, например: «Новая возможность», «Ошибка», «Улучшение». В очереди для каждого типа задачи можно настроить свой рабочий процесс. [Как настроить типы задач](https://yandex.ru/support/tracker/ru/manager/add-ticket-type)

Токен

Токен — это уникальный ключ, который нужен для доступа к ресурсам API. Токен используется для аутентификации пользователя или приложения, его нужно хранить в секрете.

Триггер

Триггер — это набор действий над задачей, которые запускаются автоматически при выполнении заданных условий. [Как настроить триггер](https://yandex.ru/support/tracker/ru/user/create-trigger)

# Ф

Фильтр

Фильтр в Трекере — это инструмент, который позволяет искать задачи по параметрам. Например, найти все задачи в заданной очереди, у которых вы автор или исполнитель. [Как настроить фильтр задач](https://yandex.ru/support/tracker/ru/user/create-filter)

# Ц

Цель

Цель в Трекере — это сущность, которая описывает результат или желаемый итог работы, к которому стремится команда. С помощью этого инструмента можно отслеживать прогресс выполнения целей и оценивать их ключевые результаты. [Как использовать цели](https://yandex.ru/support/tracker/ru/goals/goals-start)

# Ч

Чеклист

Чеклист — это список дел или этапов работы, в котором можно отмечать выполненные пункты. В Трекере можно добавить чеклист к задаче. [Как создать чеклист](https://yandex.ru/support/tracker/ru/user/checklist)

# Э

Эпик

В [гибких методологиях](https://yandex.ru/support/tracker/ru/glossary#agile) эпик — это крупная функция или требование, которое невозможно реализовать за один [спринт](https://yandex.ru/support/tracker/ru/glossary#sprint-definition). В Трекере есть тип задач Epic, который можно использовать для группировки любых задач с общей темой. [Как использовать эпики](https://yandex.ru/support/tracker/ru/manager/epic)

# Я

Язык запросов

Язык запросов — это формат записи условий для поиска задач в текстовом виде. [Подробнее о языке запросов](https://yandex.ru/support/tracker/ru/user/query-filter)

# A

Agile (Гибкие методологии)

См. [Гибкие методологии (Agile)](https://yandex.ru/support/tracker/ru/glossary#agile).

# S

SLA

SLA в Трекере — это набор правил, который устанавливает временные рамки для обработки задач очереди. Например, вы можете задать время, за которое исполнитель должен отреагировать на новую задачу, ответить на комментарий заказчика или полностью закончить работу над задачей. [Как настроить SLA для задач](https://yandex.ru/support/tracker/ru/sla-head)

Story

User Story («пользовательская история») в гибких методологиях (Agile) — это описание возможности или функции, которую требуется реализовать в продукте. В Трекере есть тип задач Story, который можно использовать для группировки любых задач с общей темой. [Как использовать истории](https://yandex.ru/support/tracker/ru/manager/epic)

Story Point

Story Point — это относительная единица трудоемкости задач. Обычно единица Story Point не эквивалентна какому-то определенному количеству часов. Команда оценивает задачи совместно, сравнивая их с какой-нибудь простой задачей. [Как оценивать задачи](https://yandex.ru/support/tracker/ru/manager/poker#section_estimate)

# Y

Yandex Flavored Markdown (YFM)

Разметка Yandex Flavored Markdown — это правила форматирования текста с помощью специальных символов. Разметку можно использовать, чтобы оформить текст в описании задачи и комментариях. [Как форматировать текст](https://yandex.ru/support/tracker/ru/user/markup)
