Яндекс Трекер — один из [сервисов](https://yandex.ru/support/business/services.html), которые можно подключить к организации Яндекс 360. Администратор организации, который подключил Трекер, также становится [администратором Трекера](https://yandex.ru/support/tracker/ru/role-model#admin).

Для пользователей и групп пользователей в Трекере можно настроить права доступа к отдельным элементам и возможностям сервиса.

- [Глобальный уровень доступа к Трекеру](https://yandex.ru/support/tracker/ru/role-model#global)
- [Права доступа к отдельным элементам структуры Трекера](https://yandex.ru/support/tracker/ru/role-model#elements)
- [Настройки видимости групп](https://yandex.ru/support/tracker/ru/role-model#visibility)

# Глобальный уровень доступа к Трекеру

Уровень доступа пользователя распространяется на всю структуру Трекера. От уровня доступа зависит, какие действия сможет выполнять пользователь: создавать и редактировать задачи, изменять настройки Трекера.

Настроить доступ для пользователей или групп пользователей могут администраторы Трекера и организации Яндекс 360 для бизнеса. Подробнее читайте в разделе [Как настроить доступ к Трекеру](https://yandex.ru/support/tracker/ru/access).

## Администратор

Администратор имеет доступ ко всем элементам структуры Трекера. По умолчанию администратором Трекера назначается пользователь, который создал организацию Яндекс 360 или [подключил](https://yandex.ru/support/tracker/ru/enable-tracker) к ней Трекер.

Чтобы назначить администраторами других сотрудников, используйте [сервис Яндекс 360](https://admin.yandex.ru/).

Действия, доступные администратору:

- Управление пользователями Трекера и [правами доступа](https://yandex.ru/support/tracker/ru/access).
- Управление настройками Трекера: создание новых [статусов](https://yandex.ru/support/tracker/ru/manager/workflow-status-edit#create-status), [резолюций](https://yandex.ru/support/tracker/ru/manager/create-resolution#create-resolution) и [типов задач](https://yandex.ru/support/tracker/ru/manager/add-ticket-type#create-ticket-type), настройка [глобальных полей](https://yandex.ru/support/tracker/ru/user/create-param#global-field) задач, подключение [репозиториев](https://yandex.ru/support/tracker/ru/user/add-repository).
- Управление [настройками очередей](https://yandex.ru/support/tracker/ru/manager/edit-queue-general).

## Пользователь с полным доступом

Пользователи могут использовать все возможности Яндекс Трекера:

- [Создание](https://yandex.ru/support/tracker/ru/user/create-ticket) и [редактирование](https://yandex.ru/support/tracker/ru/user/edit-ticket) задач.
- Поиск задач с помощью [конструктора фильтров](https://yandex.ru/support/tracker/ru/user/create-filter) и [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter).
- Добавление [комментариев](https://yandex.ru/support/tracker/ru/user/comments).
- Создание и настройка [очередей](https://yandex.ru/support/tracker/ru/queue-intro).
    В том числе создание [автодействий](https://yandex.ru/support/tracker/ru/user/create-autoaction), [триггеров](https://yandex.ru/support/tracker/ru/user/create-trigger) и [макросов](https://yandex.ru/support/tracker/ru/manager/create-macroses) в очереди.
- Работа с [досками задач](https://yandex.ru/support/tracker/ru/manager/agile-issues) и [дашбордами](https://yandex.ru/support/tracker/ru/user/dashboard).
- Настройка [интерфейса](https://yandex.ru/support/tracker/ru/user/personal) и [уведомлений](https://yandex.ru/support/tracker/ru/user/notifications).

## Пользователь с доступом Чтение

Режим Чтение устанавливается по умолчанию для тех сотрудников организации, для которых [не подключен сервис Трекер](https://yandex.ru/support/tracker/ru/pricing#addon). Если [администратор](https://yandex.ru/support/tracker/ru/role-model#admin) имеет доступ к Трекеру в режиме Чтение, он может изменить параметры доступа для своей учетной записи самостоятельно.

В режиме Чтение пользователи не могут совершать действия по созданию, изменению и удалению объектов, например:

- создавать задачи с помощью интерфейса Трекера;

- изменять параметры задач, их статусы и резолюции;

- комментировать задачи;

- подписываться на изменения задач.

При этом пользователям доступны все возможности Трекера, связанные с просмотром задач:

- просматривать задачи, [дашборды](https://yandex.ru/support/tracker/ru/user/dashboard) и [доски задач](https://yandex.ru/support/tracker/ru/manager/agile);

- искать задачи с помощью [конструктора фильтров](https://yandex.ru/support/tracker/ru/user/create-filter) и [языка запросов](https://yandex.ru/support/tracker/ru/user/query-filter);

- просматривать [страницы очередей](https://yandex.ru/support/tracker/ru/manager/quick-filters).

- настраивать [интерфейс сервиса](https://yandex.ru/support/tracker/ru/user/personal) и [уведомления](https://yandex.ru/support/tracker/ru/user/notifications).

# Права доступа к отдельным элементам структуры Трекера

- Задачи *очереди*. Права на создание, просмотр и редактирование задач может настроить владелец очереди или другой пользователь, которому владелец разрешил изменять настройки очереди.

    Доступ к задачам очереди можно настроить для отдельных пользователей, групп и ролей:

  - **Доступ** — пользователи, перечисленные в поле **Доступ** задачи;
  - **Наблюдатель** — пользователи, подписавшиеся на задачу;
  - **Автор** — автор задачи;
  - **Исполнитель** — исполнитель задачи;
  - **Владелец очереди**;
  - **Участник команды очереди** — пользователи, добавленные в [команду очереди](https://yandex.ru/support/tracker/ru/manager/queue-team).

    Чтобы ограничить доступ пользователей к определенным задачам внутри очереди, можно использовать компоненты.

    Как настроить доступ к очереди, читайте в разделе [Как настроить права доступа в очереди](https://yandex.ru/support/tracker/ru/manager/queue-access).

- Права для доступа к сущностям и элементам Трекера может настроить их владелец или другой пользователь, которому владелец выдал разрешения. Как настроить доступ, читайте в разделах:

  - [Проекты](https://yandex.ru/support/tracker/ru/manager/project-access)
  - [Портфели](https://yandex.ru/support/tracker/ru/manager/portfolio-access)
  - [Цели](https://yandex.ru/support/tracker/ru/goals/goal-access)
  - [Доски задач](https://yandex.ru/support/tracker/ru/manager/agile-access)
  - [Дашборды](https://yandex.ru/support/tracker/ru/user/share-dashboard#access)
  - [Фильтры задач](https://yandex.ru/support/tracker/ru/user/create-filter#nastroit-dostup-k-filtru)
  - [Шаблоны задач и комментариев](https://yandex.ru/support/tracker/ru/user/share-template)

# Доступ к API Трекера

Для доступа к API Яндекс Трекера требуется авторизация по протоколу OAuth 2.0 или с помощью IAM-токена. [Как получить доступ к API](https://yandex.ru/support/tracker/ru/api-ref/access)

При работе с API Яндекс Трекера запросы приложений выполняются от имени пользователя Трекера. Чтобы выполнять те или иные действия через API, пользователь, от имени которого выполняется запрос, должен иметь соответствующие права в Трекере.

# Настройки видимости групп

[Администратор](https://yandex.ru/support/tracker/ru/role-model#admin) может разрешить или ограничить для пользователей Трекера доступ к данным участников определенной группы пользователей, таким как логин, электронная почта и должность. Подробнее читайте в разделе [Настроить видимость для групп пользователей](https://yandex.ru/support/tracker/ru/access#visibility).
